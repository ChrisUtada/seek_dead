## 已知限制

- 归档文档内部的 `docs/xxx.md` 绝对路径引用可能失效；需要时按文件名在本目录下检索。
- 少数早期文档引用了 `docs/[已完成]xxx.md` / `docs/[已过时]xxx.md`，这些文件在 2026-11-26 之前就已被删除，属既有失效引用，非本次归档造成。
- 归档只移动文件，不修改内容（`docs/` 根目录下的基线索引已同步更新到新路径）。

## 新增归档时

