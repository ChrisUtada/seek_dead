### R1 · P1 全局空格与章节头冲突（玩家可感知）

`duel_controller.gd:2227` 的全局 `_input` 无差别处理 `KEY_SPACE`：

```gdscript
	if event is InputEventKey and event.pressed and not event.echo and event.keycode == KEY_SPACE:
		if reel_system.spinning: reel_system.stop_next_reel()
		else: _on_spin_pressed()
```

`turn_flow.on_spin_pressed()` 的守卫是 `in_loadout / in_interroom / game_state != PLAYING / _busy`。**ACT1 开局四项全部为假**（`_start_room(0)` 后 `game_state=PLAYING`、`in_interroom=false`、`_busy=false`），所以玩家在章节头上按空格"跳过"时：`_input` 先开转，`_unhandled_input` 再关屏 —— 一屏没读完，第一把已经转起来了；这也违反 `chapter_intro.gd` 自己写的"不改战斗状态、不消耗 RNG"。

修法（`duel_controller.gd` `_input()`，`in_loadout` 判断之后）：

```gdscript
	if _chapter_intro != null and _chapter_intro.visible:
		return   # M-02b：章节头期间吞掉全局快捷键（空格/回车/F8），避免隔着屏开转
```

修完第一个空格只关屏、不开转；第二个空格才 SPIN。补一条用例（放在 `m02b_chapter_flow_test` 开头，此时 ACT1 章节头正好可见）：

```gdscript
	var ev_space := InputEventKey.new()
	ev_space.pressed = true
	ev_space.keycode = KEY_SPACE
	_duel._input(ev_space)
	_check(not _duel.reel_system.spinning, "章节头可见时空格不开转")
```
