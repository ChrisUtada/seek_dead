# Seek Dead · 移除玩家等级（LV）的替代方案（2026-11-19）

> 前置：`docs/玩家等级成长现状整理_2026-11-19.md`（诊断等级为何没用）
> 用户决策：**去掉等级**；技艺并入现有三选一奖励池；不做 HP 补偿。
> 本文：行业经典做法调研 + 具体落地方案 + 改动清单。

---

## 1. 行业经典做法（为什么去掉等级是对的）

### 1.1 三种主流"局内成长"范式

| 范式 | 代表 | 做法 | 等级角色 |
|---|---|---|---|
| **无等级，卡牌+遗物驱动** | 杀戮尖塔、Balatro、Inscryption | 战后三选一拿卡，遗物提供被动；构筑即角色 | **完全没有角色等级** |
| **有等级，且等级=强度主轴** | 吸血鬼幸存者、Risk of Rain 2 | 局内升级直接给攻击/射速/叠乘区 | 等级是核心，每级质变 |
| **无局内等级，靠 meta 解锁** | 哈迪斯（镜中之夜）、死亡细胞 | 跨局积累永久升级，单局内不升级 | 单局无等级 |

核心洞察：**等级要么像范式二那样是真正的强度主轴（每级质变），要么像范式一那样干脆没有**。
最糟的是本项目现在这种——"有等级但不碰强度主轴"，沦为鸡肋刻度。

### 1.2 杀戮尖塔的关键设计（最适合本项目参考）

- **没有角色等级**。变强完全靠：战后卡牌三选一 + 遗物 + 药水。
- **meta 只解锁"内容"不加"属性"**：新卡、新遗物、新角色、升华难度——从不加起始 HP/伤害/能量。
  行业术语叫 **"Meta as variety, not power"**（解锁多样性，不解锁强度）。
- 设计理由（Mega Crit 访谈意译）：*不想让 meta 变强，因为那会掏空单局的意义*。

本项目已经有**武器熟练/铭印、攻击研磨、幕间锻魂、遗物、牌谱、三选一**——成长系统比多数 roguelite 都丰富，等级确实是多余的一层。

## 2. 本项目现状（改动前）

| 项 | 现状 |
|---|---|
| 等级上限 | Lv.6 |
| 经验来源 | 普通战1/精英2/BOSS3；非战斗节点不给 |
| 每级收益 | 最大 HP +5（满级 +25） |
| 等级附带 | Lv.2/4/6 各一次技艺三选一 |
| 攻击成长 | **与等级完全无关**（武器/研磨/锻魂/护符） |
| 技艺机制 | 升级时 `pending_picks>0` → Draft 引擎注入技艺卡进三选一 |

**关键发现**：技艺**已经通过 Draft 引擎进三选一池了**（`reward_system.gd:340-369`，`_make_perk_def()`），
只是被 `pending_picks > 0` 门控。所以"技艺并入三选一"的改动比想象小得多。

## 3. 目标方案（改动后）

### 3.1 核心变化

```
改动前：房间胜利 → 加经验 → 升级 → +5HP + 技艺三选一(pending_picks++)
改动后：房间胜利 → 直接走战后三选一（技艺作为常驻候选之一）→ 无等级
```

- ❌ 删除：等级、经验、升级、每级 +5HP、Lv.2/4/6 触发点
- ✅ 保留：8 项技艺（改为常驻进三选一池）
- ✅ 保留：所有其他成长（武器/研磨/锻魂/遗物/牌谱）
- ❌ 不做 HP 补偿（+25 本就无存在感）

### 3.2 技艺如何"常驻进池"（两种实现）

技艺已经能通过 `_make_perk_def()` 变成 Draft 卡，只需改注入条件：

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 概率注入（推荐）** | 每次战后三选一，按权重（如 15%）注入 1 张技艺卡 | 自然、不挤占其他卡；符合"技艺是可选成长" | 可能整局抽不到某项技艺 |
| B. 每次都注入 | 每次三选一都有 1 张技艺卡 | 技艺必得，选择充分 | 三选一被技艺占掉 1/3，其他成长被稀释 |

推荐 A：技艺作为"偶发的高价值选项"，而非每局固定发放——这也符合"技艺是升级附赠品"的原始定位，只是不再绑等级。

> 具体概率需拍板，建议先用 15% 跑几次实测手感。

## 5. 收益与风险

| 收益 | 说明 |
|---|---|
| 消除鸡肋系统 | 不再有"升级了但没变强"的困惑 |
| 简化成长叙事 | 变强来源清晰：武器/卡牌/遗物/锻魂，都是玩家主动选择的结果 |
| 符合品类惯例 | 与杀戮尖塔等头部作品一致，玩家理解成本低 |
| 三选一更有价值 | 技艺成为三选一的真实选项，而非"升级强制弹窗" |

| 风险 | 缓解 |
|---|---|
| 技艺被抽到太频繁/太少 | 概率可调，先 15% 实测 |
| 前期（Lv.2 本该给技艺）变弱 | 用概率注入 + 首战保底（可加"前 3 房必出 1 次技艺"） |
| 旧存档 level 字段 | 加兼容处理 |
| 相关测试需改 | 见下 |
