# Seek Dead · 转轮凑牌战斗重构：24 种牌型与制作执行方案

> 日期：2026-11-15  
> 状态：**已合并，停止按原 24 种清单继续实施**  
> 文档性质：历史设计背景，不再作为后续制作与验收依据  
> 后续唯一执行版本：`docs/转轮凑牌战斗重构_稀有度牌型整合_完整执行方案_2026-11-15.md`  
> 当前执行口径：**2 武器＋1 技能＋1 护符基础约束；3 公共牌型＋6 武器牌谱＋3 技能术式，共 12 种。**  
> 原操作原则“最后一列停下后直接结算”继续保留；原牌型数量、组件与制作步骤由新方案替换。

---

## 1. 最终结论

战斗从“逐列停轮，主要看单牌攻击和三连”调整为：

```text
读取怪物意图与当前牌谱
→ 逐列目押
→ 可选使用消耗品修正牌面
→ 最后一列停下
→ 单牌、通用牌型、装备连携直接结算
→ 怪物行动
```

本方案不移植完整麻将规则，不加入吃、碰、杠、番种、牌山或四家规则，只保留最适合本项目的部分：

- 三张牌形成一手组合；
- 同族、同源、同元素和固定牌谱带来不同连携；
- 装备决定可用牌谱；
- 转轮带决定抓牌概率；
- 目押与消耗品提供主动修正；
- 怪物通过锁列、废铁和节奏压力影响凑牌。

### 设计铁律

1. 单牌永远有效，没凑成牌型也能正常战斗。
2. 最后一列停下后直接结算，不弹换牌窗口。
3. 基础规则不提供每轮免费换牌。
4. 重转和连携补牌都是消耗品主动行为。
5. 通用牌型少而稳定，丰富度主要由装备牌谱提供。
6. 牌型效果必须有不同战术用途，不能全部只是伤害倍率。
7. 百分比收益不做无约束递归乘算，额外结算不再次触发自身。
8. 任何牌型都不能成为击败特定 BOSS 的唯一通行证。

## 2. 牌型总量与发布范围

完整内容共 **24 种**：

- **4 种通用牌型**：G01–G04。
- **20 种装备牌谱**：S01–S20。

制作顺序不是一次放出全部内容：

- 首发验证版：G01–G03 + S01–S06，共 9 种。
- 第一批扩展：加入 G04 + S07–S12，累计 16 种。
- 完整版本：加入 S13–S20，累计 24 种。

单局通常只解锁 3–6 条装备牌谱；单场战斗重点关注 1–3 条。牌谱总量用于构筑探索，不要求玩家同时记忆全部内容。

## 3. 基础术语与统一判定

### 3.1 有效牌

最终三格中，只有正常参与结算的符号是有效牌：

- 被冻结、失效的列不计入；
- MISS、废铁不作为有效组件；
- 金币、增益、治疗、护盾和状态牌可以按牌谱要求参与；
- `none` 可以参与无属性牌谱，但不能充当其他元素；
- 连携补牌不属于主转轮有效牌，只能完成指定装备牌谱。

### 3.2 来源、同族与元素

- **来源**：产生该符号的武器或技能实例，沿用现有 `grid_src` 口径。
- **同族**：`符号资源路径＋有效元素` 相同，来源可以不同。
- **同源刻**：同族且三个符号都来自同一来源。
- **清一色**：三个有效牌的有效元素相同，且不是 `none`。
- **任意**：任意有效牌；若写明“任意火／光”等，则必须是对应元素的有效牌。

### 3.3 默认无序

除牌谱特别写明“首张／最后一张”外，组合不检查列顺序：

```text
A｜B｜C
C｜A｜B
B｜C｜A
```

只要组件一致，就视为同一组合。

### 3.4 通用牌型与装备牌谱的叠加

- 四种通用牌型分别判定，每种每回合最多触发一次。
- 同一手牌可以同时触发同源刻、同族刻和清一色。
- 通用牌型的伤害奖励采用加算或固定效果，不互相乘算。
- 每回合最多触发一条装备牌谱。
- 同时满足多条装备牌谱时，按 `priority` 从高到低处理；同优先级按资源 `id` 升序，禁止临时弹窗让玩家选择。
- 连携卷轴已确定的牌谱优先于普通优先级，避免补牌后被另一条牌谱吞掉。

## 4. 四种通用牌型

| ID | 名称 | 固定判定 | 初始效果 | 战术定位 |
|---|---|---|---|---|
| G01 | 同源刻 | 三个同族符号来自同一来源 | 使用来源武器的现有同源三连与原型规则；不额外叠加一层通用倍率 | 武器身份、专精爆发 |
| G02 | 同族刻 | 三个同族符号，来源不限 | 沿用现有同族三连规则；混合来源的标准暴击倍率为 ×1.5 | 稳定直伤、共享符号构筑 |
| G03 | 清一色 | 三个有效牌为同一非 `none` 元素 | 充能 +1；本回合产生的每种状态额外 +1 层；每回合一次 | 元素、状态与充能 |
| G04 | 顺子 | 三个不同符号属于同一 `sequence_id`，分别覆盖 rank 1/2/3；无序、来源不限 | 结算前削减敌人当前护甲 30%；若敌人无甲，改为充能 +1 | 破甲、混合构筑、组件收集 |

### G04 内容规范

- 顺子只定义一条通用规则，具体序列是内容实例，不重复计入 24 种牌型。
- 每个序列必须恰好三条符号，并配置 `sequence_id` 与 `sequence_rank`。
- 首批制作火、冰、毒、光、暗各一条序列，路径在数据资源中明确填写，不使用运行时模糊推断。
- 三条序列必须能在实际卡池中获得，且不能要求同一独占符号出现两次。
- 顺子削甲只执行一次，不与其他削甲效果乘算；同阶段固定削甲采用先加算、后封顶的执行顺序。

## 6. 牌型效果统一约束

为避免 24 种内容破坏结算稳定性，所有牌谱遵守：

1. “追加伤害”只写入本轮累计结果，不重新调用完整符号结算。
2. 追加伤害不重复产生熟练、充能、同源刻或装备连携。
3. “转为穿透”只改变该部分伤害的护甲分配，不先清空护甲再重复计算直伤。
4. 同名百分比加成先加算；不同系统不得通过连续乘区形成指数收益。
5. 固定数值效果只在牌谱成功触发时执行一次。
6. S19 是唯一首发规划中跨回合保留的牌谱状态；最多一层，界面必须常驻显示。
7. 治疗、净化、护盾和金币必须走现有结算通道，不另造重复资源逻辑。
8. 连携效果不能修改共享 `.tres`，只能修改本轮或本局运行时状态。

## 7. 消耗品主动凑牌

### 7.1 现有重转卷轴：保持原作用不变

现有 `reroll_scroll` 继续执行“立刻免费重转一次，不触发敌人回合”的整手重转效果：

- 不改变使用时机、目标、次数和结算方式；
- 不改成单列回转；
- 不删除或迁移现有 `turn_flow.free_spin()` 路径；
- 本次改版只让它与新增牌型自然兼容，最终牌面仍按统一规则结算。

### 7.2 新增回转卷轴：结算前单列回转

新增消耗品 `rewind_scroll`，建议显示名“回转卷轴”，专门承担结算前单列修正：

```text
逐列目押过程中
→ 在最后一列停下前使用
→ 选择一个已停列重新旋转
→ 继续目押
→ 最后一列停下直接结算
```

规则：

- 一次使用消耗一次 charges，只回转一列。
- 其他已停列保持不变。
- 回转从当前巡航速度开始，不重新播放完整起步加速。
- 被怪物锁定、禁止重转或已经失效的列不能作为目标。
- 没有合法目标、尚未进入转轮或已经开始结算时，不消耗次数。
- 回转前不结算攻击、状态、熟练、充能或牌型。
- 同一列回转后仍从本列转轮带抽取，不改变列的概率结构。
- 若存在不同结果，避免立即原样返回刚才的“符号＋来源”；没有不同结果时提示并拒绝消耗。

### 7.3 连携卷轴：自动补成一条装备牌谱

新增消耗品 `link_scroll`，建议显示名“连携卷轴”。

```text
至少两列已经停下
→ 系统找出只差一张即可完成的已解锁装备牌谱
→ 展示可能完成的牌谱范围
→ 使用后随机确定一条
→ 在连携区生成对应补牌
→ 最后一列停下直接结算
```

硬性规则：

1. 至少两张主转轮有效牌已经停下。
2. 只能补当前已解锁、且恰好缺一张的装备牌谱。
3. 不能补 G01–G04 通用牌型。
4. 补牌不占第四格，不造成单牌伤害，不加熟练、充能或状态。
5. 补牌只参与本次被选中的装备牌谱，不参与同源、同族、清一色或顺子。
6. 多个可行牌谱随机抽取，但使用前必须公开可能范围。
7. 没有合法组合时不消耗次数。
8. 每回合最多使用一次连携卷轴，每回合仍最多触发一条装备牌谱。
9. 连携补牌结果在展示后冻结，不能通过重转、回转、重开界面或反复点击重新随机。
10. 连携卷轴是基础强度的主动修正工具，不是通关必需品。

三类消耗品的分工：

| 消耗品 | 决策 | 风险 | 收益 |
|---|---|---|---|
| 重转卷轴（现有） | 整手免费重转 | 新牌面仍可能不理想 | 保持现有整手修正能力 |
| 回转卷轴（新增） | 放弃一列重新目押 | 新结果仍可能不理想 | 保留其他牌，精准修正一列 |
| 连携卷轴（新增） | 用资源补齐最后一张 | 可行牌谱中随机 | 确定完成一条装备连携 |

## 8. 战斗界面与信息节奏

### 8.1 牌谱展示

转轮附近只展示当前已解锁且与当前构筑相关的牌谱：

```text
烈焰共鸣
[火斩] [燃烧] [任意火]
```

随着停轮逐个点亮组件：

- 已获得：正常高亮；
- 未获得：灰色；
- 可连携补牌：显示卷轴可用提示；
- 已完成：短促闪光，不弹窗。

牌谱较多时，主界面优先显示当前最接近完成的 1–3 条，其余放入可展开的牌谱列表；不能隐藏实际触发原因。

### 8.2 直接结算

最后一列停下后：

```text
最后列停止
→ 组合高亮约 0.15–0.25 秒
→ 单牌与连携结果连续结算
→ 怪物行动
```

高亮是演出，不是等待输入的新阶段。玩家可以跳过或加速演出，不影响逻辑结果。

### 8.3 连携反馈

必须明确显示：

```text
连携 · 冰火二重
火斩＋冰霜晶弹＋燃烧
穿透 20% · 燃烧/霜冻 +1
```

使用补牌时显示：

```text
连携卷轴 → 补入「任意火」
仅用于烈焰共鸣
```

玩家始终能够回答：本轮为什么触发、由哪几张组成、具体改变了什么。

## 9. 数据与程序结构建议

### 9.1 牌谱资源化

建议新增 `PatternData`，通用牌型与装备牌谱共享基础字段：

```text
id / name / desc / icon
kind                 universal | equipment
priority
unlock_paths / unlock_tags / unlock_count
match_rule           结构化组件条件
sequence_id（可选）
effect_id
effect_params
assist_allowed       装备牌谱通常为 true，通用牌型为 false
```

匹配条件至少支持：

- 精确符号路径；
- 同族、来源、元素、符号 kind；
- 武器原型与武器类型；
- 物品 `family_tags` 与 `role`；
- 不同来源数量；
- 不同元素数量；
- 指定武器 R 等级；
- `sequence_id + sequence_rank`。

不要在 UI 或 24 个独立 `if` 中分别写判定。使用一个纯匹配器接收最终三格与当前构筑，输出结构化结果。

### 9.2 推荐职责划分

- `PatternMatcher`：纯判定，不写战斗状态。
- `PatternSystem`：装备解锁集、当前牌谱、优先级和补牌候选。
- `CombatSystem`：把匹配结果写入本轮累计器，统一结算。
- `ConsumableSystem`：合法性检查、扣次和调用回转／补牌。
- `ReelSystem`：单列回转、停列状态和直接结算入口。
- `PatternTray`：只读展示当前牌谱、组件和触发原因。

### 9.3 结算顺序

```text
最终三格冻结
→ 读取装备解锁牌谱
→ 判定通用牌型与一条装备牌谱
→ 汇总单牌贡献
→ 应用通用牌型修正
→ 应用装备连携修正
→ 统一结算伤害、护甲、状态、护盾、治疗、金币和充能
→ 检查元素爆发与后续既有流程
→ 怪物行动
```

所有效果先进入本轮累计器，避免在匹配阶段反复调用伤害函数。

## 11. 自动验收清单

### 11.1 每种牌型的通用测试

24 种牌型逐一覆盖：

- 合法组合能触发；
- 缺少任一必要组件不触发；
- 无序排列结果一致；
- 冻结、MISS、废铁不能充当有效组件；
- 同一类型每回合不重复触发；
- 装备解锁条件未满足时不触发；
- 追加效果只执行一次；
- 触发文案与实际效果一致。

### 11.2 重点边界测试

- 同源、同族、清一色同时成立时分别触发一次，伤害不指数相乘。
- 多条装备牌谱同时成立时只执行最高优先级一条。
- 连携补牌不能完成通用牌型，不能产生单牌收益。
- 连携补牌候选在展示后固定，不能重复随机。
- 现有重转卷轴保持整手免费重转，不触发敌人额外回合。
- 新增回转卷轴只回转目标列，不触发敌人额外回合。
- 最后一张主牌停下后不存在等待输入的换牌状态。
- S17 消耗护盾不会超过当前护盾。
- S19 蓄势最多一层，下一轮只强化首个合格伤害符号。
- S20 的追加攻击不再次触发武器大师或其他连携。
- 运行时牌谱不修改共享武器、符号或消耗品资源。

### 11.3 体验节奏的量化目标

以下用于固定种子模拟与数据调参，不作为虚假的人类体验结论：

- 普通构筑平均每 2–3 回合形成一次有实际价值的牌型。
- 特化构筑平均 1–2 回合一次，但高级精确牌谱不能每场必发。
- 不使用消耗品时不存在长期空转或无法清普通房的 Build。
- 同一轮通常只有 0–2 条值得关注的装备牌谱接近完成。
- 不使用消耗品时的操作步骤不高于现有停轮流程。
- 消耗品演出可加速，不增加强制确认点击。
