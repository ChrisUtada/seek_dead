# Seek Dead 全局跑局验证报告：完美流程 / 全收集 / 难度曲线 / 机制使用率

**日期**：2026-11-19
**方法**：headless 自动化探针 `tools/full_run_probe.gd`，`Engine.time_scale=40` 加速演出，
完美目押模拟（直接把转轮光标设到目标符号 index 后 lock，命中率 100%），关闭 demo 跑完整三幕。
**样本**：6 个固定种子（111 / 333 / 555 / 777 / 999 / 1234），tactical 策略。
**附加**：1 个 DoT 专项种子（火+光 DoT 武器，强制停 DoT 符号）验证 DoT 流派机制。

## 2. 难度曲线

### 2.1 每房平均回合数（6 种子聚合）

| 房间序号 | 平均回合 | 观察 |
|---|---|---|
| 1-4 | 1.2 → 2.0 | 前段秒杀，几乎无威胁 |
| 5-8 | 2.2 → 4.7 | 缓步爬升，第 8 房波动大（1-12 回合） |
| 9-12 | 3.4 → 3.8 | 中段平稳 |
| 13-16 | 2.0 → 5.0 | 后段抬升 |
| 17-24 | 4.5 → 16.0 | **末段陡增**，第 23 房平均 16 回合（10-22） |

### 2.2 按幕聚合

| 幕 | 平均回合/房 | 平均 HP 变化/房 |
|---|---|---|
| ACT1 | 2.3 | +3.5 |
| ACT2 | 3.6 | +9.9 |
| ACT3 | 5.4 | +13.4 |

**反直觉发现**：平均 HP 变化全为正——玩家在绝大多数房间是**净回血**的。
死亡不是被慢慢磨死，而是 **BOSS 房的单次爆发**（如 seed 111 深渊监视者房：135 HP → -22，
3 回合内被打出 157 伤害）。所以"难度"体现为少数几个尖峰，不是平滑曲线。

这与 L3 P2 压平 ante 的目标一致（前期不再有强度墙），但也意味着：**后续难度调节重点应放在
BOSS 爆发伤害与玩家应对手段的匹配，而不是普通怪的幕内爬升**。

### 4.2 闲置 / 极少使用 ⚠️

| 机制 | 数据 | 原因 |
|---|---|---|
| **DoT（burn/poison/圣灼/蚀影）** | 常规策略 **0 次** | 探针总停"最高权重伤害符号"（`_default_target` 只认 kind=damage），DoT 符号（kind=status）从不入选 |
| **DoT 爆发（6.2/6.3 核心）** | 常规 0；专项 2 次（燃 13 层 → 468 伤害） | 同上；机制本身成立，但常规路径碰不到 |
| **遗物爆发联动（6.3）** | 遗物拿到 1-2 个，但 DoT 不用→联动失效 | 依赖 DoT 被使用 |
| 攻击/净化消耗品 | 0（仅 heal 7 次） | 探针策略只用治疗，非游戏缺陷 |
| 符文重抽 / 输入缓冲 / 敌人强制停 | 0 / 0 / 0 | 探针未触发；真人可用 |
| 图鉴收集 | 武器 30-35/90、技能 4/42 | 单局无法全收集（设计如此，跨局累积） |

**DoT 专项验证**：用火+光 DoT 武器 + 强制停 DoT 符号时，`dot_burn=14`、`dot_holy_burn=11`，
且触发"燃 13 层爆发 468 伤害"。**证明 6.2/6.3 的 DoT 系统、四元素状态、遗物联动都是活的，
问题在于玩家默认不会把它纳入构筑**——这是引导/可见性问题，不是机制失效。

## 5. 探针局限（重要，避免误读）

本报告数据来自"完美目押 + 单一目标符号"探针，与真人最优玩家有差距：

1. **构筑选择弱**：战后成长卡由 `auto_pick` 随机选，未做最优构筑规划；
2. **单一目标符号**：探针每回合都停同一个最高权重伤害符号，不会根据局面切 DoT/盾/治疗——
   这正是 DoT 使用率 0 的直接原因，**不能解读为"游戏里 DoT 用不到"**；
3. **消耗品保守**：只用治疗 + 净化，没用攻击类消耗品，低估了输出；
4. **0/6 通关 ≠ 游戏不可通关**：真人玩家会针对性选构筑、用攻击消耗品、换强武器，
   探针未模拟这些。0/6 更准确的含义是"**无脑单一输出符号 + 完美目押仍不足以通关**"。

## 6. 结论与建议

1. **难度曲线**：前期过于宽松（平均小幅回血），后期 BOSS 爆发陡增。P2 压平 ante 已解决"强度墙"，
   但"BOSS 一击秒杀"成为新的尖峰。建议后续关注 BOSS 爆发伤害与玩家应对窗口的匹配。
2. **卡点**：分散在 ACT1-ACT3 的多个 BOSS，玩家容易因构筑不足在任意点崩盘。
3. **DoT 流派**：机制完整且能爆发（专项验证），但**常规玩法几乎不会触发**——
   建议增加引导（如首把 DoT 武器时提示、DoT 符号在转轮中更醒目、或把 DoT 符号纳入默认目标候选），
   否则 6.2/6.3 的大量内容投入会"做了但玩家碰不到"。
4. **6.1 意图系统**：全类型意图都出现，heavy 高频（85 次），重击预警有实际用武之地。
5. **全收集**：单局无法完成（设计如此），需跨局累积；本次探针未模拟跨局元进度。
