## 0. 通用代码事实（理解各武器机制的公共前提）

- **符号有效元素继承**（`reel_system.gd:970-979`）：special 优先取 `reel_element`；其余符号自身 `element != none` 用自身，否则继承武器 `element`。这是暮光手斧（武器底色 none + 符号自描述 dark/light）能保留双元素的代码根据。
- **格数换算**（`reel_system.gd:393-394`）：`cells_for(w)=clampi(round(w),1,8)`，权重 3→3 格、5→5 格、6→6 格。
- **签名生效链**（`pattern_system.gd:104-154` 的 `find_signature`）：基础牌谱命中 + 携带 key_paths 专属武器 + 签名 match_rule 满足，三者齐备才生效。**隐藏前置**：W02 需 `element:ice` 标签×2（即 2 把冰武器），W05 需 `element:dark`×2（2 把暗武器）——单带一把旗舰时签名层不会被查询。
- **回路构筑层判定**（`circuit_system.gd:191-298`）：三连=符号族≥3格；状态=有 status 符号；破甲=有 pierce 或 HEAVY 符号族≥3格；对子=≥2 个 damage 符号族；异色=≥3 种有效元素；攻守=同时有 damage 与 shield/heal。
- **铸式系统**（`forge_style_system.gd:26-75`）仅支持 fire_sword/dagger/battle_axe/ice_staff 四把，**六把目标武器全部不在其中**；本轮深化不涉及铸式，如需纳入另立专项。

## 1. 集中 = 绝对零度 `absolute_zero.tres`

### 1.1 核心玩法与操作目标
极端偏重单一伤害符号（ice_crystal 权重 5=5 格）的集中构筑。操作目标：追求 ice_crystal 三连爆发，靠霜 frost 挂状态叠加伤害；放弃多元素覆盖与坏落点恢复，换取高单符号三连率与爆发上限。

### 1.2 当前符号结构与基础数值
| 符号 | kind | element | status_type | 权重 |
|---|---|---|---|---|
| 霜 frost | status | ice | frost | 1.0 |
| 冰霜晶弹 ice_crystal | damage | ice | — | 5.0 |

BP 16 / 命中 0.91 / 暴击 0.12×2.5 / archetype MAGIC / 远程 / element=ice / role=damage / unique_group=`weapon_ice_frost_line` / act 2–3 / source normal+elite+shop+anvil+chest+boss。

### 1.3 优势与明确代价
- 优势：ice_crystal 5 格为冰系组内地标，三连率与单符号爆发鲜明；signature `SIG_W02_ZERO` 提供 frost_extra+3、threshold 4、enemy_atk_mult 0.7（霜封+削敌攻）。
- 代价：仅 1 个 damage 族 → 构筑层报告"对子不可达"（**但真实结算下 ice_crystal 对子+frost 状态可能触发，见 §10.2，待验证**）；仅 ice 一种有效元素 → 异色协奏不可达；frost 权重仅 1 → 霜冻浓度低、控制弱；无 pierce 且 MAGIC≠HEAVY → 破甲余波不可达；**精度 0.91 并非低命中**，真实代价是单元素、低霜冻浓度与坏落点缺少恢复手段（不写"低命中"）。

### 1.4 适合 / 不适合的敌人
- 适合：冰系弱点敌人、可被霜冻削攻的高攻敌人、需要集中爆发的精英/Boss。
- 不适合：多元素弱点敌人（无覆盖）、需要破甲的护甲墙（无 pierce）、对子/异色机制敌人。

### 1.5 替换关系
同组 `weapon_ice_frost_line`：`blizzard_staff`(frost4+crystal3)、`ice_staff`(crystal4+frost3)、`frost_wand`(frost4+crystal2)。它可替换这些武器的"ice_crystal 集中输出位"；数值上这些武器可替换它，但 `SIG_W02_ZERO` 签名独占、机制层不可替换。

### 1.6 关联牌谱 / 回路 / 技能 / 护符
- 牌谱：签名 `SIG_W02_ZERO`（epic，base W02）、基础 `W02 霜封连携`、可参与 `SIG02 冰火二重`（需冰+火各一）。
- 回路可达（**构筑层报告**）：**三连回响 ✓、状态反应 ✓**；破甲/异色/攻守 ✗。对子报告 ✗，但真实结算可能可触发（§10.2）。
- 技能：chill（寒触）、frost_shard（霜裂）、glacier_spear（霜棘）。
- 护符：frost_core_relic（伤害符号+6）、status_charm（状态×1.5）、cinder_heart（×2.0）、element_charm（克制+0.2）。

### 1.7 是否调整数值 / 结构及理由
**建议本轮不调整。** 两处文案/代码偏差需在卡面澄清而非改数值：① mechanism_summary 宣称"同源三连 35% 穿透"无代码落点（triple_pierce=false，MAGIC 三连只加 charge_points），应改为"三连充能+1、状态+1"的真实表述；② 保持 ice_crystal 5 格的集中身份，不为了覆盖而加符号。若评审要强化集中，优先提升 signature 的 frost_seal 收益，而不是加第二伤害族（会稀释集中身份）。

### 1.8 可自动验证的验收指标（首轮为观察线，非硬合格线）
- ice_crystal 落线三连率、单 SPIN 峰值输出（先报中位数与波动，阈值回评审锁定；"≥1.15 倍""排名前 2"为**观察线**）；
- frost 平均层数 < 冰霜枪，验证"集中≠状态控制"分工；
- 异色协奏/破甲余波在单武器构筑下不可达（结构性硬约束）；
- 对子赔付在构筑层报告不可达，但真实结算可能可触发（§10.2）——**观察项，不作最终验收**。

## 2. 状态控制 = 冰霜枪 `ice_gun.tres`

### 2.1 核心玩法与操作目标
全表最高状态符号权重（frost 5）+ 高命中 0.95 的稳定挂状态构筑。操作目标：快速叠霜冻到阈值触发 signature 的低门槛 frost_seal（threshold 3、enemy_atk_mult 0.85），**通过高频霜冻、削攻和稳定冰伤取胜**，不是 DoT 路线。
> **评审修正（2026-11-21）**：`resources/statuses/frost.tres` 的 `base=0`，霜冻只提供**减攻**、不造成持续伤害。本武器定位为**状态控制旗舰**；"DoT 输出路线"未被本轮验证，单列为覆盖缺口（见 §10.1）。

### 2.2 当前符号结构与基础数值
| 符号 | kind | element | 权重 |
|---|---|---|---|
| 霜 frost | status | ice | 5.0 |
| 冰弹 ice_shot | damage | none→继承ice | 3.0 |

BP 11 / 命中 0.95 / 暴击 0.05×2.0 / archetype LIGHT / 远程 / 可双持 / element=ice / role=damage / unique_group=`weapon_ice_frost_line` / act 1–3。

> ⚠️ `status_effect_type=2` 是零消费遗留字段（全代码仅 `weapon_data.gd:24` 声明），真实状态靠 frost 符号 kind=status，不影响玩法。

### 2.3 优势与明确代价
- 优势：frost 5 格全表最高状态权重 + 0.95 命中 → 状态施加最稳定；signature 阈值降到 3 层、enemy_atk_mult 0.85，更早削敌攻。
- 代价：ice_shot 仅 3 格，直接伤害峰值低于绝对零度；单 damage 族 → 构筑层报告"对子不可达"（**但真实结算下 ice_crystal 对子+frost 状态可能触发，见 §10.2，待验证**）；单元素 → 异色不可达；无 pierce → 破甲不可达；**削攻收益依赖霜冻覆盖率**，断档则控制价值下降。

### 2.4 适合 / 不适合的敌人
- 适合：高攻需削攻的敌人、可被霜冻控制的敌人、冰系弱点敌人。
- 不适合：短战斗（控制尚未兑现）、状态免疫/高层数门槛敌人、需要爆发秒杀的场景、DoT 输出需求（本武器不提供持续伤害）。

### 2.5 替换关系
同组 frost 权重次高：blizzard_staff(4)、frost_wand(4)、ice_staff(3)、frost_blade(3)、rime_saber(3)。它可替换"高频霜冻+高命中位"；这些武器状态权重接近但 signature 阈值不同（ice_gun 阈值 3 更早），机制层不完全等价。`icicle_dart`(hit 0.95) 是命中替代但走 damage 而非 status。

### 2.6 关联牌谱 / 回路 / 技能 / 护符
- 牌谱：签名 `SIG_W02_ICEGUN`（rare，base W02，threshold 3 / ×0.85）；基础 W02。
- 回路可达（**构筑层报告**）：**三连回响 ✓、状态反应 ✓**；破甲/异色/攻守 ✗。对子报告 ✗，但真实结算可能可触发（§10.2）。
- 技能：chill、frost_shard、glacier_spear。
- 护符：status_charm、cinder_heart、spore_heart(×1.8)、venom_gland_relic(挂层+1)、frost_core_relic。

### 2.7 是否调整数值 / 结构及理由
**建议本轮不调整。** 保持 frost 5 格与 0.95 命中作为状态控制身份；不增加第二 damage 族（会稀释控制构筑）。若实测显示削攻收益不足，优先调 signature 的 enemy_atk_mult 或 frost_extra，不改符号结构。status_effect_type=2 仅登记为遗留字段——本阶段不清字段、不改机制。

### 2.8 可自动验证的验收指标（首轮为观察线，非硬合格线）
- **平均霜冻层数与覆盖率**；
- **霜冻实际减少的敌方攻击 / 承伤**（削攻兑现值）；
- **W02 / 签名 frost_seal 削攻触发率**；
- **直接冰伤与生存收益之间的交换**；
- **短战斗中控制尚未兑现时的劣势**；
- 直接冰伤峰值 < 绝对零度（验证状态控制与集中分工）；
- **已删除**："DoT 伤害占比 ≥ 35%"——frost base=0 不造成持续伤害，该指标不可能成立。DoT 输出路线单列为覆盖缺口（§10.1）。

## 3. 破甲 = 蚀日之刃 `eclipse_blade.tres`

### 3.1 核心玩法与操作目标
**暗系签名破甲 / 高阶处决破甲代表**（`triple_pierce=true` 的武器共 15 把，蚀日并非唯一；其独占点是 epic 签名 SIG_W05_ECLIPSE 的 60% 处决线，为全表最高）。靠 shadow_slash 6 格三连破甲，signature 提供处决线（exec_threshold 0.6、exec_ratio 0.6）。操作目标：用破甲打开高甲敌人的护甲窗口，再用处决链收割；对低甲敌人不应无条件最优。

### 3.2 当前符号结构与基础数值
| 符号 | kind | element | status_type | 权重 |
|---|---|---|---|---|
| 暗斩 shadow_slash | damage | dark | — | 6.0 |
| 蚀影 shadow_blight | status | dark | shadow_blight | 3.5 |

BP 23 / 命中 0.77 / 暴击 0.10×2.5 / **triple_pierce=true** / archetype HEAVY / 近战 / element=dark / role=damage / unique_group=`weapon_dark_pure_triple` / act 2–3。

### 3.3 优势与明确代价
- 优势：triple_pierce 直接提供破甲（circuit_armor_break 可达）；shadow_slash 6 格三连率极高；signature 处决线 60% 全表最高，形成"破甲→处决"完整链。
- 代价：命中 0.77 为六把最低（破甲时机不稳）；单 damage 族 → 构筑层报告"对子不可达"（真实结算下可能可触发，§10.2）；单元素 → 异色不可达；对低甲敌人破甲收益归零，此时 BP 23 高但仅靠数值，不应无条件最优。

### 3.4 适合 / 不适合的敌人
- 适合：高护甲 Boss/精英、可被处决线收割的低血敌人、暗系弱点敌人。
- 不适合：低甲/无甲杂兵（破甲价值归零）、高命中要求的稳定输出场景、需要对子/异色的构筑。

### 3.5 替换关系
同组 `weapon_dark_pure_triple`：`night_scythe`（暗斩5+蚀影3.5，BP23，有 SIG_W05_NIGHT 处决线50%）是直接下位；`dread_greatsword`（暗斩6，BP22，无状态无签名）是纯数值替代。蚀日可替换"暗系单符号破甲成长终点"位。

### 3.6 关联牌谱 / 回路 / 技能 / 护符
- 牌谱：签名 `SIG_W05_ECLIPSE`（epic，base W05，pierce_ratio 0.35 / exec_threshold 0.6 / exec_ratio 0.6）；基础 `W05 暗影处刑`（需 2 把暗武器解锁）。
- 回路可达（**构筑层报告**）：**三连回响 ✓、状态反应 ✓、破甲余波 ✓**；异色/攻守 ✗。对子报告 ✗，但真实结算可能可触发（§10.2）。
- 技能：shadow_bolt、shadow_curse、life_siphon、meteor_judgment（三连破甲）。
- 护符：crush_seal(40%破甲)、pierce_charm(25%)、bone_splinter(15%)、glass_edge(30%)、rage_charm(×1.5)、sharp_charm(×1.10)。

### 3.7 是否调整数值 / 结构及理由
**建议本轮不调整。** 保留 0.77 低命中作为"破甲时机风险"的明确代价，不为了提高稳定而改命中（会破坏代价设计）。若实测显示对低甲敌人仍无条件最优，应审查的是破甲赔付公式（对低甲是否仍给收益），而非改武器数值——这属于 combat_system 层,不是本武器深化范畴。

### 3.8 可自动验证的验收指标（首轮为观察线，非硬合格线）
- 高甲敌人破甲触发率、破甲后 TTK 对照（"≥80%""缩短≥25%"为**观察线**，阈值回评审锁定）；
- **结构性硬约束**：低甲敌人的 TTK 不优于同 BP 无破甲武器（验证非无条件最优）；
- **MISS 格读取真实建带格数**：hit_rate=0.77 只决定 MISS 权重，**不等于所有配装下实际必有 23% 废铁格**；记录真实建带 MISS 格与破甲失败率，不写死 23%；
- signature 处决触发次数与 exec_threshold 0.6 的达成率（观察项）；
- 蚀日非唯一 triple_pierce 武器（15 把中之一），验证其独占价值是 60% 处决签名而非破甲字段本身。

## 4. 防御 = 坚壁钉锤 `mace.tres`（S2-2 改造，全表唯一 shield 武器）

### 4.1 核心玩法与操作目标
全 90 把唯一携带 shield 符号的武器，iron_slash 3 + iron_wall 3 同时提供伤害与护盾，使攻守转换回路可达。操作目标：用护盾换取生存，以低 BP 8 与无破甲兜底为代价，不能形成无代价永续生存。

### 4.2 当前符号结构与基础数值
| 符号 | kind | element | 权重 |
|---|---|---|---|
| 铁斩 iron_slash | damage | none | 3.0 |
| 铁誓 iron_wall | **shield** | none | 3.0（单格护盾 6）|

BP 8 / 命中 0.86 / 暴击 0 / archetype MEDIUM / 近战 / element=none / **role=defense** / family_tags=[shield,combo] / unique_group=`weapon_none_guard_line` / act 1–3。

### 4.3 优势与明确代价
- 优势：唯一单武器同时产 damage+shield → circuit_damage_shield 可达（S2 专项 38/0 已验证）；护盾可抵消承伤。
- 代价：BP 8 为六把最低；iron_wall 占 3 格 → 输出格减少；失去原重武器三连破甲兜底（triple_pierce=false、MEDIUM）；无 signature。

### 4.4 适合 / 不适合的敌人
- 适合：高频攻击敌人（护盾抵消收益高）、需要稳过的高压节点、缺护符时的生存位。
- 不适合：低攻敌人（护盾浪费）、限时爆发场景（输出不足）、需要破甲的护甲墙。

### 4.5 替换关系
`weapon_none_guard_line` 仅此一把，全表唯一 shield 持有者，**无可替换也无替代**——结构性独占。它可替换"`iron_slash×5` 白板簇"中的防御需求位。

### 4.6 关联牌谱 / 回路 / 技能 / 护符
- 牌谱：无专属签名；可参与 W06 无锋磨砺（element:none，需 2 把无元素武器）。
- 回路可达（**构筑层报告**）：**三连回响 ✓、攻守转换 ✓**；状态/破甲/异色 ✗。对子报告 ✗，但真实结算下"铁斩对子+铁誓护盾"可能触发（`_has_pair_damage` 第二符号族不限 damage，护盾亦可，§10.2）——**待真实落点验证，不作既定事实**。
- 技能：guard、iron_wall、aegis、calm、sanctuary、war_banner；T02 防御术式。

### 4.7 是否调整数值 / 结构及理由
