> 目标：全部关系直觉可解释、抗性分布均匀、经典设计背书、改动面最小（ElementCounter 单文件 + HUD 弱/抗显示）。

## 1. 最终矩阵

```
克制 ×1.5（直觉）：
  火 → 冰（融化）、火 → 毒（高温消毒）
  冰 → 火（灭火，与火互克）
  光 → 暗（驱散）、光 → 毒（圣光净化）
  暗 → 光（吞噬，与光互克）
  毒 → 暗（腐蚀幽冥）

抵抗 ×0.85（被克方的还击 + 同元素）：
  同元素对打（火打火 / 冰打冰 / 毒打毒 / 光打光 / 暗打暗）——宝可梦式同属性减伤
  毒 打 火、毒 打 光（被消毒 / 净化）

中性 ×1.0：
  其余无关系组合；任意一方为 none（无属性 / 普通攻击恒中性）
```

## 3. 经典设计依据

| 规则 | 出处 |
|---|---|
| 同元素对打减伤（0.85） | 宝可梦：火打火 / 水打水 = 0.5（同属性抵抗） |
| 互克对（火↔冰、光↔暗） | FFX（火↔冰、雷↔水、风↔土、圣↔暗）、SMT/Persona（火↔冰、光↔暗） |
| 单向补充（毒链：火→毒、光→毒、毒→暗） | 宝可梦单向克制 / Persona 混合结构 |
| 无属性 = 中性基准（普通攻击） | SMT 物理位、FF 物理攻击、宝可梦普通系 |
| 抵抗 = 被克制方的还击吃亏 | 宝可梦抵抗逻辑（草弱火 → 草打火 0.5） |

## 4. 设计意图

- **零反直觉关系**：每个克制都能一句话解释（融化/灭火/消毒/净化/驱散/吞噬/腐蚀）。
- **抗性均匀**：同元素 0.85 让每个元素都有"被打 0.85"的场景（打同元素敌人），不再只有毒承担抗性。
- **温和惩罚**：0.85 而非 0.7；无关系组合保持中性 ×1.0（不为对称硬凑关系）。
- **与既有系统正交**：频率（传统 slots 档位制）、三连暴击（CRIT_CHANCE）、装备共鸣（Synergy）均不受影响。
- **BOSS 解法不变**：Act1 冰→火 1.5、Act2 暗→光/毒 1.5 双解、Act3 光→暗 1.5——已验证。

## 5. 实现要点

- `element_counter.gd`：
  - `BEATS` 改为 元素 -> 被克数组（fire:[ice,poison]、ice:[fire]、poison:[dark]、light:[dark,poison]、dark:[light]）
  - `multiplier()`：同元素 → RESIST；`def in BEATS[atk]` → ADVANTAGE；`atk in BEATS[def]` → RESIST；否则 NEUTRAL
  - `relation()` 新增「同源」档（同元素对打）
  - `weakness(def)` / `resists(def)` 改返回 **Array[String]**（多克制/多抗性）
- `battle_hud._update_enemy_element()`：弱/抗多元素用「·」拼接（如「弱 火·毒 ×1.5」「抗 光·毒·毒 ×0.85」）
- 敌人视角呈现不变：HUD 显示「弱 X」「抗 Y」，玩家无需背表
