# BOSS设计草案

按照经典的地下城奇幻（Dungeon Crawl）**包装，并引入**“阶段递进（Act1 单阶段 → Act2 双阶段 → Act3 三阶段）”**与**“最终 BOSS 投影（随机复刻前 11 个 BOSS 机制）”的重构设计。

这种阶段递进结构非常契合心理学的“病程演变”：

- **Act 1（单阶段）**：单一种类的急性创伤/症状发作，直来直往。

- **Act 2（双阶段）**：情绪与病理开始出现“代偿与转变”（如躁抑交替、执念化），展现出双面性。

- **Act 3（三阶段）**：复杂的复合型创伤，心防层层剥离，呈现出彻底的碎裂与终极抵抗。

在机制上，依然严格遵照【五元素环（火>冰>毒>光>暗>火）】与【转轮/护甲/DoT/干扰】的结算逻辑。

### 第一幕：冰封地牢与沉沦（Act 1：单阶段 · 躯体与情绪的僵局）

*主题：地下城底层的寒冷、发霉、瘫软与被困感。*

#### 1. 冰封铁瓮（The Frozen Maiden）—— 重度抑郁与情感麻木 `固定首领`

- **隐喻**：情感冰封与极度沉重的躯体感，将自己锁在冰冷的铁棺里。

- **阶段**：**【单阶段】**

- **元素 / 弱点**：**冰（Ice）** / 弱 **火（Fire）**

- **机制 Gimmick**：`熔铸冰墙 (rust_armor)`

- **呈现**：每 2 回合自动在身上叠加厚重冰甲（`RoomData.armor`），同时向玩家转轮释放 Frost 状态降低行动效率。

- **克制解法**：火系爆破融化冰甲、破甲直击（`pierce_armor`）突破。

#### 2. 碎裂石像鬼（The Brittle Gargoyle）—— 躯体化障碍与完美假面 `轮替`

- **隐喻**：伪装成坚不可摧的石像，实则内心极度脆弱，一触即碎。

- **阶段**：**【单阶段】**

- **元素 / 弱点**：**冰（Ice）** / 弱 **火（Fire）**

- **机制 Gimmick**：`玻璃大炮 (glass_cannon)`

- **呈现**：护甲极低，但攻击力极高。受击时会向玩家反弹石屑（微量自噬伤害）。

- **克制解法**：护盾防御（*守备/铁壁*）撑过前几回合高攻，随后精准抢杀。

#### 3. 酸蚀恶鬼（The Acidic Ghoul）—— 慢性自责与毒性耻感 `轮替`

- **隐喻**：腐烂在地下城角落吃食垃圾的恶鬼，代表不断反刍的自我否定与内疚。

- **阶段**：**【单阶段】**

- **元素 / 弱点**：**毒（Poison）** / 弱 **光（Light）**

- **机制 Gimmick**：`酸蚀毒性 (status_bomb)`

- **呈现**：单次攻击伤害低，但每回合为玩家叠加高层 Poison/Burn DoT。DoT 达 10 层会引发高额爆炸。

- **克制解法**：净化药剂（Purify）、DoT 护符、光系净化。

#### 4. 茧居石雕（The Cocooned Sentinel）—— 极端回避与社交恐惧 `隐秘`

- **隐喻**：盘踞在地下城密室、用岩石和藤蔓将自己死死封住的守卫。

- **阶段**：**【单阶段】**

- **元素 / 弱点**：**冰（Ice）** / 弱 **火（Fire）**

- **机制 Gimmick**：`封闭壁垒 (shield_heal)`

- **呈现**：不断叠加超厚护盾并自我治疗，同时锁死玩家转轮里的技能符号（Jam）。

- **克制解法**：强穿透符号、破甲护符、强袭药剂。

### 第二幕：狂热迷宫与执念（Act 2：双阶段 · 情绪失控与病理代偿）

*主题：迷宫深处失控的狂热、病态的秩序与刺耳的低语。*

#### 5. 迷宫低语者（The Whispering Priest）—— 焦虑症与灾难化思维 `固定首领`

- **隐喻**：脑海中停不下来的自我怀疑与灾难预测。

- **阶段**：**【双阶段】**

- **元素 / 弱点**：**暗（Dark）** / 弱 **光（Light）**

- **机制 Gimmick**：`灾难低语 (whisper_lock)`

- **P1（焦虑缠身）**：高频释放 Jam/Lock 意图，锁死玩家转轮格。

- **P2（恐慌发作，HP<50% 触发）**：加入 Chaos（混乱转轮符号），且攻击附带暴击。

- **克制解法**：抗扰护符（*抗扰/呓语残页*）、净化药剂、光系武器照亮。

#### 6. 躁怒元素使（The Manic Elementalist）—— 双相情感障碍·躁狂发作 `轮替`

- **隐喻**：无法控制的情绪爆发，从极度狂躁迅速坠入极度抑郁。

- **阶段**：**【双阶段】**

- **元素 / 弱点**：**火（Fire）** / 弱 **冰（Ice）**

- **机制 Gimmick**：`躁抑交替 (bipolar_phase)`

- **P1（躁狂发作）**：攻击力翻倍且每回合额外行动，但每回合扣除自身 5% HP。

- **P2（抑郁僵直，HP<50% 触发）**：变为冰属性，攻击力大幅下降，但防御与护甲大幅提升，进入顽固防御。

- **克制解法**：P1 用冰系冻结/护盾撑过高攻，P2 用火系爆破破甲。

#### 7. 天平审判官（The Inquisitor of Order）—— 强迫症与完美主义 `轮替`

- **隐喻**：对规则的病态偏执，地下城里不允许有一丝不整齐。

- **阶段**：**【双阶段】**

- **元素 / 弱点**：**光（Light）** / 弱 **暗（Dark）**

- **机制 Gimmick**：`律法强迫 (compulsion_rule)`

- **P1（规则宣告）**：强制要求玩家本回合转出特定符号模式（如全同色或无连线），未达成则进行重击。

- **P2（严刑惩戒，HP<50% 触发）**：若未达成规则，会额外锁死玩家一个技能槽或消耗品槽。

- **克制解法**：重转卷轴（Reroll）、暗系打破规则。

#### 8. 无名虚空（The Nameless Void）—— 述情障碍与情感解离 `隐秘`

- **隐喻**：无法感知和表达情绪，将自我隔离在虚无的废墟中。

- **阶段**：**【双阶段】**

- **元素 / 弱点**：**暗（Dark）** / 弱 **光（Light）**

- **机制 Gimmick**：`情感剥离 (emotional_vacuum)`

- **P1（功能剥离）**：使玩家所有“护符”效果暂时失效。

- **P2（全面麻木，HP<50% 触发）**：使玩家“技能”也暂时失效，强制纯数值拉锯。

- **克制解法**：依靠高基础面板（Base Power）武器硬刚，或用光系恢复正念。

### 第三幕：深渊王座与创伤（Act 3：三阶段 · 创伤闪回与终极自我）

*主题：深渊最深处的刺眼创伤、碎裂的人格与直面自我。*

#### 9. 深渊监视者（Abyss Watcher）—— 创伤后应激障碍 (PTSD) `固定首领`

- **隐喻**：过往的噩梦如刺眼的镁光灯，不断侵蚀当下的现实。

- **阶段**：**【三阶段】**

- **元素 / 弱点**：**光（Light）** / 弱 **暗（Dark）**

- **机制 Gimmick**：`创伤侵蚀 (abyss_erosion)`

- **P1（噩梦侵袭）**：注入“废铁/创伤格”到玩家转轮池。转出时浪费回合并受到反噬伤害。

- **P2（闪回暴走，HP<66%）**：每回合强制让玩家转轮“自动重转一次”，打乱预判。

- **P3（深渊吞噬，HP<33%）**：废铁格比例翻倍，且自身获得高额光系伤害加成。

- **克制解法**：暗系武器遮蔽强光、重转/净化卷轴洗掉废铁格。

#### 10. 碎裂魔王（The Shattered King）—— 解离性身份障碍 (DID) `轮替`

- **隐喻**：为了承受痛苦而撕裂成的多重人格碎片。

- **阶段**：**【三阶段】**

- **元素 / 弱点**：**毒（Poison）/ 暗（Dark）** / 弱 **火（Fire）/ 光（Light）**

- **机制 Gimmick**：`人格裂变 (split_ego)`

- **P1（愤怒人格）**：纯火系高攻，附带 Burn。

- **P2（恐惧人格，HP<66%）**：切换为冰系高防，不断叠盾。

- **P3（悲伤人格，HP<33%）**：切换为毒系高控，高频挂毒。

- **克制解法**：根据阶段动态切换对策武器，或用 DoT 跨阶段削血。

#### 11. 耻辱审判官（The Grand Inquisitor）—— 毒性耻感与自我否定 `轮替`

- **隐喻**：内心深处严苛的审判者，记录你所有的失败与缺陷。

- **阶段**：**【三阶段】**

- **元素 / 弱点**：**光（Light）** / 弱 **暗（Dark）**

- **机制 Gimmick**：`罪业清算 (shame_counter)`

- **P1（罪业记录）**：记录玩家本局失误（受击/空转），转化为伤害乘区。

- **P2（拷问心防，HP<66%）**：清空玩家所有护盾，逼迫玩家纯血量承伤。

- **P3（终极审判，HP<33%）**：若玩家血量低于 50%，伤害再翻倍。

- **克制解法**：精确连线减少失误、暗系拉下神坛。

### 12. 最终 BOSS：勇者的阴影（The Hero's Projection / Shadow）`真·最终 BOSS`

- **病理隐喻**：荣格心理学中的“阴影（Shadow）”。它是你在地下城（心理困境）中一路克服的所有恐惧、焦虑、创伤的镜像总和。**它不是要被毁灭的魔王，而是需要被理解与接纳的自己。**

- **阶段**：**【三阶段】**

- **元素 / 弱点**：**混沌/全元素适应（Adaptable）**

#### 机制 Gimmick：`万象投影与自我和解 (all_boss_gimmicks & acceptance)`

- **阶段 1：躯体与焦虑的投影（HP 100% ~ 66%）**

- **表现**：从 Act 1 和 Act 2 的前 8 个 BOSS 机制中，**每 2 回合随机抽选一个技能组合**使用！

    - 例：本回合使用【迷宫低语者】的 `whisper_lock`（锁轮） + 【冰封铁瓮】的 `rust_armor`（加护甲）。

- **玩家体验**：考验玩家对前两幕所有对策机制（破甲、抗扰、净化、冰火克制）的综合应变能力。

- **阶段 2：深渊与创伤的镜像（HP 66% ~ 20%）**

- **表现**：开始加入 Act 3 的强力技能（`abyss_erosion` 注入废铁、`split_ego` 属性切换），同时**镜像复制玩家当前的武器与技能**，玩家用什么，它就用同样的符号还击。

- **玩家体验**：极度高压的镜像对决，逼迫玩家打出极高的连线匹配与资源管理。

- **阶段 3：终极和解（HP < 20% 触发）**

- **机制转变**：BOSS 的所有杀伤性意图完全消失，转轮盘变为纯粹的“光 / 暗 / 心形 / 融合”符号。战场音乐变得舒缓。

- **通关条件（非暴力解法）**：BOSS 不再能被普通伤害击杀（HP 锁在 1 点）。玩家只需在转轮中**达成一次三连匹配（无论任何符号）**，或**使用一次净化药剂/恢复技能**，勇者就会放下手中的武器，走向投影并与自己的阴影拥抱。

- **结语隐喻**：你无需战胜你的心理疾病，你只需要学会与它握手言和，并带着它继续生活。游戏通关。
