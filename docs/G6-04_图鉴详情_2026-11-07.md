## 1. 做了什么

- 新增 `CodexSystem`（`scripts/systems/codex_system.gd`）：装备图鉴的静态详情与跨局统计。
- 铁砧屏底栏新增「📖 图鉴」按钮：分类（武器 / 护符 / 消耗品）、已拥有/全池计数、未拥有占位。
- 详情面板展示：
  - **路线**：武器元素 + 符号组成（名称 + 类别）；护符/消耗品给类别与元素。
  - **机制**：武器攻击/命中/三连倍率与破甲、状态、护盾、回复标记；物品给效果描述与「有代价」。
  - **真实来源**：读 `anvil_meta.item_sources`，格式为 `ACT · 棋盘/线性 · 节点或房型 · 房间名`，最多 3 条。
  - **使用次数**：武器/护符按整备确认次数，消耗品按实际使用次数。
  - **最高熟练**：跨局保留的武器最高 R 等级与点数。
  - **铭印组合**：最高熟练那一局的锋铸次数与调律符号。
- 新增 `anvil_meta.codex`，只加不删；老档缺键补空，已有收藏与来源不动。

**没有改**：战斗数值、成长曲线、奖励、掉落、商店、铁砧池/保底/重复返还、RNG、`balance_config.tres`。

## 2. 存档

```json
"anvil_meta": {
  "codex": {
    "res://resources/weapon_templates/fire_sword.tres": {
      "uses": 3,
      "best_rank": 3,
      "best_mastery": 7,
      "forge": 2,
      "tune": {"res://resources/symbols/burn.tres": 1}
    }
  }
}
```

- 键为装备 `resource_path`；只记录有统计的装备。
- `uses` 统一为「使用次数」：武器/护符 = 带进一局的次数，消耗品 = 实际消耗次数。
- `best_rank` / `best_mastery` 只升不降；`forge` / `tune` 是刷新最高纪录那一局的铭印快照。
- 老档没有 `codex` 键：载入补空字典，所有统计从 0 开始，不回收已拥有内容。
- 写入时机：整备确认（装备计数）、消耗品使用、每次 BOSS 结算、战败结算。中途退出可能丢失未结算的计数。

## 3. 界面

- 入口：铁砧屏底栏最左「📖 图鉴」；不消耗铁砧点数。
- 左侧：`已拥有 N / 全池 M` + 分类列表；已拥有显示名称，未拥有显示「？？？」且不可选。
- 右侧：选中装备的详情行（前缀固定为 类别 / 路线 / 机制 / 来源 / 使用 / 熟练 / 铭印）。
- 480 宽度下为左右两栏（列表 168px + 详情自适应），960 / 1440 下同布局放大。
- 护符/消耗品不伪造熟练与铭印，显示「熟练 / 铭印：不适用」。
