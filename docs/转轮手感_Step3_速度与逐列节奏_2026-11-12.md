## 1. 参数改动

| 参数 | 旧值 | 新值 | 方案区间 |
|---|---|---|---|
| 主滚动速度（control） | 0.15s/格 = **6.7 格/秒** | 1/9s/格 = **9.0 格/秒** | 8–10 |
| 高速封顶（control） | 0.06s/格 = **16.7 格/秒** | 1/12s/格 = **12.0 格/秒** | 10–12 |
| 高速封顶（readable / speed） | 0.085s/格 = 11.8 | 1/11s/格 = **11.0** | 10–12 |
| 加速斜率（control） | 0.0010 / 拍 | **0.0020 / 拍** | — |
| 加速斜率（readable / speed） | 0.0007 / 拍 | **0.0014 / 拍** | — |
| 落地减速吸附 | — | 0.12–0.16s（Step 2） | 0.12–0.16 |
| 逐列基础停顿（自动停轮） | 每拍停一列（约 0.10s） | **0.25s** | 0.22–0.28 |
| 后续列间隔增量 | 0 | **+0.07s**（0.25 / 0.32 / 0.39） | 0.06–0.08 |

说明：

- 加速段约 1.5s 从 9 格/秒升到 12 格/秒；`readable` 最高 11 格/秒，保留「慢化」预设差异。
- 所有预设共享新的巡航速度；`preview / visual / buffer / feedback` 与 control 同速。
- `stable` 技艺的前 2 回合 0.17s/格（5.9 格/秒）保持不变，属于成长效果，不在本轮范围。

## 2. 逐列停轮节奏

- **手动按停不额外加延迟**：点列 / 空格立即提交吸附，保持输入响应；玩家自己的按键间隔就是手动节奏。
- **自动停轮（敌人夺轮 / forced）**改为按方案节奏逐列停下：
  - 第 1 列：旋转开始后 0.25s；
  - 第 2 列：再 0.32s；
  - 第 3 列：再 0.39s；
  - 仍走与手动完全相同的 `stop_next_reel → lock_reel → _begin_absorb` 入口，落点算法一致。
- 实现方式：`on_spin_tick` 按上一拍 `wait_time` 累计 `_auto_stop_left`，到点才提交下一列；不会同一拍连停多列。

## 3. 旋转耗时记录

- `ReelSystem` 新增模型耗时：
  - `_spin_model_seconds`：每次节拍按当前 `wait_time` 累计；
  - `_spin_end_model`：停轮请求时记录「当前时间 + 吸附时长」，多列取最大值；
  - `last_spin_seconds()`：`finish_spin` 时取两者最大值，供探针/测试记录完整旋转（节拍 + 吸附）。
- 既有 `RunTelemetry` 的 `spin_seconds / avg_spin`（真实时间）保留不动，用于实机统计。
- 本轮不新增任何无意义等待：停轮节奏只作用于自动停轮，手动停轮仍是请求即吸附。
