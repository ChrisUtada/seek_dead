## 1. 本轮做了什么

按计划 §8.4「首批只允许宝箱、神龛、武器藏库三类，每幕至多 1 个特殊格，替换一个普通节点」，
本轮先落 **宝箱**：

- 每张棋盘 **恰好 1 个特殊格**（宝箱 / 神龛 / 武器藏库，随机），固定宝箱时即 **1 个宝箱**，
  替换 4 条尾路中随机一条的普通战斗；
- 宝箱节点总数不变（标准 25 / 长尾 29），共享骨架与中段不动；
- 该尾路因此 **少一场战斗、多一个宝箱**：用「少打一仗」换确定收益，是路线选择的一部分；
- 宝箱的类别与具体物品在**生成时冻结**，节点文案只公开类别（武器 / 护符 / 消耗品 / 金币），
  具体物品落地开启时才揭晓；岔路提示会标注哪一侧含宝箱。

## 2. 类别与结算

| 类别 | 生成时冻结 | 落地结算 | 失败 / 满槽兜底 |
|---|---|---|---|
| 武器 | `pick_reward_weapon_path()` 选定 1 把 | 复用武器格流程：空槽入槽、满槽打开替换预览 | 已持有 → 折算金币 +15 |
| 护符 | 获取权重抽 1 件非信物护符 | 复用护符格流程：入槽并立即生效 | 已持有 / 槽满 → 折算金币（卖价） |
| 消耗品 | 获取权重抽 1 件消耗品 | 入腰带（实例化，允许同类重复） | 腰带满 → 折算金币（卖价） |
| 金币 | 池空时的兜底类别 | +15 金币 | — |

掉落/金币数值全部沿用既有规则，没有新增货币、没有额外战斗、没有改战斗数值。

## 3. 生成顺序（在 G4-02 之后）

```text
本局种子
→ 抽骨架（standard / long_tail）
→ 抽分支价值模板
→ 按骨架写节点类型
→ 抽特殊格（宝箱 / 神龛 / 武器藏库）替换一条尾路的普通战斗
  ├─ 宝箱：冻结类别 + 具体物品
  └─ 神龛：冻结效果 + 数值（G4-04 神龛轮追加）
→ 分配剩余战斗 RoomData（同盘不重复）
→ 分配武器格 / 护符格
→ 冻结并展示
```

宝箱节点带有 `treasure_kind` 与 `item_path`，但节点 `desc` 只写类别；
`battle_rooms` 相应少 1 间（标准 15 / 长尾 15 场候选），`ria`、`battle_index` 仍按路径顺序对齐。

## 4. 已知取舍

- **该尾路 7 场战斗**：宝箱顶掉的是普通战斗，走这条尾路的成长经验会少一场；
  这是「用风险/成长换确定装备」的代价，等真人复测确认是否过强或过弱。
- **特殊格是单一槽位**：一局只会出现宝箱 / 神龛 / 武器藏库之一，宝箱不再保证每局出现（4 条尾路随机 1 条）。
- 隐藏房/献祭/复杂随机事件继续暂缓（§8.4）。
- 宝箱不消耗 RNG 以外的状态：悬停、刷新、进出商店不会重掷类别或物品（同种子可复现已断言）。
