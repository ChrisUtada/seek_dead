# 房间全面装配计划

## 一、目标

制作 **25 个可游玩的完整房间**，每个房间一次性包含：

- **墙壁碰撞体**（StaticBody2D 分段 + 门洞）
- **障碍物/掩体**（柱子、箱子堆、书柜、柜台等）
- **视觉地面**（ColorRect 纯色底 + 可选装饰 tile）
- **占位 Marker**（宝箱、商店、陷阱，后面换真实场景）
- **SpawnMarker**（按房间尺寸放入适量）
- **DoorMarker**（每个房间 1~4 个门）

## 二、策略

### 原则

1. **不直接改现有 5 间房**。保留作参考，新建统一模板体系
2. **房间模板驱动**。一个 `room_template.tscn` 定义固定骨架，复制后填内容
3. **按 Size 分类**。Small(5个) / Medium(8个) / Large(8个) / Boss(4个)

### 模板骨架 `room_template.tscn`

```
RoomBase (Node2D)
├── NavigationRegion2D          # 按房间尺寸调整 nav poly
├── Floor (Node2D)              # 视觉层——ColorRect 占位，后期换 TileMapLayer
│   ├── ColorRect               # #2a2a2a 纯色地板，尺寸 = Nav 内框
│   └── DoorGlow (ColorRect)    # #00ff44 半透明，32×16，标记门位置
├── Walls (Node2D)              # 组织容器，collision_layer=4
│   ├── StaticBody2D "TopWall_L" / "TopWall_R"
│   ├── StaticBody2D "BottomWall_L" / "BottomWall_R"
│   ├── StaticBody2D "LeftWall_T" / "LeftWall_B"
│   └── StaticBody2D "RightWall_T" / "RightWall_B"
├── Obstacles (Node2D)          # 组织容器，collision_layer=4
│   ├── StaticBody2D "Pillar_1"     # 柱子
│   ├── StaticBody2D "CrateStack_1" # 箱子堆
│   └── ...
├── Markers (Node2D)            # 组织容器
│   ├── Interactable_Chest    (Marker2D, group="interactable")
│   ├── Interactable_Shop     (Marker2D, group="interactable")
│   ├── Trap_Spikes           (Marker2D, group="interactable")
│   ├── PlayerSpawn           (Marker2D)
│   └── SpawnMarker[1~N]      (Marker2D, group="spawn")
└── Doors (Node2D)
    └── DoorMarker[1~4]       (door_marker.tscn)
```

## 三、三种标准尺寸

| 尺寸 | Nav 内框 | 外框（外扩 16px） | 最小 | 最大门数 | 房间数 |
|------|----------|-------------------|------|---------|--------|
| Small | 256×256 ~ 416×384 | 288×288 ~ 448×416 | 5 | 1 | 5 |
| Medium | 448×320 ~ 576×480 | 480×352 ~ 608×512 | 5 | 2 | 8 |
| Large | 640×432 ~ 800×544 | 672×464 ~ 832×576 | 5~8 | 3 | 8 |
| Boss | 640×448 ~ 960×576 | 672×480 ~ 992×608 | 8~12 | 1~2 | 4 |

- Small 房间数 ≤ 2 门（1入1出），Large/Boss 可 3~4 门

## 四、每间房的制作流程

### Step 1：从模板复制

`room_template.tscn` → `room_xx.tscn`，调整 NavigationRegion2D 多边形到目标尺寸。

### Step 2：墙壁分段

**规则**：外框内边距 16px = 墙厚。DoorMarker 位置留 32px 门洞。

```
房间外框 W×H，墙厚 T=16，门洞宽 D=32

顶边分段：
  - gaps: [(door_i.x - 16, door_i.y)]  for door_i on top edge
  - 按 x 排序，切成连续段
底边、左边、右边同理
```

### Step 3：视觉地面（ColorRect 占位版）

- 每个房间加一个 `ColorRect` 作为地板，尺寸 = Nav 内框，颜色 `#2a2a2a`
- 装饰 Sprite2D：无（等美术素材）
- 每个 DoorMarker 对应位置加 `ColorRect` 半透明绿块（`#00ff44` alpha 0.3，32×16），标记入口方向

### Step 4：美术素材替换方案（未来）

ColorRect 占位方案设计为**可原地替换**，结构对照：

| 当前（占位期） | 未来（美术期） | 替换方式 |
|----------------|---------------|----------|
| `Floor/ColorRect`（`#2a2a2a`） | `Floor/TileMapLayer`（贴图铺地） | 删 ColorRect，加 TileMapLayer，贴图对齐 Nav 外框 |
| `Floor/DoorGlow`（色块） | 无，门洞由 TileMap 缺口自然可见 | 删 DoorGlow |
| 墙壁 `CollisionShape2D`（线框） | 保持不变 | **不改**——碰撞体独立，TileMap 墙贴图对齐碰撞体位置即可 |
| 障碍物 `StaticBody2D` + `ColorRect` | `StaticBody2D` + `Sprite2D` | 删 ColorRect，加 Sprite2D，纹理对齐碰撞体 |
| 无 TileSet physics layer | 仍不加 | TileSet 只做视觉，碰撞永远靠 StaticBody2D |

**替换流程**（每间房 2 分钟）：
1. 展开 `Floor` 节点
2. 删 `ColorRect`（地板）和 `DoorGlow`
3. 加 `TileMapLayer`，选对应 tileset，铺地面和墙贴图
4. 展开 `Obstacles` 下每个障碍物
5. 删 `ColorRect`，加 `Sprite2D`，纹理对齐碰撞体
6. 目测对齐，保存

**关键规则**：永远不修改 `Walls`/`Obstacles` 中的 `StaticBody2D` + `CollisionShape2D`，它们是碰撞系统的唯一真实来源。

### Step 5：障碍物/掩体

每间房放入 2~6 个障碍物（取决于房间尺寸），规则：

| 类型 | 碰撞形状 | 碰撞层 | 用途 |
|------|---------|--------|------|
| 柱子 (Pillar) | Rectangle(24×24) | ENV | 遮挡射击线 |
| 箱子堆 (Crate) | Rectangle(32×32) | ENV | 半高掩体 |
| 书柜 (Bookshelf) | Rectangle(16×64) | ENV | 走廊分割 |
| 柜台 (Counter) | Rectangle(64×16) | ENV | 射击位 |

- 障碍物离墙壁 ≥ 16px，离门洞 ≥ 32px
- NavigationRegion2D 的导航多边形需要**减掉障碍物占据区域**（用 NavigationPolygon 的 `add_outline` 或 Polygon2D 挖孔）

### Step 6：放置占位 Marker

每间房：

| Marker | 数量 | 说明 |
|--------|------|------|
| PlayerSpawn | 1 | 玩家出生点 |
| SpawnMarker | 4~12 | 敌人刷怪点，group="spawn" |
| Interactable_Chest | 0~2 | 宝箱占位 |
| Interactable_Shop | 0~1 | 商店占位 |
| Trap_Spikes | 0~2 | 陷阱占位 |

### Step 7：注册到 RoomManager

在 `resources/rooms/` 下创建对应的 `room_xx.tres`（RoomConfig Resource）：

```gdscript
# room_xx.tres 结构
room_size = 0 / 1 / 2 / 3  # SMALL/MEDIUM/LARGE/BOSS
scene_path = "res://scenes/rooms/room_xx.tscn"
```

在 `room_manager.gd` 的 fallback 列表中加入新房间。

### Step 8：导航网格更新

NavigationRegion2D 的 Polygon 必须：

1. **覆盖地板区域**（墙内侧 16px 缩进）
2. **减去障碍物**——每个障碍物在 NavigationPolygon 上打一个孔

简化方案：如果 NavigationPolygon 挖孔太麻烦，障碍物区域直接用 `NavigationObstacle2D`（不修改 nav poly，运行时动态避障）：

```
Obstacles/
├── StaticBody2D "Pillar"
│   ├── CollisionShape2D
│   └── NavigationObstacle2D    # 添加到每个障碍物下
```

`NavigationObstacle2D` 会让 AI 绕过障碍物，不需要修改 NavigationPolygon。推荐此方案。

## 六、导航网格处理

重点说明 NavigationObstacle2D 方案 vs Polygon 挖孔方案。

**推荐：NavigationObstacle2D**

```
每个障碍物（StaticBody2D）加一个 NavigationObstacle2D 子节点：
- avoidance_enabled = true
- radius = 自动匹配碰撞形状半径
- 无需修改 NavigationPolygon
```

优点：不影响现有 nav poly，AI 自动绕行，支持动态障碍物
缺点：AI 绕行行为略"软"（不会完全贴合障碍物边缘）

**如果要求精确阻挡**：在 NavigationRegion2D 的 Polygon 上挖孔

```
每个障碍物在 NavigationPolygon 中加一个 outline（内轮廓）：
navigation_polygon.add_outline(PackedVector2Array [...])
navigation_polygon.make_polygons_from_outlines()
```

## 七、验证标准

| 检查项 | 通过条件 |
|--------|----------|
| 玩家不能穿墙 | 向墙壁行走时停止 |
| 玩家能通过门洞 | 走进门洞到达另一房间 |
| 子弹撞墙消失 | 射击墙壁后 bullet 回池 |
| AI 绕开障碍物 | 敌人在障碍物两侧均有路径可达目标 |
| 玩家可站在障碍物后 | 用障碍物遮挡射击线 |
| SpawnMarker 正确刷怪 | 每个 wave 在 spawn 标记位置生成敌人 |
