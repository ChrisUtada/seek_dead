# 房间全面装配计划

## 一、目标

制作 **25 个可游玩的完整房间**，每个房间一次性包含：

- **墙壁碰撞体**（StaticBody2D 分段 + 门洞）
- **障碍物/掩体**（柱子、箱子堆、书柜、柜台等）
- **视觉地面**（ColorRect 纯色底 + 可选装饰 tile）
- **占位 Marker**（宝箱、商店、陷阱，后面换真实场景）
- **SpawnMarker**（按房间尺寸放入适量）
- **DoorMarker**（每个房间 1~4 个门）

## 二、策略

### 原则

1. **不直接改现有 5 间房**（room_1~room_boss）。保留作参考，新建统一模板体系
2. **代码生成**：使用 `room_generator.gd`（`@tool` 脚本）一次性生成全部房间，避免手动编辑
3. **按 Size 分类**。Small(5个) / Medium(8个) / Large(8个) / Boss(4个)

### 历史

| 阶段 | 工具 | 状态 |
|------|------|------|
| 旧方案 | `room_builder.gd` + `roombuild.tscn` | ❌ 已弃用（StaticBody2D 定位 bug + ownership 未递归设置） |
| 新方案 | `room_generator.gd` + `room_generator.tscn` | ✅ 当前方案 |

**关键修复**（从旧 builder 迁移时修复）：

- `StaticBody2D.position` 设为墙段左上角（旧版设为 0，碰撞体偏移错误）
- `CollisionShape2D.position` = shape 中心偏移
- `_own_recursive()` 跳过 instance 子节点（防止 DoorMarker 重复子节点）
- `ENV_LAYER` 从 4 改为 3（Pickup → Environment，匹配玩家 `collision_mask=4`）
- `ColorRect.mouse_filter = MOUSE_FILTER_IGNORE` 避免地板/DoorGlow 吞掉鼠标事件
- `add_to_group("spawn", true)` 让 SpawnMarker 的 group 信息持久化到 tscn

## 三、生成工具 `room_generator.gd`

`scripts/rooms/room_generator.gd` + `scenes/rooms/room_generator.tscn`

### 用法

```bash
# 在 Godot 中打开 room_generator.tscn，按 F6（运行当前场景）
# 脚本会生成所有房间并退出
```

或命令行：
```
godot --headless scenes/rooms/room_generator.tscn
```

### 生成内容

每次运行 `generate_all()`：

1. **`room_template.tscn`** — 模板骨架（最小值，可在编辑器中复制）
2. **`room_xxx.tscn`** — 每个 RoomDef 生成一个完整房间场景
3. **`resources/rooms/room_xxx.tres`** — 对应的 RoomConfig Resource

### 房间场景结构

```
room_xxx (Node2D)
├── NavigationRegion2D           # 按 nav_rect 生成四个顶点
├── Floor (Node2D)
│   ├── ColorRect                # #2a2a2a 纯色地板，size=nav_rect.size
│   └── DoorGlow[1~N]           # #00ff44 半透明 32×16，标记门位置
├── Walls (Node2D)               # 组织容器，collision_layer=3
│   ├── StaticBody2D "TopWall" / "TopWall_L" / "TopWall_R" (墙段)
│   ├── StaticBody2D "BottomWall" / ...
│   ├── StaticBody2D "LeftWall" / ...
│   └── StaticBody2D "RightWall" / ...
├── Obstacles (Node2D)           # 组织容器，collision_layer=3
│   └── StaticBody2D "Pillar_1"
│       ├── CollisionShape2D
│       ├── NavigationObstacle2D (avoidance_enabled=true)
│       └── Visual (Polygon2D 色块)
├── Markers (Node2D)
│   ├── PlayerSpawn              (Marker2D)
│   └── SpawnMarker[1~N]        (Marker2D, group="spawn")
└── Doors (Node2D)
    └── DoorMarker[1~N]          (door_marker.tscn 实例)
```

## 五、添加新房间流程

### Step 1：在 `_define_rooms()` 中添加 RoomDef

```gdscript
rooms.append(_mk("room_01", "石质大厅", RoomSize.SMALL,
    Rect2(16, 16, 256, 256),
    [dd(0, 144)],                          # 顶边 1 个门
    [ob("pillar", 80, 80), ob("pillar", 200, 180)],  # 2 个柱子
    4))                                    # 4 个 SpawnMarker
```

### Step 2：运行生成器

打开 `room_generator.tscn` → F6，或者 headless 运行。

### Step 3：验证

在资源管理器确认 `scenes/rooms/room_01.tscn` 和 `resources/rooms/room_01.tres` 已生成。

## 六、生成器核心实现细节

### 墙壁分段（`_wall_segments`）

**规则**：外框缩进 16px = 墙厚。DoorMarker 位置留 32px 门洞。

```
房间外框 outer(W×H)，墙厚 T=16，门洞宽 D=32

顶边：
  gaps = [d.pos for d where d.edge=0], 按 x 排序
  在 gap - 16 和 gap + 16 之间切开 → TopWall_L / TopWall_R
底边、左边、右边同理
```

### 障碍物（`_make_obstacles`）

| 类型 | 碰撞形状 | 视觉色块颜色 | 用途 |
|------|---------|-------------|------|
| pillar | Rectangle(24×24) | #8B7355 | 遮挡射击线 |
| crate | Rectangle(32×32) | #CD853F | 半高掩体 |
| bookshelf | Rectangle(16×64) | #6B3A2A | 走廊分割 |
| counter | Rectangle(64×16) | #A0522D | 射击位 |

每个障碍物含：
- `CollisionShape2D` — 物理碰撞
- `NavigationObstacle2D` — AI 绕行（avoidance_enabled=true, radius 自动适配）
- `Visual (Polygon2D)` — 编辑器可见色块占位

### 节点 ownership（`_own_recursive`）

```gdscript
func _own_recursive(node: Node, owner: Node):
    if node != owner:
        node.owner = owner
    if node != owner and node.scene_file_path != "":
        return  # 跳过 instance 子节点（防止 DoorMarker 子节点被重复打包）
    for child in node.get_children():
        _own_recursive(child, owner)
```

### RoomConfig 生成

```gdscript
var cfg := RoomConfig.new()
cfg.scene = scene
cfg.room_name = r.name
cfg.room_size = r.size as int
match r.size:
    RoomSize.SMALL: cfg.min_enemies = 3; cfg.max_enemies = 6
    RoomSize.MEDIUM: cfg.min_enemies = 5; cfg.max_enemies = 8
    RoomSize.LARGE: cfg.min_enemies = 6; cfg.max_enemies = 10
    RoomSize.BOSS: cfg.min_enemies = 0; cfg.max_enemies = 0; cfg.boss_count = 1
```

## 七、RoomManager 发现机制

`room_manager.gd:_load_configs()`：

1. 扫描 `res://resources/rooms/*.tres`
2. 每个 `.tres` 加载为 RoomConfig，过滤 `scene` 非空者
3. 若 `.tres` 文件不存在，回退到硬编码 fallback 列表（room_1~room_boss）

所以新房间只需 `room_xxx.tres` 文件出现在 resources/rooms/ 目录即可自动注册。

## 九、美术素材替换方案（未来）

| 当前（占位期） | 未来（美术期） | 替换方式 |
|----------------|---------------|----------|
| `Floor/ColorRect`（`#2a2a2a`） | `Floor/TileMapLayer`（贴图铺地） | 删 ColorRect，加 TileMapLayer，贴图对齐 Nav 外框 |
| `Floor/DoorGlow`（色块） | 无，门洞由 TileMap 缺口自然可见 | 删 DoorGlow |
| 墙壁 `CollisionShape2D`（线框） | 保持不变 | **不改**——碰撞体独立，TileMap 墙贴图对齐碰撞体位置即可 |
| 障碍物 `Polygon2D`（色块） | `Sprite2D` + 纹理 | 删 Polygon2D，加 Sprite2D，纹理对齐碰撞体位置 |
| 无 TileSet physics layer | 仍不加 | TileSet 只做视觉，碰撞永远靠 StaticBody2D |

**关键规则**：永远不修改 `Walls`/`Obstacles` 中的 `StaticBody2D` + `CollisionShape2D`，它们是碰撞系统的唯一真实来源。

## 十一、工作量预估（批量生成）

使用 `room_generator.gd` 代码生成 + 手动调整 RoomDef 参数：

| 任务 | 预估 |
|------|------|
| 编写 25 个 RoomDef（`_define_rooms`） | 30 min |
| 批量运行生成器 | 1 min |
| 验证（抽样 5 间） | 30 min |
| 手动细化（障碍物布局优化、门洞位置微调） | 2~3 h |
| **合计** | **~4 小时** |

## 十二、验证标准

| 检查项 | 通过条件 |
|--------|----------|
| 玩家不能穿墙 | 向墙壁行走时停止 |
| 玩家能通过门洞 | 走进门洞到达另一房间 |
| 子弹撞墙消失 | 射击墙壁后 bullet 回池 |
| AI 绕开障碍物 | 敌人在障碍物两侧均有路径可达目标 |
| 玩家可站在障碍物后 | 用障碍物遮挡射击线 |
| SpawnMarker 正确刷怪 | 每个 wave 在 spawn 标记位置生成敌人 |
