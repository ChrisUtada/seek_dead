# 房间环境碰撞体实施计划

## 一、现状

| 房间 | 有 TileMap 墙贴图 | 有 NavigationPolygon | 有碰撞体 |
|------|:-:|:-:|:-:|
| room_1.tscn (SMALL) | ✅ Dungeon_Tiles.png | ✅ (16,16)-(580,352) | ❌ |
| room_2.tscn (SMALL) | ✅ Water_tiles.png | ✅ (16,16)-(420,590) | ❌ |
| room_3_medium.tscn (MEDIUM) | ❌ 无任何 TileMap | ✅ (16,16)-(512,384) | ❌ |
| room_4_large.tscn (LARGE) | ❌ 无任何 TileMap | ✅ (16,16)-(640,448) | ❌ |

- ENVIRONMENT 碰撞层 = **Layer 3**（bit 值 4）
- 玩家 `collision_mask` 和敌人 `collision_mask` 均已包含 Layer 3
- TileSet 的物理层从未配置，没有任何碰撞形状
- NavigationPolygon 仅用于 AI 寻路，不阻挡移动

## 二、方案选择

**选型：在每间房 .tscn 中直接放置 StaticBody2D 墙壁片段**

原因：
1. room_3/room_4 没有 TileMapLayer，TileSet 碰撞方案不通用
2. 墙壁需要留门洞，不能一个矩形封死 —— 分段放置可控
3. 设计分辨率 640×360，像素对齐，位置可目视调整

## 三、实现步骤

### 步骤 1：新建墙壁节点容器 per room

每间房创建一个 `Walls` 子节点（Node2D，纯粹的组织容器），内部包含若干 StaticBody2D。

#### 墙壁生成规则

```
房间外框 = NavigationPolygon 外扩 16px（墙厚）
墙壁分段 = 四条边，在 DoorMarker 位置留门洞（门洞宽度 = 32px）
```

| 房间 | 外框 (x1,y1)-(x2,y2) | 墙厚 | 门洞位置 |
|------|----------------------|------|---------|
| room_1 | (0,0)-(596,368) | 16px | (19,0)-(53,0) 顶边？→ 需确认 DoorMarker 实际坐标 |
| room_2 | (0,0)-(436,606) | 16px | ... |
| room_3_medium | (0,0)-(528,400) | 16px | ... |
| room_4_large | (0,0)-(656,464) | 16px | ... |

#### 每段墙壁的结构

```
Walls (Node2D)
├── StaticBody2D "TopWall"           (collision_layer=4, collision_mask=0)
│   └── CollisionShape2D "Shape"     (RectangleShape2D)
├── StaticBody2D "TopWall_Right"     (如果门洞把顶边分成两段)
│   └── CollisionShape2D
├── StaticBody2D "BottomWall"
│   └── CollisionShape2D
├── StaticBody2D "LeftWall"
│   └── CollisionShape2D
└── StaticBody2D "RightWall"
    └── CollisionShape2D
```

### 步骤 2：确定每个房间的门洞位置

读取所有 DoorMarker，确定其在房间边界上的投影：

| 房间 | DoorMarker | global_position | direction |
|------|-----------|-----------------|-----------|
| room_1 | DoorMarker (DOWN) | (21, 38) | 2 (DOWN) → 顶边缺口 |
| room_1 | DoorMarker2 (RIGHT) | (565, 38) | 0 (RIGHT) → 右边缺口 |
| room_2 | DoorMarker | (408, 23) | 0 (RIGHT) → 右边缺口 |
| room_2 | DoorMarker2 | (408, 577) | 1 (DOWN) → 底边缺口 |
| room_3_medium | DoorMarker | (21, 38) | 2 (DOWN) → 顶边缺口 |
| room_3_medium | DoorMarker2 | (565, 38) | 1 (DOWN) → 底边缺口 |
| room_4_large | DoorMarker | (21, 38) | — 入口 |
| room_4_large | DoorMarker2 | (565, 38) | 1 (DOWN) → 底边缺口 |

**注意：** DoorMarker 的 `direction` 是从房间前往方向，不是墙壁的边。缺口分析：

顶边（y=0 线）：
- DoorMarker.y 接近 0 → 顶边缺口
- door_1: DoorMarker(21,38) → y=38 接近 0 → 顶边

底边（y=max）：
- DoorMarker.y 接近 room_height → 底边缺口
- door_2: DoorMarker2(408,577) y=577 接近 606 → 底边

左边（x=0）：
- DoorMarker.x 接近 0 → 左边缺口

右边（x=max）：
- DoorMarker.x 接近 room_width → 右边缺口
- room_1 DoorMarker2(565,38) → x=565 接近 596 → 右边
- room_2 DoorMarker(408,23) → x=408 接近 436 → 右边

### 步骤 3：编辑每间房的 .tscn

直接在 Godot 编辑器中打开每个房间场景：

1. 添加 `Walls` (Node2D) 作为 room 根节点的子节点
2. 在 Walls 下添加 StaticBody2D，设置 `collision_layer = 4`（Layer 3 bit），`collision_mask = 0`
3. 为每个 StaticBody2D 添加 CollisionShape2D 子节点，选 RectangleShape2D，调整大小和位置
4. 按边界分段添加，DoorMarker 位置留出 32px 门洞

**推荐的墙壁参数（以 room_1 为例）：**

```
房间外框: (0,0)-(596,368)，墙厚 16px
DoorMarker(21,38) → 顶边缺口，缺口中心 x=21，门宽 32px → (5,0)-(37,16) 挖空
DoorMarker2(565,38) → 右边缺口，缺口中心 y=38，门宽 32px → (580,22)-(596,54) 挖空

墙壁分段列表：
- 顶边左段: StaticBody2D, position=(0,0), size=(588,16)  ❌ 太大挡住门
  实际：顶边左段从 x=0 到 x=5，右段从 x=37 到 x=596
  - TopWall_Left:  position(0,0) size(5,16)
  - TopWall_Right:  position(37,0) size(559,16)  ← 但 37+559=596 正确

- 底边: StaticBody2D, position=(0,352), size=(596,16)  ← 完整无缺口

- 左边: StaticBody2D, position=(0,0), size=(16,368)  ← 完整无缺口

- 右边: 被 DoorMarker2 在 y=38 打断
  - RightWall_Top:  position(580,0) size(16,22)
  - RightWall_Btm:  position(580,54) size(16,314)
```

### 步骤 4：对 room_3_medium 和 room_4_large —— 无 TileMap

这两间房没有贴图，只有 NavigationPolygon。需要同时：

1. **添加墙壁**：同上方案，外框基于 NavigationPolygon 外扩 16px
2. **可选添加 TileMapLayer 或 Sprite2D**：让房间有视觉地面
   - 最简单方案：加一个 ColorRect 做纯色背景，或从 room_1 复用 tile 图
   - 可选不处理纯视觉——仅墙壁就能物理阻挡

### 步骤 5：验证

| 检查项 | 方法 |
|--------|------|
| 玩家不能穿墙 | 进入游戏，向各方向墙壁移动，应被阻挡 |
| 玩家能通过门洞 | 走到 DoorMarker 位置，应能通过 |
| 敌人不能穿墙 | 观察 AI 导航到目标时是否绕墙 |
| 子弹撞墙消失 | 射击墙壁，子弹应 `_return_to_pool()` |
| 导航网格一致 | NavigationAgent2D 路径不穿墙 |

## 四、房间参数速查表

| 房间 | Nav 左上 | Nav 右下 | 外框左上 | 外框右下 | 墙壁厚度 | 门洞列表 |
|------|----------|----------|----------|----------|----------|----------|
| room_1 | (16,16) | (580,352) | (0,0) | (596,368) | 16 | 顶边(5~37), 右边(22~54) |
| room_2 | (16,16) | (420,590) | (0,0) | (436,606) | 16 | 右边(7~39), 底边(392~424) |
| room_3_medium | (16,16) | (512,384) | (0,0) | (528,400) | 16 | 顶边(5~37), 底边(549~581) |
| room_4_large | (16,16) | (640,448) | (0,0) | (656,464) | 16 | 入口(5~37), 底边(549~581) |

**外框计算公式**：`外框左上 = Nav左上 - 16`, `外框右下 = Nav右下 + 16`

## 五、注意事项

1. **门洞宽度取 32px**（2 tiles），与 DoorMarker 碰撞体宽度 32px 一致
2. **墙厚 16px**（1 tile），与 TileSet tile_size 一致
3. **collision_layer = 4**（Layer 3 bit），与现有 CollisionSystem 约定一致
4. **collision_mask = 0**（墙壁不主动检测任何物体），避免冗余碰撞信号
5. **不要阻挡 DoorMarker 的 Area2D** —— DoorMarker 在墙壁内侧，与墙壁不重叠
6. 如果某房间没有 TileMapLayer（room_3/room_4），考虑加一个 TextureRect 或纯色背景做视觉地板，但不是必须
