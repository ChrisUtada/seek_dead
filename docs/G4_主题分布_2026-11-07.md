## 1. 本轮做了什么

G4 的「主题分布」按**尾路主题 + 路径连贯**落地：

1. **尾路主题**：每条尾路的主题来自该尾路 BOSS 的元素；
2. **首战同系**：尾路首战（depth 10）优先选与 BOSS 同元素的普通房；
   节点文案前置「主题：X（与 BOSS 同系）」，玩家在落地前就能看出这条尾路的元素基调；
3. **路径连贯**：共享段与中段相邻战斗不同元素；
4. **精英不重复**：同一条路径上的两个精英（共享 n4 + 支路精英）元素不同。

只改变「选哪间房」，**不改房间数值、掉落、ria、战斗规则、存档**；主题不是新系统，
没有新增标签栏、货币或状态。

## 2. ACT1 内容约束

当前 ACT1 元素分布决定了「可保证」的边界：

| 类型 | 元素分布 |
|---|---|
| BOSS | 冰 ×3、毒 ×1（共 4） |
| 精英 | 冰 ×2、毒 ×2（共 4） |
| 普通 | 无 ×2、毒 ×3、光 ×2、冰 ×3、暗 ×1、火 ×1（共 12） |

- **精英不重复可保证**：共享精英取 A 后，两条支路精英只能取另一种元素 B；
  剩余正好 2 间 B 元素精英，两个支路各一间。
- **尾路主题可保证**：尾路首战先于共享段分配，且最多 3 条非特殊尾路；
  3 个冰 BOSS 需要 3 间冰普通房（池中正好 3 间），毒 BOSS 有 3 间毒普通房可选。
- **相邻不同可保证**：先定精英、再定精英两侧的普通房，避免普通房占用精英唯一可用的元素；
  若池子仍不足，才退回「同类型未用」，绝不空置（兜底分支保留）。

## 3. 生成顺序

```text
本局种子
→ 抽骨架 / 分支价值模板 / 节点类型
→ 抽特殊格（宝箱 / 神龛 / 武器藏库）
→ 先分配 4 个 BOSS（决定四条尾路主题）
→ 再分配 3 条尾路首战（优先与 BOSS 同元素）
→ 分配共享精英 n4
→ 分配两条支路精英（避开 n4 元素）
→ 分配支路普通 → n6 → n3（避开已定的相邻战斗）
→ 冻结标题 / 文案 / 主题 / 岔路提示
```

特殊格替换掉的尾路首战只记录 `theme`（供分支信息与测试使用），
不覆盖宝箱/神龛/武器藏库自身的功能文案。

## 4. 公开信息

- 尾路首战（普通）：`主题：冰（与 BOSS 同系）` + 普通战斗元素/机制；
- 尾路 BOSS：沿用既有标题与元素；
- 岔路：沿用「上路/下方：BOSS 名字（元素）」，本轮未新增独立风险标签；
- 特殊格：沿用各自文案（宝箱只公开类别、神龛/藏库公开效果或武器）。

## 5. 已知取舍

- ACT1 有 3 个冰 BOSS，因此**出现 3 条冰主题尾路是内容分布的必然结果**，不是生成偏差；
  若要让四条尾路主题各异，需要先补 ACT1 BOSS 元素分布（内容改动，不在本轮）。
- 尾路首战固定同元素后，普通战斗的元素多样性会略降；换来的是「选尾路 = 选元素基调」。
- 尾路首战与中段精英之间不强制不同元素（主题优先）；共享段/中段内部严格交替。
- 主题只做「选择偏置」，不是硬锁：内容池不足时会退回未用房间，优先保证不空置、不重复。
