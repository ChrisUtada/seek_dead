## 3. 获得方式

| 类别 | 获得机制 | 证据 |
|---|---|---|
| **基础牌谱 W01–W06** | 装备条件自动激活（凑齐 unlock_tags 数量或 unlock_paths 精确武器），无需习得 | `unlock_tags=["element:fire"], unlock_count=2` 等（各 w*.tres） |
| **基础牌谱 T01–T03** | 无解锁条件（`unlock_paths/tags` 为空），战斗中凑齐牌型即可 | t01–t03.tres |
| **SIG02 冰火二重** | 装备条件（冰、火装备各一件，tag_count=1），无需习得 | s02_frostfire_dual.tres |
| **签名 sig_*（11 张）** | **三条件同时满足才生效**：①三选一「图纸」习得（`learn_signature`）→ ②携带**专属武器**（`key_paths` 里那把）→ ③凑齐签名的 `match_rule` 牌型。缺一不可 | `pattern_system.gd:101-130` 的 `find_signature`：`learned.has(id)` + `loadout.has(key_path)` + `solve_rule(cards, match_rule)` 三条件；`seed_sig_*.tres` 的 `effects=[{"effect_id":"learn_signature",...}]` |

**关键结论（2026-11-19 最终定稿，用户拍板）**：

签名牌谱 = **那把专属武器的专属强化**。生效需**三条件同时满足**：

1. **三选一习得**（`learned`）：先抽到「图纸」并习得；
2. **携带专属武器**（`key_paths`）：必须装备签名绑定的那把武器（如 `sig_fire_sword` → 火焰剑）；
3. **牌型满足**（`match_rule`）：战斗中凑齐签名的符号组合。

缺一不可。换成同元素的另一把武器**不行**——必须是指定的那把。这保留了"签名"的身份感。

**历史变更**：
- 早期：携带专属武器即自动生效。
- `b9400af`（11-19 早）：曾移除 key_paths 携带检查，改成"任意同元素武器 + 习得"即可——**已废止**。
- `2026-11-19` 用户拍板恢复：签名必须有那把武器。图纸不加"持有武器才出现"门槛（随机出现，
  玩家自行权衡）。基础牌谱 W01–W06 的装备条件自动激活**保持不变**。

## 4. 升级

| 项 | 结论 |
|---|---|
| 牌谱等级/熟练度/强化 | **无升级机制**。全项目搜索无 `pattern_level/pattern_upgrade/牌谱升级` 实现；`mastery` 是武器熟练系统（R1–R4），与牌谱无关 |

## 5. 使用 / 触发

**三个易混概念**（这是"怎么凑出来"的关键）：
- **轨道（track）**：分类标签（weapon_attack / skill_support / signature），**不决定凑牌方式**；
- **解锁条件（unlock_paths/tags）**：需要装备什么武器/护符，即"带什么"；
- **凑牌方式（match_rule）**：转轮上必须停出的符号组合，即"停出什么"。

生效要求"带对装备 + 停对牌"两者同时满足。各牌的具体凑牌方式见 §6 明细表。

**触发流程**：

```
每回合停轮 → PatternMatcher.match(cards) 按 match_rule 判定命中哪些牌谱
  → PatternSystem.resolve_equipment(matched, unlocked, assist_id) 选本回合生效的装备牌谱（至多 1 条，按 priority 降序，同优先级按 id 升序）
  → 通用牌型 resolve_universal 全部返回（不互斥）
  → 签名 find_signature：base_pattern_id 匹配 + 已习得(learned) + 携带专属武器(key_paths) + 牌型满足
  → 结算层按 effect_id 找实现，读 effect_params 应用效果
```

| 维度 | 说明 | 证据 |
|---|---|---|
| 判定条件 | `match_rule` 结构化 `{"all":[...], "any":[...]}`，条件含 `sym`（符号路径）、`kind`、`source_element`、`source_kind`、`skill_role` | `pattern_matcher.gd:38,140-142,191-215` |
| 牌型组成 | 通常为 3 张：符号牌 + 武器伤害牌 + 任意武器牌；T 类为 1 技能牌 + 2 武器牌 | 各 *.tres 的 match_rule |
| 生效数量 | 装备牌谱**至多 1 条/回合**（互斥，取最高优先）；通用牌型全部生效 | `pattern_system.gd:71-99` |
| 辅助 | `assist_allowed` 决定是否可被「连携卷轴」补牌凑成（通用牌型固定 false） | `pattern_data.gd:47` |
| 效果类型 | 伤害倍率（damage_mult）、穿透（pierce_ratio）、处决线（exec_threshold）、状态层数（burn/frost/poison_extra）、削敌攻（enemy_atk_mult）、护盾（shield_flat）、治疗（heal_mult）、武器伤害倍率（weapon_damage_mult） | 各 *.tres 的 effect_params |

### 5.1 效果参数术语表（把表格里的数字翻译成人话）

| 参数 | 含义（怎么算 / 什么时候触发） |
|---|---|
| **`threshold`（阈值）** | **霜冻层数门槛**。霜封连携先给敌人加霜冻层（`frost_extra`），当敌人身上霜冻**总层数 ≥ 阈值**时，本回合敌方攻击才会被削弱（`enemy_atk_mult`）。例：「霜冻+3，阈值4，敌攻×0.7」= 加 3 层后若累计≥4 层，敌人这回合攻击力降到 70%。阈值越低越早触发。见 `pattern_effects.gd:117-129` |
| **`attack_ratio`（齐射比例）** | **黎明圣辉专属**。追加的一次穿透齐射伤害 = `两把解锁武器当前基础攻击之和 × 比例`。「50%→80%」是签名把齐射从攻击和的 50% 提升到 80%，不是伤害整体翻倍。见 `pattern_effects.gd:95-109` |
| `exec_threshold` / `exec_ratio`（处刑线/处刑比） | 暗影处刑：敌人 **HP 占比 < 处刑线**（如 35%）时，暗伤转穿透的比例从基础值（20%）提高到处刑比（35%）。见 `pattern_effects.gd:144-146` |
| `damage_mult` | 该类伤害倍率。1.25 = +25%，1.4 = +40% |
| `pierce_ratio` | 该类伤害转为**穿透伤害**的比例（穿透绕过护甲） |
| `frost_extra` / `burn_extra` / `poison_extra` | 额外附加的状态层数（霜冻/燃烧/中毒） |
| `enemy_atk_mult` | 达标后**本回合敌方攻击力**的乘区，0.7 = 降到 70%；每回合重置（`duel_controller.gd:151`） |
| `instant_ratio` | 毒爆连携：立即结算的伤害 = 满额毒 tick × 该比例（如 0.6 = 60%），不减少毒层 |
| `shield_flat` / `shield_heavy` | 固定护盾值；敌方处于蓄力/重击意图时改用 `shield_heavy` |
| `heal_mult` / `low_hp_threshold` | 治疗倍率；HP 占比低于阈值时额外净化 1 个减益 |
| `weapon_damage_mult` | 本回合武器伤害倍率（不强化技能伤害） |
| `min_sources` | 要求伤害至少来自 N 个不同武器来源（防同一把武器凑数） |

### 6.1 基础牌谱（10 张）

> **轨道（track）**只是分类标签（武器攻击 / 技能辅助 / 签名），不告诉你怎么凑。
> **凑牌方式**来自 `match_rule`，是转轮上必须停出的符号组合；**解锁条件**是"带什么装备"。二者都满足才生效。

|---|---|---|---|---|---|

| W04 黎明圣辉 | 武器攻击 | 圣辉长剑+破晓之弓 | 圣辉斩符 + 破晓弹符 + 光元素武器牌 | 穿透齐射 = 双武器攻击和的 50% |
| W05 暗影处刑 | 武器攻击 | 2 把暗武器 | 2 张暗伤牌 + 任意武器牌 | 暗伤 20% 转穿透；HP<35% 提高到 35% |
