## 2. 本轮修正：首轮触发阈值 3 → 2

**问题**：Step 1 后 10 个 `aim_only` 种子里，寒铁精英有 2/4 场在 2 回合内结束，冰封铁瓮有 2/5 场在 2 回合内结束。旧节奏首次爆发在第 3 回合，这些对局只看到「蓄势、蓄势」；精英的整场机制完全没有出现。

**修正**：`rust_armor_gimmick` 新增静态参数 `first_pressure_turn`，默认等于 `interval`（其他房间行为不变）；两只样板设为 `2`：

- 第 1 回合：蓄势；
- 第 2 回合：爆发（叠甲 + 冻结）；
- 第 3 回合：恢复（熔铸间隙）；
- 之后每 3 回合重复（2 → 5 → 8）。

没有修改任何基础 HP / 攻击，没有改变层数、护甲量或加压频率，也没有引入动态橡皮筋。依据方案 §5.2「只有正常 Build 下仍无法看到核心机制时，才单独调整耐久或触发阈值」。

**读数**：

1. 所有实际出现的样板对局都至少看到一次爆发；3 回合以上的对局都能看到完整恢复窗口。
2. 仍保留唯一的 2 回合击杀（seed 1414 BOSS，单回合 391 伤害 ×2 对 638 HP）。它在第 2 回合看到爆发，但用特殊三连清掉 +8 护甲后直接击杀；属于方案允许的「爆发玩家快速击杀」，不是机制失效。
3. 首轮前移会让冻结的 `randf()` 提前一回合消费，后续房间的 RNG 序列随之变化；因此跨种子的总回合数/承伤只作参考，不当作因果对比（例如 seed 1515 总回合 16 → 27 来自整局 RNG 重排，不是样板房加耐久）。
4. 修正后 seed 888 BOSS 从 2 回合变为 4 回合：第 2 回合的 +8 护甲让原本溢出的伤害多打一轮；这是阈值调整的直接代价，量级为 1–2 回合，没有堆 HP。

## 4. 真实应对与主动改打法

### 4.1 每段高压的多对策（`rhythm_windows_test` 覆盖）

- **蓄势**：保持输出 / 强化药剂 / 攻击药剂 / 提前三连或穿透 / 「保留资源」兜底；
- **爆发**：特殊三连破甲、穿透直击、破甲酸液、冻结时清净药剂、承压输出、强化药剂、「直接承伤」兜底；
- **恢复**：特殊三连、穿透、破甲酸液、直接输出。

标准提示只列当前带内/腰带内真实存在的对策，不显示唯一目标；>2 条时主栏省略、其余进 tooltip。

### 4.2 对局证据

**seed 999 · 冰封铁瓮 · 3 回合**

- 第 1 回合（蓄势）：特殊三连清空 53 护甲，连线 337 + 核爆 79（HP 638 → 222）。
- 第 2 回合（爆发）：+8 护甲、冻结第 1 列。目标列被冻结，玩家只停 2 列，改为获得 12 护盾 + 回复 21，承受重击 40；没有强行追三连。
- 第 3 回合（恢复）：特殊三连清掉剩余 8 护甲，337 + 79 击杀。

**seed 666 · 寒铁精英 · 3 回合**

- 第 1 回合（蓄势）：256 伤害（HP 304 → 10）。
- 第 2 回合（爆发）：+4 护甲、冻结第 3 列；玩家改为 4 护盾 + 20 回复，承受 44。
- 第 3 回合（恢复）：特殊三连清甲，256 + 38 击杀。

两场都出现「高压回合主动放弃输出、转防御/回复，恢复回合再收尾」；这是 Step 3 要求的「至少一次主动改变打法」。

| 出口 | 结果 |

| 阶段改变目标价值，不只加 HP/攻击 | ✅ 爆发改变目标为破甲/净化/接受列损失；恢复把目标切回输出；基础 HP/攻击未改 |

**结论**：Step 3 出口成立。节奏样板从「长战才可见」改为「所有实际对局至少看到一次爆发，3 回合以上看到完整恢复」。
