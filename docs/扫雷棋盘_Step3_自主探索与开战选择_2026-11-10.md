## 1. 本切片范围

Step 2 已经能揭示、移动、战斗、获得装备。Step 3 把「何时开战」的决定权交回玩家：

- BOSS 确认层提供「继续探索 / 挑战 BOSS」，误点不会强制开战；
- 精英点击后先看战利品与邻近装备目标，再选择「返回探索 / 挑战精英」；
- 查看构筑：随时只读查看当前 Build，不领取奖励、不消耗 RNG；
- 撤回整备：两次确认后结束远征回整备页，记录 `retreat`；
- 已击败的精英 / BOSS 只作为已探索格，不会重复开战或重复发奖。

默认 `layout_mode = "legacy"` 不变，以上交互只在 4×4 网格生效。

## 2. BOSS：可见终点，不因误点开战

点击相邻的 BOSS 格时：

- **不移动、不消耗、不揭示额外内容、不改数字**；只打开确认层；
- 确认层显示名称、HP / 攻、元素、特殊机制、真实弱点（`ElementCounter.weakness`，×1.5）与当前武器元素；
- 按钮为 **[继续探索] [挑战 BOSS]**；
- 「继续探索」关闭确认层，玩家留在原格，可继续探索、可稍后再次点击 BOSS；
- 「挑战 BOSS」才真正进入并消耗 BOSS 格，随后进入既有战斗流程。

没有装备数量、地图完成率或击败数门槛：从任意相邻格都可以直接挑战。

## 3. 精英：先看定向奖励，再主动挑战

点击相邻精英格时同样只打开预览：

- **不移动、不消耗**；按钮为 **[返回探索] [挑战精英]**；
- 预览包含：
  - 名称、HP / 攻、元素、特殊机制；
  - 战利品：金币囤 + 铁砧点 + 1 项高品质奖励（既有精英规则）；
  - 高品质候选：武器 / 消耗品 / 生命回复；
  - 邻近目标：与精英相邻的武器 / 护符具体名称（开局已冻结，不会落地重抽）；
- 「返回探索」不改变任何状态；「挑战精英」才进入并消耗精英格；
- 精英被击败后，再次点击该格只会移动（已探索格），不会二次开战。

## 4. 查看构筑（只读）

网格棋盘左下角新增「查看构筑」入口：

- 显示武器、技能、护符、消耗品（含剩余次数）、成长进度 / 技艺 / 铭印、HP、金币、已击败数；
- 显示转轮符号的权重合计（按符号 + 有效元素聚合，排序后展示）；
- **不调用 `build_strips()`**（该函数会用 `randi()` 洗牌），因此查看不消耗 RNG；
- 不改变地图、数字、节点、Build、HP 或奖励；
- 关闭后回到棋盘原状态。

## 5. 撤回整备（二次确认）

网格棋盘左下角新增「撤回整备」入口：

1. 第一次确认：「撤回整备？本局临时成长、地图进度与未结算奖励将失去。图鉴 / 收藏 / 解锁与局外点数保留。」
   - [取消] 直接关闭，不改变任何状态；
   - [继续撤回] 进入第二次确认。
2. 第二次确认：「再次确认：结束本次远征并回到整备页。不会获得区域 BOSS 或通关奖励。」
   - [取消] 回到棋盘，本局继续；
   - [确认撤回] 结束远征。

确认后：

- `RunJournal.finish("retreat")`，终局原因记录为 `retreat`（不是 `defeat` / `clear`）；
- `Codex.record_run` 保留本局武器最高熟练（与战败口径一致）；
- `RoomFlow.return_to_loadout()` 落盘 meta、清空本局勾选 / 腰带 / 成长、收起棋盘并打开整备页；
- 不发区域 BOSS 或通关奖励，也不保留本局临时成长与地图进度。

打开、停留在任一确认层或取消，都不改变数字、节点、Build、HP 或 RNG。

## 6. 已击败节点与回访

- 普通怪 / 精英 / BOSS 胜利后由 `BoardSystem.note_battle_won()` 标记 `defeated`；
- 再次点击已击败的战斗格只执行相邻移动（`last_move_revisit = true`），不弹确认、不重复结算；
- BOSS 在真实流程中胜利后进入幕间 / 奖励，不返回本幕网格；测试中直接调用 `return_to_board()` 验证标记与数字更新。

9. 查看构筑打开 / 内容 / 关闭，且不消耗全局 RNG、不改地图 / 数字 / HP；
10. 撤回两次确认流程：第一次取消、第二次取消、最终确认；
