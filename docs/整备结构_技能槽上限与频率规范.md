# 整备结构 · 技能槽上限与频率规范

> 状态：**已落地（2026-08-10）**——用户拍板：技能槽硬上限 3 + 技能 weight 统一下调 ≤1.5。本文档为后续设计/调参的参考资料（技能频率、整备结构、稀释控制的决策依据）。
> 关联：传统 slots 频率改造（2026-08-10，权重档位制）、武器上限 2（2026-08-07 拍板）、数值膨胀与策略深度设计框架（稀释刹车）。

---

## 1. 背景：不对称稀释问题

**现状事实**（代码基线：`loadout_system.cat_cap` / `reel_system.build_strips`）：

| 类别 | 槽位 | 天花板 | 进池符号 |
|---|---|---|---|
| 武器 weapon | 初始 2 | **硬限 2**（2026-08-07 拍板，商店不可买第 3 把） | 每把 1-2 个符号（主 w5-6 + 副 w2-3） |
| 技能 skill | 初始 1 | 原 UNCAPPED 无限（2026-08-10 前） | 每技能 1 个符号（w2-3） |

**问题**：武器硬限 2 把（符号贡献恒定），技能无上限（商店买即开槽）——技能符号（功能/buff/第二元素）无限挤占主输出带子，**不对称稀释**：武器符号密度持续下降 = 主输出"转不到"。

**量化**（传统 slots 频率档位制：w≥4→4 格 / w≥2→3 格 / 保底 2 格；rare/epic 封顶 2 格）：

| 组合 | 武器符号格数 | 技能符号格数 | 武器占比 |
|---|---|---|---|
| 2 武 + 1 技 | ~13 格 | 3 格 | ~76% |
| 2 武 + 3 技 | ~13 格 | 9 格 | ~57% |
| 2 武 + 5 技 | ~13 格 | 15 格 | **~43%** |

## 2. 决策（2026-08-10 用户拍板，双管齐下）

| 方案 | 内容 | 效果 |
|---|---|---|
| **A. 技能槽硬上限 3** | `loadout_system.cat_cap("skill")`：UNCAPPED → **3**（初始 1 → 商店买到 3 封顶） | "2 武 + 3 技"稳定比例，技能符号总格数封顶 ~6-9 格 |
| **B. 技能 weight 统一下调 1.0** | 17 个技能 .tres 的 `weight` 2/3 → **1.0** | 每技能落保底 2 格（低频功能符号） |

**实现细节**：
- `loadout_system.gd`：`cat_cap("skill")` 返回 3（`grow_slot` 的 min 逻辑既有，自动尊重上限）；`cap_text` 显示 "3"（不再 ∞）
- `duel_controller.gd`：注释同步（技能退出 UNCAPPED 进池类）
- 17 个 `resources/skills/*.tres`：`weight = 1.0`（注意 .tres 行尾 CRLF/LF 混合，批量替换用 `(?m)^weight\s*=\s*[\d.]+(?=\r?$)`）

## 3. 落地后实测（F6，2 武器 iron_sword/fire_sword + 3 技能 rage/calm/flame_mark）

| 符号 | 来源 | base 格数（×平铺） |
|---|---|---|
| 铁斩 | iron_sword（common 主符号 w5） | 4 格 |
| 燃 / 火斩 | fire_sword（rare，稀有度封顶） | 2 格 |
| 火印 / 狂怒 / 定心 | 技能（weight 1.0 保底档） | **2 格** |
| MISS / 金币 | 全局 | 2 格 |

- 技能符号恒定 2 格 ≤ 攻击符号（common 4 / rare 2）——**"技能总体低于攻击"成立**（与 rare 持平 = 目押下限，不应再低）
- 3 技能封顶后技能总占 ≤33%，武器占比不再被挤（上限锁死）
- 技能槽 grow：1→2→3 封顶，第 4 个不可购买（can_grow_slot=false）

## 4. 规范结论（后续设计参考）

1. **技能 = 低频功能符号**：weight 一律 1.0（新技能照此）；技能符号格数 = 保底 2 格档
2. **技能槽硬限 3**：整备结构锚点 "2 武 + 3 技"；不再为技能做"买即开槽"扩到 3 以上
3. **武器保留硬限 2 + UNCAPPED 语义已失效**（2026-08-07 起武器也是硬限 2）——武器符号密度恒定，稀释只来自"技能种类"（封顶 3）与 MISS/废铁注入
4. **未来内容新增**：新技能只进 SKILL_POOL（整备可选、商店可卖），不进带子密度竞争——频率恒 2 格
5. 若未来手感需调：技能 weight 影响档位边界（1.0 保底 2 格；≥2 升 3 格）——但 2026-08-10 定稿以 2 格为准，调整需评审
