> 筛选条件：`act_min <= 1 <= act_max`，即第一幕可出现。共 **31** 个（技能库总计 40 个）。
> 其中 `demo_config.skill_pool` 白名单取 **8** 个，标 ⭐。

## 一、数值口径

| 字段 | 含义 |
|---|---|
| `base_power` | 技能攻击力／效能。伤害类按此计伤；增益类作为量级参考 |
| `hit_rate` | 命中率，`1 - hit_rate` = 该符号注入转轮后变成废铁 miss 格的比例 |
| `weight` | 注入转轮池的权重（与武器符号同池竞争出格概率） |
| `symbol` | 技能在转轮上的符号，**技能本身不产生效果，只把该符号塞进转轮** |
| `crit_mult` | 三连暴击倍率（象征凑齐 3 连按此倍率结算） |
| `triple_pierce` | 三连时是否清空敌方护甲 |

伤害公式（与武器同源）：

```
total = int((连线dmg + special×chain_mult) × assault × buff_mult × 元素克制)
元素克制：×1.5 克制 / ×0.85 抵抗 / ×1.0 无关系
```

## 四、三连 / 暴击 / 破甲

**全部 31 个 ACT1 技能都使用默认值**，没有任何技能单独改写：

| 项 | 默认值 | 说明 |
|---|---|---|
| `crit_mult` | `2.0` | 三连必暴，按 2 倍结算 |
| `crit_chance` | `0.0` | 非三连无额外暴击率加成 |
| `triple_pierce` | `false` | 三连不清空敌方护甲 |

也就是说「三连」对技能只提供 **连锁倍率 + 必暴**，破甲是武器侧的专属轴（`triple_pierce` 为 true 的装备才触发）。

## 六、demo 白名单与幕次的一个不一致

`demo_config.skill_pool` 声明了 10 个技能，但其中两个的 `act_min = 2`，**在 ACT1 不可达**：

| 技能 | id | act_min | act_max | 稀有度 |
|---|---|---|---|---|
| 再生术 | `shadow_regen` | 2 | 3 | rare |
| 炎息 | `fire_breath` | 2 | 3 | rare |

`loot_pool.gd` 会按 `act >= act_min and act <= act_max` 过滤，所以运行时不会漏出这两个，
**demo 实际可获得的技能是 8 个**，那两个白名单条目是空占位。

如果希望 demo 也能拿到，需要把它们的 `act_min` 改成 1；否则建议从 `skill_pool` 里移除以避免误读。
