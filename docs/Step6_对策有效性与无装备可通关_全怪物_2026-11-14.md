## 1. 结论

**装备没有成为门票**。新增第 48 套定向回归 `counterplay_test.gd`，单套实跑 `PASS (checks=162 fails=0)`：61/61 房间在「无消耗品 / 无护符 / 无抗扰加成」的基础 Build 下全部打到 `WON`，无软锁、无超时；9 个玩家侧减益与 4 类转轮干扰意图均验证到「至少两种应对真实有效」；3 个代表房的双 Build 都能通关。

按 Step 6「只有存在真实缺口时才调整装备，不为每个 debuff 造唯一解」的口径，本步**不新增、不调整任何装备**。上一轮对策覆盖核查中的真缺口（验证覆盖）已补上。

## 3. 测试设计

脚本 `tests/counterplay_test.gd`（454 行），固定种子 `SEED=20261114`，单房回合预算 400、单回合帧保护 900。

| 组 | 覆盖 | 关键做法 |
|---|---|---|
| A | 9 个玩家侧减益（69 条断言） | 施加后断言效果真实生效；`DebuffSystem.DEFS` 应对文案 ≥2 条且至少一条不依赖装备；清净 / 净化药剂通道解除后效果倍率或操作限制恢复；无装备通道按机制分别走破甲解腐蚀、换符号解反噬、按序停列解缠绕、跨回合计时自动到期 |
| B | 4 类转轮干扰意图 `jam / lock / chaos / auto_stop`（24 条） | 断言 `purifiable=true` 且净化后 `value_mult=0`；不净化时断言 `pending_*` 确实生效（非纸面机制），并实跑一回合确认 `turn_count` 推进或战斗结束，不被软锁 |
| C | 61 个房间全量（66 条） | 裸 Build：腰带为空、护符为空、`charm_interf_resist<=0`，只保留 2 把基础武器；逐房 `_on_spin_pressed` 跑到 `WON`，结算后跳过战后界面；记录每房回合数 |
| D | 3 个代表房双 Build（3 条） | 窃语咒师 / 腐化史莱姆 / 勇者的阴影，各跑「裸 Build」与「净化 + 清净 + 抗扰 + 守备」两条路 |

`GOD_HP=1000000` 只作用于测试实例，用于把判定聚焦在「是否因缺装备被软锁」而非随机死亡，**不代表无装备在真实数值下可稳定通关**。
