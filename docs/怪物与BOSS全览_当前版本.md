本文按当前资源文件静态盘点，数值为 `.tres` 基础值，**未乘 ante 缩放**。机制摘要以当前 `gimmick_params` 为准。

## 0. 阅读说明

### 0.1 数值口径

- `RoomData.hp / atk / armor` 为 0 时，分别回落到行为族的 `hp_base / atk_base / armor_base`。
- 实战数值 = 基础值 × ante 缩放：
  - **HP / 护甲**：`1.75^(act-1) × 1.15^ria`
  - **ATK**：`1.30^(act-1) × 1.06^ria`
- `ria` = 本幕内战斗序号（0 起）。棋盘普通/精英节点按路径深度取 0–6；**BOSS 固定 `ria=7`**。
- 护甲是扁平池：伤害先破甲、后掉血；护甲同样按 HP 缩放。机制覆写护甲的 BOSS（如茧居石雕）以机制值为准。
- 每幕基础抽取结构：**5 普通 + 2 精英 + 1 BOSS = 8 战**（`run_act_layout`）；棋盘同一张图会为 4 条尾路分配不同 BOSS，玩家实际只走其中一条。
- 线性模式：每幕从本幕 BOSS 池抽 1 名常规 BOSS；真·最终 BOSS 在 ACT3 后追加。
- 棋盘模式：ACT3 的 4 条尾路 BOSS 节点正好覆盖「3 名常规 BOSS + 勇者的阴影」。

### 0.2 元素克制速查

| 攻击元素 | 克制（×1.5） | 被抵抗（×0.85） |
|---|---|---|
| 火 | 冰、毒 | 同元素；被毒抵抗 |
| 冰 | 火 | 同元素 |
| 毒 | 暗 | 同元素；被火、光抵抗 |
| 光 | 暗、毒 | 同元素 |
| 暗 | 光 | 同元素；被毒抵抗 |
| 无 | — | — |

> 表中「弱点」列为敌人受到 ×1.5 伤害的元素。

### 0.3 意图类型

| 意图 | 名称 | 说明 |
|---|---|---|
| `attack` | 攻击 | 基础攻击 |
| `heavy` | 重击 | 攻击 ×2.0 |
| `jam` | 注废 | 向转轮注入废铁，可被净化 |
| `lock` | 锁轮 | 锁定一列，可被净化 |
| `chaos` | 乱权 | 打乱转轮权重，可被净化 |
| `auto_stop` | 夺轮 | 自动停轮，可被净化 |

按幕解锁：**ACT1 仅攻击/重击 → ACT2 解锁注废/锁轮/乱权 → ACT3 解锁夺轮**。  
行为族若含未解锁意图，会先被过滤；全部被过滤空时回落本幕默认表。

## 6. 维护提示

- 新增怪物：在 `resources/rooms/` 放一个 `RoomData` 资源，填 `name / hp / atk / armor / element / kind / act`，可选 `archetype / gimmick_script / gimmick_params / art / mechanic_summary`。启动时自动扫描，无需登记。
- 行为族新增/调整：改 `resources/archetypes/*.tres`，所有引用它的房间同步生效。
- 全局难度台阶：改 `resources/config/balance_config.tres` 的 `ante_*`；本文「实战 HP」列会随之变化。
- 当前所有 `resources/rooms/*.tres` 中，`kind` 只有 `normal / elite / boss` 三种；`final_boss=true` 的只有 `hero_shadow.tres`。
