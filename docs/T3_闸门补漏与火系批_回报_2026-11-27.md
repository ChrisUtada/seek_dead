## 一、日志闸门补漏

### A1 漏洞证据（先红）

旧闸门只看 `SCRIPT ERROR` / `RESULT FAIL` / `FAILED N`，构造两条探针日志放入 `%TEMP%`：

| 探针 | 内容 | 旧闸门结果 |
|---|---|---|
| `smoke_probe_fmt1.log` | `SOMETHING RESULT: 26 checks, 1 fails` | 未命中 → `LOGCHECK: OK (2 files)`，退出码 0 |
| `smoke_probe_fmt2.log` | `SOMETHING RESULT: FAIL` | 未命中 → 同上 |

即：失败日志可以整体通过闸门。两种格式恰好是部分套件的真实输出形态（`RESULT: N checks, M fails` 与 `RESULT: FAIL`）。

### B1 规则扩展（五条，不改判定强弱）

`tools/check_smoke_logs.ps1` 现按行匹配五条规则（a–e）：

| 规则 | 匹配 | 说明 |
|---|---|---|
| a | 含 `SCRIPT ERROR` | 原样保留 |
| b | `RESULT\s+FAIL` | 原样保留 |
| c | `FAILED\s+[1-9]` | 原样保留 |
| d | 数字在前 `(?i)\b[1-9]\d*\s+fails?\b(?!\s*[:=]\s*0\b)` 或 关键字在前 `(?i)\bfails?\s*[:=]\s*[1-9]\d*\b` | 新增；抓 `1 fails` / `fails=1` 两种顺序 |
| e | `(?i)RESULT\s*[:：]\s*FAIL` | 新增；抓 `RESULT: FAIL`（全角/半角冒号） |

a/b/c 未放宽；a/b/c 与 d/e 的差别只在新增覆盖，不改原有命中条件。`0 fails`、`fails=0`、`checks=10 fails=0` 均不误报（d 的数字在前分支用负向前查排除 `[:=] 0`，关键字在前分支要求值 ≥1）。

PowerShell 5.1 读无 BOM UTF-8 时按 ANSI 解码，正则里的全角冒号会损坏，故用 `[char]0x3A`/`[char]0xFF1A` 拼出；注释行改为纯 ASCII，避免中文吞掉换行。

### B2 运行前清旧日志

`run_smoke.bat` 在 `setlocal` 后新增：

```bat
del /q "%TEMP%\smoke_*.log" 2>nul
```

防止旧日志被闸门当成本轮证据。

- **C1 两份坏样本**：`powershell -File tools/check_smoke_logs.ps1` →
  ```

  BAD  smoke_probe_fmt2.log:1  SOMETHING RESULT: FAIL
  ```
