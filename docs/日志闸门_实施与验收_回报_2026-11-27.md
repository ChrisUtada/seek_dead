## 1. 改动

### 1.1 新增 `tools/check_smoke_logs.ps1`

- 参数：`-LogDir <目录>`（默认 `%TEMP%`）、`-Pattern <通配>`（默认 `smoke_*.log`）。
- UTF-8 读取，不改任何日志文件。
- 命中任一即违规：
  - a) `SCRIPT ERROR`
  - b) 正则 `RESULT\s+FAIL`
  - c) 正则 `FAILED\s+[1-9]`
- 输出：每行 `BAD  <文件名>:<行号>  <原文前 120 字符>`。
- 有违规 → `LOGCHECK: BAD (N hits in X/Y files)` + exit 1；
  无 → `LOGCHECK: OK (<N> files)` + exit 0。

### 1.2 `run_smoke.bat` 末尾追加（3 + 1 行）

```bat
echo [logcheck] scanning %TEMP%\smoke_*.log for SCRIPT ERROR / RESULT FAIL ...
powershell -NoProfile -ExecutionPolicy Bypass -File tools\check_smoke_logs.ps1 -LogDir "%TEMP%"
if errorlevel 1 (
  set FAIL=1
  echo   FAIL -- SCRIPT ERROR / RESULT FAIL found in smoke logs, see above
)
```

> 说明：`echo` 文案用英文而非工单里的中文原句——`run_smoke.bat` 原文件是纯 ASCII（无 BOM），
> 在中文 Windows 的 cmd（OEM 936）下写入 UTF-8 中文会乱码。功能与判失败口径不受影响。
