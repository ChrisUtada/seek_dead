# #14 护符缺口 · 内容审查与补齐（2026-11-21）

> 纪律：不为全绿随便补两件；先审查职责/机制家族/重复度、六身份缺口、获取来源，再决定补或下调目标。

## 1. 审查结论

### 1.1 缺口根因
- `smoke_lint.gd:30` 护符门槛 45，实测目录仅 43 → 红灯。
- 根因是提交 `cf1d54e`（P1 删 3 个死信物 `abyss_relic`/`rust_relic`/`whisper_relic`，补 1 个 `hero_emblem_relic`）净 -2，数量门槛未同步。
- "45 件"来自 M6-C4 内容铺量目标（`docs/装备收集规划_200.md:126-138`），是**自定内容目标**，非运行时功能需求。

### 1.2 现有 43 件机制家族分布
| 家族 | 件数 | 评价 |
|---|---:|---|
| shield（每回合护盾） | 7 | 高度同质，仅数值阶梯 4/6/8/10/12/14 |
| damage_mult（泛用乘区） | 5 | 高同质，纯数值 |
| armor_pierce / heal / status_boost | 各 4 | 阶梯完整 |
| damage_bonus / room_shield / element_boost / interference_resist | 各 3 | 正常 |
| first_hit | 2 | 正常 |
| thorns / dot_amp / dot_reduce / free_reroll / charge_start | 各 1 | **全部是 BOSS 信物独占** |

- 同质化主来源：shield 7 + damage_mult 5 = 12 件（27.9%）。
- 按 role：damage 22 / defense 15 / recovery 4 / utility 2。

### 1.3 六身份的机制性护符缺口（非泛用乘区）
| 身份 | 现状 | 机制性缺口 |
|---|---|---|
| 集中 | 伤害加值/DoT/克制倍率 | 无三连专属赔付 |
| 状态控制 | DoT 倍率 + 挂层（挂层仅 BOSS 信物） | **挂层加速/控制时长无普通可及护符** |
| 破甲 | 4 件破甲阶梯 + 2 泛用 | 破甲供给最密 |
| 防御 | 7 件全护盾 | **无普通可及反伤（thorns 仅 BOSS 信物）** |
| 跨元素覆盖 | 3 克制倍率 + 1 泛用 | 异色协奏无专属（克制向已拥挤） |
| 对子 | 6 件全是泛用乘区/加值/首击 | **对子赔付 0 件机制护符**（最明确空白，但现有 effect 系统无 hook） |

### 1.4 关键约束发现
护符 effect 枚举是**封闭的 13 种**，全部映射到数值型 `charm_*` 字段（`loadout_system.gd:185-203`）：
power/shield/heal/damage_mult/armor_pierce/element_boost/status_boost/dot_reduce/thorns/dot_amp/free_reroll/charge_start/first_hit。

"对子赔付""攻守转换/护盾转输出""异色协奏加成"等用户期望的机制在战斗代码中**没有 hook 点**，新增必须改战斗结算代码（combat_system/circuit_system），超出"补内容"范围，故本次不实施。

但 `thorns`（反弹）与 `dot_amp`（挂层 +1、降低 DoT 爆发门槛）是**真实战斗机制**（`combat_system.gd:1081/157/1171`），且目前**只由 BOSS 信物持有**，普通玩家无法及。这两件属于"改变战斗行为"的机制位，非泛用攻击乘区，符合补件标准。

## 2. 补齐方案（2 件非信物机制护符）

### 2.1 荆棘胸甲 `thorn_plate.tres`
- effect = `thorns` 0.15（敌人攻击反弹 15%，穿透护甲；低于石屑之心 0.2）
- 代价：`downside_effect = shield`，每回合护盾 -3
- family_tags = shield/dark，role = defense，rarity = uncommon，act 1-3
- source_tags = elite/shop/chest（**不含 anvil**，不依赖已删除的铁砧）
- 适用构筑：防御身份（坚壁钉锤），以承伤换输出；纯堆盾路线收益下降
- unique_group = charm_thorn_plate（不与信物互斥）

### 2.2 蚀纹符 `venom_lattice.tres`
- effect = `dot_amp` 1（DoT 挂层 +1，且 DoT 爆发门槛 -1）
- 代价：`downside_effect = damage_mult` 0.9（全局伤害 ×0.9）
- family_tags = fire/ice/poison，role = damage，rarity = uncommon，act 1-3
- source_tags = elite/shop/chest
- 适用构筑：状态控制身份（冰霜枪），加速 DoT 引爆；直伤爆发路线收益下降
- unique_group = charm_venom_lattice

## 5. 结论与边界

- **45 件目标保留**（不下调）：缺口根因是一次无关删除的副产物，补齐两件落在真实机制空白而非堆数值。
- 两件新护符均用现有 effect 枚举实现，**未改任何战斗结算代码**；机制价值来自填补"普通可及的反伤/挂层"空白。
- 未实现的机制位（对子赔付/攻守转换/异色协奏/处决线等）需战斗系统 hook 扩展，属 S6 内容生产与工具化范畴，**本次不制造同质内容凑数**。
- #14 关闭后，S5 收口的所有结论不变；#14 护符补齐为独立内容专项。
