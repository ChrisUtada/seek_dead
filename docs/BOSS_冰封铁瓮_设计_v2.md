## 1. 定位与特色

**Act1 固定首领（教学位）**：Act1 BOSS 槽「4 候选选 1」的 fixed 候选（权重 6 ≈ 43%）。教学主题「**破甲三件套**」——全游戏唯一一个 BOSS 教完三条破甲爆发路径：

```
① 破甲武器三连清甲（triple_pierce：铁剑/战斧/夜幕镰刀，任意符号三连）
② 克制三连 → 清甲 + 20% max HP 核爆（Plan C）
③ 元素充能满 5 → 清甲 + 15% max HP 穿透爆发（T21 赛道）
```

**教学双线设计（V2 重构）**：
- **主线·破甲**：熔铸冰甲叠加（3 回合节奏）逼玩家主动掌握至少一条破甲路径——破甲动词的教学场。
- **副线·解冻**：寒霜侵蚀冻结格（与叠甲同频挂层）教「清净药剂」用途与「失效格」概念——**Act2 锁轮/乱权（低语者）与律法目押（审判官）的前置教学**：先会「解冻」再会「净化」。

**教学决策树**（每回合玩家面对的问题）：叠甲了吗？→ 破甲/穿透/火武削血；冻结了吗？→ 清净解冻或绕开；两者都来 → 腰带取舍（清净/治疗/强袭 4 格压力）。**教学位 = 决策最少、反馈最清晰**——不引入意图干扰（净化药剂本战无用，故意留白给 Act2）。

## 3. 机制（rust_armor + frozen，全参数化 T24）

### 3.1 熔铸冰甲（主线）
- 每 **3** 回合叠 1 层（`interval`，拉宽教学窗口）；每层 +8（`per_stack`），上限 3 层（`max_stacks`）——叠加基础甲 20 上 → 峰值 44。
- 破甲路径（三件套）：①triple_pierce 破甲武器三连清空 ②穿透符号直击（后落地扩充：穿甲重弩/寒渊长枪/圣光钉锤等 pierce 武器）③破甲符概率穿透 ④充能爆发清甲（T21）。

### 3.2 寒霜侵蚀（副线·玩家侧冻结格）
- **固定节奏**（教学确定性，用户拍板 2026-08-07）：第 3/6/9 回合与叠甲同频挂冻结 1 层。
- spin 前冰封 1 列（本轮无法 spin、不参与结算、**不封 trash/MISS 格**）；每 1 层冻 1 列、上限 2 列、`decay=1` 每回合 -1 层；冻结列每轮随机。
- **交互**：清净药剂（cleanse）解冻——副线教学（解冻 → 解状态 → Act2 教净化意图）。
- **单侧性纪律**：玩家侧冻结 = `frozen` StatusDef；`frost` 回归纯敌人侧（冰武减攻）。

### 3.3 与已有 BOSS 的差异化（V2 补齐）

| BOSS | 叠甲/防御机制 | 正解轴 |
|---|---|---|
| 冰封铁瓮（教学位） | **永久叠加甲**（每 3 回合 +8，破甲一次投资永久生效） | 破甲三件套 + 火武克制 + 清净解冻 |
| 茧居石雕 v2（Act1 隐秘） | **周期重置甲**（闭合补满 45 → 开合归零） | 节奏管理：攒爆发进窗口 |
| 碎裂魔王 P2（Act3） | **每回合叠甲 +6**（上限 45） | 穿透/破甲 + DoT 跨阶段削血 |
| 深渊监视者（Act3） | 甲 35→45 两档固定 | 穿透直击厚甲 |

- 铁瓮 = 叠甲机制的**教学原点**：永久甲（一次投资永久生效）是最简单的叠甲模型——后续所有叠甲变体（周期重置/每回合叠/分档）都是它的改造。
- 冻结格 = 转轮干扰的**教学原点**：失效格（冻结）→ 锁列（低语者锁轮）→ 注废（深渊侵蚀）——干扰强度的阶梯。
