## 1. 定位与特色

**Act1 固定首领（教学位）**：Act1 BOSS 槽「4 候选选 1」的 fixed 候选（权重 6 ≈ 43%）。教学主题「**破甲三件套**」——全游戏唯一一个 BOSS 教完三条破甲爆发路径：

```
① 破甲武器三连清甲（triple_pierce：铁剑/战斧/夜幕镰刀等破甲武器/技能，**自身符号 ×3** 触发）
② 克制元素连线 → 清甲 + 20% max HP 核爆（counter_triple：同符号克制 ≥2 连，或同元素 3 格，可不同符号）
③ 元素充能满 5 → 清甲 + 15% max HP 穿透爆发（charge_burst_pct=0.15，T21 赛道）
```

**教学双线设计（V2 重构）**：
- **主线·破甲**：熔铸冰甲叠加（3 回合节奏）逼玩家主动掌握至少一条破甲路径——破甲动词的教学场。
- **副线·解冻**：寒霜侵蚀冻结格（与叠甲同频挂层）教「失效格」概念与清净药剂用法——**Act2 锁轮/乱权（低语者）与律法目押（审判官）的前置教学**：先会「解冻」再会「净化」。

**教学决策树**（每回合玩家面对的问题）：叠甲了吗？→ 破甲/穿透/火武削血；冻结了吗？→ 清净当回合解除（保住输出）或硬扛（次回合自消）；两者都来 → 腰带取舍（清净/治疗/强袭 4 格压力）。**教学位 = 决策最少、反馈最清晰**——不引入意图干扰（净化药剂本战无用，故意留白给 Act2；其首次教学位 = **Act2 低语者锁轮战**——锁轮意图 purifiable，净化可抵消，接上「先会解冻再会净化」的下一环）。
- **优先级纪律（V2 + 2026-08-13 用户拍板）**：主线（破甲）为必学项；副线（解冻）为条件式——冻结与叠甲同频（第 3/6/9 回合）、**随机 1~2 列（1 列更常见）、次回合自动解除**（见 §3.2），无清净药剂也不会死锁；清净药剂 = 当回合立即解除的可选优化，非必修。

## 3. 机制（rust_armor + frozen，全参数化 T24）

### 3.1 熔铸冰甲（主线）
- 每 **3** 回合叠 1 层（`interval`，拉宽教学窗口）；每层 +8（`per_stack`），上限 3 层（`max_stacks`）——叠加基础甲 20 上 → 峰值 44。
- 破甲路径总表（V2 统一口径：**爆发三件套 + 补充手段**，钩子见 `combat_system.gd`）：

| 类别 | 路径 | 触发条件 | 效果 |
|---|---|---|---|
| 爆发·① | 破甲武器三连 | triple_pierce 武器/技能自身符号 ×3（铁剑/战斧/夜幕镰刀等） | 清空护甲（`on_counter("special")`） |
| 爆发·② | 克制元素连线 | 同符号克制 ≥2 连，或同元素 3 格（可不同符号） | 清甲 + 核爆 20% max HP 穿透（`counter_triple`） |
| 爆发·③ | 元素充能 | 克制命中累计满 5 次（charge_max） | 清甲 + 15% max HP 穿透（charge_burst_pct=0.15） |
| 补充 | 穿透符号直击 | pierce 符号（穿甲重弩/寒渊长枪/圣光钉锤等） | 无视护甲直接扣 HP（不清甲） |
| 补充 | 破甲护符 | 破甲符 25% / 碎甲之印 40% | 非穿透伤害概率直击 HP |

### 3.2 寒霜侵蚀（副线·玩家侧冻结格）
- **固定节奏**（教学确定性，用户拍板 2026-08-07）：第 3/6/9 回合与叠甲同频挂冻结（叠甲封顶后冻结同步停止）。
- **随机量（2026-08-13 用户拍板）**：每次冻结随机 **1~2 列，1 列更常见**（`two_cols_chance=0.3`，读 gimmick_params）；**次回合自动解除**（frozen `decay=1`）——无清净药剂不会死锁。
- spin 前冰封该列（本轮无法 spin、**整列不参与计数/匹配/结算**——不产生伤害、不触发连线）；冻结列每轮随机。
- **冻结选取不封废铁**：`pick_frozen_cols` 跳过当前显示为 trash/MISS 的列（冻结废铁格 = 浪费；全为废铁时回落随机）。
- **交互**：清净药剂（cleanse）——`use_cleanse` 清 `player_frost` + 清 `frozen_cols` + 刷新转轮格子，**当回合立即解除冻结列**（蓝框即时撤除，本回合 3 列全转）；冻结回合未用清净也只是损失本回合部分输出，次回合自消。副线教学（失效格 → 清净解冻 → Act2 教净化意图）。
- **单侧性纪律**：玩家侧冻结 = `frozen` StatusDef；`frost` 回归纯敌人侧（冰武减攻）。

### 3.3 与已有 BOSS 的差异化（V2 补齐）

| BOSS | 叠甲/防御机制 | 正解轴 |
|---|---|---|
| 冰封铁瓮（教学位） | **永久叠加甲**（每 3 回合 +8，破甲一次投资永久生效） | 破甲三件套 + 火武克制（+ 清净当回合解冻可选） |
| 茧居石雕 v2（Act1 隐秘） | **周期重置甲**（闭合补满 45 → 开合归零） | 节奏管理：攒爆发进窗口 |
| 碎裂魔王 P2（Act3） | **每回合叠甲 +6**（上限 45） | 穿透/破甲 + DoT 跨阶段削血 |
| 深渊监视者（Act3） | 甲 35→45 两档固定 | 穿透直击厚甲 |

- 铁瓮 = 叠甲机制的**教学原点**：永久甲（一次投资永久生效）是最简单的叠甲模型——后续所有叠甲变体（周期重置/每回合叠/分档）都是它的改造。
- 冻结格 = 转轮干扰的**教学原点**：失效格（冻结）→ 锁列（低语者锁轮）→ 注废（深渊侵蚀）——干扰强度的阶梯。

### 3.4 参数化（gimmick_params）
```json
{"interval": 3, "per_stack": 8, "max_stacks": 3}
```
> 空 = 回落代码默认（interval 2 / per_stack 8 / max_stacks 3）——注意与定稿 interval 3 不同：教学位参数**必须显式写入**（清空即叠甲节奏变紧）。缺省兼容仅服务于复用本脚本的 Act2/3 BOSS（规范 §10「教学位回归」）。
