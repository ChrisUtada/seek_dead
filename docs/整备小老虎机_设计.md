# 整备小老虎机 · 设计（武器自选 + 护符/技能随机三选一）

> 状态：**设计定稿（2026-08-10）**——待拍板细节（§8）后实施。
> 关联：老虎机主题一致性（整备也是"转"出来的）、铁砧 gacha（盘外随机）/ 整备（盘内随机）/ 商店（局内主动）三层随机-选择谱系、owned 拥有池（摇奖池来源）、Hades 式"武器自选 + 祝福随机三选一"参照。

---

## 1. 设计目标

1. **主题统一**：整备环节也用"小老虎机"摇——老虎机主题贯穿"整备 → 战斗 → 铁砧"全流程
2. **每局差异**：护符/技能随机化 → 重玩性提升，破"最优解死板配装"
3. **核心构筑权保留**：武器自选不动——玩家对"打法主体"的掌控不丢
4. **随机必须有选择权**：杜绝"纯 RNG 赌局"（随机 ≠ 有趣；随机 + 决策 = 有趣）

## 2. 现状分析

| 品类 | 现状 | 槽位 |
|---|---|---|
| 武器 | 自选（owned 池勾选） | 无硬顶（UNCAPPED） |
| 护符 | 自选（owned 池勾选） | cap 3 |
| 技能 | 自选（全池） | 无硬顶（UNCAPPED） |
| 消耗品 | **自选 1 种**（SLOT_INIT["active"]=1） | 腰带 4 格（局内商店扩容） |

痛点：护符/技能自选 → 每局配装趋同（最优解），且与铁砧"抽装备"的乐趣重复（铁砧抽到的新件在整备被无视）。

## 3. 方案总览（Hades 式）

```
武器：自选（现状不动）——核心构筑权

护符：小老虎机摇 3 候选 → 选 1（可重复整备摇满 cap 3）
技能：小老虎机摇 3 候选 → 选 1
消耗品：自选 1 种（现状不动）——战术对策资源必须可控
```

**品类分工原则**：
- 消耗品 = **对策资源**（净化/清净/重转应对干扰机制）→ 必须可控，不随机
- 护符/技能 = **构筑资源**（乘区/协同）→ 适合随机，且每局差异已足够
- 随机化的收益由护符/技能承担，消耗品保持战术底线稳定

## 4. 各品类规则

### 4.1 武器（不变）
自选，无硬顶；进池规则不变（owned + 铁砧授予）。

### 4.2 护符（小老虎机 3 选 1）
- 每次"整备摇奖"：从候选池摇 **3 个候选 → 玩家选 1**；可重复摇奖直至 cap 3（每格一次决策）
- 候选池 = owned_charms（拥有池）；**协同加权**（见 §5.1）
- 允许放弃（不选）——槽位留空
- 视觉：复用 `anvil_cell.tscn` 组件改造（3 格横排，选 1 后其余收起）

### 4.3 技能（小老虎机 3 选 1）
- 同上：3 候选选 1，可重复摇（UNCAPPED 无硬顶，次数由玩家自定）
- 候选池 = SKILL_POOL（技能暂全池，待 owned_skills 扩展）
- 协同加权同护符

### 4.4 消耗品（不变）
- 自选 1 种（现状）
- **不随机理由**：① 机制解（净化/清净/重转）必须可控，纯随机会产出"无解局"（jam BOSS 无净化）② 局内商店全池售卖已兜底对策缺口 ③ 每局差异已由护符/技能提供，消耗品随机是边际收益
- 若未来想丰富开局资源：**扩 2 格自选**（对策 + 通用各 1）优于"1 自选 + 1 随机"（无随机方差，更直接）

## 5. 关键机制

### 5.1 协同加权（防无效组合）
候选池按**与已选武器的协同度**加权，保底至少 1 个协同件：
- **元素协同**：护符/技能携带的符号/效果元素 == 武器元素 → 权重 ×2
- **类型协同**：破甲护符（配破甲武器）、状态护符（配毒/冰武）等效果-武器联动 → 权重 ×1.5
- **保底**：3 候选里至少 1 个与当前武器同系/联动（否则纯随机 = 火武配毒护符的无效组合）

### 5.2 Reroll（把随机变成决策）
- 每次整备可重摇：消耗 **训练点**（train_per_level 体系）或金币（待拍板，§8）
- 重摇 = "有代价的再决策"——随机本身是乐趣，代价防无限刷

### 5.3 对策保底（消耗品不随机，但候选需含对策）
- 消耗品虽自选，但整备 UI 增加"对策提示"：检测当前局 BOSS 机制（若有已知 BOSS），提示建议携带净化/清净/重转（只提示，不强制的选择权）

## 6. 与现有系统联动

| 系统 | 联动 |
|---|---|
| owned 池 | 护符候选从 owned_charms 摇；铁砧授予的新护符立即进整备候选池 |
| 铁砧 | 盘外随机收集 → 整备候选池的"池扩张"——收集的价值在整备兑现 |
| 商店 | 局内主动补强：整备没摇到的关键件商店可买（互不冲突，补随机方差） |
| 训练场 | 训练点作为 reroll 货币候选（或另设金币 reroll） |
| 单侧性纪律 | 不新增装备；候选/加权全数据驱动 |
