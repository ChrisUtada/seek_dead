## 2. 首批成就与判定

| ID | 名称 | 条件 | 触发点 |
|---|---|---|---|
| `first_clear` | 初次深入 | 首次击败任意 ACT1 BOSS | BOSS 房胜利 |
| `four_hunters` | 四席猎手 | 累计击败 4 个不同 ACT1 BOSS | BOSS 房胜利（按 `RoomData.resource_path` 去重） |
| `same_element` | 同系共振 | 击败 BOSS 时两把武器元素相同且非 `none` | BOSS 房胜利 |
| `off_element` | 异系调度 | 击败 BOSS 时两把武器元素不同且均非 `none` | BOSS 房胜利 |
| `armor_break` | 破甲专家 | BOSS 房内触发一次破甲并获胜 | `CombatSystem.on_counter` 清甲 |
| `status_apostle` | 状态使徒 | BOSS 房内状态伤害累计 ≥ 25 并获胜 | `CombatSystem.tick_status` |
| `guardian` | 坚守 | 击败 BOSS 时本局累计格挡 ≥ 40 | 局内遥测 `damage_blocked` |
| `board_treasure` | 棋盘寻宝 | 在棋盘武器格主动获得（含替换）一把武器 | `_board_weapon` / `_board_weapon_replace` |
| `elite_route` | 高危路线 | 本局进入过精英节点并击败 BOSS | 棋盘精英节点进入 + BOSS 胜利 |
| `peaceful` | 特殊结局 | 以非暴力和解击败 BOSS | `peaceful_win` + BOSS 胜利 |

说明：

- 「完成一幕」按本项目现有结构解释为「击败一名幕 BOSS」；棋盘模式每条尾路的 BOSS 即本局终局。
- 同系/异系只统计 `WeaponData.element`，`none` 不计；武器槽上限 2，因此只比较两把。
- 状态/格挡门槛是首版观测值，只影响成就判定，不参与任何战斗结算。
- 棋盘寻宝只认「武器格」；武器藏库、宝箱和 BOSS 战利品不计入（避免一个成就覆盖所有获取途径）。
- 成就只解锁一次，不发属性、不发货币、不替代铁砧；`初次深入`/`四席猎手` 的定向解锁机会由 G6-02 承接。

## 3. 存档与兼容

```json
"anvil_meta": {
  "career": {
    "unlocked": ["first_clear", "board_treasure"],
    "bosses": ["res://resources/rooms/a1_brute_none.tres"]
  }
}
```

- 老档没有 `career` 键：载入时补 `{"unlocked": [], "bosses": []}`，不报错、不删已有收藏。
- 只保留当前定义表内的成就 ID；未知 ID 不进内存，但也不会主动从旧存档中抹除其它键。
- 每次解锁/新增 BOSS 记录立即 `save_meta()`，与铁砧/收藏同一落盘路径。
- 局内临时标记（本场破甲、本场状态伤害、本局精英路线）不落盘，`reset_run()` 清零。
