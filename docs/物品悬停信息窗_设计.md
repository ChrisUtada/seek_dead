# 物品悬停信息窗（Item Tooltip）· 设计

> 状态：**设计定稿（2026-08-10）**——已预留图标位，待实施（Step 1-4）。
> 目标：商店/整备/铁砧/腰带所有物品悬停显示"具体用处"，玩家无需记忆或翻文档。
> 关联：ItemCard（IconRect 图标预留位同模式）、battle_theme.tres（TooltipPanel/Label 已像素化）、Palette、T4 内容规划。

---

## 1. 方案选型（最佳实践结论）

**采用：Godot 内置 `tooltip_text` + BBCode + 已主题化的 TooltipPanel/Label**，不手写跟随/定位组件。

| 对比 | 内置 tooltip_text（选用） | 自定义 Control（现有 symbol_tooltip 模式） |
|---|---|---|
| 鼠标跟随 / 延迟 / 显隐 | Godot 自动处理 | 手写 |
| 富文本 | BBCode（颜色 / 换行 / 加粗） | 手搭 Label 树 |
| 主题 | TooltipPanel/Label 已像素化 ✓（V5 落地） | 需单独样式 |
| 代码量 | 设一行字符串 | ~50 行 / 组件 |

> 现有 `symbol_tooltip`（符号悬停，特殊锚点）保留不迁移；物品悬停统一走内置 tooltip。

## 2. 图标位置预留（本设计重点）

**工具提示内容结构顶部预留图标位**（与 ItemCard.IconRect 预留同模式）：

```
┌─────────────────────┐
│  [图标位] 名称 · 稀有度 │   ← 第一行：图标 + 名称
│  元素 · 攻 X · 命中 Y%  │   ← 第二行：核心数值
│  符号表 / 效果描述       │   ← 第三行起：详情
└─────────────────────┘
```

- **现用（emoji）**：ItemData.icon / SkillData.icon / RewardData.icon 已有 emoji 字段，直接显示；WeaponData 暂无 icon 字段 → 先用符号 label（首个符号）占位
- **预留（美术）**：结构上为 `TextureRect` 图标位预留（对齐 ItemCard 的 IconRect 方案）——未来武器/物品美术图入库时，只替换显示层，不改变 tooltip 结构
- **尺寸**：图标位固定 12×12（480×270 像素 UI 基准），emoji 与未来图统一按此格渲染

## 3. 数据层（单一生成器，DRY）

新增 `scripts/utils/item_tooltip.gd`：

```gdscript
class_name ItemTooltip
extends RefCounted

# 按资源类型生成 BBCode 富文本（颜色用 Palette；字段缺失兜底文件名）
static func for_resource(res: Resource, kind: String = "") -> String
```

| 类型 | 内容结构 |
|---|---|
| WeaponData | `[icon] [color=金]名称[/color]·[color=稀有度色]稀有度[/color]` + `元素·攻 X·命中 Y%` + 符号表（label×权重） |
| ItemData(passive) | 图标 + 名称·稀有度色 + `description`（效果已中文）+ 负面效果行（如有） |
| ItemData(active) | 图标 + 名称 + `description` + `charges`（可用次数） |
| SkillData | 图标 + 名称 + `description` + 符号×权重 + 元素 |
| RewardData | 图标 + label + desc（现有字段直接用） |
| 兜底 | 无 icon 时首符号 label；`res == null` 时资源文件名 |

**稀有度 → 颜色**：common 灰 / uncommon 绿 / rare 蓝 / epic 紫（Palette 补 4 常量或复用现有色板）。

## 4. UI 层接入点

`ItemCard` 增加便捷方法：

```gdscript
func set_tooltip(res: Resource, kind: String = "") -> void:
	tooltip_text = ItemTooltip.for_resource(res, kind)
```

| 位置 | 卡片 | 动作 |
|---|---|---|
| 商店购入 `_make_shop_card` | ItemCard | `set_tooltip(load(path), kind)` |
| 商店卖出 `_make_sell_card` | ItemCard | 同上（tooltip 给全量信息） |
| 商店升级 `_make_upgrade_card` | ItemCard | 详细数值 tooltip |
| 整备副屏 `_make_item_card` | ItemCard | `set_tooltip(...)` |
| 铁砧格 `anvil_cell` | AnvilCell | 摇出结果 tooltip（结果 dict 含 path） |
| 腰带格（consumable cells） | 已有 tooltip_text | 改走生成器统一格式 |
| 奖励 / 元进度卡 | ItemCard | RewardData 已有 desc，可选 |

## 5. 主题与配置

- TooltipPanel/Label 已像素化 ✓；BBCode `[color]` 直接用 Palette 色值，无需改主题
- `project.godot`：`gui/timers/tooltip_delay_sec = 0.3`（默认 0.5 偏慢，商店快速浏览场景调快）
- 多行文本用 BBCode `\n` 控制；长描述自动换行

## 6. 防御与一致性

- `for_resource` 对 `res == null` / 字段缺失兜底（返回文件名），防 load 失败白框
- 所有 tooltip 单一生成器 → 格式一处改全生效
- 单侧性纪律：只读资源字段，不新增装备；图标位预留不阻断 emoji 现用
