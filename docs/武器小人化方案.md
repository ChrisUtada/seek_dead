# 武器小人化方案（表现层升级）

> 状态：**📋 方案定稿（2026-08-13，待落地）**——表现升级：武器卡与**转轮符号**全部小人化。
> 现有基础：整备页 5 小人方案（`[已完成]整备页_5小人_复古掌机_执行方案.md`）+ assets 已有小人素材（wq/jn/xh/hf/tz.png）+ 玩家/敌人像素小人（char.png 16×16 / enemy.png）+ BOSS 立绘（bossbf.png 48×48）——同一套 16×16/24×24 像素风管道。
> **2026-08-13 修订（用户拍板）**：转轮符号也从 emoji 改为小人图标——现符号 label 多为组合 emoji（❄️💠 / ☣❄️ / ⛓），640×360 下放大模糊、快速转动难认、需多一层「emoji→符号」翻译；小人图标（系别配色 + 形状）辨识更直观。
> 核心结论：**符号小人（系别默认 + 每符号可覆盖）+ 武器小人（卡面/收藏）+ L2 战斗随行**——小人统一承担「机制辨识 + 在场表现」。

---

## 1. 现状与问题

| 表现位 | 现状 | 问题 |
|---|---|---|
| **转轮符号格** | 组合 emoji（❄️💠 / ☣❄️ / ⛓ / ⚔） | 放大模糊、快速转动难认、需多一层「emoji→符号」翻译——易读性差（用户拍板改小人） |
| 武器卡（整备/商店/奖励/铁砧） | emoji 图标（🔥/❄️/✨）+ 文字 | 24 把武器之间辨识度低，无情感连接 |
| 战斗 HUD 玩家精灵 | 固定 char.png，与武器无关 | 武器在场感缺失 |

## 2. 表现价值（为什么好）

1. **辨识度**：每把武器一个小人 = 一眼可认的视觉符号——「我收集的不是数据，是小人军团」
2. **情感连接**：小人 = 有「角色感」（VS 式角色收集 / Cult of the Lamb 式随从感）——直接强化收集驱动（与正式收藏制、GAME+ 收藏解锁券联动）
3. **美术管道零新增**：16×16/24×24 像素静态立绘，与 char.png / BOSS 立绘同风格，WeaponData 加 `character: Texture2D` 字段即数据驱动

## 3. 符号小人化（转轮格，2026-08-13 用户拍板）

- **转轮符号格改用小人图标**：组合 emoji 放大模糊 + 多一层翻译；小人（系别配色 + 形状）快速转动也能一眼辨系
- **数据方案**：`SymbolData` 新增 `@export var character: Texture2D = null`——空 = 回落「系别默认小人」（见下），有 = 每符号自定义小人（特殊符号专用）
- **系别默认小人**（约 8-10 个素材，成本可控）：火/冰/毒/光/暗/无 六系各 1 + special（炎爆）/gold/MISS/trash 各 1——转轮格显示「系别小人」，克制判定靠小人配色一眼可读
- **emoji label 保留**：tooltip / 图例 / 战斗日志继续用 emoji + 文字（小人管转轮辨识，文字管精确语义）
- **共享符号跨武器**：小人按**符号自身**（SymbolData.character 或系别默认）显示，与武器元素派生无关——停轮匹配仍按「符号+元素」结算，小人只是视觉

## 4. 武器小人化（卡面/收藏/随行）

| 层级 | 内容 | 表现提升 | 成本 | 优先级 |
|---|---|---|---|---|
| **L1** | 武器卡/收藏/铁砧/奖励卡：该武器的小人立绘替代 emoji 图标 | 收集欲望 + 界面质感 | 小：24 张静态立绘 + 1 字段 | 首选 |
| **L2** | 战斗 HUD 玩家精灵旁显示「当前武器小人」（随武器切换） | 战斗画面丰富度 | 中：HUD 布局 + 切换逻辑 | 次选 |
| **L3** | 玩家化身随武器换装（持剑/斧/杖 = 不同小人形象） | 终极表现（Dead Cells 式） | 大：玩家动画重做 | 远期 |

> 武器小人（WeaponData.character）与符号小人（SymbolData.character）独立：符号小人 = 系别辨识；武器小人 = 收藏/在场身份。

## 5. 数据方案

- `weapon_data.gd` 新增：`@export var character: Texture2D = null`（武器小人立绘；空 = 回落现有 emoji 图标）
- `symbol_data.gd` 新增：`@export var character: Texture2D = null`（符号小人；空 = 回落系别默认小人）
- 系别默认小人映射：ElementCounter 元素 → `assets/characters/elem_{fire|ice|poison|light|dark|none}.png` + `special/gold/miss/trash.png`
- 素材目录：`assets/characters/`（命名 `fire_sword.png`、`elem_fire.png` 等，16×16 或 24×24 像素风）
- 渲染位：转轮格 `_refresh_cell`（符号小人）/ 整备卡 `_make_item_card` / 商店卡 / 奖励卡 / 铁砧卡（武器小人）——有 character 用 TextureRect，否则 emoji 回落
- 类别小人（wq/jn/xh/hf/tz）保留：作为整备页 5 小人布局的类别代表；武器小人 = 类别小人的具体化变体
