## 1. 验收方法

不靠肉眼猜：先写取证工具 `tools/loadout_layout_probe.gd` / `.tscn`，在
**480×270 / 960×540 / 1440×810** 三档窗口下逐屏实例化真实 `duel`，读取节点真实尺寸、
主题字号、每行文本宽度、自动换行后的占用高度、滚动区与内容最小高度，再截图。

产物：`docs/baseline/2026-11-08_loadout/`

- `probe_data.txt`：逐卡逐行的测量值；
- 每档 8 张：`main_*`（副屏收起）、`weapon_*` / `skill_*` / `active_*` / `passive_*`（副屏四类）、
  `preview_*`（转轮带预览）、`career_*`（生涯成就）、`forge_*`（铸式）；
- `board_960x540.png`：受主题字号修正影响面检查（棋盘屏）。

## 2. 实测问题

| # | 问题 | 证据 |
|---|---|---|
| 1 | **物品卡字号是 16，不是 10** | `ui_button.tscn` 的主题写成了 `Button/fonts/font_size = 10`；Godot 4 只认 `Button/font_sizes/font_size`，该行一直被忽略，按钮退到默认 16px。实测 `get_theme_font_size("font_size")=16` |
| 2 | **物品卡文字被整段裁掉** | 卡内可用宽 178px（护符卡带 20px 图标时 158px）；武器数值行 182px、技能描述最长 591px、消耗品 474px、护符 511px，而 `autowrap=OFF` + `clip_text=true` → 描述后半句直接看不见（例：「解除自身负面状态：驱散寒霜…」只剩前 17 字） |
| 3 | **底部栏零边距、恰好占满 480** | 7 个子项 + 6×8 分隔 = 480，`offset_left=0/right=480`，金币图标与计数文字贴着屏幕左缘，与标题 10px 边距不一致 |
| 4 | **预览弹层的「关闭」按钮 16px** | 漏设字号，比同屏其它文字（8–11px）大一截 |
| 5 | **生涯弹层没有可见关闭入口** | 只能「点任意处退出」，与预览/铸式弹层的「关闭」按钮不一致 |
| 6 | **换类目沿用上一类目的滚动位置** | 技能 10 条滚到底再切武器，列表停在中间（实测 `before=486`） |

## 3. 修复

### 3.1 物品卡字号（根因）

`scenes/ui/ui_button.tscn`：

```diff
-Button/fonts/font_size = 10
+Button/font_sizes/font_size = 10
```

影响面：所有**没有显式字号覆盖**的 `ui_button` 实例。逐一核对：

- 整备物品卡（本次要修）、奖励屏「跳过」按钮（实测 10px，96×30 尺寸不变）；
- 战斗 HUD / 商店 / 铁砧 / 棋盘的按钮都有 `theme_override_font_sizes` 或自身是 `ItemCard`，不受影响；
- 棋盘屏「前进 / 进入战斗」随之为 10px，与同屏 7–10px 文字一致（见 `board_960x540.png`）。

### 3.2 卡片文本不再裁切（`scripts/ui/card_factory.gd`）

- `autowrap_mode = AUTOWRAP_WORD_SMART`、`clip_text = false`：描述改为换行显示，卡片按内容长；
  列表本来就可滚动（技能 10 条 = 774px，视口 144px）。
- 武器数值行按语义拆两行：`攻 · 元素 · 命中` / `暴击 · 机制`。
  整行实测 182px 超 178px，自动换行只会把「· —」挤到下一行，拆行更稳定。
- 新增 `_short_desc()`：描述只保留**效果句**——去掉「——…」引出的设计备注，
  超过 34 字在句末收尾或加「…」。这是显示层截断，不改任何资源文本。
  （原文如「…（持续 2 回合）——P2 高攻窗口容错，与守备/铁壁叠加稳字流」，
   卡上只留「定心符入轮：本回合起护盾 +8（持续 2 回合）」。）
- 新增 `scripts/ui/item_button.gd`：整备卡造卡时 `set_script` 挂上，只重写
  `_make_custom_tooltip`，用现成的 `ItemTooltip` 生成富文本悬停信息窗（名称/稀有度/数值/符号）。
  其余 `ui_button` 实例不受影响。

### 3.3 底部栏与弹层

- `loadout_scene.tscn` 底部栏：`offset_left 6 / offset_right 474`、`separation 5`
  → 左右各留 6px，子项总和 462 < 468，余量由「确认开战」吸收。
- 预览弹层「关闭」补 `font_size 9`。
- 生涯弹层末尾补同款「关闭」按钮（`font_size 9`，120×26）。
- `_fill_sub()` 重建列表后 `sub_scroll.scroll_vertical = 0`。

## 4. 验证

- **新回归测试** `tests/g8_loadout_layout_test.gd` / `.tscn`（smoke 第 21 套）：
  143 项断言全过，覆盖字号=10、自动换行/不裁切、每张卡文本高宽够、底部栏边距与不越界、
  三个弹层内容可见、换类目回顶、悬停窗可生成。
  - 反证：临时把主题改回 `Button/fonts/font_size` 再跑，测试报 4 条 FAIL（四类目字号=16），
    确认不是空跑。
- `smoke_lint`：1191 / 0；全量 `run_smoke.bat`：**21 套 ALL GREEN**
  （L2+L3 3617 / 0；`m4_career_test` 因新增关闭按钮由 12→13 个子项，断言同步更新为
  「12 条内容 + 1 关闭按钮」并加了「末尾是 Button」的检查，79 / 0）。
- 三档窗口截图逐张核对：四类卡文本完整、无贴边；武器 4 行；护符带图标时仍留 158px；
  预览/生涯/铸式在 480×270 下分别为「放得下 / 放得下 / 需滚动（已有滚动条）」。
- 存档：探针与测试均在隔离 `APPDATA` 下运行，真实存档 SHA-256 与 mtime 未变
  （`24CCBDF9…DD5B5`）。

## 5. 已知限制 / 不在本切片

- 卡上描述是**摘要**，完整条目靠悬停 `ItemTooltip`；而 `ItemTooltip` 自己的描述上限是
  26 字（既有设计），因此最长条目在悬停窗里也是摘要——是否放宽到两行需产品决定，未改。
- 护符卡带 20px 图标时可用宽少 20px，描述会多折一行；未改图标绑定（M3-03）。
- 商店 / 奖励 / 铁砧 / 图鉴 / 局末的统一验收尚未做，§12 该条保持未勾选，本切片只完成整备屏。
