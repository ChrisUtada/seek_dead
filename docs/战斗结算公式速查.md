# 战斗结算公式速查（seek_dead）

> 据源码逐项整理（duel_controller.gd / battle_math.gd），覆盖普通符号、2连/3连、special、克制、破甲、连锁重触发、敌人回合。
> 调参入口：所有 `@export` 常量在 Inspector 改，勿硬编码。平衡铁律见底部「乘区纪律」。

---

## 0. 坐标系（老虎机本体）

| 项 | 值 | 含义 |
|---|---|---|
| `REELS` | 3 | 转轮列数 |
| `ROWS` | 1 | 每列行数 |
| `PAYLINES[0]` | `[[0,0],[1,0],[2,0]]` | 唯一一条 payline：3 列各取第 0 行连成一线 |
| 落子 | 每列从自身 `reel_strip` 随机取 1 格 → `grid[reel][0]` | 频率 = 该装备自身 weight；MISS 占比 = `Σ 装备符号权重 × (1-hit) / 总权重`（2026-08-09 恢复：按 hit_rate 聚合，MISS 格文字显示、kind=trash 不结算） |

> 因为是 1 行 3 格，一条线上**最多只能出现 3 同**。所谓"2连 / 3连"就是同一「符号 + 有效元素」在 payline 上落了 2 格 / 3 格。

---

## 1. 连线判定（counts）

遍历 `PAYLINES[0]` 的 3 个格子，按 **`符号 resource_path + 有效元素`** 分组计数，得 `c`（下面的 `raw`）：

- `c = 1` → 单符号
- `c = 2` → **2 连**
- `c = 3` → **3 连**（满线）

共享符号跨武器时元素可能不同，所以**按「符号 + 元素」算一组**，避免冲突。

---

## 2. 每符号伤害分量（`_contribute`）

先算"这件物品打出去的攻击力"和"这一下的基础值"：

```
item_power   = _weapon_power_map[符号.resource_path]        # 物品 base_power + 元进度武器加成
power_scale  = item_power / BASE_POWER_REF   (若 item_power>0 否则 1.0)
agg_flat     = run_power_bonus + charm_power_bonus
             + Σbuff("power") + gold_upgrades["power"] * POWER_STEP
flat         = sym.base * power_scale + agg_flat
             = sym.base + (sym.base*power_scale - sym.base + agg_flat)   # bonus = 括号部分
em           = ElementCounter.multiplier(elem, enemy_element)   # 克制>1 / 抗性<1 / 中性=1
```

**连线倍率 `mult`**（关键）：

```
mult = raw + ( gold_upgrades["line"] * LINE_STEP   if raw >= 2   else   0 )
```

| 情况 | raw | mult（默认 LINE_STEP=1，无 line 升级） |
|---|---|---|
| 单符号 | 1 | **×1** |
| **2 连** | 2 | **×2**（有 line 升级则 ×(2+line*LINE_STEP)） |
| **3 连** | 3 | **×3**（有 line 升级则 ×(3+line*LINE_STEP)） |

> 注释原文：普通符号单颗即结算，出现 n 次 ×n。line 升级（连线精通）只在 `raw>=2`（确为连线匹配）时叠加，不假造单符号爆发。

按 `kind` 结算到累加器 `acc`：

| kind | 公式 | 备注 |
|---|---|---|
| `damage` | `dv = flat * mult * em`；`pierce_armor?→pierce:dmg`；三连 ×`crit_mult_val` | 吃 power_scale / agg_flat / 元素克制；`raw>=3` 触发武器 `crit_mult`（方案 A） |
| `shield` | `+= sym.base * power_scale * mult * crit_mult_val` | **不吃** agg_flat、**不吃** 元素克制（强度轴缩放）；三连同样 ×`crit_mult_val` |
| `heal` | `+= sym.base * power_scale * mult * crit_mult_val` | 同上 |
| `status` | `acc.status_stacks[type] += mult * crit_mult_val` | 每层 = 1 连线点，三连 ×`crit_mult_val`（方案 A 起全部类型同源暴击） |
| `special` | 见下 | 见 §3 |

---

## 3. special 符号规则（爆发核心）

```
crit_mult_val = item.crit_mult（来自 LoadoutItem，默认 2.0；仅 raw>=3 生效，否则 1.0）
# 方案 A：所有符号类型（damage/shield/heal/status/special）三连统一按 crit_mult_val 结算
sv   = flat * mult * em * crit_mult_val
pierce_armor? → pierce : special
```

| 任意符号 落点 | 行为 |
|---|---|
| 1 同（raw=1） | 生效，`v = flat * 1 * em`（无连线加成、无暴击） |
| **2 连**（raw=2） | `v = flat * 2 * em`（连线倍率生效，无暴击） |
| **3 连**（raw=3） | `v = flat * 3 * em * crit_mult_val（**暴击 ×crit_mult_val**，默认 ×2.0） |

- special 三连埋点 `acc["special_triple"] = true` → 触发反制破甲（§5）与连锁续发（§7）。
- 克制元素三连埋点 `acc["counter_triple"] = true`（仅当 `em>1.0 且 raw>=2`）→ 触发核爆（§5）。
- ⚠ 方案 A（2026-08-04）：退役硬编码 `SPECIAL_TRIPLE_CRIT`，改为 `LoadoutItem.crit_mult`（强度轴，可由 .tres 定 2.0~3.0 制造稀有度纹理）；普通符号三连终于有「暴击感」，special 保留破甲+连锁。

> ⚠ 暴击按"实落数"判定，line 升级只改 `mult` 不假造三连暴击。

## 4. 阶段 1：防御 / 增益 / 状态先落地（`_evaluate` 上半）

顺序很重要（buff 当回合即生效，命中当回合就吃到）：

1. **buff 符号**（kind=buff）先结算：`_grant_buff` → 剩余回合 `add = max(1, buff_turns) * mult`。
2. **金币符号**：`g = GOLD_PER_COIN(=1) * c` 直接加 `gold`（不造成伤害）。
3. 常规符号（damage/shield/heal/status/special）走 §2/§3 累加到 `acc`。
4. 落地：
   - `player_shield += acc.shield + _agg_shield()`（铁壁 buff + 守望护符 trickle）
   - `player_hp = min(max, hp + acc.heal + _agg_regen())`
   - `enemy_status[type] += acc.status_stacks[type]`

---

## 5. 反制即爆发（Plan C）

结算完阶段 1 后判定（**counter 优先于 special**）：

```
if acc.counter_triple:        # 克制元素三连
    _on_counter("element")
elif acc.special_triple:      # special 三连
    _on_counter("special")
```

`_on_counter(kind)`：
- **始终**：若 `enemy_armor > 0` → 护甲清零（开启"伤害直击 HP"的破甲窗口，对所有敌人通用）。
- `kind == "element"`：**额外核爆** `burst = enemy_hp_max * 0.20`，穿透直击 HP。

## 6. 阶段 2：攻击结算（乘区链）

```
buff_mult       = charm_damage_mult * (Π buff("damage_mult")) * [1 + min(gold_upgrades["joker"]*JOKER_STEP, JOKER_CAP_FACTOR-1)]
assault         = assault_next_spin            # 强袭药剂倍率（用后清零）
normal_subtotal = acc.dmg + acc.special * chain_mult
pierce_subtotal = acc.pierce
normal_total    = int(normal_subtotal * assault * buff_mult * TEST_PLAYER_DMG_MULT)
pierce_total    = int(pierce_subtotal * assault * buff_mult * TEST_PLAYER_DMG_MULT)
total           = normal_total + pierce_total
```

破甲 / 掉血（`_apply_enemy_damage`）：
- **非穿透**：先扣 `enemy_armor = min(armor, dmg)`，溢出部分进 `enemy_hp`。
- **穿透**（pierce）：直接扣 `enemy_hp`。

> `chain_mult` 仅作用于 **special 部分**（见 §7）；`acc.dmg` 部分不享受连锁。

### 完整单发伤害公式（以普通 damage 符号、无连锁为例）

```
单符号(raw=1)   dv = flat*1*em
2 连(raw=2)     dv = flat*2*em
3 连(raw=3)     dv = flat*3*em
→ 最终该符号贡献 = int( dv * assault * buff_mult * TEST_PLAYER_DMG_MULT )   （非穿透先破甲）
```

special 三连单发：
```
sv = flat * 3 * em * 2.0 * chain_mult
→ 最终 = int( sv * assault * buff_mult * TEST_PLAYER_DMG_MULT )
```

## 7. 连锁重触发（`_on_spin_pressed`）

```
_chain = 0
loop:
    chain_mult = 1.0  if _chain==0  else  CHAIN_STEP ** _chain   (CHAIN_STEP=1.5)
    await _evaluate(chain_mult)
    if not _last_special_triple or enemy_hp<=0: break
    _chain += 1
    if _chain >= CHAIN_MAX(=4): break
    免费 _begin_spin() 重转
```

- 续发条件：**本发产生 special 三连**（`_last_special_triple`）。
- 连锁倍率只作用 special 部分：`acc.special * chain_mult`。
- 封顶：`CHAIN_MAX=4` 发，最高 `CHAIN_STEP^3 = 1.5^3 = ×3.375`（第 0 发 ×1，第 1 发 ×1.5，第 2 发 ×2.25，第 3 发 ×3.375）。
- 连锁是否续上看 RNG 是否再给 special 三连——是**可见的尖峰**，非黑箱级联。

## 8. 敌人回合（`_enemy_turn`）

`enemy_intent` 决定：

| 意图 | 行为 |
|---|---|
| `attack` / `heavy` | `_enemy_deal_damage(value 或 enemy_atk)` |
| `jam` | 下一轮某列被废铁占据 |
| `lock` | 下一轮某列固定不变 |
| `chaos` | 下一轮权重打乱（优势符号削弱） |
| `none` | 落空（被净化） |

敌人伤害闸口 `_enemy_deal_damage`：
```
atk_down = 1 - min(0.5, frost*0.2 + poison*0.2)    # 敌人被削弱（状态 debuff）
eff      = round( raw * atk_down * boss_atk_mult )
blocked  = min(player_shield, eff)
dealt    = eff - blocked
player_shield -= blocked ; player_hp -= dealt
```

状态 DoT（`_tick_status`，在敌人回合内）：
```
dot += int( round( enemy_status[st] * status_base * status_element_mult * TEST_STATUS_DMG_MULT ) )
enemy_status[st] -= 1
```
`TEST_STATUS_DMG_MULT=3.0`（灼烧/毒等 DoT 永久倍率）。

回合末 `_tick_buffs`：所有玩家 buff 剩余回合 −1，到期清除。

## 9. 关键常量表（Inspector 调参）

| 常量 | 默认 | 作用 |
|---|---|---|
| `BASE_POWER_REF` | 32.0 | base_power 归一化支点 |
| `TEST_PLAYER_DMG_MULT` | 1.5 | 玩家直击总伤害永久倍率 |
| `TEST_STATUS_DMG_MULT` | 3.0 | 状态 DoT 永久倍率 |
| （已退役）`SPECIAL_TRIPLE_CRIT` | — | 方案 A 改为 `LoadoutItem.crit_mult`（默认 2.0，普通/special 三连同源）；见 §3 |

| `CHAIN_MAX` | 4 | 连锁重触发上限（发数） |

| `MISS` 符号 | 占比随装备 `hit_rate`（0.78~0.90 → MISS 10~22%） | 2026-08-09 恢复；kind=trash 不匹配/不结算，可滚过规避 |

| `WEAPON_HIT_STEP` | 0.05 | 每级武器命中率 +5%（降废铁） |

## 10. 乘区纪律（架构铁律，勿破）

1. **战斗内只许 `special` 连锁重触发这一处局内乘区**。新主动操作/协同可改符号命中/保留/强度，但**不轻易开新伤害乘区**。
2. 强度轴（物品 `base_power`/`hit_rate`/`element`）只定伤害，**不定频率**；频率轴（per-item `weight`）只定出现次数，**不定伤害**。稀有度只定强度。
3. 膨胀/策略放 build 层（武器/技能/护符/协同）；战斗内结算保持"3 乘区"清晰：连线数 × 克制 × （护符/增益/强袭/连锁/共鸣）。
4. 平衡常量已 `@export`，调参走 Inspector，**勿硬编码**；纯数学改动落 `battle_math.gd`。
