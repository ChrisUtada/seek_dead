## 0. 结论（一句话）

把"RPG 的强度"与"老虎机的频率"拆成**两个互不越界的轴**：**强度轴交给物品**（稀有度 / 攻击力 / 命中率 / 克制），**频率轴留在符号**（由 `kind` 自动派生）。符号的 `rarity_tier` 字段退役，频率改为 `kind → 档位` 的纯函数。这样既满足用户"稀有度在物品上"的诉求，又不会让神装"打不出去"。

---

## 1. 用户需求（原始三条）

1. **武器/技能 = 符号**：武器与技能就是符号的来源，因此符号的稀有度**由武器/技能的稀有度决定**（而非符号自带）。
2. **武器 = 经典 RPG 装备**：含攻击力 + 克制属性 + 命中率（命中率 ≈ 废铁），且这些属性**可升级**。
3. **技能 = 经典 RPG 分类**：含远程攻击、buff 加成、恢复等形态（而非当前只能塞一个 buff）。

---

## 2. 现状诊断（对照代码实证）

| 用户需求 | 现状（代码实证） | 差距 |
|---|---|---|
| ① 稀有度由物品决定 | `rarity_tier` 写在**每个 SymbolData 上**（S1 落地），武器 `WeaponData` 无稀有度字段 | 稀有度挂错层——该在物品 |
| ② 武器 = 攻击力+克制+命中率，可升级 | 攻击力三处缝合：`symbol.base` + `meta.weapon_base_bonus`(`_weapon_base_map`) + `_agg_power_flat`；克制在 `weapon.element`；**命中率不存在**，废铁是 S5 全局池级注入（按幕 15~23%，与具体武器无关） | 攻击力散落、命中率缺失、废铁是"全局税"而非"武器属性" |
| ③ 技能按 RPG 分类 | `SkillData` 只能提供**一个 buff 符号**（haste/rage），无攻击/恢复形态 | 技能形态单薄 |

**根本问题**：当前是"**符号中心**"——符号是原子、自带稀有度，武器只是符号搬运工。目标转为"**物品中心**"，但频率不能全盘上移（见 §3）。

## 3. 核心洞察：稀有度其实有两个轴（混合式的由来）

> ⚠ 这是整方案的关键前提，必须先确立，否则会自伤。

- **强度轴（power）**：传说武器 → 符号数值更强、命中更高、升级上限更高。✅ 该跟物品稀有度走。
- **频率轴（frequency）**：符号在转轮上出现多少次。

**如果频率也跟物品稀有度走 → 灾难**：传说武器"稀有" → 它的符号很少出现 → 你装备了神装却打不出去 = 废品。违背 RPG 直觉。

**结论（混合式）**：
- **物品稀有度 → 只决定强度**（base_power 量级、命中率基线、升级上限、商店价、掉落稀有度）。
- **符号频率 → 仍按"角色"治理**：攻击符号是主体、special（爆发）保持低频（唯一局内乘区，频率必须稀有）。频率与物品稀有度**解耦**。

---

## 4. 频率 = f(kind)：`rarity_tier` 退役

这是混合式最省事的地方——频率档**根本不用手填**，由 `kind` 自动派生：

| `kind` | 自动频率档 | 理由 |
|---|---|---|
| `damage` / `status` | 高频（主体） | 输出主力，该常见 |
| `special` | **低频（爆发）** | 唯一局内乘区，必须稀有（无论武器多神） |
| `buff` | 中频 | 增益点缀 |
| `gold` | 工具档 | 经济来源 |
| `trash` / `miss` | 填充档 | 由 hit_rate 决定 |

→ 频率 = f(kind)，强度 = f(物品 rarity)。**两个轴都是派生值，不在任何处手填稀有度**。
→ 现有 S2/S3/S6 的保底/上限治理**原样保留**，只是判定键从 `rarity_tier` 换成 `kind` 映射出的档。

## 5. 目标数据结构

### 5.1 物品层（武器 / 技能统一为 `LoadoutItem` 基类，待确认 #2）

```gdscript
# LoadoutItem（武器/技能的共同基类）
@export var category: String    # "weapon" | "skill"  —— 槽位/UI 分列依据
@export var rarity: Rarity      # 强度档位 + 升级上限 + 商店价（不定频率！）
@export var base_power: float   # 攻击力 / 效能（升级主通道，需求②）
@export var hit_rate: float     # 命中率（miss = 废铁，可升级，需求②）
@export var element: String     # 克制属性（通常固定）
@export var symbols: Array[SymbolWeight]  # 该物品贡献的符号（结算单元，不再自带 rarity）
```

### 5.2 符号层（SymbolData 减负，`rarity_tier` 退役）

```gdscript
@export var kind: String        # 结算行为 + 频率档来源
@export var base: float         # 数值偏移（相对 base_power 的权重）
@export var status_type: String
@export var element: String
```

> 符号只保留结算字段 + 角色（`kind`）。稀有度、攻击力、命中率、克制**全部上移到物品**。

## 6. 转轮池构建（对每件装备跑一遍）

1. **符号格**：按 `kind → 频率档` 给格数（special 少、damage 多）——频率轴。
2. **miss 格**：按 `hit_rate` 补废铁格（`1 - hit_rate` 越多 miss 越多）——强度轴的命中。
3. **强度**：物品 `rarity` + `base_power` 写入该物品符号的结算。

> 注入顺序建议（取代当前 S5 全局 trash）：
> 池符号（含 miss 格） → 最小带长平铺 → S4（符号私有化后删除，见 §8）→ S2/S3（保底/上限，按 kind 档）→ 洗牌。

---

## 7. 结算公式

```
伤害 = (物品 base_power × 符号 base 偏移) × 连线 × 克制(物品 element)
```

- 频率在转轮阶段已定型，结算只管强度。
- **没有新增任何伤害乘区**：`base_power` 是线性基础轨（契合双轨膨胀）；`hit_rate` 是频率不是乘区；`element` 是已有克制乘区。
- 唯一局内乘区仍是 special 三连连锁重触发（保留）。

## 8. 完整走查：传说火焰剑 vs 普通铁剑

| | 普通铁剑 | 传说火焰剑 |
|---|---|---|
| `rarity` | common | epic |
| `base_power` | 12 | 30 |
| `hit_rate` | 0.75（25% miss） | 0.92（8% miss） |
| `element` | none | fire |
| 转轮 | 铁斩(高频) + **25% 废铁** | 火斩(高频) + 火special(低频) + **8% 废铁** |
| 结算 | 12 × 连线 × 1.0 | 30 × 连线 × 克制(弱火 ×1.5) |
| 升级 | base_power↑ / hit_rate↑ | 同 |

**重点**：传说剑**又强（30>12）又准（92%>75%）**，但它的 `火special` 和普通剑的 special **一样低频**——稀有度让它更强更准，却没让爆发变廉价。这就是混合式不犯"神装打不出去"的原因。

## 11. 已确认的 3 个决策点（2026-08-03 用户拍板，按 AI 建议执行）

1. ✅ **频率 = f(kind)**（`rarity_tier` 退役）：符号频率档由 `kind` 自动派生，稀有度只定强度。采纳理由——避免"神装打不出去"，且频率档零手填、S2/S3/S6 治理逻辑原样保留（仅改判定键为 kind 映射档）。

3. ✅ **符号私有化**：每个物品的符号不跨物品共享（火焰剑的 burn ≠ 火焰法杖的 burn），从根源消除"共享符号累加垄断"，S4 `_enforce_symbol_cap` 可删。用户已知悉代价：失去"叠 burn"的火系 build 累加爽感，换取频率治理简化与无垄断。

## 12. 设计取舍记录（讨论中的评估结论）

> 供后续回顾，非动工依据。

- **纯物品中心（频率也跟物品稀有度）是退步**——神装打不出去。故采用混合式（频率留符号层）。
- **"命中率 = 废铁"是全方案最稳赚的一步**——比 S5 全局 trash 税更优雅、更 RPG；难度刹车回归由敌人 ante 涨血涨攻承担（已存在），但 ante 曲线需重新审视以补足失去的稀释。
- **转轮必须永远有 miss 是老虎机隐藏约束，RPG 模型没有**——hit_rate 不能趋近 100%，需人为留底（如 common 最低 70%），否则高命中神装让稀释刹车失效、转轮变无脑。
- **符号私有化会失去"叠 burn"爽感**——治病同时切了爽点，净收益待 F6 实测判断。
- **S1–S8 不后悔**——它教会我们"稀释/垄断/爆发稀有"三类失败模式，这些教训在任何模型下都需处理。

**改动清单**
1. **`_contribute` 攻击力改读 `base_power`（清三处缝合）**：
   - 旧：`flat = sym.base + _agg_power_flat() + _weapon_base_map.get(sym.resource_path, 0)`——伤害由「符号自身 base + 元进度聚合 + 每符号 meta 映射」三处缝合，武器强度被 smuggle 进 per-symbol map。
   - 新：`_weapon_power_map[符号] = 物品 base_power + meta.weapon_base_bonus`（在 `_build_pool` 构建，共享符号取最高）；`_contribute` 内 `scale = item_power / BASE_POWER_REF`，`flat = sym.base × scale + _agg_power_flat()`。
   - `damage` / `special` 走 `flat`（含 base_power 缩放 + 元进度聚合 + 元素克制）；`shield` / `heal` 走 `sym.base × scale × mult`（随 base_power 缩放，但不吃伤害元进度 `_agg_power_flat` 与元素克制，符合其防御/治疗语义）。
   - 未命中映射（异常路径）退化为 `scale=1.0`（旧模型），保证非武器符号不丢伤害。
2. **`BASE_POWER_REF` 常量（=32.0）**：base_power → 伤害的归一化支点。`base_power == REF` 的武器，符号伤害等于 `sym.base`（即旧模型数值）；高于 REF（高稀有度）按比例放大（落实「稀有度→强度」），低于则缩小。此为**调参旋钮**：P11 内容广度阶段会把 `sym.base` 重标为相对 base_power 的真正偏移比，届时可去掉 REF 归一化。
3. **删 wild（百搭符）**：`const WILD_SYMBOL` / `WILD_FRAC` 常量删除；`_build_strips` 注入块删除；`_evaluate` 的 wild→special 计数合并逻辑删除；`_enforce_kind_tier` 排除项删除；`resources/symbols/wild.tres` 经 `git rm` 删除。用户此前已认定 wild 在 REELS=3/ROWS=1 下近似废铁、是 debuff，物品中心模型里无归属。
4. **删 `SymbolData.rarity_tier` 字段**：`symbol_data.gd` 去字段定义；15 个非 wild 符号 .tres 去 `rarity_tier =` 行。频率治理在 P2 已全面改读 `kind`，该字段自 P2 起即为死字段。

**伤害公式（最终）**
```
伤害 = (物品 base_power ÷ BASE_POWER_REF) × sym.base × 连线 × 克制(物品 element) ＋ 元进度聚合(_agg_power_flat)
```
- `base_power` 是物品固有强度（P1 落地）；`sym.base` 暂为绝对值（P11 重标为相对偏移比）；`_agg_power_flat` = run/charm/buff/gold 元进度，非物品固有、正确保留。

**待 F6 验证点（P3 回归重点）**
- 伤害数值是否如预期：`BASE_POWER_REF=32` 下，平均武器（base_power≈32）伤害≈旧模型；稀有武器（flame_staff 50）→ ×1.56；普通武器（iron_sword 18）→ ×0.56。若整体偏强/偏弱，调 `BASE_POWER_REF` 或 `TEST_PLAYER_DMG_MULT`。
- 护盾/治疗符号是否随武器 base_power 合理缩放，不出现异常数值。
- special 三连爽点（暴击 ×2 + 连锁）是否仍稳定触发（频率由 P2 KIND_SHARE 决定，P3 不影响频率）。
- wild 删除后转轮无百搭干扰、special 三连更难但更"干净"（符合用户判定）。

## 18. P6 落地说明（频率层重构：装备自洽 / per-item weight，2026-08-04）

> 频率层重大转向：退役中央 f(kind) 预算，改为「每件装备用自身 weight 决定自己符号多常出现、用自身命中率决定自己转轮废铁占比」的直觉模型。用户判定"武器自决频率"更符合直觉（见对话：铁剑带治疗/格挡的违和感、weight 字段失效的困惑）。本机无 Godot，需用户 F6 真机验证。

**动机**
- 旧 f(kind) 把频率收归中央、按 kind 预算统一发牌，武器/技能的 `.tres` 内 `weight` 字段完全失效，导致"铁剑带治疗很奇怪"却无法靠 weight 解释、也无法让铁剑精简成"铁斩+special"就让它频率变纯粹。
- 用户要求"由武器决定自己的符号多常出现"。per-item weight 即此：每件装备频率 100% 由它自己的 weight 决定，与稀有度/中央预算无关。

**机制（duel_controller.gd）**
- `_build_pool` 现在产出结构化 `pool_items`（每件装备一段 `{name, hit, syms:[[SymbolData, weight, element]]}`），并仍产出扁平 `pool`（供图例/状态查询/奖励等 legacy 消费者，HUD 完全不用改）。
- `_build_strips` 改为：**每件装备用自身 weight 生成一段等长（_ITEM_STRIP_TARGET=16）的「自洽子带」**，按 `cnt = maxi(1, roundi(target * w/wsum))` 分配符号格（权重越大越常出现）；该装备废铁格 = `roundi(target * (1 - 自身命中率))`，夹在 MISS_FLOOR/CEIL；所有装备子带拼接 + `_GOLD_CELLS=2` 金币常驻 → 洗牌成 3 根转轮副本。
- 共享符号不再跨装备累加权重（每件装备子带独立、互不挤压），垄断根因结构性消除；稀有度仍只定强度，不影响出现次数。

**移除（死代码）**
- 常量 `KIND_SHARE` / `KIND_CEIL`；函数 `_enforce_kind_tier`；变量 `_pool_miss_frac`；chaos 池操作 `_apply_chaos_pool` / `_restore_pool` / `_pool_backup`（乱权改为在 `_build_strips` 向整带注入额外废铁，忠实还原"等比重削弱所有装备"意图）。

**保留（不受影响）**
- 3 根转轮共享视觉、落点由玩家停止时机决定；`_evaluate` 结算 / special 三连暴击破甲 / 连锁免费重转 / 强度轴缩放（`_weapon_power_map`、BASE_POWER_REF）全部不变。HUD 不改动。

**连带效应（正面的，已被后续决策推翻，保留作历史）**
- 铁砧屏 `meta["weapon_upgrades"]`（主符号权重锻造）**不再是死代码**：per-item 下所加权重直接提升该武器主符号出现频率，铁砧点数有了真实反馈（§17 的 TODO 已解）。
- ⚠️ **2026-08-05 修订**：上述「铁砧 = per-item 强化」方向已被 `商店升级重构_执行方案.md` §6 推翻。最新定案中铁砧 = **纯 gacha**，`weapon_upgrades` / `interference_resist` 等 per-item 旋钮**退役（待代码清理）**，故本条「不再是死代码」结论**已失效**——这些旋钮重新变回待清理的死代码。本段仅记录 P5 当时的落地状态。

**调参入口（替代原 KIND_SHARE）**
- 改某符号频率 → 改该装备 `.tres` 内对应符号的 `weight`（同装备内权重越大越常出现）。
- special 爆发频率偏低（因 special weight 通常小）→ 想更常触发 special 三连，调高各装备 special 符号的 `weight`，或加一把 special 权重高的武器/技能；不再有全局 special 预算旋钮。
- `_ITEM_STRIP_TARGET`（每件子带长）、`MISS_FLOOR`/`MISS_CEIL`（废铁占比兜底）仍可整体调。

**设计取舍**
- **未拆成"每件装备独立可见转轮"**：保留 3 转轮共享视觉以零改动 HUD、零风险（本机无法 F6）。频率逻辑已是 per-item 自洽；若后续想要"每把武器一根可见转轮"，需把 REELS 改动态=进池装备数并改 HUD cells 布局（更高风险，留作可选 follow-up）。

**待 F6 验证点（P6 回归重点）**
- 铁剑 `.tres` 的 weight(铁斩6/格挡3/治疗1/特殊1) 是否真实反映到转轮占比（铁斩明显最高频、治疗/特殊为小保底）。
- 带 recovery 技能 / 火焰剑后，各装备符号按各自 weight 混合，无跨装备累加垄断。
- 低命中武器（如 hit_rate 0.80）自身转轮废铁占比约 20%，高命中武器废铁更少。
- 铁砧锻造某武器主符号后，该武器主符号出现频率上升（铁砧不再无效）。
- special 三连触发频率：若明显低于旧 KPI（每房≥1），调高各装备 special weight（这是预期内的调参动作，非 bug）。
