## 2. 界面结构

```text
普通 / 精英胜利
→ 战利品阶段
   标题：{来源名} · {品质名}战利品        例：普通战 · 进阶战利品
   副标题：同层三选一：三项品质相同，按用途与当前 Build 选择
   三张卡：品质名 + 物品名 / 结果行 / 条件行；机制与完整条件进 tooltip
   底栏：重抽 · 同层    跳过 · 金币 +N
→ 选卡 / 重抽 / 跳过（结算一次）
→ 成长阶段（仅当本房真实触发技艺或铭印）
   标题：成长 · 技艺 / 铭印
   一张卡 + 页头本局成长摘要
   底栏：保留到下次战斗
→ 收尾：铁砧点 / 金币 / 掉落 → 间歇或棋盘
```

BOSS 仍走专属战利品屏（保留主题池、BOSS 信物、空池铁砧兜底），本步只统一卡面品质显示；
BOSS 触发的成长继续留在队列，进入下一战斗房的成长位。

## 4. 交互状态与纪律

| 操作 | 入口 | 结果 |
|---|---|---|
| 查看 | 悬停卡片 | tooltip = 机制 + 条件 + 结果（含替换说明） |
| 确认 | 点卡 | 按 build 时冻结的 payload 结算一次 |
| 替换 | 满槽点武器卡 | 替换弹层；选定旧武器后 `settle_loot_replace` 结算一次；取消留在本屏 |
| 转化 | 点重复 / 满槽卡 | 金币或熟练（Step 6 规则），展示值即结算值 |
| 重抽 | 底栏「重抽 · 同层」 | 只换同层候选；品质层 / 跳过金币 / 标题不变 |
| 跳过 | 底栏「跳过 · 金币 +N」 | 结算冻结金币一次，然后照常进入成长阶段 |
| 保留 | 成长阶段「保留到下次战斗」 | 不发放任何东西，成长队列原样保留 |
| ESC | `ui_cancel` | 战利品阶段：只吞输入，不结算不关闭；成长阶段：等于保留 |
| 整体跳过（bot / 旧路径） | `_on_reward_skip_pressed` | 跳过战利品 + 放弃本次成长（队列保留），直接收尾 |

只结算一次由 `RewardSystem._loot_settled` 统一保证：重复点击、重复结算、替换后再结算都返回
`already_settled`；结算失败（例如槽位竞争）不置位，不消耗机会。
