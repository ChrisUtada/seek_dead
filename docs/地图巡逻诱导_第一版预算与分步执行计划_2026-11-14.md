# Seek Dead · 地图巡逻与诱导：第一版预算与分步执行计划

> 日期：2026-11-14  
> 状态：Step 0 / 0.5 / 1 / 2 / 3 / 4 已完成（开发／AI 测试入口）；正式入口待 Step 5A 后开放；全量 56 套回归 ALL GREEN（2026-11-14 15:45，11m53s，见 `docs/baseline/2026-11-14_smoke_56/`）  
> 目标：为每个 ACT 制作一张真正有玩法、可理解、可重复探索的地图。  
> 核心：**地图负责观察、移动、等待、绕行与诱导；转轮负责战斗与成长结算。**

## 1. 第一版目标

### 1.1 单幕目标

- 一张逻辑地图；
- 首次完整探索约 **50–70 分钟**；
- 熟练使用固定路线后可缩短到约 25–40 分钟；
- 玩家能够清楚理解怪物下一步、陷阱收益和当前路线；
- 不使用扫雷数字，不使用行动点转轮，不把地图退化成节点选择器。

### 1.2 固定预算

| 项目 | 第一版预算 |
|---|---:|
| 逻辑地图 | **14×9，126 格** |
| 实际可行走格 | **55–70 格** |
| 普通战斗 | 10–14 场 |
| 精英战 | 2–3 场 |
| BOSS | 1 场 |
| 总战斗数 | **14–18 场** |
| 武器／装备宝箱 | 3–5 个 |
| 商店 | 1–2 个 |
| 休整点 | 1–2 个 |
| 特殊事件 | 3–5 个 |
| 破甲／控制类陷阱 | 2–4 个 |
| 同屏巡逻怪 | 默认 1 只，后期区域最多 2 只 |

以上数量是内容预算，不是要求每张地图随机塞满。任一数值调整都要同步更新地图校验和时间模型。

## 2. 核心体验与操作

### 2.1 玩家循环

```text
观察当前地形、奖励与怪物预告
→ 移动 / 等待 / 绕行 / 回访
→ 地图推进一个回合，怪物执行公开行动
→ 触发宝箱、事件、陷阱或战斗
→ 转轮完成战斗并获得成长
→ 返回地图继续规划
→ 准备后主动挑战 BOSS
```

### 2.2 地图操作

| 操作 | 规则 |
|---|---|
| 点击相邻可行走格 | 移动一格并推进一个地图回合 |
| 等待 | 原地不动，推进一个地图回合 |
| 查看目标 | 只读信息，不推进回合 |
| 查看构筑 | 只读，不改变地图或 RNG |
| 回访已探索格 | 不重复领取奖励，不重复触发已消耗内容 |
| 撤回整备 | 沿用现有撤回规则，不发放未结算奖励 |
| 挑战 BOSS | 玩家主动确认，不因探索率强制开门或锁门 |

### 2.3 硬性边界

- 不用转轮决定基础移动方向；
- 不设置移动行动点；
- 不让怪物无预告瞬移；
- 不用随机即死陷阱；
- 不让所有怪物都动态追踪玩家；
- 不根据玩家 Build 或 HP 暗改怪物强度；
- 不把全图清空设为唯一正确路线；
- 不靠长时间动画填充地图时长。

## 3. 地图结构与内容布局

### 3.1 三个区域，一张逻辑地图

地图内部按视觉和功能分为三个区域，不切换独立关卡：

| 区域 | 目的 | 内容重点 |
|---|---|---|
| A · 入口区 | 教会移动、等待与诱导 | 1 只巡逻怪、1 个陷阱、1 个基础宝箱 |
| B · 交汇区 | 路线取舍与 Build 补强 | 商店、休整、精英、2 条分支路线 |
| C · 深层区 | 综合应用与 BOSS 准备 | 最多 2 只巡逻怪、稀有奖励、BOSS 入口 |

区域之间使用明显的地形、门框或地板色区分，不增加读图成本。

### 3.2 路线要求

至少提供三类路线：

| 路线 | 成本 | 收益 |
|---|---|---|
| 稳妥路线 | 普通战斗较多，消耗 HP／消耗品 | 稳定成长与基础装备 |
| 精英路线 | 更高战斗压力 | 高阶铭印、护符或稀有装备 |
| 诱导路线 | 需要观察巡逻和使用陷阱 | 降低战斗压力或获得额外战利品 |

要求：

- 起点到 BOSS 至少存在一条无需特定装备的可达路径；
- 关键路线不能被随机巡逻永久堵死；
- 重要奖励不能被不可恢复的地图状态永久锁死；
- 精英可绕行，BOSS 可提前挑战；
- 不设计必须全图清空才能获得最大收益的固定答案。

### 3.3 巡逻规则

每只巡逻怪至少配置：

| 字段 | 说明 |
|---|---|
| 怪物资源 | 对应现有房间与战斗机制 |
| 起点格 | 固定或由模板冻结 |
| 巡逻路径 | 明确、可循环、可预测 |
| 当前路径索引 | 决定下一格 |
| 下一步预告 | 地图和详情面板同步显示 |
| 警戒范围 | 默认相邻格，不做隐藏扩大 |
| 接触结果 | 进入现有转轮战斗，不额外扣血 |
| 陷阱结果 | 开局破甲、损失 HP 或控制窗口，最多一种主效果 |

规则：

- 怪物只在玩家移动或等待后行动；
- 预告与实际移动必须一致；
- 怪物路径不因为查看、取消或重开界面改变；
- 怪物不进入墙体、已消耗出口或不可行走格；
- 多只怪物行动顺序固定，不用随机顺序；
- 接触怪物后若进入战斗，地图状态在战斗返回时保持可解释。

### 3.4 陷阱规则

首版只使用一种基础陷阱：**破甲陷阱**。

- 位置始终公开；
- 触发后向玩家显示“下一场战斗：敌方护甲 X → 0”；
- 不直接秒杀怪物；
- 不跳过转轮战斗；
- 同一只怪物只能从同一陷阱获得一次该效果；
- 玩家主动踩陷阱不能受到无预告伤害；
- 陷阱触发和战斗进入顺序固定，不能重复刷效果。

后续增加其它陷阱时，每次只新增一种，并单独完成测试。

## 4. 镜头与 UI 预算

### 4.1 地图显示

- 主视口一次显示约 `8×6` 至 `9×7` 格；
- 镜头跟随角色，但不改变地图逻辑；
- 格子必须能清楚显示角色、怪物、陷阱、宝箱和下一步箭头；
- 不通过整体缩小把 14×9 地图全部塞入一屏；
- 提供简化小地图或目标追踪，不重复显示完整信息。

### 4.2 右侧信息栏

只显示当前需要的信息：

1. 选中目标名称与类别；
2. 怪物当前格和下一格；
3. 陷阱对下一场战斗的真实影响；
4. 当前 HP、金币和构筑入口；
5. 当前可执行操作。

### 4.3 底部操作栏

```text
移动（点击相邻格） · 等待一回合 · 查看构筑 · 撤回整备
```

文案要求：

- “等待”必须说明会推进地图回合；
- 怪物下一步不能只靠颜色表达；
- 陷阱奖励必须写出具体数值或具体破甲结果；
- 不显示抽象的移动点、探索点、搜寻点。

## 5. 时间预算模型

### 5.1 中位目标

| 部分 | 中位预算 |
|---|---:|
| 12 场普通战 × 约 1.5 分钟 | 18 分钟 |
| 3 场精英战 × 约 3 分钟 | 9 分钟 |
| 1 场 BOSS × 约 5 分钟 | 5 分钟 |
| 地图移动、巡逻与诱导 | 10 分钟 |
| 战利品、商店与整备 | 10 分钟 |
| **单幕中位目标** | **约 52 分钟** |

### 5.2 模型纪律

- AI 的真实运行耗时不能直接视为玩家耗时；
- 使用“每次移动、等待、战斗回合、奖励选择”的独立时间参数建模；
- 分别输出稳妥、精英优先、诱导优先三条路线；
- 同时记录内容数量和战斗回合数，避免用增加 HP 的方式延长游戏；
- 时间不足时优先检查奖励决策和地图路线价值，不直接增加空格或怪物 HP。

### 5.3 预算调整顺序

```text
先调整无效等待与重复操作
→ 再调整战斗节奏
→ 再调整内容数量
→ 最后才调整地图尺寸
```

## Step 0.5 · 前置终局与奖励语义契约

> 目的：在开放正式入口前解决多幕断裂、节点类型缺失和旧测试兼容问题。**不得通过退役 `g7_run3_test` 或 `loot_explore_test` 规避。**

**任务**

1. 多幕终局改为配置驱动，禁止把 BOSS `final` 静态写死：
   - `cfg.acts = 1`：唯一一幕的 BOSS 才结束整局；

2. 建立节点类型注册表：`battle / elite / boss / chest / armory / shop / rest / event`。
3. 明确奖励来源映射：

| 维度 | 自动方法 | 通过条件 |
|---|---|---|
| 地图结构 | 遍历地图数据与寻路 | 尺寸、有效格、内容数量、连通性全部合规 |

| 移动 | 合法／非法输入批量测试 | 不穿墙、不越界、不重复结算 |
| 等待 | 连续等待与查看混合输入 | 等待只推进一次，查看不推进 |
| 巡逻 | 固定输入序列模拟 | 预告与实际位置一致，无永久堵路 |
| 陷阱 | 触发、进战、返回、回访 | 效果只发一次，战斗可正常完成 |
| 战斗联动 | 读取实际护甲与战斗结果 | 地图预告值等于战斗实际值 |
| 奖励 | 领取、重复点击、撤回、战败 | 不重复发奖，图鉴与来源正确 |
| 成长队列 | 选择 queued／选择其它项 | 未选项保留，已选项不重复出现 |
| 保存恢复 | 保存后重新加载并继续输入 | 地图、巡逻、内容消耗和 RNG 状态一致 |
| UI | 自动布局检查与截图 | 无越界、遮挡、不可用按钮 |

AI 报告必须区分：逻辑正确性、路线完成能力、模型时间估算。模型估算不能直接当作真实体验时长结论。

## 8. 停止条件与返工规则

出现以下任一情况，不进入下一阶段：

- 地图尺寸或内容数量超过预算但没有对应时间报告；
- 巡逻预告与真实移动不一致；
- 怪物能穿墙、重复触发战斗或永久堵死路线；
- 陷阱可以无限刷奖励或跳过战斗；
- 查看构筑、取消、重开界面会改变 RNG 或地图内容；
- BOSS 被探索率或装备数量强制锁门；
- 奖励、成长、装备来源发生重复或丢失；
- 出现第二套移动资源、行动点转轮或扫雷规则；
- 自动测试失败或全量回归未通过。

返工时优先修改单个模板或单只怪物，不同时调整地图大小、敌人 HP、巡逻速度和奖励数量。
