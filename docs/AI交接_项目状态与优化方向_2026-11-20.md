## 1. 项目是什么

**Seek Dead**（`project.godot` 名 "Seek Dead Prototype"）——Godot 4.7 / GDScript only 的
俯视角**回合制老虎机肉鸽**。核心玩法：把"改造老虎机"当构筑——转轮由装备符号聚合而成，
玩家按停决定落点，3 行 1 格（REELS=3 / ROWS=1）的落点组合触发伤害/状态/金币等结算。

- 一局流程：整备 → 对决 → 战后三选一 → 房间推进 → 结算 → 铁砧(meta)
- 一局规模：3 幕、24 房 + 真·最终槽（线性；棋盘模式另按路径顺序）
- 复古掌机 UI：viewport 480×270、nearest 过滤、Pixel 字体
- 存档：轻 meta（铁砧点/解锁/图鉴），无本局 Run 存档（G2/G3/G4 验收须单会话内完成）

**规模**（当前）：121 个 .gd 脚本、91 个武器模板、21 个牌谱 `.tres`（20 张生效）、
80 个符号、12 个正式奖励定义、73 个测试脚本。

## 4. 工程铁律（违反会出灾难性 bug，务必遵守）

1. **手写 tscn**：绝不给 `instance=ExtResource` 实例内写覆盖子节点（Godot 重存会剥离 → @onready null）
2. **字体**：`default_font` 指 `.tres`；FontFile.tres 用 Godot 4 格式（only `font_path` + `allow_system_fallback=false`）；`.import` 须 `antialiasing=0/hinting=0`
3. **DeviceFrame**：`sb_frame` 四边 border_width 统一 10，顶边不能 >10（会遮商店/下一房按钮）
4. **删除/移动**：别用 `git rm`/`rm`（安全包装会删整目录 + 残留 index.lock）；用 `git rm --cached` 或文件管理器删后 `git add -A`
5. **工具文件系统分裂**：Bash/git 与 Read/Edit/Write 可能见不同工作树 → `git add -A` 后 `git diff --cached` 验证
6. **Edit 后必验证**：批量 Edit 后 `git diff`；commit 前 `git diff --stat`
7. **Godot 灾难恢复**：删场景先在编辑器关 tab；恢复 `git checkout HEAD -- <dirs>` + `verify_overlays.py` + headless
8. 🔴 **扫 `res://` 目录必须用 `ResourceLoader.list_directory`**，禁 `DirAccess.get_files()`——导出后资源进 PCK + `.remap`，DirAccess 只返回 .gd/.import（编辑器永不复现，只在导出包爆）
9. 🔴 **战斗演出不得消耗全局 RNG**：演出随机走 `RandomNumberGenerator` 实例（`BattleAnimator._rng`）、pixelfx 走 `Px.Rng`，禁 `randf()`
10. **GDScript `:=` 无法推断动态加载对象的无类型返回**：用显式 `var x: Dictionary` / `var b: bool`（G1/G2 同类踩坑 3 次）
11. **异步测试**：测试里 async 调用必须 `await`，否则协程在 `quit()` 后被丢弃、断言不执行
12. **\.tres 不能有 UTF-8 BOM**（Godot 报 `Expected '['`）；新 PNG 须跑 `--headless --path . --editor --quit` 生成 .import

**工具链**：Godot 在 `D:\Godot\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64.exe`（**不在 PATH**）。
用户手动 F6 验证为主；AI 跑 headless 测试：
`"D:/Godot/...exe" --headless --fixed-fps 60 --path . res://tests/<name>.tscn`。
Python 用 `py -3.15`。静态核对用 `verify_overlays.py`。测试常用隔离 APPDATA 避免 meta 污染。
