## 一、游戏概述

### 1.1 游戏名称

- **英文名称**: Seek Dead
- **中文名称**: 寻死者

### 1.2 游戏类型

- **核心类型**: 俯视角动作角色扮演游戏 (Top-Down Action RPG)
- **游戏模式**: 单人模式 / 双人合作模式 / PVP对战模式 / 循环模式

### 1.3 游戏平台

- PC (Steam)
- 支持控制器和键鼠操作

### 1.4 游戏引擎

- Godot 4.x（GDScript）

### 1.5 游戏背景

游戏设定在一个末日废土世界，玩家扮演一名机甲战士，在充满危险的区域中探索、战斗、收集资源，揭开世界的真相。

### 3.1 关卡结构

| HighReward | 7 | 高奖励场景 | P1 |

| Sacrifice | 9 | 献祭场景 | P1 |
| Performance | 10 | 演出/剧情场景 | P2 |

#### 3.1.2 随机场景生成

游戏采用程序化场景生成系统：

1. 确定总场景数
2. 分配入口场景和Boss场景（首尾固定）
3. 随机分配精英场景、高奖励场景、金币场景、献祭场景
4. 填充普通场景
5. 根据难度调整普通场景为简单或困难

**优先级**: P0

#### 3.1.3 场景过渡

- 所有玩家进入睡眠状态后自动切换到下一关
- 玩家死亡后可在复活点复活

## 五、游戏模式

### 5.1 章节模式 (Chapter Mode)

- 按章节逐步解锁关卡
- 每个章节包含多个场景
- 支持简单、普通、困难三种难度
- **优先级**: P0

### 5.2 循环模式 (Loop Mode)

- 无限循环的随机场景
- 每3个场景后出现Boss
- 根据循环次数增加难度
- 通关场景数记录最高纪录
- **优先级**: P1

### 5.3 PVP模式 (PVP Mode)

- 玩家对战
- 计分系统
- 胜利/失败统计
- 特殊PVP AI行为
- **优先级**: P2

- 玩家拥有自己的基地

## 九、技术架构

### 9.1 核心系统

| 系统 | 职责 | 优先级 |
|------|------|--------|
| GameManager | 游戏主入口，全局状态管理 | P0 |
| BattleManager | 战斗场景管理 | P0 |
| UnitManager | 单位生命周期管理 | P0 |
| SkillManager | 技能效果与释放管理 | P0 |
| EventManager | 全局事件分发 | P0 |
| SaveManager | 存档与读档 | P0 |
| AudioManager | 音频播放管理 | P1 |
| UIManager | UI界面切换管理 | P0 |

### 9.2 状态管理

- 使用状态机模式管理战斗单位状态
- 支持暂停/恢复所有单位
- 状态包括：正常、死亡、睡眠、复活等

### 9.3 数据驱动

- 使用 JSON 配置表驱动游戏内容
- 通过 ResourceManager 管理配置数据
- 支持运行时热更新配置

### 9.4 输入系统

- 支持键鼠和控制器
- 使用 Godot InputMap 配置输入映射
- 可自定义按键绑定
