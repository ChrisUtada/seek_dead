## 2. 数据模型

每列保存（方案 §4.1）：

| 字段 | 含义 |
|---|---|
| `position` | 连续位置（单位 = 格子，与带子索引同向；按带长取模） |
| `elapsed` | 本次旋转已滚动时间 |
| `cells_per_second` | 巡航速度（默认 9 格/秒，方案试验区 8–10） |
| `ramp_seconds` | 启动加速段（默认 0.18s，二次速度曲线） |
| `decel_cells` | 停轮减速格数（默认 1 格） |
| `state` | `IDLE / SPINNING / STOPPING / STOPPED / FROZEN / LOCKED / EMPTY` |

### 2.1 速度与位置

- 速度曲线：`f(t) = start + (1-start)·min(t/ramp,1)²`，`start` 默认 0.45。
- 位置用闭式积分（不是逐帧累加位移）：

```text
t ≤ ramp :  p = p0 + v·(start·t + (1-start)·t³/(3·ramp²))
t > ramp :  p = p0 + v·(start·ramp + (1-start)·ramp/3) + v·(t-ramp)
```

因此同一时刻的位置只由时间决定，30/60/120fps 不会累积出不同落点。

### 2.2 中心与预览

- 中心索引 = `floor(position + 0.5) % 带长`，与现有 `ReelSpinView.center_index()` 的 `_frac >= 0.5` 分界一致。
- 预览 = 中心之后第 1..count 格，回绕取模，与 `ReelSystem.next_symbols()` 同口径。
- 冻结/锁轮/空带返回中心 `-1`、落点 `-1`，且不推进位置。

### 2.3 预测落点与吸附

- 停轮请求只记录当前连续位置：`landing = round(position + decel_cells)`。
- 吸附时长：`clamp(2·decel_cells / speed, 0.12, 0.16)` 秒，对应方案 §5 的落地减速区间。
- 吸附位置用二次缓出从请求位置插值到**记录的落点**，落点不会因为后续帧率或输入再次改变。
- 重复停轮同一列返回空字典；吸附完成只上报一次，之后位置冻结。

### 2.4 约束

- 没有任何 `randi/randf` 调用：动画与落点不消耗全局 RNG。
- 不读写 `grid`、不引用 `DuelController`，可在 `--script` 模式单独运行。
