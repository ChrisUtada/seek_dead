## 1. 这一版解决什么

当前实机棋盘是「按钮 + 细连线」：25 个节点挤在画面上半部（y 28–152），下半部空置，
节点只有单字标签，道路是 1px 直线，看不出地牢路线图的感觉（G1 已知问题）。

样稿把 480×270 重新分配：

| 区域 | 坐标 | 高度占比 | 内容 |
|---|---|---|---|
| 顶栏 | y 0–22 | 8% | ACT 名、HP、金币、骰子、已走格数 |
| 地图 | y 24–198 | 64% | 25 节点 / 直角道路 / 区域标注 / 低对比石砖底 |
| 底栏 | y 200–270 | 26% | 选中节点详情、构筑摘要、掷骰按钮与步数说明 |

> 计划写的是「地图约 70–75%」。本版取 64%：点阵字体 8–10px 下，底栏再压就会丢掉
> 「节点详情 + 构筑摘要」两块常驻信息；若评审更想要大地图，可把构筑摘要并入悬停 tooltip，
> 地图可涨到 70%（详见 §5 备选）。

## 2. 节点布局（13 列 × 5 行）

列宽 36px，节点框 34×28；行 y = 24 / 60 / 96 / 132 / 168。

| 行 | 节点 | 说明 |
|---|---|---|
| y 24 | n13 n21 n14 | 上路上尾路：普通 → 休整 → BOSS |
| y 60 | n7 n8 n9 · n15 n22 n16 | 岔路 A 上路 + 上路的第二条尾路 |
| y 96 | n0–n6 | 共享骨架（起点 → 武器 → 精英 → 护符 → 岔路 A） |
| y 132 | n10 n11 n12 · n17 n23 n18 | 岔路 A 下路 + 下路的第一条尾路 |
| y 168 | n19 n24 n20 | 下路第二尾路 |

- 四条尾路各自成行，四个 BOSS 在右端竖排，不必展开说明就能看出「选一条路、打一个 BOSS」。
- 岔路 A 在共享骨架上下各分一条；岔路 B 再从每条中段上下分两条尾路，与 `BOARD_EDGES` 完全一致。
- 道路为直角折线（横 → 竖 → 横），3px 宽，无抗锯齿；只画真实边，不做装饰岔路。

## 3. 视觉语言

| 元素 | 处理 |
|---|---|
| 背景 | 暗紫褐 `#160d13`；地图区略亮 `#1a1016` + 16px 低对比石砖网格 |
| 道路 · 已走 | `#5f4d45`（暖褐，亮度低） |
| 道路 · 未走 | `#3a2b31`（接近底色） |
| 道路 · 合法 | `#d5a33d` 金色（同时高亮目标节点） |
| 当前节点 | 暖白 2px 框 + 底部金色条；棋子为金环圆点，贴在节点右上 |
| 合法落点 | 金色 2px 框 + 右上角金点 |
| 已消耗 | 底色压暗、图标降饱和、文字变灰，仍可悬停查看历史 |
| 普通 / 精英 | 敌人红；精英图标带左右尖刺 |
| BOSS | 金框 + 王冠图标 + 名字前两字（如「溺王」） |
| 武器 / 护符 / 商店 / 休整 / 起点 | 剑 / 菱形护符 / 摊位 / 帐篷 / 阶梯，图标下方保留单字标签 |
| 区域标注 | 「岔路 A」「尾路 → 四座 BOSS」用弱文字，落在空白区不压节点 |

图标全部是几何绘制（矩形、三角、圆），没有引入新美术资源；G3-02 若要换成 16×16 手绘图标，
只需替换 `_icon()` 对应分支，布局与状态框不变。

## 4. 状态样例

样稿固定展示一局「上路 → 第一条尾路」的进行中状态：

- 已走：n0–n9、n13（共享骨架 + 上路 + 尾路第一格）
- 当前：n21 休整营地（回满 25% 后弹补给）
- 合法落点：n14 BOSS（唯一去路，金色道路已连到它）
- 底栏详情：营地的恢复比例、可购买类别、离开不扣费

## 5. 备选（评审时选）

| 方案 | 地图占比 | 底栏 | 取舍 |
|---|---:|---|---|
| A（本样稿） | 64% | 节点详情 + 构筑摘要 + 掷骰 | 信息常驻，地图略小 |
| B | 70% | 节点详情 + 掷骰；构筑摘要改为悬停摘要 | 更像地图，构筑信息要操作才看得到 |
| C | 75% | 只留掷骰条；详情与构筑都进 tooltip | 最像路线图，但新玩家要学 |
