## 1. 底带的正确拆分

```text
底带背景：一条完整外框 + 所有固定槽位 + 中央转轮框 + SPIN 红色底板
├─ 左侧：2 武器 + 3 技能/护符
├─ 中央：3 转轮格 + SPIN 文字按钮
├─ 右侧：4 消耗品 + 金币
└─ 上层：动态图标、数字、悬停框、按下反馈、粒子
```

### 美术底图只画（固定不变）
- 外框和金属边
- 槽位空框
- 中央凸起轮廓
- SPIN 红色横幅底板
- 少量铆钉和装饰

### 绝对不要烘焙进底图（动态内容）
- 武器 / 技能 / 消耗品图标
- 金币数字
- SPIN 文字
- 悬停 / 禁用 / 按下状态
- 停轮闪光 / 牌型高亮

## 2. 花纹简化与明暗层级

### 保留（复古感来自这些，不是花纹数量）
- 1px 近黑色外轮廓
- 1px 铜色主边框
- 上沿 + 左上角少量金色高光
- 中央顶部一个菱形宝石
- SPIN 暗红挂牌
- 左右两端 + 主要分隔处少量铆钉

### 删除
- 每角重复叠加的宝石与卷草
- 多层内外描边
- 槽位间无意义小尖刺
- 大面积金属渐变
- 连续排列的装饰珠点

> 口诀：**普通区域只保留「两层框 + 一个铆钉」，中央转轮与 SPIN 才允许复杂装饰。**
> 让视觉焦点自然落在转轮，而不是整条栏同样花哨。

### 三个明暗层级（当前底图偏暗，需拉开）

| 区域 | 目标表现 |
|---|---|
| 普通槽位 | 深紫黑底 + 暗铜框，保持安静 |
| 中央转轮 | 米白 / 浅灰内腔，**明显高于两侧亮度** |
| SPIN | 暗红底 + 浅金文字，唯一的大面积红色 |
| 金属边缘 | 铜色中间调 + 少量浅金高光，不要整条都亮 |

- 尤其保留中央转轮的**浅色内腔**：更接近示例图，且能让黑轮廓的武器/药水/金币图标更清楚。
- 阴影用 1～2px 错位**硬阴影**，不要模糊阴影或现代发光。

## 3. 坐标与交互（代码已就绪，直接沿用）

坐标表在 `scripts/ui/battle_hud.gd:2677-2685`，已核对无误：

| 常量 | 值 | 说明 |
|---|---|---|
| `BAR_TOP` | 200.0 | 底带上沿 |
| `SLOT_CELL` | 30.0 | 普通槽位 30×30 |
| `WEAPON_SLOT_X` | [20, 52] | 2 武器 |
| `SKILL_SLOT_X` | [84, 116, 148] | 3 技能/护符 |
| `REEL_SLOT_X` | [191, 237, 283] | 3 转轮格（42×42） |
| `BELT_SLOT_X` | [330, 362, 394, 426] | 4 消耗品 |
| `GOLD_SLOT_X` | 455 | 金币 |
| `SLOT_CENTER_Y` | 221.0 | 普通槽位中心 Y |
| `REEL_CENTER_Y` | 219.0 | 转轮中心 Y |
| SPIN 命中区 | 100×18 | `battle_hud.gd:2736` |

三条交互原则：
1. **透明按钮视觉可透明，命中区必须覆盖整个槽位。**
2. **按下反馈只位移 1px 或叠暗色，不改变按钮尺寸。**
3. **固定坐标只在初始化和尺寸变化时更新**，不要每帧重排（避免攻击时页面被拉长、槽位互相挤压）。
