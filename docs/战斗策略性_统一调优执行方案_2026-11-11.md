# Seek Dead · 战斗策略性统一调优执行方案（2026-11-11）

> 状态：Step 1–5 已落地并各有专项文档（2026-11-11）；Step 6 真人体验验收与扩展待执行；数值以各 Step 实测为准
> 依据：玩家体验讨论、`docs/战斗策略与数值结构审查_2026-11-11.md` 的同种子 ACT1 对照数据
> 核心判断：**不是单纯缺少策略，而是高收益组合把策略压缩成单一答案；怪物差异来不及出现，成长又主要放大输出，最终导致“无脑按也能过”与“会按就秒怪”并存。**

---

## 1. 要解决的问题

### 1.1 最优答案过于统一

元素命中可同时获得攻击、必暴、破甲、核爆、穿透和后续爆发。玩家不需要针对敌人，只需要完成元素三连。

三连治疗基础恢复 50 HP，叠加回复后还能更高，使输出与生存也能由同一套高收益操作解决。

### 1.2 怪物技能、攻击和干扰名称多，但战术作用趋同

当前已有 `attack / heavy / jam / lock / chaos / auto_stop`，但实际体验仍有三个问题：

- 普通怪死亡过快，技能与意图来不及出现；
- 干扰常被统一理解为“输出变少”，并通常都用净化解决；
- 玩家用高收益爆发跳过机制，无需识别怪物身份。

因此不能只增加技能名称，必须改变技能出现时机、组合方式与应对关系。

### 1.3 普通战与 BOSS 战节奏断层

同种子对照中：

- 无脑组 0/3 通关；
- 战术组 2/2 通关；
- 只瞄准不用消耗品组 2/2 通关；
- 战术组普通怪平均 1.1 回合，90% 一回合击杀；
- 精英平均 2.0 回合，75% 一回合击杀；
- BOSS 平均 8.5 回合。

前期几乎不需要思考，后期却重复同一套操作，时间长并没有转化为更多决策。

### 1.4 成长没有充分改变打法

如果武器、技艺、铭印和奖励主要提高输出，玩家最终仍会回到同一套元素爆发，而不是形成不同 Build 和打法。

### 1.5 独立流程问题

第 7 房精英胜利后的阻塞已经多次复现，必须作为独立 P0 流程问题处理，不能混入难度或策略结论。

## 2. 调优总原则

1. **先收敛复合收益，再增加怪物差异。**
2. **普通怪特色化，不全部精英化。**
3. **战中调整打法，局间调整 Build，不要求战中临时换装备。**
4. **每种机制至少有两种有效应对，并保留基础兜底。**
5. **普通打法能玩但有成本，正确打法有优势但不是唯一答案。**
6. **不靠堆血、加攻、长动画或增加按钮制造策略感。**
7. **AI 数据只用于机制验证，不用零延迟死亡或 AI 高停中率代替真人难度判断。**

---

## 3. 玩家侧：重建每回合的选择价值

### 3.1 每回合的选择维度

- 停哪个符号：攻击、护盾、恢复、特殊、状态或功能；
- 先停哪一列：是否保留三连、是否接受某列 MISS；
- 是否追求连击：当前收益与后续爆发的取舍；
- 是否使用消耗品：现在救场还是留给后续高压；
- 是否抢攻：承担伤害换收尾，还是继续稳守；
- 是否在恢复窗口爆发：破甲、三连、充能或普通输出。

### 3.2 不同局面的目标

| 局面 | 有效答案 | 选择成本 |
|---|---|---|
| 重击将至 | 护盾、治疗、药剂、抢斩杀 | 少输出或消耗资源 |
| 高护甲 | 三连破甲、穿透、普通磨血 | 准备成本或更长回合 |
| 注废/乱权 | 净化、换目标、接受低收益 | 失去部分输出机会 |
| 锁轮/冻结 | 净化、保留好符号、改打其他列 | 列功能损失或资源消耗 |
| 恢复/暴露窗口 | 三连、克制、充能、普通输出 | 需要提前保留资源 |
| 敌人残血 | 抢攻或稳守 | 抢攻可能反被击杀 |

### 3.3 提示方式

标准模式显示局势与真实可选对策，不指定唯一答案：

```text
重击 52
可应对：护盾符号／治疗／抢斩杀
```

无资源时不显示虚假对策，不把玩家选择其他合法方案判为错误。强引导只保留给教学、辅助或固定对照实验。

## 4. 数值结构：拆开复合收益

### 4.1 元素三连与核爆

当前一次元素三连同时包含多种高收益。先列出实际收益，再一次只调整一个轴：

1. 保留三连机制与演出，先实验核爆额外伤害 **20% → 10%–12.5% 最大 HP**；
2. 检查破甲是否仍值得追求，不把破甲削成无意义；
3. 检查必暴、穿透和充能是否仍构成唯一答案；
4. 最后再评审是否需要调整必暴规则。

**目标**：三连仍然是高潮，但不再稳定跳过普通怪的全部机制。

### 4.2 三连治疗

优先实验三连 **50 → 30–35 HP**，保留单连/二连基础恢复。复测：

- 是否仍能救场；
- 是否会长期抹平普通攻击；
- 溢出转护盾是否形成额外最优解；
- 是否需要继续调整，而不是同时削弱其他恢复渠道。

**目标**：治疗有明确价值，但不能让高命中玩家基本忽略敌方输出。

### 4.3 调整纪律

- 每次只改一个数值轴；
- 不全局提高普通怪 HP；
- 不通过锁血、固定伤害上限或强制复活维持技能演出；
- 不根据玩家 HP、Build 或连胜暗改敌人数值；
- 每轮调整后比较普通、精英和 BOSS 的回合数与资源成本。

## 5. 怪物侧：建立行为语法，而不是增加技能名称

### 5.1 普通怪：一只怪讲清楚一件事

| 怪物方向 | 核心行为 | 玩家主要判断 |
|---|---|---|
| 蓄力重击型 | 明确蓄势后重击，重击后有空档 | 防御还是抢攻 |
| 叠甲型 | 初始护甲或周期补甲 | 破甲、穿透还是普通输出 |
| 状态型 | 毒、灼烧、霜冻等持续压力 | 净化还是速杀 |
| 干扰型 | 锁列、注废或乱权 | 是否净化，如何换目标 |
| 多段型 | 多次较小攻击或连续行动 | 护盾利用与恢复节奏 |
| 恢复型 | 回血、减伤或其他持续能力 | 集中爆发还是持续压制 |

每只普通怪只保留一个主特性，不叠加成精英式长战。

### 5.2 普通怪特性出现时机

按类型放在：

- 入场即生效：场地、状态、护甲、蓄力预告；
- 首次受击：护盾、变形、暴露、反击；
- 首次转轮前：明确意图和可用对策。

即使玩家 1–2 回合爆发击杀，也要看见“它是什么、准备做什么、我如何解决它”。

禁止首回合锁血、强制复活、固定伤害上限和无意义入场长演出。只有正常 Build 下仍无法看到核心机制时，才单独调整耐久或触发阈值。

### 5.3 精英：两个已有特性形成组合

示例：

```text
叠甲 → 重击预告 → 玩家防御或破甲 → 恢复窗口
```

或：

```text
注废 → 玩家选择是否净化 → 高伤意图 → 间隙爆发
```

精英应检验 Build 和资源使用，守护明确的定向奖励，不只是 HP 和攻击更高。

### 5.4 BOSS：阶段改变选择价值

BOSS 只需少量固定意图，通过顺序与阶段形成不同问题：

- 什么时候输出收益最高；
- 什么时候需要防御或净化；
- 什么时候应保留消耗品；
- 什么时候可以三连爆发；
- 什么时候需要抢收尾。

每个高压阶段必须有可识别的恢复窗口，且窗口与真实机制一致。不能只写“输出窗口”却继续叠甲、冻结或提高攻击。

## 6. 攻击与干扰的差异化规范

### 6.1 攻击类型

| 类型 | 战术作用 |
|---|---|
| 单击 | 基础压力，允许玩家继续输出 |
| 重击 | 明确预告，检验防御、恢复或抢斩杀 |
| 多段小攻击 | 检验护盾利用率和持续恢复 |
| 蓄力 | 提供抢攻窗口，再进入高压 |
| 反击/反弹 | 检验攻击时机与是否集中一击 |
| 阶段强化 | 改变原有意图的顺序、频率或组合 |

不是每个怪都新增这些行为，而是不同怪物家族有明确身份。

### 6.2 干扰类型

| 干扰 | 应有差异 | 非净化处理 |
|---|---|---|
| 注废 | 增加低价值格，改变停轮目标 | 接受低收益、使用其他符号 |
| 锁轮 | 固定当前符号，可能有利也可能有弊 | 利用被锁住的好符号 |
| 乱权 | 改变后续带子构成 | 根据新带子重新规划 |
| 冻结 | 当前列失效 | 接受该列损失、使用其他列 |
| 夺轮 | 改变操作节奏与时机 | 适应自动停轮，不只视为废铁增加 |

净化可以保留为通用兜底，但不能是所有干扰的唯一答案，更不能无净化必败。

---

## 7. 成长与 Build：从数值增长变成打法增长

### 7.1 武器成长分工

- 锋铸：提高已经停中符号的收益；
- 调律：改变目标出现频率或带子结构；
- 防御/功能方向：强化护盾、恢复、净化或破甲的使用方式；
- 三连方向：提高连击收益，但保留执行风险；
- 稳定方向：降低波动，牺牲部分峰值。

若所有成长都等于“伤害更高”，玩家仍然只会选输出。

### 7.2 角色技艺

技艺应改变规则和资源，而不只加面板：

- 每场一次额外缓冲；
- 特定条件下获得护盾；
- 商店/补给路线收益；
- 功能符号额外效果；
- 有限换轨或精简带子。

目标是玩家能说出“我的打法变了”，而不是只说“数值变大了”。

### 7.3 Build 路线与代价

| Build | 优势 | 应有代价 |
|---|---|---|
| 同系三连 | 爆发高、破甲快 | 依赖命中和元素覆盖 |
| 异系组合 | 克制覆盖广、灵活 | 三连浓度较低 |
| 防御恢复 | 容错高、资源稳定 | 输出和收尾较慢 |
| 破甲穿透 | 处理高甲有效 | 对无甲目标收益一般 |
| 状态持续 | 长战稳定、机制鲜明 | 怕净化、怕快速战斗 |
| 目押操作 | 上限高 | 依赖玩家执行 |

验收时必须实际使用不同路线，而不是只比较同一套配装的伤害。

---

## 8. 换标签/换轨功能的边界

当前不应优先加入自由换标签。最优解已过度集中，换标签很可能变成“每回合换最高收益符号”。

只有爆发与治疗收益收敛后，才允许制作以下原型：

- 每场战斗最多一次；
- 只在旋转开始前使用；
- 只替换一个明确的低价值符号；
- 候选与 Build 有关，不提供万能最优解；
- 不修改停轮后的结果，不消耗 RNG；
- 不作为通关必需，也不要求玩家每回合使用。

它是有限战术救场，不是解决策略不足的默认答案。

# 9. 分步执行计划

## Step 0 · 处理流程阻塞与保存基线

- 修复第 7 房精英胜利后的阻塞。
- 保存当前 22/22 回归、对照数据、战斗日志和配装。
- 保留线性入口与既有测试入口。
- 冻结其他无关数值，避免归因混乱。

**出口**：所有合法路线均能进入成长并返回流程；同种子可完整跑完 ACT1。

## Step 1 · 校准元素核爆与三连治疗

- 先实验核爆额外伤害 20% → 10%–12.5%，不同时改其他伤害。
- 再实验三连治疗 50 → 30–35 HP，检查溢出转护盾。
- 比较普通/精英/BOSS 回合数、承伤、格挡、治疗与意图出现率。

**出口**：爆发与治疗仍有价值，但不再同时替代所有其他符号和敌人机制。

## Step 2 · 普通怪早期特性样板

- 选择 3–4 只普通怪，每只保留一个核心特性。
- 接入入场、首次受击或首次转轮前展示。
- 不增加锁血、复活或长演出。
- 复测普通怪是否仍能表达机制，再决定是否需要局部耐久调整。

**出口**：快速击杀也看得到怪物身份；普通怪不变成多机制精英。

## Step 3 · 精英组合与 BOSS 节奏样板

- 选择一个精英和一个 ACT1 BOSS，整理蓄势—预警—爆发—恢复。
- 每种高压提供至少两种真实应对和基础兜底。
- 阶段改变目标价值，不只增加 HP 或攻击。
- 保留现有意图和参数来源，不引入动态数值橡皮筋。

**出口**：玩家能说出高压与恢复时机，并至少一次主动改变打法。

## Step 4 · 多对策提示与结果反馈

- 标准模式显示局势与真实可选对策，不指定唯一答案。
- 提示与当前带子、消耗品和机制状态一致。
- 结果反馈区分防御、净化、破甲、恢复与爆发。
- 在 480×270、960×540、1440×810 验收，不遮挡操作。

**出口**：玩家不会因提示而无脑操作，也不会遇到虚假对策。

## Step 5 · 多 Build 对照验证

至少覆盖：

- 同系三连；
- 异系组合；
- 防御恢复；
- 破甲穿透；
- 状态持续；
- 不带特定净化物品的兜底路线。

记录每回合局势、目标、消耗品、承伤、回合数、三连/核爆/治疗和死亡点。

**出口**：不同 Build 能用不同打法处理样板，没有装备成为绝对门票，也没有唯一操作答案。

## Step 6 · 真人体验验收与扩展

至少记录：

- 玩家为什么选择某个符号；
- 哪次 BOSS 变化迫使其改变打法；
- 是否感到被迫换装或被迫看提示；
- 普通怪是否能辨认；
- 干扰是否仍都只是“净化一下”；
- 残血是否仍机械重复；
- 是否愿意继续下一局。

**出口**：玩家能复述自己的选择理由；策略来自结果差异，而不是按钮数量。通过后再扩展其他怪物与 BOSS。

## 10. 自动测试与数值验收

### 10.1 定向测试

- 重击、低血、高甲、干扰、间隙与残血提示均与真实资源一致。
- 无护盾时不显示护盾建议，无净化路径时不显示净化建议。
- 核爆与治疗的调整不改变其他伤害、成长、掉落或 RNG。
- 普通怪特性在入场/首次受击/首次转轮前出现。
- 精英/BOSS 的恢复窗口与实际不叠甲、不冻结或机制空档一致。
- 多对策提示不污染固定目标实验口径。
- 所有节点和战后流程无阻塞。

### 10.2 体验观察目标

以下是复测目标，不是立即强改的常量：

- 普通怪约 2–4 回合，爆发可以更快；
- 精英约 4–7 回合，至少一次机制与恢复窗口可读；
- BOSS 约 6–10 回合，不靠重复空转拉长；
- 普通打法有资源成本，正确打法有优势但不是唯一解；
- 普通怪即使快速死亡也能看到特性；
- 不再出现普通/精英几乎全部一回合、BOSS 独自长拖的断层。

### 10.3 回归

- 每个数值轴单独提交、单独复测。
- 每阶段运行 `run_smoke.bat`，当前全部套件必须通过。
- AI 对照只用于机制复现，真人结果用于体验判断。

---

## 11. 停止条件

- 某符号或三连仍是所有局势的唯一答案；
- 普通怪仍无法展示特性；
- 干扰仍全部只有“净化一下”的单一答案；
- 三连治疗仍能长期抹平敌方输出；
- BOSS 只靠增加 HP、攻击或速度制造变化；
- 新机制要求特定装备才能处理；
- 换标签变成每回合固定劳动或新的唯一最优解；
- 回归失败或 AI 结果被当成真人难度结论。

---

## 12. 最终完成定义

调优只有同时满足以下条件才算成立：

1. 命中带来优势，但一个命中不能完成所有事情。
2. 普通怪能表达身份，精英与 BOSS 保留更高机制层级。
3. 不同攻击和干扰需要不同处理，而不只是换名称或统一净化。
4. 每种压力有多个真实答案和基础兜底。
5. 成长能改变打法，而不只是提高伤害。
6. 战中调整目标与资源，局间调整 Build，不要求战中换装。
7. 普通打法有成本，正确打法有优势，但结果不再两极化。
8. 自动回归与完整实机流程通过，真人能复述自己的选择理由。

最终体验应当是：

> **我看懂怪物在做什么，也知道当前有几种处理方法；我选择其中一个，并通过转轮、消耗品和既有 Build 让它产生结果。**
