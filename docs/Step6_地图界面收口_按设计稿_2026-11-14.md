## 1. 口径变更（先改契约，再改代码）

设计稿是 **14×9 整图入屏**，与计划 §4.1 原有的「主视口 8×6–9×7、镜头跟随、不整图入屏」直接冲突。
按作者决定改为整图，并同步改了计划 §4.1–4.3：

| 项 | 原契约 | 现契约 |
|---|---|---|
| 地图范围 | 9×7 镜头跟随 | **14×9 整图入屏** |
| 格子 | 34px | **16.6px**（14×16.6=232.4 / 9×16.6=149.4） |
| 格内表现 | 16px 图标 + 单字标签 | **统一单字**（普/精/王/宝/图/商/休/事/门），陷阱画红色 X |
| 右侧栏 | 目标 / 怪物 / 陷阱 / 构筑 / 操作 五段文字 | **「当前局面」**：摘要 + 巡逻预告卡 + ①②③ 三张链路卡 + 等待按钮 + 系统入口 |
| 底部 | 4 个操作按钮 | **说明条**（分工文案），操作移入右栏 |

`MapRuntime.camera_origin()` 未删：它是运行时查询契约，第 54 套仍断言镜头四角钳制，只是界面不再据此裁剪。

## 4. 过程中踩到并修掉的三个渲染坑

1. **autowrap Label 最小高度退化成 1px**：VBox 把它压成一条线，文字根本不画。修法是显式给
   `custom_minimum_size.y = 字号 × 1.5 × 行数`。
2. **面板盖住绘制层**：`_panel()` 后 `add_child` 会排在 `_art` 之上，地图区被面板底色整块遮住。
   修法是先建面板再加绘制层。
3. **Label 行高不受控撑破视口**：38 个汉字的底条 Label 最小高度被字体行高顶到 23px，
   251+23 > 270。地图面板标题、副标题、区域标注、图例、底条改成**绘制层直接 `draw_string`**，
   字号与基线完全可控，并顺手把标题提到 12px、副标题与区域标注提到 10px（12px 点阵字体下才清晰）。

## 4.5 试玩发现的两个真 bug（不是 UI 问题）

作者试玩报「无法进入战斗」，查下来是 Step 2b 单路径收敛留下的两处运行时缺口 + 一处层级问题：

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 点「进入战斗」被弹回地图，只显示一句起点提示 | `DuelController._on_board_node_entered()` 的 `match` 只认旧类型名 `normal / treasure / shrine`，新地图节点是 `battle / chest / event`，全部落进默认分支 | 分支改为 `"battle", "normal", "elite", "boss"` / `"chest", "treasure"` / `"event", "shrine"`，新旧名共存 |
| 2 | 走一步后棋子不动、位置仍显示起点；确认层再点一次就卡死 | `BoardSystem.advance_to()` 从头到尾没同步 `current_id`，门面的「当前位置」永远停在起点；`_on_confirm_battle` 判断 `current_id != node.id` 恒成立 → 再走一次是 `same_cell` 被拒 → 直接 return | `advance_to()` 成功移动后 `current_id = id` |


> 为什么之前 56 套全绿也没抓到：所有测试都是直接调 `board.advance_to()` / `runtime.try_move()`，
> **没有任何一条走「点击格子 → 落点 → 确认 → 战斗」的界面链路**，也没断言 `current_id` 会跟随移动。
> 已在第 56 套补 G 组 7 项（`点击后当前位置离开起点` / `同步到战斗格` / `弹出确认层` /
> `确认后真的进入战斗` / `地图界面隐藏` / 敌方血量已初始化）。
>
> 鼠标可达性另行实测：用 `InputEventMouseButton` 真实推送到 (89, 139)（战斗格中心），
> `current_id` 由 m57 变为 m58 且确认层弹出——面板没有拦截点击，格子热区正常。

## 6. 已知限制

1. **8–9px 中文仍偏糊**：项目默认字体是 12px 点阵（VonwaonBitmap-12），非 12px 尺寸会重采样。
   地图面板已提到 10–12px，右栏卡片说明受 147 宽限制只能 8–9px。要彻底解决需换字体或放大字号，
   会牺牲信息量。
2. **怪物与玩家没有立绘**：设计稿里的雕像风怪物、像素小人需要新美术；当前玩家是 8×8 图标，
   怪物是红框 + 单字。等美术资源到位再替换。
3. **①②③ 三张卡是静态链路说明**，不是动态状态机；只有 ① 的说明会随巡逻预告改写。
4. **镜头上限仍在运行时不生效**：`camera_origin()` 保留但界面不再使用，第 54 套的镜头断言
   测的是运行时契约，与界面无关。
