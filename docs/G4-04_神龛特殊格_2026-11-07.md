## 1. 本轮做了什么

按计划 §8.4「首批只允许宝箱、神龛、武器藏库三类，**每幕至多 1 个特殊格**，替换一个普通节点」，
宝箱落地之后补上第二类 **神龛**：

- 特殊格改为**一个槽位**：生成时在 `treasure` / `shrine`（现为三类，含 `armory`）中随机一类，不再各占一格；
- 特殊格固定替换 4 条尾路中随机一条的**首格普通战斗**（depth 10），节点总数不变（标准 25 / 长尾 29）；
- 神龛的**效果在生成时冻结并开局公开**（与宝箱「公开类别、隐藏物品」相反：神龛没有隐藏信息，落地立即结算）；
- 岔路提示同步标注该侧是「宝箱」还是「神龛」，玩家可以据此选路。

`BoardConfig.special_id`（空 = 随机，`"treasure"` / `"shrine"` = 固定）用于测试、调试与截图工具。

## 2. 效果池（全部沿用既有合法数值）

| 效果 | 数值 | 结算 | 边界 |
|---|---|---|---|
| 恢复 `heal` | 35% 最大 HP（向上取整） | 立即回血，封顶最大 HP | 满血时提示「无需恢复」，节点照常消耗 |
| 强化 `maxhp` | 最大 HP +12，并恢复 20% 新上限 | 立即生效 | 本次战斗/本局持续 |
| 守护 `ward` | 下一场战斗开局 +15 护盾 | 写入 `_reward_system.run_shield_next`，可与既有护盾叠加 | 可连续累积 |

没有新增货币、没有新增战斗、没有改任何战斗数值或伤害公式；三档数值均复用现有奖励效果量级。
`shrine_value` 随效果写入（35 / 12 / 15），便于后续调参与文档核对。

## 3. 生成顺序（在 G4-02 之后）

```text
本局种子
→ 抽骨架（standard / long_tail）
→ 抽分支价值模板
→ 按骨架写节点类型
→ 抽特殊格（treasure / shrine / armory）并替换一条尾路的普通战斗
   ├─ 宝箱：冻结类别 + 具体物品，节点文案只公开类别
   └─ 神龛：冻结效果 + 数值，节点文案直接公开效果
→ 分配剩余战斗 RoomData（同盘不重复）
→ 分配武器格 / 护符格
→ 冻结并展示
```

## 4. 已知取舍

- **宝箱不再保证每局出现**：特殊格是单一槽位，一局只会看到宝箱 / 神龛 / 武器藏库其中之一（随机）。
  这是「每幕至多 1 个特殊格」的直接结果；若复测发现宝箱的装备惊喜感更重要，可调整权重。
- 该尾路 **7 场战斗**（特殊格顶掉一场普通战斗），成长经验少一场，与宝箱相同。
- 神龛是纯收益、无选择：它提供的是路线价值（这条尾路更稳），而不是落地时的决策。
- ~~武器藏库~~：已落地（两把可见武器二选一），见 `docs/G4-04_武器藏库特殊格_2026-11-07.md`；
  隐藏房 / 献祭 / 复杂随机事件继续暂缓。
