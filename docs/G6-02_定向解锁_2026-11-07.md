# G6-02 定向解锁「未拥有装备三选一」

> 日期：2026-11-07
> 阶段：G6 最小生涯 / 定向解锁（P2）第二切片
> 关联：`docs/棋盘探索_战后成长与局外生涯_制作执行方案.md` §8.3、`docs/G6-01_生涯成就_2026-11-07.md`
> 前置说明：G5 真人复测仍未取数；本切片不改变战斗数值、奖励、掉落、RNG 或存档旧字段。

---

## 1. 做了什么

- 生涯里程碑开始发放**定向解锁机会**：`初次深入`、`四席猎手` 各 +1 次。
- 机会写入 `anvil_meta.career.unlock_charges`，跨局保留，**不新增货币/解锁券**。
- 局末元进度屏先展示「未拥有装备三选一」，选完再进入原有铁砧点结算。
- 候选只来自当前卡池中**未拥有**的合法内容：
  - 武器：`owned_weapons` 之外；
  - 护符：`owned_charms` 之外；
  - 消耗品：`owned_consumables` 之外；
  - 排除 BOSS 信物（仍只走 BOSS 战利品）。
- 选择后立即写入对应拥有池与图鉴来源体系，并检查收藏里程碑；下一局整备即可见。
- 候选生成使用独立 `RandomNumberGenerator`，**不消耗**战斗/开局链路的全局 RNG。

**没有改**：战斗数值、成长、奖励、掉落、商店、铁砧保底/重复返还、存档旧字段、`balance_config.tres`。

---

## 2. 触发与存档

| 里程碑 | 机会 |
|---|---|
| `first_clear` 初次深入 | +1 |
| `four_hunters` 四席猎手 | +1 |

```json
"anvil_meta": {
  "career": {
    "unlocked": ["first_clear", "four_hunters"],
    "bosses": ["res://resources/rooms/a1_brute_none.tres", "..."],
    "unlock_charges": 1
  }
}
```

- 老档缺 `unlock_charges` → 默认 0；负数载入时归 0。
- 机会在选中后才扣减；只关闭/退出游戏不会消耗（下次局末继续提示）。
- 全部合法装备都已拥有时，候选为空，流程直接进入铁砧点结算；机会保留，等后续新增内容。
- 重复选中同一路径会被拒绝，不会重复写入或重复扣机会。

---

## 3. 候选规则

1. 先从武器 / 护符 / 消耗品各抽 1 个（类别有货时），再补齐到 3 个。
2. 候选互不重复，且全部未拥有。
3. 不出现 BOSS 信物；不出现 ACT1 Demo 白名单之外的内容（沿用现有池过滤）。
4. 卡片展示：图标、名称、类别、元素（无属性则省略）、攻击/命中或效果短描述；完整说明走 tooltip。
5. 候选在每次打开解锁屏时重新抽取；没有“刷新”按钮，也不消耗任何资源。

---

## 4. 界面流程

```
BOSS 通关
  → 生涯成就结算（可能 +1 解锁机会）
  → 若有机会：生涯解锁 · 未拥有装备三选一
        选中 → 写入图鉴/拥有池 → 收藏里程碑检查
  → 原「一局结束 · 本局获得」铁砧点结算
  → 确认 → 回整备（新装备已在拥有池）
```
