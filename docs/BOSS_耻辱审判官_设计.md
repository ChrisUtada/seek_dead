## 1. 定位与特色

**Act3 三阶段隐秘 BOSS（失误问责型）**：Act3 BOSS 槽「3 候选选 1」的 **hidden（隐秘）候选**（fixed 深渊监视者权重 6 / rotating 碎裂魔王 3 / hidden 耻辱审判官 2 ≈ 18%）。幕内全清后开启，预告显示？？？。三阶段 = 毒性耻感的机制化：罪业记录（每次失误被记账）→ 拷问心防（护盾被剥）→ 终极审判（残血血线双重清算）。

```
P1 罪业记录（HP 100% → 66%）：玩家每回合受击或空转（无伤害）→ 罪业 +1——敌方攻击 ×（1 + 罪业×0.08）
P2 拷问心防（HP < 66% 触发一次）：清空玩家护盾 + 每回合开局剥盾——纯血量承伤
P3 终极审判（HP < 33% 触发一次）：玩家血量 < 50% 时敌方伤害再 ×2——血线双重清算
```

**定位（与无名虚空/审判官错位）**：无名虚空 = 装备剥夺（外部惩罚）；耻辱审判官 = **失误问责**（操作惩罚）——罪业来自玩家自己的受击/空转，越拖越痛（罪业不衰减）。天平审判官 = 规则目押（主动遵守）；耻辱审判官 = 失误记账（被动问责）。**操作纪律（MISS 按停 + 护盾管理 + 少空转）即生存**。

## 3. 机制（shame_counter 罪业清算，全参数化 T24）

### 3.1 P1 罪业记录（HP 100% → 66%）

- **罪业计数**（`sins`，房内不衰减、P1/P2/P3 持续累计）：每回合检测两个来源——
  - **受击罪**：玩家本回合受击（`player_hp + player_shield` 比上回合低，敌人行动后 on_turn_begin 检测）→ +1。
  - **空转罪**：玩家本回合未造成任何伤害（`enemy_hp` 未变化，on_turn_resolved 检测）→ +1。
- **罪业乘区**：`boss_atk_mult ×= (1.0 + sins × sin_atk_per)`（默认每罪 +0.08）——失误累积 = 敌方伤害水涨船高（越拖越痛）。
- 意图 attack 50 / heavy 30 / jam 20；日志「⚖ 罪业+1（受击/空转）：当前罪业 N」+ HUD 罪业行（日志 + 状态行）。

### 3.2 P2 拷问心防（HP < 66% 触发，一次性）

`on_damaged` 检测 `enemy_hp <= enemy_hp_max * phase2_hp_ratio` 且未触发过 → 进入 P2：
- **清空护盾**：`player_shield = 0`（当前盾当场剥除）。
- **每回合剥盾**：此后每回合 `on_turn_begin` 清空 `player_shield`（护符/增益获得的盾无法保留）——**纯血量承伤**（护盾流 build 被打回原形，同无名虚空「装备独立性」的护盾向变体）。
- **攻击回落**：×`phase2_atk_mult`（默认 0.9，罪业乘区之上叠乘）；意图 attack 40 / heavy 40 / jam 20。
- 触发瞬间日志 + 飘字「⚖ 拷问心防：护盾剥离——纯血量承伤」。

### 3.3 P3 终极审判（HP < 33% 触发，一次性）

- **血线审判**：此后每回合 `on_turn_begin` 检测 `player_hp <= player_hp_max × low_hp_ratio`（默认 0.5）→ 本回合敌方伤害额外 ×`low_hp_mult`（默认 2.0）——残血 = 双重清算（罪业乘区 × 血线 ×2）。
- **攻击 ×`phase3_atk_mult`**（默认 1.0）；意图 attack 50 / heavy 50。
- 触发瞬间日志 + 飘字「⚖ 终极审判：血线之下，罪无可赦」。

### 3.4 与已有 BOSS 的差异化

| BOSS | 阶段机制 | 正解轴 |
|---|---|---|
| 无名虚空（Act2 双） | 装备剥夺（护符+技能） | 裸输出 |
| 深渊监视者（Act3 三） | 池稀释（注废→闪回→吞噬） | 洗盘 + 少带 |
| 碎裂魔王（Act3 三） | 三元素切换（火→冰→毒） | 三换克制武器 |
| 耻辱审判官（Act3 三） | **失误问责**（罪业→剥盾→血线） | **操作纪律**（少空转 + 盾管 + 血线） |

- **罪业 = 自找的惩罚**（区别于所有「敌人主动」机制）：玩家操作越稳，BOSS 越弱——MISS 按停、护盾管理、不空转即正解。
- **血线双重清算**：P3 残血 = 罪业 × 血线双乘区——与「拖杀」对抗（速杀或保血线二选一）。
