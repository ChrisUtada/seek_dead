# Seek Dead · ACT1 试玩说明

> 面向测试者的一页纸。版本以实际交付包为准（导出 preset「ACT1 Demo」）。
> 玩法细节与反馈模板见文末，可直接复制填写。

## 这是什么

《Seek Dead》是一个俯视角回合制「老虎机肉鸽」：转动三列转轮，让同符号连线产生攻击 / 防御 / 状态，利用元素克制击败敌人。本试玩只包含 **ACT1** 的完整闭环，目标游玩时长约 **60 分钟（4–5 轮）**。

## 怎么玩

- **转轮目押**：空格 / 点击 SPIN 旋转，再按空格或点击逐列按停。停到相同符号 = 连线，三连必暴击。
- **元素克制**：火克冰、光克毒、冰克火（×1.5）。敌人弱点在右侧面板。
- **破甲三连**：带破甲标记的武器（战斧 / 铁剑）三连可清空护甲。
- **状态**：燃 / 霜 / 毒挂上即生效，可被「清净 / 净化」类消耗品解除。
- **局内成长**：
  - 角色历练：清房获得经验（普通 1 / 精英 2 / BOSS 3），升级时三选一技艺。
  - 武器熟练：本房真正打出有效结算的武器获得熟练，到 R2 / R3 时选择铭印（锋铸加攻 / 调律加符号权重）。
- **构筑信息**：整备页底部「🎰带」可查看当前真实转轮带与共鸣；商店、奖励、BOSS 替换弹层会显示替换后的格数与共鸣得失。

## BOSS 应对（ACT1 四席）

| BOSS | 应对 |
|---|---|
| 冰封铁瓮（固定）| 叠甲 + 冻结 → 火武 ×1.5 + 破甲三连 + 清净解冻结 |
| 碎裂石像鬼（轮替）| 反弹 → 护盾流或速杀 |
| 酸蚀恶鬼（轮替）| 挂毒爆炸 → 光武 + 清净 / 蚀毒壁垒 |
| 茧居石雕（隐秘）| 开合节律 → 攒爆发打开合窗口 |

## 本试玩包含什么

- 仅 ACT1：每轮 8 房（5 普通 + 2 精英 + 1 常规 BOSS）+ 四 BOSS 轮替 / 隐秘抽取。
- 内容白名单约 51 件：14 把武器 · 10 个技能 · 17 个护符（含 4 个 BOSS 信物）· 10 个消耗品。
- 商店、铁砧、新档初始池、奖励候选都只出白名单内容；正式版存档不受影响（关闭开关即恢复三幕全量）。
- 局内成长（角色技艺 / 武器熟练铭印）覆盖白名单全部武器，不再局限于 4 把样板。
- 缺图内容一律使用现有素材或 emoji 占位，属于已知状态。

## 一局怎么结束

- 打完第 8 房（这一局抽中的 ACT1 BOSS）→ **BOSS 战利品三选一** → **「ACT1 试玩结束」结算**（铁砧点数入账、战利品进收藏）。
- 结算后 **回整备**：可以花铁砧点数、看图鉴、换配装，再点「确认开战 ▶」开下一轮。
- 战败同样回整备（失败弹层 → 返回整备），上局金币与局内成长清零，铁砧点数 / 收藏保留。
- 一局只会遇到 **1 个 BOSS**（四席中按权重抽 1），想验另外三个 BOSS 就多开几轮。

## 已知限制

- 只有 ACT1；ACT2 / ACT3 与真·最终战不在本次范围。
- 美术为占位 / 第一版视觉，不是最终效果。
- 铁砧与图鉴是跨局收集，请多玩几轮再评价。

## 如何启动 demo（内部）

两种方式任选：

1. **导出构建（发给试玩者用这个）**：已打包为单文件 `build/ACT1_Demo/Seek Dead ACT1 Demo.exe`，双击即玩（PCK 已内嵌，无需配套文件）。重新打包：
   ```
   Godot_v4.7-stable_win64_console.exe --headless --path . --export-release "ACT1 Demo" "build/ACT1_Demo/Seek Dead ACT1 Demo.exe"
   ```
   preset 的 `custom_features = "act1_demo"` 会自动启用 demo 模式，无需改资源；`tests/` 与 `tools/` 已从包内排除。
2. **编辑器 / F6**：把 `resources/config/demo_config.tres` 的 `enabled` 勾上（`act_only` 保持 true）。

关闭方式：取消 `enabled` 或使用正式版 preset。

> 调试构建（编辑器 F6 / `--export-debug`）启动时日志会打印
> 「◆ ACT1 DEMO 模式：武器 14 / 技能 10 / 道具 27 / 房间 20（仅 ACT1，不含真·最终）」，
> 可据此确认白名单与 ACT1 收窄生效；release 包按 Debug.log 约定静默。
