## 2. 复测方法

- 使用 Step 1 落点：核爆 12.5% max HP、三连治疗 45 HP。
- 10 个种子（666 / 777 / 888 / 999 / 1010 / 1111 / 1212 / 1313 / 1414 / 1515），`aim_only`（不使用消耗品，隔离治疗道具影响）。
- `strategy_probe` 新增逐房记录：
  - `trait` / `mechanic_summary`；
  - 入场瞬间的 `armor_start` / `armor_max_start` / `frost_start` / `jam_start`；
  - 离房前的 `trait_done`（首次受击/首次转轮触发标记）。
- 修正探针：精英/BOSS gimmick 不一定有 `_done` 字段，改用 `get("_done") == true` 防御，避免中断离房记录。

---

## 3. 数据

10 局共 50 个普通房，其中带早期特性 16 个（32%）。

| 怪物 | 出现次数 | 1 回合击杀 | 入场/首轮前可见证据 |
|---|---:|---:|---|
| 毒壳壁垒 `shell` | 7 | 5/7 | `armor_start = 20`、`armor_max_start = 20` |
| 冰锋群蝠 `frost_open` | 3 | 3/3 | `frost_start = 1`、`trait_done = true` |
| 窃语咒师 `jam_open` | 4 | 2/4 | `jam_start = 0`、`trait_done = true` |
| 辉光游侠 `first_hit_ward` | 2 | 2/2 | 首次受击后 `armor_end = 10`、`trait_done = true` |

对照：

- 无特性普通房：27/34 一回合击杀（79%）；
- 带特性普通房：11/16 一回合击杀（69%）。

**读数**：

1. 4 只样板在 10 个种子里全部实际出现；Step 1 的 5 种子样本中窃语咒师 0 次，扩大样本后才出现 4 次，说明样板覆盖率需要按种子方差看。
2. 带特性普通房仍然以 1 回合为主，但特性在玩家第一次动作前或第一次受击时已经可见：护甲条、冻结列、注废列、首次受击日志与右栏机制摘要。
3. `first_hit_ward` 在 1 回合击杀时也会触发（`armor_end = 10`），属于「看到它是什么」但不改变结果；不构成锁血或额外耐久。
4. 普通房 1 回合占比没有因为特性样板的加入进一步恶化；局部耐久不需要调整，且方案明确不全局加血。

## 4. 出口判断

| 出口 | 结果 |
|---|---|
| 快速击杀也看得到怪物身份 | ✅ 机制摘要 + 入场日志 + 护甲/冻结/注废状态在首次动作前或首次受击时可见 |
| 普通怪不变成多机制精英 | ✅ 每只怪仅 1 个 `trait`，无锁血 / 复活 / 阶段变化 |
| 不需要局部耐久调整 | ✅ 特性可读，1 回合击杀仍保留；不提高 HP |
| 特性不依赖特定 Build | ✅ 四类特性均为通用资源/状态应对（破甲、清净、接受列损失、抢杀） |

**结论**：Step 2 出口成立。本轮不需要新增普通怪或修改耐久；已有 4 只样板足以承担「身份可读」的示范。
