## 1. 累计器加了两个元素桶

牌谱要算「火系伤害 +25%」「火冰伤害转穿透」，而原来的 `acc` 只有一个混合的 `dmg`。
`acc["lines"]` 是给人看的字符串，没法参与运算。所以在 `contribute()` 里加了结构化累加：

| 字段 | 含义 | 谁用 |
|---|---|---|
| `dmg_by_elem` | 该元素本轮造成的**总伤害**（含穿透部分） | S01「火系伤害 +25%」 |
| `dmg_bucket_by_elem` | 其中**真正进了 `acc["dmg"]`** 的部分 | S02「火冰伤害 20% 转穿透」 |
| `source_dmg` | 按来源汇总的本轮伤害 | 后续 S11/S13/S20 的「该武器追加 X%」 |

两个桶分开是必要的：转穿透只能从 `dmg` 里搬，如果按总伤害算，本来就在 `pierce` 里的部分会被算两次。

## 2. 新增 `pattern_effects.gd`

所有效果只写累计器，不重调符号结算、不递归：

| 牌谱 | 效果 | 实现要点 |

| S01 烈焰共鸣 | 火系伤害 +25%、燃烧 +1 | 取 `dmg_by_elem.fire`，加成写入 `acc["dmg"]` |
| S02 冰火二重 | 火冰伤害 20% 转穿透、燃烧/霜冻各 +1 | 从 `dmg_bucket_by_elem` 的 fire/ice 各搬 20% 到 `pierce` |
| S03 黎明圣辉 | 追加穿透齐射 = 两件来源武器攻击和 × 50% | 读 `weapon_power()`（含槽位成长），直接进 `pierce` |
| S05 盾击连携 | +8 护盾，转本轮护盾量 50% 伤害 | 先加 `shield` 再按总量算 |

## 2.1 S04 的口径，以及一个被顺带修掉的静默失效

「标准毒结算」的真实实现在 `CombatSystem.tick_status()`：

```text
每跳 = 层数 × status_base("poison") × 元素倍率 × 状态护符乘区
```

S04 按同一公式算「这次如果 tick 会打多少」，取 50% 作为即时伤害。

**与 tick 的一处差别必须写明**：tick 是 `enemy_hp -= dot`（完全裸伤害、不受任何乘区影响），
而本效果走 `acc["pierce"]`，会照常吃本轮强袭/增益/虚弱乘区。所以它是「一次穿透伤害，
基础值等于毒 tick 的 50%」，不是绕过结算的直扣。这个差别写在代码注释里。

### 顺带修掉的静默失效

做 S04 时发现：`_apply_patterns()` 跑在 `_phase_defense()` **之后**，而后者在末尾已经把
`acc["status_stacks"]` 写进了 `enemy_status`。所以牌谱往 `status_stacks` 里加层**根本不会生效**。

这意味着 Step 2 交付时的 S01「燃烧 +1」、S02「燃烧/霜冻各 +1」**都没有真正落地**，
而当时 H 组的断言读的是 `acc["status_stacks"]`，所以一直显示通过 —— 属于假通过。

修法：牌谱新增的状态写进独立字段 `acc["pattern_status"]`，由 `_apply_patterns` 末尾统一落地。
断言也改成读 `pattern_status` 与 `enemy_status`，而不是 `status_stacks`。

## 3. `match_rule` 求解器

牌谱的判定不能只看「是否三连」，要看「三个格子凑不凑得出指定组合」。加在 `PatternMatcher` 里：

```gdscript
solve_rule(cards, {"all": [{"kind":"damage","element":"poison"}, {"sym":"...poison.tres"}, {"element":"poison"}]})
```

三张牌对三个条件，用回溯分配，每个条件必须拿到**不同的**牌。支持的条件：

- `{"sym": path}` 精确符号
- `{"element": "fire"}` 指定元素
- `{"kind": "shield"}` 符号类型
- `{"source": path}` 指定来源
- `{}` 任意有效牌

## 4. 移除旧三条永久共鸣

方案要求「避免新旧效果叠加」，所以把三个资源的数值字段清空：

| 资源 | 清空前 | 清空后 |
|---|---|---|
| `flame_resonance.tres` | `weight_bonus` 火斩/燃烧 +2 | `{}` |
| `frostfire.tres` | `crit_bonus` 0.5 | `0.0` |
| `holy_pair.tres` | `element_boost` light ×1.2 | `""` / `1.0` |

`desc` 同步改成「旧永久效果已移除，改由牌谱 S0x 接管」，避免 UI 继续显示错误的说明。

资源本身保留（id / name / 图标仍在），因为 UI 还靠它们显示「已激活」，删掉会断引用。

**这意味着玩家手感会变**：烈焰共鸣从「更容易摸到火」变成「打得更疼」，冰火二重从「暴击更高」变成「转穿透」，黎明圣辉从「光伤 ×1.2」变成「追加齐射」。这是方案的既定设计，不是 bug。
