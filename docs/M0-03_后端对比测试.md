## 2. 候选后端（任选两个）

| 后端 | 适用 | 备注 |
|---|---|---|
| Retro Diffusion | 像素角色、图标、动画候选 | 有在线服务与 Aseprite 插件 |
| PixelLab | 静态像素图标与角色 | API / 网页 |
| 本地 ComfyUI | 需合适显卡，可长期锁模型与参考图 | 无账号依赖，成本是时间 |
| 其他可稳定联网的像素生成服务 | — | 不以宣传选型，只看实测 |

选型纪律：**不看宣传看实测**；同一题的后端差异必须来自后端本身，不能来自 prompt 改写。

## 3. 执行步骤

```bash
# 1) 每个后端按卡出图，存到：
#    raw/art/backend_compare/<backend>/<card_id>_c1.png ...
#    raw/art/backend_compare/<backend>/manifest.json
#    （manifest 记录：后端、模型/版本、种子、prompt、参考图批次、日期）

# 2) 拆成两张 contact sheet（原图对照）
python tools/art_pipeline/pipeline.py palette --out docs/M0-03/palette_v3.png

# 3) 逐题归一（参数按卡的 kind：icon24 / sprite48 / boss96）
python tools/art_pipeline/pipeline.py normalize raw/art/backend_compare/<backend>/w_fire_sword_c1.png \
    docs/M0-03/backend_compare/<backend>/w_fire_sword_c1.png --mode icon24
# （批量可写manifest驱动的小脚本，属后续增量）

# 4) 规格检查 + contact sheet
python tools/art_pipeline/pipeline.py check docs/M0-03/backend_compare/<backend>/*.png \
    --mode icon24 --json docs/M0-03/backend_compare/<backend>/check.json
python tools/art_pipeline/pipeline.py sheet \
    --out docs/M0-03/backend_compare/<backend>/sheet.png --scale 3 --silhouette \
    --items docs/M0-03/backend_compare/<backend>/*.png
```
