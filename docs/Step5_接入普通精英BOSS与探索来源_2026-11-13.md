## 2. 探索来源规则

```text
棋盘生成
→ 为本次生成取一次专用种子（randi()；同种子可复现）
→ 节点类别（武器 / 护符 / 消耗品）由棋盘决定
→ 按 chest 来源行抽品质
→ 取该品质层、该类别、当前幕次合法的候选
→ 排除本局已装备 / 已带护符 / 本节点已用路径
→ 具体物品写回节点 item_path（生成时冻结）
```

- **品质只来自 chest 行**：35 / 40 / 22 / 3（基础 / 进阶 / 稀有 / 传说）。
- **不跨来源**：探索不会借用普通战、精英或 BOSS 的品质表。
- **空层处理**：抽中的品质层在该类别下没有合法候选时，只在 chest 行内按原权重改抽一个
  「有候选」的品质层；不凭空提层、不跨来源。整类都为空才返回空，节点按既有规则折算金币。
- **信物隔离**：`include_relics = false` 且 `*_relic.tres` 不带 `chest` 标签，探索永不冻结 BOSS 信物。
- **冻结口径**：物品路径在 `generate()` 内写死；查看、重生成（同种子）、回访节点都读取同一个
  `item_path`，不重新抽取。
- **RNG 隔离**：探索抽取使用棋盘生成器持有的 `RandomNumberGenerator`，不消耗全局/战斗/奖励 RNG。

### 2.1 线性棋盘

`BoardGenerator` 新增 `_gen_act` 与 `_loot_rng`，在 `generate()` 开头取一次 `randi()` 作为种子。
宝箱、武器格、护符格、武器藏库全部通过 `_pick_explore(category, exclude)` 取物；
旧 `pick_explore_weapon_path()` / `acq_weighted_pick` 已从探索通道移除。

### 2.2 4×4 扫雷棋盘

`BoardGrid` 沿用 `grid_seed` 初始化的 `_rng` 作为探索抽取流：同 seed 的武器 / 护符完全一致，
且仍不消耗全局 RNG。旧的 `_weighted_take`（获取权重）已删除。

## 3. 商店确定性

| 幕 | 品质阶梯（6 格） | 类别序列（6 格） |
|---|---|---|
| 1 | common ×3 / uncommon ×2 / rare ×1 | weapon / active / skill / passive / active / weapon |
| 2 | common ×2 / uncommon ×2 / rare ×2 | weapon / active / passive / skill / weapon / passive |
| 3 | common ×1 / uncommon ×2 / rare ×2 / epic ×1 | weapon / passive / active / skill / weapon / weapon |

- 品质与类别都由 `BalanceConfig` 按幕次给出，商店不再走随机来源表。
- 具体物品仍由商店专用 RNG 抽取；价格继续走 `ShopConfig` 的
  `kind + rarity + 当前持有数` 公式（含既有 jitter），不与战斗战利品共用随机逻辑。
- 指定类别在该层无合法候选时（例如 act1 稀有消耗品尚未解锁）回退到该层任意类别，
  保证货架恒为 6 格；回退只影响类别，不改变品质阶梯。
- 已带护符 / 技能仍不上架；BOSS 信物仍不进商店。
