## 1. 本步做了什么

新增 14×9 地图回合运行时 `scripts/board/map_runtime.gd`，作为**开发／AI 测试入口**。它消费 `MapBoardBuilder` 已冻结的节点图，只持有运行时状态（坐标 / 回合 / 消耗 / 遭遇），不写回 cell、不重抽内容、也不持有 RNG。

| Step 2 任务 | 落地 | 说明 |
|---|---|---|
| 1 点击相邻格移动，等待原地推进 | ✅ | `try_move()` 用 `MapGrid.neighbors()` 做四邻判定，成功即 `turn+1`；`wait_turn()` 只推进一次 |
| 2 回访只移动，不重复发奖 | ✅ | `consumed` 只记探索内容；二次进入返回 `kind=revisit`，不追加 `settled_log` |
| 3 镜头跟随角色，目标信息可读 | ✅ | `camera_cells()` 固定 9×7 窗口随角色滚动并钳制在 14×9 内；`view()` 返回目标类型 / 来源 / 消耗 / 是否相邻 |
| 4 查看构筑与取消不推进回合 | ✅ | `view()` / `view_build()` / `cancel()` 均只读，状态指纹与内容指纹前后一致 |
| 5 保存／恢复坐标、回合、消耗 | ✅ | `to_dict()` / `from_dict()`，带版本、种子、幕号校验；JSON 往返实测 |
| 6 只用开发入口，不开放产品默认入口 | ✅ | 无产品侧引用；`cfg.map14x9_enabled` 仍为 `false`，仅 `map_dev_override` / `--map14x9-dev` 可提前进入 |
| 7 同步核对 `g8_loadout_layout_test` | ✅ | 复跑 `G8_LAYOUT|RESULT PASS (121/121)` |

**没做什么（守住 Step 2 边界）**：`board_system.gd` / `board_screen.gd` / `board_config.gd` 一行未改，`layout_mode` / `use_grid()` 双开关与两个模式按钮原样保留，旧模型与旧测试均未退役。巡逻怪物行为属 Step 3，破甲陷阱结算属 Step 4，界面实际绘制属 Step 6。

## 3. 布局契约（480×270）

| 项 | 取值 | 校验 |
|---|---|---|
| 视口 | 480×270 | 项目既定目标分辨率 |
| 镜头窗口 | 9×7 格（9 < 14、7 < 9） | 不整图入屏 |
| 格子像素 | 34 | ≥ 24，可容纳角色 / 怪物 / 陷阱 / 箭头 |
| 地图区 | 348×246 | 右侧信息栏 132 + 底部操作栏 24 |
| 镜头像素矩形 | 306×238，落在 (21, 4) | ⊂ 地图区 |
| 操作栏 | 4 × 92×18，间距 6，居中 (47, 249) | 全部在视口内，最右 433 < 480 |

操作顺序冻结为 `move / wait / build / withdraw`，对应计划 §4.3 的「移动（点击相邻格）· 等待一回合 · 查看构筑 · 撤回整备」。
