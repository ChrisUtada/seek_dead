## 0. 前提

- 默认路径已是棋盘 + 三幕（`BoardConfig.acts = 3`），棋盘模式**没有线性间歇态**（`room_flow.enter_interroom` 在棋盘直接回棋盘），
  所以「每幕 1 次」的服务入口必须在棋盘屏上，线性模式的间歇按钮作为并行入口。
- 只改本局运行时状态：不写 `res://resources/`、不写 `MetaStore.meta`、不新增货币（P0 §7 已锁边界）。

## 1. 一期范围（照抄方案 §7.2，不扩大）

| 项 | 规则 |
|---|---|
| 符号精简 | 选一个**非核心**符号，**减少 1 个实际格**；每个符号本局最多精简 1 次 |
| 技能卸除 | 卸除本局某个技能 → 该技能符号与 MISS 贡献按现有建带规则消失；不退款、不给替换技能 |
| 次数 | **每幕 1 次**，符号精简与技能卸除**共享**；随幕重置，不跨局累计，不用新货币 |
| 保护 | 金币常驻格 / MISS / 敌人注入废铁 / BOSS 机制符号不进候选；每个符号保底 1 格；整条带至少保留 1 个 damage 符号；每把已装备武器至少保留 1 个可结算符号 |
| 预览 | 应用前展示**真实**前后：逻辑带长、实际带长（含最小带长平铺）、该符号格数与占比、技能损失的符号与 MISS 贡献 |
| 不可逆 | 应用后无撤销；无合法候选时不显示入口，不出死奖励 |
| 不做 | MISS 净化、废铁/注入、BOSS 注入、带长越短伤害越高的奖励、任何新乘区 |

## 2. 切片

### B1 · 规则层 `StripTrimSystem`（无 UI）

- 新增 `scripts/systems/strip_trim_system.gd`：本局状态 + 候选 + 预览 + 应用 + 次数记账 + `reset_run()`。
- 候选键与建带聚合键一致：`符号 resource_path|有效元素`（`reel_system.build_strips` 的 `agg` 键）。
- 技能卸除只动本局 `selected_skills`（与 `WeaponMastery.imprints` 同一类运行时状态，`reset_run` 清空）。

**验收**：P0 §7.4 的 1 / 4 / 5 / 6 四项 + 候选规则与保护规则。

**完成（2026-11-09）**：`strip_trim_system.gd` 已落地。API：`reset_run / current_act / trims_left /
entry_state / candidates / preview / apply`；状态只有 `trimmed`（key → 次数）与 `used_by_act`（幕 → 次数）。
`entry_state()` 给入口三态：`ready` / `used`（本幕已用）/ `none`（还有次数但无合法候选）。
`loadout_system.reset_run_state()` 调用 `_trim.reset_run()`，与熟练/铭印同为「本局运行时状态」。

### B2 · 建带接入（预览 = 正式）

- `reel_system.build_strips`：按精简状态扣格（先算正常格数，再减 `trimmed[key]`，仍受保底 1 格约束）；
  `_collect_skill_items`：跳过已卸技能。
- `reel_preview.compose`：接受同一份精简状态，保证预览与正式一致（含最小带长平铺）。

**验收**：P0 §7.4 的 1 / 5；同种子同精简状态两次建带逐格相同。

**完成（2026-11-09）**：`ReelPreview.compose(...)` 末尾新增 `trim: Dictionary = {}`，在 `cells_for` 之后
`cells = maxi(1, cells - cut)`；`ReelSystem._apply_trim(key, cells)` 读 `_ctrl._trim.trimmed`，同一保底。
`DuelController._trim` 在 `_ready` 预加载实例化。技能卸除走 `selected_skills.erase` + `_build_pool`，
符号与 MISS 贡献按现建带规则自然消失（不改 `_collect_skill_items`）。
实测：符号 4→3 格时逻辑带 15→13（MISS 格按 total 比例重算，属既有规则），实际带长 39→39（最小带长平铺吸收）。

### B3 · 灰盒入口

- 棋盘屏一个「✂ 精简（本幕 1/1）」按钮：只在有合法候选时出现，弹层列出候选 + 真实前后预览 + 不可逆确认。
- 线性间歇态同按钮（并行入口，同一套系统）。
- 无合法候选 → 不显示按钮；用完后按钮显示「本幕已用」。

**验收**：反复开关界面/进出节点不能刷新次数或重掷随机；跨幕次数重置；技能卸除后无法通过重开界面恢复。

**完成（2026-11-09）**：弹层统一在 `battle_hud.show_trim_dialog()`（挂在 duel 根节点，
棋盘屏 `hud.hide()` 时仍可见，与营地弹层同一处理）。棋盘屏按钮 `board_screen._trim_btn`
（底栏 400,238 74×22，掷骰提示同步收窄到 254px），线性间歇入口在 InfoBar 代码内建
`interroom_trim_btn`（插在「商店」左侧，`set_interroom_enabled` 里按 `entry_state()` 刷新）。
弹层行为：候选行直接给「符号 4→3 格 · 带 15→13（实际 39→39 格）」；点选后预览区给
逻辑带 / 实际带（含平铺）/ 伤害格 / MISS 的前后；确认按钮带候选名并标注「不可逆」。
用尽后按钮显示「✂ 本幕已用」并禁用；`none` 状态隐藏。应用后棋盘信息栏（`board.feedback`）
与 HUD 反馈行各出一行日志。
