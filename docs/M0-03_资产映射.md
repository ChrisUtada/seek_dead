## 2. 回落路径（改图不阻塞运行）

| 表现位 | 回落顺序 | 代码位置 |
|---|---|---|
| 敌人 / BOSS 立绘 | `RoomData.art` → `enemy.png` | `battle_hud.gd:8`、`duel_controller.gd:559` |
| 武器图标 | （无字段）→ 首个符号 `label` emoji | `item_tooltip.gd:76-78` |
| 护符 / 消耗品图标 | `ItemData.icon` → `◆` | `item_tooltip.gd:98` |
| 技能图标 | `SkillData.icon` → `✦` | `item_tooltip.gd:110` |
| 奖励图标 | `RewardData.art` → `RewardData.icon` | `battle_hud.gd:426` |
| 转轮符号 | `SymbolData.label`（emoji 文本） | 转轮格渲染 |
| 状态 / 意图 | `icon` emoji | `battle_hud.gd:100-103` |

M3 新增字段只做表现绑定：`WeaponData.icon: Texture2D`、`SymbolData.icon: Texture2D`、敌人沿用 `RoomData.art`。空值必须继续回落到上表，保证逐批替换不破旧表现。

## 3. 视觉 ID → 房间映射

61 个房间 = **11 个轮廓族 + 13 个 BOSS 独立轮廓**。普通/精英敌人按族复用，元素与精英状态用「附件 + 局部身份色」表达。

| `behemoth_worm` | 宽体 + 前伸环形口 | 1 | `humus_worm` |

合计 **48** 个普通/精英房间。

### 3.2 变体规则（不做「换色敌人」）

- **元素变体**：主体保持 `enemy_body` 珊瑚红 + `enemy_dark`，元素色只出现在 1–2 处身份部件（火苗 / 冰晶 / 毒滴 / 光斑 / 暗雾），面积 ≤15%。
- **精英**：在族基准上增加轮廓附件——角/冠、外骨骼、更大武器、悬浮环或底座，不用放大或换色区分。
- **复用上限**：同族同元素不重复出图；跨幕同一族直接复用同一张。

### 3.3 出图数量（48 房间）

| 类别 | 数量 | 说明 |
|---|---:|---|
| 族基准图 | 11 | 每族 1 张 48×48 |
| 元素附件 | 5 | 火 / 冰 / 毒 / 光 / 暗，透明叠加 |
| 精英附件 | 5 | 角冠 / 装甲 / 巨武 / 悬浮环 / 底座 |
| **合计** | **21** | 覆盖 48 个房间 |
