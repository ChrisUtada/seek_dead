## 5. 出图与后处理口径（沿用 61 只怪物踩实的经验）

- 提示词指定**纯洋红 #FF00FF 纯色底**并写明「背景色不得出现在物件上」；抠底用**洋红度 `min(R,B)-G > 40`**（背景是渐变洋红时固定色距失效），水印区 `x≥870 & y≥915` 直接置 alpha=0。
- 母版 96×96 RGBA，成品 48×48：BOX 降采样 + 26 色量化 + 对比 1.12，轮廓比 LANCZOS 硬。
- 构图沿用已接入两把：**斜向、刃朝右上 / 柄朝左下、撑满画面**；暗色系主体 meanL 明显高于背景（建议 ≥60），靠局部亮灰高光与冷色裂缝保气质，不要整体压暗。
- 粒子一律 **1×1**（`assets/fx/fx_px1.png`），4×4 贴图在 48px 下会变脏点。
- 🔴 **每一把武器图标都必须带元素色粒子**（2026-11-13 用户叮嘱「都要加上，不要忘记了」）：粒子是**引擎层运行时统一注入**，不画进 PNG —— `WeaponIcons.apply()` / `ItemCard.set_art(tex, size, fx_color)` → `CPUParticles2D` + `assets/fx/fx_px1.png` 1px 火星，颜色取 `WeaponIcons.color_for(element)`。因此新 PNG 只要按 `icon_<id>.png` 命名接入就**自动带粒子，不需要逐把配特效**。逐把验收必须在「商店货架卡 / 房奖励卡」两处目视确认火星可见；发射点按图格尺寸自适应（`item_card.gd`，商店 32 / 奖励 36 / 生涯 24），别写死 48 口径。转轮符号格的按停爆裂粒子是另一套（`battle_hud.gd` 的 `cell_icon_fx`），已覆盖全部符号。
- 文件名严格 `icon_<资源 id>.png`，与 `.tres` 文件名一一对应；接入零改动。
- 造型 / 气质判断交回人工确认，**逐把确认后再进下一把**；不拿风格规范约束出图，效果优先。
- 🔴 **所有武器图标一律不出现手**（2026-11-13 用户拍板）：握柄手 / 拳头 / 手套 / 布缠都不行，柄尾只留护手或圆头。提示词必须写 `no hand / no fist / no glove / no cloth wrap` 并放进 OBJECT 段。烬裂砍刀 v2 因 AI 加浅粉握柄手被否，定向清色后留暗棕碎壳 + 断柄，生成端缺陷只能重出。
- 明度判断交回用户：烬裂砍刀 v1 meanL 43 被拍板「暗色版可以」，不要拿角色立绘的 ≥60 铁律硬压武器图标；但生成端仍要写局部亮灰高光，避免整片近黑融入底色。
- 母版 96 + 成品 48 走 `tools/prep_weapon_icon.py` 纯缩放（**不量化**：实测两把锚点 231 / 318 色）；本条上方「26 色量化」是旧 `prep_icon.py` 口径，与实际锚点不符，别照抄。
