## ② W03 门禁换构筑

### 问题

原构筑 `blight_spear + corrosive_bow` 两把均已软封存，违反「门禁构筑必须取自正式 30 把」。旧构筑仍可跑（归档武器可加载），但不再代表新玩家。

### 选型过程（5 种子×1200 轮，临时探针，跑完删除）

| 组合 | 组成率中位 | 每几回合 | 备注 |
|---|---|---|---|
| **plague_reaper + poison_dagger** | **23.5%**（探针）/ **23.1%**（门禁实跑） | 4.3 | **定稿** |
| venom_queen + plague_reaper | 25.3% | 4.0 | 接近上限 |
| venom_queen + venom_sickle | 22.3% | 4.5 | 两把都待迁移 |
| venom_sickle + poison_dagger | 22.4% | 4.5 | |
| venom_sickle + plague_reaper（工单建议初值） | 14.1% | 7.1 | 出带 |
| miasma_staff + poison_dagger | 14.3% | 7.0 | 出带 |
| miasma_staff + venom_queen | 12.6% | 7.9 | 出带 |
| miasma_staff + plague_reaper | 10.4% | 9.6 | 出带 |

**为何不用工单建议的 `venom_sickle + plague_reaper`**：两把武器共用 `venom_bite`，转轮按「符号+元素」聚合，4+5=9 权重被 `MAX_SYMBOL_CELLS=8` 截到 8 格；两把的中毒状态符号再占 3 格；收割者命中 0.75 又追加 MISS 格 —— 有效伤害占比跌到约 55%，组成率只有 14.1%。

**定稿 `plague_reaper + poison_dagger` 的理由**：落在带中（23.1%，4.3 回合/次）；`poison_dagger` 已完成状态迁移，后续扫批不会动它，门禁只剩一把武器会在扫批时变化；同时满足「两件毒元素装备」的 W03 解锁。
