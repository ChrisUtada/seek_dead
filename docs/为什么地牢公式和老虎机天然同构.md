



# 为什么地牢公式和老虎机天然同构

地牢的复玩性来自：**收集的惊喜**（几百把枪）+ **机制对抗**（弹幕模式）+ **微操作手感**（翻滚/翻桌）+ **风险决策**（诅咒/贪婪）。老虎机恰好有对应基因——**转轮就是枪库**、**结算就是弹幕对抗**、**装备组合就是 Synergies**。所以这些设计能直接翻译，而不是生搬。

## ① 装备共鸣（Synergies）—— 首推，低风险高回报

地牢的灵魂是「捡到 A + B 时，突然发现它们组合出隐藏效果」。这种**发现的惊喜**是复玩性的核心，也是你最缺的「想集齐」的目标感。

**落到你的架构**（这正好撞上你的铁律红利）：

- 你的符号/装备已是 `.tres` Resource，装备是 `LoadoutItem` 容器。新建一种 **Synergy 资源**（`.tres`）：`{需要同时装备的 weapon/skill/charm 列表, 效果(改符号 base / 加新符号 / 调乘区)}`。
- 用 `ResourceScan` 自动扫描 `resources/synergies/`——**完全符合你「加内容=新建 .tres、不改代码、不碰全局表」的铁律**，加一个共鸣就是加一个 .tres。
- 在 `_build_pool` / `_contribute` 时检测 loadout 组合，激活协同。例：铁剑+火焰剑 → 解锁「烈焰斩」；燃烧护符+毒护符 → 「毒焰」双 DoT 并存加 bonus。
- **关键约束**：协同只改**强度/机制**，不改频率（守住「频率 per-item、稀有度只定强度」）；它是 build 层选择，正好符合你「膨胀/策略放 build 层」的定位。

## ② BOSS 转轮招式（弹幕化）—— 次推，用现有通道

地牢 Boss 靠弹幕 Phase 有「性格」。老虎机没弹幕，但 **BOSS 可以操纵转轮来攻击你**。你已经有 `gimmick_script` + `boss_trash` 机制通道，只欠扩展成**签名招式**：

- 「锁链」：战斗中锁定某列转轮不让停，逼你打残阵；
- 「吞噬」：每 N 回合吃掉你某符号的 weight，削弱核心输出；
- 「封印」：暂时封禁你的 heal/shield 符号；
- 「破坏」：往转轮注大量废铁（`boss_trash` 雏形已有）。

每个 BOSS 一个招式，配上你的 ante 曲线，幕三 BOSS 才真正「难」而不是「血厚」。**风险低（现有通道）、回报高（机制对抗取代数值对抗）**。

## ③ 主动操作（手感深水区）—— 中后期，但别乱开乘区

地牢的翻滚无敌帧、翻桌给玩家**持续的控制感**。你的老虎机目前偏被动（按 spin → 看结果），这是「手感单薄」的根源。可加的主动手段：

- **单轮锁定**：`_locked_prev` 已有雏形 → 做成玩家主动「按住某列，这次转它不动」（耗能量），对应翻桌级微操作；
- **目押急停**：转轮滚动时在「好符号」经过时按停（街机老虎机的目押，直接上操作深度）；
- **抢击**：读 `enemy_intent`（已有）在敌人出手前抢转打断。

**⚠ 最重要的纪律**：你定了「战斗内只许 special 连锁重触发这一处局内乘区」。新主动操作要**只改变符号命中/保留，不轻易开新伤害乘区**，否则破坏你的「3 乘区」设计铁律。

## 次要调味（广度）

- **风险回报**：精英房（T6 战前补给已有 gold/anvil/shield）加第 4 种「献祭」（献血量换幕内加成）；战后「贪婪宝箱」赌加倍。
- **探索**：极低 weight 的「彩蛋符号」（仿 `GOLD_SYMBOL` 的全局注入）、`RoomData kind=hidden` 的隐藏奖励房（注意兼容 `_sort_rooms` 和 `_is_run_final`）。

## 建议的推进顺序

1. **第一批**：① 装备共鸣 + ② BOSS 招式 —— 直接补「想集齐」和「机制对抗」两块短板，且全程用现有架构，风险最低。
2. **第二批**：③ 主动操作 —— 手感深水区，但严格守住乘区铁律。
3. **第三批**：④⑤ 广度调味。
