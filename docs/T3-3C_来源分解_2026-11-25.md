## 1. 真实键样例（A1 探针原文）

一次性探针跑真实 `evaluate()`（铁剑 + 匕首，来源统一 `iron_sword`），`last_settlement_acc` 实际内容：

```text
# W07 落线：iron_slash + burn + fire_slash
source_dmg     = { "iron_sword": 22.0 }
source_heal    = {  }
source_shield  = {  }
dmg_by_elem    = { "none": 22.0 }
pattern_status = { "burn": 1 }
status_stacks  = { "burn": 1.0 }
pending_banners = [{ "text": "🔥⚔ W07 强化燃刃", "color": (0.8902, 0.3569, 0.3137, 1.0) }]
lines = [
  "   ⚔️ 铁斩  基础12(=11+1) = 12",
  "   🔥 火斩  基础10 = 10",
  "   ✦ 牌谱「强化燃刃」已触发",
]

# 三守备：source_shield = { "iron_sword": 18.0 }
# 三治疗：source_heal   = { "iron_sword": 45.0 }
```

键形态结论：

- `source_dmg` / `source_heal` / `source_shield` 的 key 是 **`source_id`**（武器/技能短 id，如 `iron_sword`），
  无 `source_id` 时回退为符号资源路径；value 为 `float`。
- `dmg_by_elem` 的 key 是元素（`none` / `fire` / …），与 `source_dmg` 同源累加。
- `pattern_status` 的 value 是整数层数；`status_stacks` 是符号层（float），本区只读 `pattern_status`。
- `pending_banners` 元素为 `{text, color}`，`text` 形如 `<icon> <id> <名字>[·签名]`。
- `lines` 中牌谱行形如 `✦ 牌谱「强化燃刃」已触发`。

## 2. 契约（B 组）

`static func build_sources(last_acc: Dictionary) -> Array[Dictionary]`，每行：

```gdscript
{"kind": "damage" | "heal" | "shield" | "status" | "pattern",
 "label": String, "value": int, "unit": String}
```

| kind | 来源 | label | value | unit |
|---|---|---|---|---|
| damage | `source_dmg` | key 的 `get_file().get_basename()` | 四舍五入取整 | `点` |
| heal | `source_heal` | 同上 | 同上 | `点` |
| shield | `source_shield` | 同上 | 同上 | `点` |
| status | `pattern_status` | 状态展示名（burn→燃烧等，未收录回退键名） | 层数 | `层` |
| pattern | `pending_banners`；无 banner 时回退 `lines` 中「牌谱「名」」行 | 牌谱名（去掉 `·签名` 后缀） | 1 | `条` |

顺序：damage → heal → shield → status → pattern。`value == 0` 的条目直接跳过（不产生「0 伤害」噪声）；
空 acc / 无来源返回空数组。`build_rows()` 未改动。

## 3. 只读证明

- `build_sources()` 只读 `last_acc`，不写任何键；测试用 `duplicate(true)` 前后相等断言。
- 面板 `open(rows, sources)` 对 `rows` / `sources` 均做深拷贝快照，不改传入数组。
- 打开/关闭来源面板前后 `_loot.seed_value()` / `enemy_hp` / `charge_points` / `turn_count` 不变
  （`t3c_combo_sources_test` 4 条断言）。
- 不调用结算、掉落、RNG 或任何会推进回合的方法。

## 4. 与面板的接口（C 组）

```gdscript
func open(rows: Array[Dictionary], sources: Array[Dictionary] = []) -> void
func show_combo_panel(rows: Array[Dictionary], sources: Array[Dictionary] = []) -> void
```

- `sources` 非空时，在组合区段之前渲染：
  - 标题 `本轮来源`
  - 每行 `标签  数值 单位`（例：`iron_sword  12 点`、`燃烧  1 层`、`强化燃刃  1 条`）
  - 一条 `—` 分隔
- `sources` 为空时整段不出现。
- 新增只读属性：`last_rendered_sources`（深拷贝）、`rendered_source_texts`（来源行文本）。
- 接线：`_on_combo_requested` 同时调 `build_rows` 与 `build_sources(last_settlement_acc)`，
  经 `hud.show_combo_panel(rows, sources)` 传入。
