## 1. 当前一句话定位

Seek Dead 的核心不是卡牌收集或角色升级，而是：

> **玩家通过战后三选一与武器替换，持续改造老虎机的符号构成、中奖规则和滚轴操控，最终形成具有独特玩法的中奖引擎。**

核心体验链：

```text
读取敌人意图
→ 选择目标符号
→ 手动停轮
→ 结算符号 / 牌谱 / 回路
→ 看懂伤害与生存结果
→ 战后做一次主要改造
→ 在下一场兑现构筑
```

## 2. 当前设计基线

### 2.1 引擎的四个改造面

| 改造面 | 职责 | 边界 |
|---|---|---|
| 武器底盘 | 符号来源、基础效能、精度、元素与签名 | 装备 2 把；本局仓库支持换入换出 |
| 符号带 | 真实格数、构成、浓度、精简与效果改造 | 所有预览与实战共用同一真实带模型 |
| 中奖规则 | 固有牌谱/签名 + 本局回路 | 回路最多装备 2 个，不无上限递归 |
| 滚轴操控 | 信息、节奏、补救与有限修正 | 不变成自动三连或替玩家操作 |

### 2.2 正式跑局：无地图的连续构筑战斗

当前采用线性结构，不保留分岔地图作为正式玩法层。

每幕固定 8 房：

| 顺序 | 房间 | 职责 |
|---|---|---|
| 1 | 普通战斗 | 开始构筑 |
| 2 | 普通战斗 | 延续构筑 |
| 3 | 宝箱或事件 | 直接惊喜 / 有代价的交易 |
| 4 | 精英战斗 | 第一次机制验收 |
| 5 | 普通战斗 | 兑现特殊房收益 |
| 6 | 精英战斗 | 第二次机制验收 |
| 7 | 营地 | Boss 前恢复或整理 |
| 8 | Boss | 本幕总验收 |

构成：**3 普通 + 2 精英 + 1 宝箱/事件 + 1 营地 + 1 Boss**。真·最终 Boss 另按当前流程追加。

不设置军械库、随机房间多选一或额外地图层。

### 2.3 战后流程

```text
战斗胜利
→ 战后三选一
→ 房间歇页
→ 可选打开商店，或直接下一房
```

不回大厅、不重置成长、不强制每战进入商店。

### 2.4 各奖励来源的唯一职责

| 来源 | 应承担 | 不应承担 |
|---|---|---|
| 普通战斗 | 一次标准引擎改造 | 多层额外补给 |
| 精英 | 一次高价值引擎改造 | 最终形态中自动护符入槽 |
| 宝箱 | 一件保密到开启的武器/普通护符/消耗品 | 三选一、通用数值成长 |
| 事件 | 有明确收益与代价的引擎交易 | 无决策随机扣血/给物 |
| 营地 | 恢复 25% HP，或精简符号/卸除技能 | 免费装备、额外 Draft |
| Boss | 遗物与主题武器/高价值选择 | 普通池无差别填充 |
| 商店 | 玩家主动付费修正 | 免费救济、无限随机武器 |

### 2.5 信息公开与随机

- 当前 ACT 的 Boss 应在开幕时公开名称、立绘、元素、弱抗和核心机制。
- 只给客观信息，不给准备方向或推荐答案。
- 宝箱类型可见，具体物品保密到主动开启。
- 事件选项、收益与代价在进入后展示。
- 特殊房内容可提前冻结，但冻结只服务可复现、合法过滤和未来存档，不等于提前公开。
- 所有随机生成不得因演出、开关商店或重复点击消耗额外随机流。

### 2.6 持有状态语义

| 状态 | 含义 | 用途 |
|---|---|---|
| 局外已解锁 | 永久内容池与图鉴资格 | 不等于本局持有，不应阻止商店购买 |
| 本局仓库已有 | 本局实际获得但未装备 | 可换装；商店显示“仓库已有”并禁止重复购买 |
| 当前已装备 | 正在贡献战斗 | 商店显示“已装备”并禁止重复购买 |
| Boss 遗物 | 独立 `run_relics` 本局遗物栏 | 不占普通护符槽，不与护符数量混算 |
| 消耗品腰带 | 按格与 charges 管理 | 允许同类重复，不套用唯一持有规则 |

### 2.7 武器进入三选一与品质表达

武器仍属于局内构筑，但在 Draft 中承担“改变引擎底盘”的限频选择，不作为高频填充卡：

- **获得武器**：提供新的构筑底盘，进入本局仓库，不强制换装；满槽时必须展示真实替换得失。
- **仓库换装**：在已有武器间横向调配，不包装成新成长，也不与获得武器共用含混标题。
- **来源分工**：普通 Draft 以符号、回路和操控改造为主，武器限频出现；精英、Boss 和宝箱承担更定向、高辨识度的武器来源。
- **普通不等于必换**：武器价值来自符号结构、精度、元素与签名。若普通武器只是短期过渡品，应修内容与跨幕价值，不用高品质标签掩盖。

武器获取卡只使用一个品质口径：**卡面继承具体 `WeaponData.rarity`，不得因为来自精英战或属于新获得而显示“进阶”。**

| 文案 | 只表达 |
|---|---|
| 普通 / 进阶 / 稀有 / 史诗 | 物品或效果的实际品质 |
| 新获得 / 仓库已有 / 已装备 | 本局持有状态 |
| 武器获取 / 仓库换装 | 奖励行为类型 |

推荐卡面为“【普通武器】战斧”，或“战斧／普通 · 武器 · 本局未持有”。不采用“进阶奖励 + 普通武器”的双品质卡面。非武器奖励可以按效果强度分级；具体物品奖励则继承物品品质。

### 2.8 风险与照顾玩家的边界

应保留：

- 基础目押可读性、真实意图和结算归因；
- Boss 信息、无效奖励过滤和换装预览；
- Boss 前营地与有限应急资源；
- 新手机制教学与固定种子复现。

应限制叠加：

- 自动改判、资源补偿、追赶、保底、免费恢复和额外奖励不能全部同时承担同一风险；
- 不为每次换装、失败或空池都建立第二套补偿；
- 不让保护机制替玩家做构筑选择；
- 不让奖励密度高到“选什么都差不多”。

2026-11-22 挑战审查补充：

- 商店不得通过自由切换元素/武器族来遍历候选池；每房货架收敛为 4 格，每幕商店武器机会上限为 2 次，reroll 冻结武器对象。
- 精英可以提供主题和高价值武器，但不应每场都直接给出当前敌人的精确克制答案；强化 Draft 不得再叠加自动护符。
- 幕间锻魂需要重新评审职责，不能把自动“符号伤害 +8、最大 HP +20 并同步回血”长期当作无选择的额外礼包。
- 消耗品必须通过库存与货架供给保持应急资源的稀缺性，不能只靠价格限制。
- T1.8 评审补充（2026-11-23）：同种子 A/B 未显示当前商店消耗品供给稳定破坏生存压力，
  **目前没有足够证据支持削减**库存、货架格、reroll 或购买上限。bot 买了不用，不能证明真人
  滥用购买时仍然安全；后续评审生存压力优先检查符号治疗（占 86–91%），而非继续削减商店。
- 每回合无效格转收益需要限额评审。T1.9 静态梳理（2026-11-23）已核实 `control_mercy`
  真实行为为「落在无效格转化为 +2 金币，不改变落点、不做改判，空转照旧」；敌方注废走独立
  `reason="jam"` 路径，根本不进入 mercy 分支。此前"同时抹除注废与精度代价"的判断不准确，
  以代码为准修正。
- 信息预览、死亡演出、品质统一、重复购买保护、固定目录价与无障碍设置不属于降低挑战，不以此为由回退。

## 8. 具体执行方案：25 节点、19 场战斗（2026-11-22）

> 本节把房间数量、奖励次数和战斗强度口径明确为可执行规格。目标是有效决策密度，不是让 25 个节点全部出现怪物。

### 8.1 固定数量

每幕固定：

- 普通战斗 3 场；
- 精英战斗 2 场；
- 宝箱/事件 1 个；
- 营地 1 个；
- Boss 1 场。

整局：

- 三幕共 24 个节点；
- 真·最终 Boss 追加为第 25 个节点；
- 普通/精英/幕末 Boss 战斗共 18 场；
- 加最终 Boss 后共 **19 场战斗**；
- 宝箱/事件与营地共 6 个非战斗节点。

不再宣称这与旧版 24 场幕内战斗在成长、经济和时长上完全等价。

### 8.2 每幕奖励预算

| 来源 | 每幕次数 | 内容 |
|---|---:|---|
| 普通战斗 | 3 | 标准战后 Draft |
| 精英战斗 | 2 | 强化战后 Draft |
| 宝箱/事件 | 1 | 直接物品或明确交易 |
| 营地 | 1 | 恢复 25% HP 或整理 |
| Boss | 1 | 遗物 + 主题武器/高价值选择 |

整局普通/精英 Draft 共 **15 次**，幕末 Boss 奖励 3 次；真·最终 Boss 独立收束。

不叠加精英自动护符、特殊房战后 Draft、营地装备或其他平行奖励。精英自动护符的移除必须先通过 ACT2 输出与生存替代验证。

### 8.3 非战斗内容口径

- **宝箱**：一件武器/普通护符/消耗品，保密到开启；武器进本局仓库，不强制换装。
- **事件**：收益与代价明确的二选一，优先改造符号、回路、操控或当前能力，不做纯 HP/金币数值填充。
- **营地**：恢复 25% HP 或精简/卸除一个合法目标；完成后可开商店或直接 Boss。
- 三类节点均不发清房金币、熟练、战斗掉落或战后 Draft。

### 8.4 战斗强度必须按实际战斗序号

普通/精英敌人的幕内强度位置应依据**本幕已经经历的实际战斗数**，不是房间数组下标。

- 宝箱、事件和营地不得提高下一场敌人的 ante 强度位置。
- Boss 继续使用幕末基准，不因非战斗节点额外抬升。
- 房间推进、日志和测试必须能区分“节点序号”和“战斗序号”。

### 8.5 经济与成长校准顺序

1. 验证每幕 5 次普通/精英 Draft 是否足以形成构筑。
2. 验证精英强化 Draft 能否支撑 ACT2 输出与生存。
3. 验证宝箱/事件是否提供有效但不重复的构筑资源。
4. 用固定目录价复核商店收入/支出是否匹配。
5. 检查 Boss 前是否仍依赖旧精英自动护符。

出现断层时先调整具体奖励内容，不直接补全局攻击，也不为恢复旧曲线机械增加重复战斗。

### 8.6 验收标准

- 总节点 25、战斗 19，房间类型和顺序固定。
- 每幕 5 次普通/精英 Draft、1 次特殊收益、1 次营地、1 次 Boss 奖励。
- 非战斗房不增加敌人强度，不触发清房奖励。
- 玩家在精英与 Boss 前能形成基本引擎。
- ACT1/2/3 输出、生存、死亡点和时长有同种子对照。
- 完整三幕、最终 Boss、老档、导出和全量 smoke 通过。
- 当前 M-02a 已有实现仍需完成 §4.1 的返工，不因本规格新增而标为完成。
