## 1. 停列短确认（边框 + 轻微缩放）

每次某列停稳（手动 / 自动 / 夺轮 / 锁轮 / 冻结）后，该列会得到一次 0.14s 的短确认：

| 元素 | 表现 | 约束 |
|---|---|---|
| 边框 | 格子内嵌 `StopFlash` Panel，透明底 + 2px 边框，从 alpha 1 淡出到 0 | `mouse_filter = IGNORE`，不拦截点击 |
| 缩放 | 格子 `scale` 按 `1 → 1.08 → 1` 的正弦脉冲，0.14s 回正 | 只改 `scale`，不改布局尺寸，不推动相邻格 |
| 颜色 | 按停轮结果分级（见下表） | 与停轮文本颜色同一语义 |

| 结果 | 边框颜色 |
|---|---|
| `target` / `lock` | `Palette.ACCENT_GOLD` |
| `miss` / `jam` | `Palette.POP_DAMAGE` |
| `forced`（夺轮） | `Palette.MUTED_DIM` |
| 其它（普通落点） | `Palette.TITLE` |

实现要点：

- `ReadabilitySystem.on_stop` **无条件**调用 `hud._pulse_stop_cell(reel, outcome)`。停轮文本仍受 `feedback_enabled` 控制，所以 `control` 预设只多一个视觉确认，不新增文本、预览或缓冲，P1 的预设差异不变。
- 每次脉冲先 `kill` 上一列/上一格的旧 Tween，避免连续停轮叠加；`_clear_stop_feedback` 在新回合/新旋转前把 alpha、scale 归零，不跨回合残留。
- 脉冲与吸附完成同帧触发：视觉上「吸附落定 → 边框亮起」，不会提前于结算。

## 2. 回合反馈分级与连击层次

底部单行反馈沿用 Step 5 的文本内容，只增加颜色与 0.12s 缩放脉冲：

| 结果 | 颜色 | 基础缩放 |
|---|---|---:|
| 核爆 / 充能爆发 | `ACCENT_GOLD` | 1.10 |
| 三连 / 同元素三连 | `ACCENT_GOLD` | 1.07 |
| 破甲 | `ARMOR` | 1.05 |
| 护盾 / 治疗 / 溢出转盾 | `POP_SHIELD` / `POP_HEAL` | 1.03 |
| 普通命中 | `TITLE` | 1.02 |
| 无命中 | `TITLE` | 1.00 |

连击层次：

- 在基础缩放下再叠加 `+0.006 × (clamp(最高连击, 0, 8) - 1)`；
- 2 连 +0.006，8 连 +0.042，**8 连封顶**（12 连与 8 连幅度相同）；
- 最高组合（核爆 + 8 连）峰值约 `1.10 + 0.042 = 1.142`，仍在格子/反馈行的空白余量内。

`_clear_badges`、`_show_action_feedback`、`_show_spin_summary` 会重置反馈行颜色与缩放，保证回合间不串色、不残留脉冲。

## 3. 音效：本轮不可实现，已用视觉替代

- 全项目检索确认：无任何 `.wav / .ogg / .mp3` 资源，也没有 `AudioStreamPlayer` 节点或代码。  
- 因此方案中的「停列音效 / 连击音调递增」本轮无法落地；改用**停列边框 + 缩放**作为每次操作的确认，用**反馈行缩放幅度**作为连击「音调」的可视替代。
- 音频接入需要单独的素材与音频总线方案，已延后；本轮不引入占位音效，避免后续替换时产生行为差异。

## 6. 边界与下一步

- 缩放只作用于 `Control.scale`，不改变 `GridContainer` 布局；1.08 倍约为 38px 格子外扩 3px，属于有意为之的短促反馈。
- 反馈行与停列边框共用同一套 Palette 语义；若后续调整伤害/护甲色，需要同步检查这两处分级。
- 音频（停列音效、连击音调）明确延后；在没有音频资源前不新增无声占位。
- 下一步 Step 5：30/60/120fps 实机停轮核对、逐列点击/连续按停/锁轮/冻结/自动停轮、完整 ACT1、`run_smoke` 与真人体验复核。
