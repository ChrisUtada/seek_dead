## 1. 定位与特色

**隐秘 BOSS（高难隐藏内容）**：Act1 BOSS 槽「4 候选选 1」的 hidden 候选（权重 2 ≈ 14%）；幕内全清后开启（BOSS 槽为幕内最后一房，条件恒满足）；预告横幅「？？？（隐秘 · 条件解锁）」不剧透。

**主题升级（v2）**：盘踞在地下城密室、用岩石与藤蔓死死封住自己的守卫。但茧壳必须周期性地裂开一道缝换气——**它探出头的瞬间，既是它最具攻击性的时刻（恐惧驱动的先发制人），也是它唯一脆弱的时刻**（社交恐惧「被迫露面」的双向暴露）。

```
① 开合节律：周期 4 回合 = 闭合×3（厚甲 45 + 回血 6 + 注废骚扰）→ 开合×1（甲 0 + 重击）
② 闭合期磨血惩罚：输出被厚甲吃掉、它还回 6 → 闭合期硬磨 = 净亏，逼玩家等窗口
③ 开合期风险对赌：它重击、你爆发 —— 窗口博弈
```

**定位**：铁瓮（教学位）教「破甲三件套」；茧居 v2（隐秘位）验收「**节奏管理**」——把资源（三连 / 强袭 / 充能 / 重转）攒进对的那一回合。

## 3. 机制（开合节律 cocoon_cycle，全参数化 T24）

### 3.1 封闭壁垒·开合（核心）
- **进房即闭合**（on_room_start：`enemy_armor_max` 设为 `shell_armor`=45 并补满）
- **回合计数**：闭合 `closed_turns`=3 回合 → 第 4 回合**开合**（`enemy_armor_max` 归 `open_armor`=0）→ 次回合**重新闭合**（甲重设 45 补满），循环
- **闭合期每回合回 6**（满血不触发）；**开合期不回血**（探头时无暇休养）
- **甲在每次闭合重置**——闭合期破甲只管当前周期（与铁瓮永久甲的核心差异）
- 参数化（T24）：
```json
{"cycle_period": 4, "shell_armor": 45, "open_armor": 0, "heal_per_turn": 6, "open_heavy_mult": 2.0}
```
> 闭合期意图权重走 `RoomData.intents`（attack 45 / jam 35 / heavy 20 内联）；开合期 gimmick 强制重击（`open_heavy_mult` 倍率）——意图覆盖后 `_refresh_meta` 刷新 HUD，玩家提前一回合可见窗口。

### 3.2 意图随相切换（可读预告）
- 闭合期：attack 45 / jam 35 / heavy 20——缩在壳里骚扰、注废锁轮（jam 净化药剂可抵消）
- 开合期：heavy 70 / attack 30——探头发狠
- 换权走迷宫低语者 whisper_lock「乱权」先例（on_turn_begin 按相改权重）；HUD 预告 + 🐚 ICON + 日志「茧壳裂开！」——**玩家永远提前知道下一回合是不是窗口**，窗口博弈成立的前提

### 3.3 解法轴区分（为什么不再是「铁瓮同解」）

| BOSS | 甲的形态 | 正解轴 |
|---|---|---|
| 冰封铁瓮（教学位） | 永久叠加 | 破甲三连清空（一次投资，永久生效） |
| 茧居石雕 v2（隐秘位） | **周期重置** | **节律**：把爆发攒进开合窗口；穿透全程无视甲 |

- 破甲三连仍可用，但每周期要重新投资 → 从「正解」降级为「备胎」
- 穿透符号全程直击 HP（无视闭合甲），开合窗口对它无额外收益 → 穿透流跳过机制（build 投资的合理奖励，与铁瓮一致）

### 3.4 可选调参（默认关）
- `panic_seal_threshold`（默认 0 = 关）：开合期单段伤害超过阈值立即提前闭合（受惊缩回）——防一发入魂、加博弈纹理。供 F6 调参后再决定是否启用

## 4. 对策与联动（解法矩阵）

| 对策轴 | 具体 | 联动 |
|---|---|---|
| **节律·主解** | 闭合期蓄力（攒强袭/充能、重转凑三连）→ 开合期倾泄 | 新验收点：资源 × 时机 |
| **穿透·特权** | pistol 20/82% / ice_gun 30/88%（pierce 直击 HP）/ 穿甲重弩（组合型 #1） | 无视周期（build 特权） |
| **元素克制** | fire_sword 45/88% / flame_staff 40/86%（×1.5）+ 元素契印 ×1.7 | 克制命中喂充能，窗口内全吃 |
| **爆发·窗口** | 强袭×2 / 充能核爆 / 三连暴击 / 蓄势（组合型 #2） | 窗口内兑击杀 |
| **破甲·备胎** | 铁剑/战斧 triple_pierce 清 45 甲 | 仅管当周期，闭合重置 |
| **抗干扰** | 净化药剂（抵 jam 注废，purifiable） | 闭合期净化 = 保住蓄力节奏 |
| **重转·调度** | 重转卷轴 | 把三连挪进窗口的核心调度工具 |
| **基础功** | MISS 按停规避 | 闭合期白回合最亏 |

**节奏参考**：R1-3 闭合（甲 45 + 回 6 + jam 骚扰；玩家按兵蓄力 / 重转凑牌）→ R4 开合（甲 0，它 heavy；玩家强袭 + 三连 + 克制全倾）→ R5 重封（甲回 45）→ 循环。窗口错过 = 再等 3 回合，拖杀惩罚来自回血。
