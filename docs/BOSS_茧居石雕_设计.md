## 1. 定位与特色

**隐秘 BOSS（高难隐藏内容）**：Act1 BOSS 槽「4 候选选 1」的隐秘候选（`boss_role=hidden`，权重 2 ≈ 18%）——**幕内全清后开启**（BOSS 槽为幕内最后一房，条件恒满足）；下一房预告横幅显示「？？？（隐秘 · 条件解锁）」不剧透，遇上是惊喜。

```
① 封闭壁垒：每 3 回合 +15 厚盾（峰值 +45，叠在基础甲 15 之上）→ 破甲窗口硬闸门
② 自我治疗：每回合回 6 HP → 输出必须持续压过回复，拖得越久越亏
③ 注废锁轮：jam 意图注废一列（净化药剂可抵消）→ 干扰输出节奏
```

**定位**：铁瓮（教学位）教完破甲三件套后，茧居石雕是**同解的隐秘验收关**——盾比铁瓮更厚更快、回复吃掉磨血流，只有穿透/破甲三连/强袭爆发能稳过。

## 3. 机制

### 3.1 封闭壁垒（shield_heal · 核心）
- **叠盾**：每 `shield_interval`（默认 3）回合 `enemy_armor_max += shield_amount`（默认 15）+ 补满，上限 `shield_max`（默认 45）——比 rust_armor（8/层）更厚更快
- **自我治疗**：每回合 `heal_per_turn`（默认 6）回血（enemy_hp +=，日志飘字）——磨血流的对撞器：净输出必须 > 6/回合 + 等效盾 5/回合 ≈ 11/回合
- 参数化：`gimmick_params = {"shield_interval": 3, "shield_amount": 15, "shield_max": 45, "heal_per_turn": 6}`（T24 新规）

### 3.2 注废锁轮（jam 意图）
- 意图剖面 attack 50 / heavy 25 / jam 25：jam = 注废一列（`pending_jam_reel`，下一轮该列废铁占据）
- **净化药剂可抵消**（purifiable）——单侧性职责下净化药剂（敌人意图对策）在本战成为正解（铁瓮/酸蚀恶鬼用清净药剂，职责分明的对应对）

### 3.3 破甲三件套的验收
- 盾是扁平池（先破甲后掉血）：**破甲武器三连（triple_pierce）清空** / **穿透符号直击** / **破甲符概率穿透** / **充能爆发清甲+20% max HP**
- 与铁瓮差异：盾更快更厚 + 回复抵消 → 磨血流（非克制慢慢磨）会被拖死，逼玩家用爆发/穿透

## 4. 对策与联动（解法矩阵）

| 对策轴 | 具体 | 联动 |
|---|---|---|
| **穿透·主解** | pistol 20/82% / ice_gun 30/88%（pierce 符号直击 HP） | 无视厚盾——盾再厚也没用 |
| **破甲·清盾** | 铁剑/战斧/夜幕镰刀（triple_pierce）三连清空 + 破甲符 25% | 打开直击窗口（铁瓮教学成果验收） |
| **爆发·窗口** | 强袭×2 / 元素充能核爆（清甲+20% max HP）/ 三连暴击 | 破甲窗口内输出必须兑成击杀 |
| **净化·干扰** | 净化药剂（抵消 jam 注废意图） | 干扰意图对策（与清净药剂职责分离） |
| **武器·克制** | fire_sword 45/88% / flame_staff 40/86%（×1.5） | 克制命中喂充能，双轴并行 |
| **重转** | 重转卷轴（凑三连/克 2 连） | 破甲窗口多一搏 |
| **基础功** | MISS 按停规避 | 白回合 = 白吃回血 + 盾更厚 |

**节奏参考**：开局 attack/jam 平压 → 第 3 回合首次 +15 盾 + 回血累积 → 中期盾峰值（60）+ 注废干扰 → 玩家凑破甲三连/换穿透开直击窗口 → 强袭爆发击杀（击杀窗口错过 = 盾再起，拖杀循环）。
