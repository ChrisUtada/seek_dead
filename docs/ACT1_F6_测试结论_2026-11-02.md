## 2. 结论

### 2.1 M4 出口：**未通过**

M4 出口的四项条件：

| 条件 | 状态 | 证据 |
|---|---|---|
| Demo 可独立导出并完整游玩 | ✅ | 本局完整通关，无阻塞 |
| 自动回归全绿 | ✅ | 13/13、5352 断言 |
| **成长获得用户验收** | ❌ | 38C「说不清方向」、39C「没感觉变强」、42C「没改变打法」 |
| 形成测试者反馈清单 | ✅ | 本测试表 |

**阻塞项只有一个：成长不可感知。** 不是 bug、不是崩溃，而是玩家打完说不清自己成长了什么、也没觉得变强。按 M4 出口规则，不能宣布 M4 完成。

### 2.2 M4-03 节奏：**回合数达标，体感未达标**

- 达标：普通房 2–4 回合（14B）、BOSS 6–10 回合（43B），落在设计窗口内。
- 未达标：整体「太快」（15A / 53A）、敌人与 BOSS「太简单」（23A / 44A）、首次游玩 10 分钟内通关（3A）、BOSS 战「没有最挫时刻」（47D）。

结论：**问题不在回合数，而在单回合的威胁感和决策压力**。回合数被控制在窗口内，但每回合伤害过高或敌人太弱，导致「回合数正常、体验太快」。

### 2.3 M5 核心循环：**未触发「必须重做」条件，但不建议直接扩三幕**

按测试表规则，核心项（双武器负协同 / 元素机制弱 / 换装停滞 / 元素单极化）均未命中正式条件；且只有 1 局，未达到「≥3 局命中」的判定线。因此：

- **形式上**：可以继续 M5 的内容扩充。
- **实际上**：成长验收未通过、难度过低，直接扩三幕会把「玩家不需要优化也能过」放大到三幕。建议先完成 P0 调优并复测，再决定是否进入 M5。

## 4. 优化方案

### P0-1 · 难度与时长（只调数值，不改结构）

**目标**：首次游玩 12–20 分钟；敌人「合适」；BOSS「合适」且有一次「差点翻车」的时刻。

| 动作 | 建议幅度 | 说明 |
|---|---|---|
| BOSS HP | +20% ~ +30% | 先只动 BOSS，观察回合数是否仍在 6–10 |
| 敌人攻击 | +10% ~ +15% | 制造威胁感，不增加血量拖延 |
| 玩家伤害 | 暂不动 | 避免同时改两个轴，无法归因 |
| BOSS 机制 | 保持现状 | 45B 已能理解，问题在数值不在机制 |

**验收**：23 = B、44 = B、3 落在 B/C、47 ≠ D（出现一次「差点输」）、14 仍为 B、43 仍为 B。

### P0-2 · 成长可感知（M4 出口阻塞项）

**目标**：玩家打完能说出「这局我走的是角色 HP 线 / 武器熟练线」，并感觉变强。

| 动作 | 说明 |
|---|---|
| 减少次数、加大单次幅度 | 40A 认为「太少」，但单纯增加次数会更无感；优先让每次选择有明确结果 |
| 展示前→后对比 | 不只显示「+2 攻击」，而是显示「每转期望伤害 / 带子格数 / 最大 HP」的实际变化 |
| 把成长与构筑方向绑定 | 技艺选择对应生存/运筹/目押；铭印选择对应「更多格 / 更高攻」，让玩家能归纳方向 |
| 增加常驻成长摘要 | 战斗 HUD 或整备页显示「本局成长：Lv.3 · 锋铸 ×1 · 调律 ×1」 |
| 首次成长位置保持 | 36B（第 3–4 房）已在窗口内，不改 |

**验收**：37 = A/B、38 = A/B、39 = A/B、42 = A/B；40 不再集中选 A（太少）或 D（太多）。

### P1-3 · 目押可读性

**目标**：玩家敢说「我大概能停中目标符号」，三连从「偶尔」提升到「每房 1–2 次」。

| 动作 | 说明 |
|---|---|
| 转轮速度 | 降低约 15%，或第三列接近目标符号时短暂减速 |
| 目标高亮 | 停轮前高亮当前列的攻击/克制符号，不改结算 |
| 停轮反馈 | 停下后显示「命中 / 差一格」，让玩家建立手感 |
| 不做「每转必出攻击」 | 会破坏静态带子可读性，已被文档否决 |

**验收**：11 = A、12 = A/B、16 = A/B、17 = A/B。

### P1-4 · 意图可执行

**目标**：看到意图后，玩家能做出具体应对，而不是「只是知道」。

| 动作 | 说明 |
|---|---|
| 显示后果数值 | 「重击 -24 HP」「注废 2 格」而不是只显示类型 |
| 高亮应对符号 | 当前带子中能防御/净化/治疗的符号加边框 |
| 提前量明确 | 显示「本回合 / 下回合」而不是模糊的下一意图 |
| 不新增按钮/系统 | 保持现有单意图模型 |

**验收**：19 = A、20 = A/B、21 = A/B。

### P1-5 · 双武器协同

**目标**：玩家能感觉到「两把武器在一起更强」，并愿意尝试共鸣。

| 动作 | 说明 |
|---|---|
| 共享符号可视化 | 同元素双武器时显示「火斩 ×2 已合并」，让聚合规则可见 |
| 共鸣进度提示 | 整备/战斗显示「火焰共鸣 1/2」，差一件时提示 |
| 修复死效果 | 现有火焰共鸣 +2 权重不增加格数（已记录的反面教材），改为真实格数或数值收益 |
| 引导异元素组合 | 用提示/成就引导「火+毒」「冰+火」，但不新增系统 |

**验收**：34 = A/B、35 = A/B；7 不再全是 A（同元素）而出现 B（异元素）尝试。

### P2-6 · 内容量

**目标**：回应 54D「内容太少」，但不与 P0 调优抢优先级。

| 动作 | 说明 |
|---|---|
| 明确 Demo 边界 | 试玩包只有 14 武器 / 8 房 / 单局 1 BOSS；正式版武器已 90 把 |
| 扩充 F6 白名单（可选） | 若希望试玩更有构筑空间，可把 demo 白名单从 14 扩到 20–25 把 |
| 补 BOSS 覆盖 | 本轮只遇到 1 个 ACT1 BOSS；M4-02 要求 4 个 BOSS 可达，需再跑 3 局覆盖 |
| 不做全量铺量 | 当前问题不是「武器不够」，而是「现有 14 把没被用出差异」 |

## 5. 复测计划

- **样本**：至少 3 名测试者 × 3 局（共 9 局），首局仍用默认配装。
- **重点题**：12（停轮命中）、16–17（三连）、20–21（意图）、31（换装）、34–35（协同）、38–39–42（成长）、23/44（难度）。
- **通过线**：
  - P0 调优后：23/44 至少一项转为 B；38/39/42 至少两项转为 A/B；首次通关时长进入 12–20 分钟。
  - P1 调优后：12 转为 A/B；20 转为 A/B；34 转为 A/B。
- **核心循环复核**：若上述弱信号在 ≥3 局仍命中（尤其 34 = D、20 = D、12 = C），按 M5-04 暂停扩三幕，先出《核心循环修订方案》。

## 6. 风险与说明

1. **单局样本**：本结论基于 1 局首次游玩，不能替代多局、多测试者数据；测试表本身设计为 5 局汇总。
2. **Demo 边界**：10 分钟通关与「内容太少」受 ACT1 Demo 白名单限制（14 武器 / 8 房 / 单局 1 BOSS），不等于完整三幕的体量。
3. **BOSS 覆盖不全**：本轮只遇到 1 个 ACT1 BOSS，M4-02 的「4 个 BOSS 可达路径」尚未验证。
4. **调参纪律**：P0-1 一次只动一个轴（先 BOSS HP，再敌人攻击），每次改动后跑 `p1b_baseline` + `run_smoke.bat`，TTK/承伤偏离 ±30% 即停。
5. **不改核心结构**：本阶段不改三连判定、不新增系统、不做 ROWS=2 / 主动锁定 / 抢击。
