# 武器制作逻辑 · 设计规范（基础属性 / 机制 / 元素三层模型）

> 状态：规范文档（2026-08-07）。依据：LoadoutItem/WeaponData/SymbolData 字段 + 本会话全部平衡收敛（T1 专属符号、T21 单武器、T22 资源化、去 MISS、同元素三连、稀有度定价）。
> 用途：新武器制作 = 按本文档分层填 .tres，零代码；后续 T4（90 武器）批量铺料的唯一规范。
> 关联：装备收集规划_200（数量/稀有度分配）、战斗平衡收敛_执行方案（数值锚点）。

---

## 1. 核心模型：武器 = 三层

```
武器 .tres
├── ① 基础属性层  数值骨架（多强）：rarity / base_power / crit_mult / 符号 base / weight
├── ② 机制层      行为效果（什么效果）：符号 kind / pierce / status / buff / special
└── ③ 元素层      克制身份（克制谁）：element / reel_element / 符号元素继承
```

三层正交：同一机制可配不同元素（火剑/冰剑同机制不同克制）；同一元素可配不同数值。

## 2. ① 基础属性层（数值骨架 · 决定「多强」）

| 字段 | 位置 | 规范 | 说明 |
|---|---|---|---|
| `rarity` | LoadoutItem | common/uncommon/rare/epic（40/30/20/10 金字塔） | **只定强度，不定频率**（神装也正常出现） |
| `base_power` | LoadoutItem | 参照档位：common 20~35 / uncommon 25~45 / rare 40~50 / epic 40~50 | **唯一伤害数值源**（2026-08-07 重构 T12）：伤害 = `base_power + 元进度` × 连线 × 克制；符号 base 不再缩放 |
| `crit_mult` | LoadoutItem | 2.0（common）~3.0（epic 上限） | 三连/同元素三连暴击倍率 |
| `crit_chance` | LoadoutItem | 0.0 ~ 0.15（2026-08-07 新增） | **非三连暴击率加成**：总暴击率 = `BALANCE.crit_chance(0.20)` + 此值；**高 base 低暴击 = 武器代价轴**（替代退役的 hit_rate） |
| `symbols[].weight` | SymbolWeight | 主符号 6~7 / 特殊机制 1~2 | 该武器符号出现权重（16 格预算内分配） |
| `hit_rate` | LoadoutItem | **已退役（去 MISS）** | 不再影响转轮；勿填 |

**数值锚点**：单符号伤害 ≈ `base_power × 连线 × 克制 × 暴击`（符号 `base` 字段仅对 heal/shield/status 符号生效：治疗/护盾 = `sym.base × 连线 × 暴击`，不吃攻击力/克制）。

## 3. ② 机制层（行为效果 · 决定「什么效果」）

机制全部由**符号 kind** 分派（结算分支见 `_contribute`）：

| kind | 行为 | 规范 |
|---|---|---|
| `damage` | 常规伤害（吃连线/克制/暴击/穿透） | 每武器**至少 1 个专属伤害符号**（禁共享：圣辉/破晓复用 arcane_bolt 的教训，`117d7ae` 已修） |
| `special` | 三连破甲 + 连锁重转 | weight 恒 1；元素走 `reel_element` |
| `status` | 叠状态（burn/frost/poison → StatusDef） | **武器特殊机制之一**（如毒匕挂毒、冰枪挂霜）；status_type 对应 `resources/statuses/` 的 id |
| `shield` / `heal` | 加护盾/回血 | **武器不携带**（2026-08-07 重构：归护符/技能/房奖励）；符号 base 小值（如治疗 6） |
| `buff` | 技能增益（迅捷/狂怒） | 技能专用，武器不携带 |

**机制参数**：
- `pierce_armor`：穿透护甲直击（射击类符号 pistol_shot/ice_shot 置 true）
- `buff_effect/value/turns`：技能增益定义（武器不用）

**设计原则**：
- **武器符号 = [主攻击符号（专属，weight 6-7）] + [特殊机制符号（special 或 status，weight 1-2）]**——不携带治疗/护盾/增益
- 特殊符号是武器「灵魂」——三连破甲/连锁的载体，rare+ 建议携带

## 4. ③ 元素层（克制身份 · 决定「克制谁」）

| 字段 | 位置 | 规则 |
|---|---|---|
| `element` | WeaponData | 武器元素：普通符号（自身 element=none 时）**继承**此值 |
| `reel_element` | WeaponData | special 符号元素（优先于 element） |
| `symbol.element` | SymbolData | 非 none 则**独立生效**（覆盖继承） |

**继承规则**（`_eff_element`）：
```
special 符号 → reel_element（非 none 时）
其他符号    → 自身 element 非 none 用之；否则继承武器 element
```

**五元环**：`火 > 冰 > 毒 > 光 > 暗 > 火`（克制 ×1.5 / 抵抗 ×0.85，单向玩家→敌人）。

**分布规范**（装备收集规划 §14.6）：
- BOSS 多为强元素（逼克制核爆）；普通怪 none 居多
- 武器池元素均匀（90 把 = 6 元素桶 ×15，§12.3）；**当前 12 把：火2/冰1/毒1/光2/暗2/无4**

## 5. 组装规则（新武器制作流程）

```
Step 1 · 身份元素：定 element / reel_element（或 none）
Step 2 · 定强度：rarity → base_power（对照 §2 档位）→ crit_mult → crit_chance（高 base 低暴击）
Step 3 · 设计符号：专属主攻击符号（label 元素 glyph）weight 6~7
         + 特殊机制符号（special 或 status，weight 1~2）
         ✗ 不携带 heal/shield/buff（归护符/技能）
Step 4 · 数值自查：§6 校验清单
```

**模板**（新 .tres 骨架）：参照 `holy_sword.tres`（圣辉斩 + 治疗 + special 的标准样板）。

## 6. 平衡校验清单（制作后自查）

- [ ] 伤害符号**专属**（无与其他武器/技能共享）
- [ ] `base_power` 与 `rarity` 匹配档位（§2）
- [ ] `crit_mult` 在 2.0~3.0 内；**`crit_chance` 与 base_power 成反比**（高 base 低暴击：battle_axe 50/0、pistol 20/0.15）
- [ ] 主符号 weight 6~7、特殊机制符号 1~2（**无 heal/shield/buff**）
- [ ] special 符号元素走 `reel_element`（与武器元素一致或刻意不同）
- [ ] 穿透武器（如远程）置 `pierce_armor`
- [ ] 元素归属明确（克谁/被谁克），不与同幕 BOSS 元素冲突
- [ ] 遗留字段（damage/attack_speed/attack_range/cleave/knockback/bullet/ammo/heat/status_effect_*）**不填**（ARPG 原型残留，转轮战斗不读取，见 §7）

## 7. 遗留字段说明（勿填）

`WeaponData` 中以下字段为早期 ARPG 原型残留，转轮战斗**不读取**：`damage / damage_type / attack_speed / attack_range / weapon_scene / grip_point / visual_offset / visual_scale / status_effect_type / status_effect_damage / status_effect_duration / heat_per_attack / bullet_scene / bullet_speed / max_ammo / ammo_per_shot / cleave_angle / knockback_force`。
→ 制作武器时忽略；如需清理，可后续立项移除（建议随 T4 内容批次一起）。

## 8. 样板拆解：圣辉长剑（rare）

| 层 | 配置 | 理由 |
|---|---|---|
| 身份 | 圣辉长剑 / light / reel_element=light | 光系主输出（克 Act2 暗 BOSS） |
| 基础 | rare / base_power 45 / crit_mult 2.0 | 45 = rare 档高位 |
| 机制 | 圣辉斩(damage,9,weight6) + 治疗(heal,2) + special(1) | 主攻 + 续航 + 三连破甲 |
| 元素 | 全部符号 light（治疗继承） | 光系纯一，克制闭环清晰 |
