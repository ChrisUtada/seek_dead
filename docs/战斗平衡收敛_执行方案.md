## 1. 背景与问题

### 1.1 核心问题：单武器最优

实测与模拟均显示**单带 1 把武器是最容易通关的配置**，根源在转轮机制的结构性矛盾：

```
三连率 ∝ f³，f = 目标符号占带子预算的份额
单带火焰剑：fire_slash 占 ~6/16 → 三连率 ≈ 5.3%
双带火+毒：fire_slash 占 ~3/16 → 三连率 ≈ 0.7%（差 8 倍）
```

方案 B（`59d2ab1`）用 `CRIT_CHANCE=0.20` 独立暴击把**期望伤害**解耦了，但通关靠的**爆发杠杆**（三连必暴 / 破甲 / 核爆 / 连锁重转 / 免费回合）全部挂在「同符号」事件上——期望拉平 ≠ 手感拉平，多带（尤其异元素）依然全面吃亏。

### 1.2 矛盾精确定位

- **同元素多带不矛盾**：方案 B 的 `(符号|元素)` 聚合让同元素武器共享符号累加（同剑×2 三连率 0.158→0.123 持平）
- **异元素多带必然矛盾**：符号不聚合 → 任何单一符号份额下跌 → 三连崩；其唯一价值「每房克制 ×1.5」是分散的、攒不出爆发

### 1.3 高伤害武器无脑碾压

战斧/夜幕镰刀（base 50）、圣辉长剑/火焰剑（45）纯数值最优——武器选择退化为比 base_power。

## 2. 目标

1. **消灭整备阶段的「数量最优解」**：整备只问「带哪把」，不问「带几把」
2. **把「多带」从 build 决策变成局内经济决策**：开局集中，局内商店扩散
3. **强化克制 = 武器选择的信息量与回报**（带对元素有明确收益）
4. **给覆盖流（异元素/技能补元素）一条独立爆发赛道**：元素充能
5. **强武器平衡零运行时机制**：不引入次数/弹药/槽位系统

---

## 3. 核心设计：开局集中 → 局内扩散

### 3.1 整备阶段：1 武器 + 1 技能开局

| 项 | 现状 | 改造 |
|---|---|---|
| 武器槽初始 | `SLOT_INIT["weapon"] = 2` | **→ 1**（整备只能带出 1 把） |
| 技能槽 | 1（不变） | 技能 = 第二输出源 + 第二元素（magic_bolt=光 / recovery=治疗） |
| 输出源总数 | 2 武器 + 1 技能 = 3 | **1 武器 + 1 技能 = 2**（砍掉一个） |
| 确认条件 | `LOADOUT_MIN=1`（不变） | 满足 |
| 卖出保护 | 「至少保留 1 把」（不变） | 满足 |

- 整备 = 选「主武器（元素/密度/特殊符号）+ 技能（第二元素/功能）」+ 护符 + 消耗品
- **开局三连密度最大化**：带子 = 1 武器符号 + 技能符号 + 金币 + 废铁，教学与爽感前置

### 3.2 局内商店：扩武器 = 成长时刻

- 商店武器页保留全池售卖；**首次购买第 2 把武器 = 本局扩槽（现有"买即开槽"逻辑）**——从 1→2 是明确的节奏改变点
- 多带的代价由玩家在 run 内体验过单武器密度后**自己做出**（金币 + 密度稀释），而非开局硬塞
- 溢出约束：`LOADOUT_MIN=1`、卖出保护不变；`SLOT_INIT` 改 1 后 `_cat_max("weapon")` 随购买成长

## 4. 克制强化（选择杠杆 · 已拍板）

**目标**：让「选哪把武器」成为「选什么解法」。克制体系已有一套完整杠杆，本方案做**显性化与强化**，不加大惩罚：

| 杠杆 | 现状 | 本方案 |
|---|---|---|
| 克制倍率 | ×1.5 / 抵抗 ×0.85 / 中性 ×1.0 | **不变**（惩罚保持温和，总纲「惩罚温和」） |
| 克制命中 | 仅倍率 | **额外 +1 元素充能**（见 §5，把分散克制收益变成节奏） |
| 元素优势护符（T2） | 元素契印 +0.2 | 不变 |
| 克制 2 连 | 破甲 + 20% max HP 核爆（counter_triple） | 不变 |
| HUD 呈现 | 敌人面板「弱 X ×1.5 / 抗 Y ×0.85」 | 不变（可预知性已具备） |

**决策闭环**：课程化预告（每幕元素集中，Act1 冰系）→ 开局选火武器 + 光技能（双覆盖）→ 房内 HUD 弱 X → 商店针对性补元素 → 带对 = ×1.5 + 充能加速 + 核爆机会；带错 = ×0.85 温和 + 技能/护符补救。

## 5. 元素充能（覆盖流爆发赛道 · 新机制）

**动机**：异元素覆盖的克制收益是分散的，攒不出爽点；充能把「分散克制命中」累积成爆发。

```
每次造成克制伤害（em > 1.0，含技能/护符符号）→ 充能 +1
充能满 5（可调）→ 自动释放「元素爆发」：
  穿透核爆（无视护甲直击 HP，伤害 = 敌人 max HP × 15~20% 档）+ 清甲 + 演出
```

- 触发后充能归零重新积累
- 抵抗/中性命中不充能（只奖励带对）
- **异元素多带 / 技能补元素 → 充能显著更快**——覆盖流的节奏感 = 每次克制命中都在「攒」
- HUD：敌人面板下挂充能条（当前元素色），看得见的进度
- 数值锚点：充能爆发期望 ≈ 三连爆发的期望，但来源不同（单带 = 一次高概率，覆盖流 = 五次分散积累）

**三赛道并存（本方案后的完整杠杆体系）**：

| 赛道 | 来源 | 状态 |
|---|---|---|
| 三连流 | 符号密度（单带 / 同元素聚合） | ✅ 已有 |
| 充能流 | 克制命中积累（异元素 / 技能补元素） | 本方案新增 |
| 对策流 | 克制 ×1.5 + 契印 + 核爆 + HUD 预知 | ✅ 已有（§4 强化显性） |

共鸣（T15）组合空间重定位为 **武器 × 技能 × 护符**（单武器后不再有武器×武器组合，需复核现有 3 个示范 .tres 的 paths 引用）。

## 6. 强武器平衡：废弃次数限制的论证与替代

### 6.1 演进记录（为何废弃）

| 尝试 | 问题 |
|---|---|
| 弹药方案（限次进转轮） | 被动消耗，玩家无法控制时机——不想用的时候在耗弹；打空=空手无解（基础武器无限可兜底，但管理成本高） |
| 特殊槽方案（主动爆发卡） | 整备可用破坏开局设计；局内获得需要存储 → 背包系统；槽位替换决策无意义 |
| 结论 | **「次数限制」制造管理成本（跟踪/时机/存储），而它想解决的问题已有天然约束** |

### 6.2 替代：三重天然约束（零运行时机制）

| 约束 | 机制 | 位置 |
|---|---|---|
| ① 稀缺性 | **稀有度定价阶梯**：商店价格按稀有度（common 6-8 / uncommon 12-16 / rare 20-24 / epic 35+ 金，可并入 ShopConfig 或武器 .tres），一局买不起两把 epic | 商店/经济层 |
| ② 代价 | **高 base 低命中 trade-off（2026-08-09 恢复）**：带子按 `hit_rate` 聚合 MISS 格——高 base 武器（如夜幕镰刀 50/0.78）带子更脏，命中代价与稀有度定价 + 特殊符号并存 | WeaponData / reel_system |
| ③ 天然刹车 | **密度稀释**：带越多三连率越低——「多带和三连矛盾」本身就是平衡器 | 机制层（已有） |

**不做**：次数限制、弹药、特殊槽、背包——全部废弃，管理成本归零。

### 6.3 数值收敛（可选微调）

- 高 base 档 45~50 → 收敛到 40~45（缩小碾压差），epic 保留天花板感
- 按「base_power / hit_rate / 特殊符号价值」三维规范武器强度（见 §6.2 ②），替代纯 base 比拼
