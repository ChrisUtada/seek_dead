# G4-01 分支价值模板扩至 5 套（非对称精英）

> 日期：2026-11-08
> 阶段：G4 随机棋盘（P1）续作 · G4-01「4–6 套模板」收口
> 关联：`docs/统一制作执行计划_2026-11-06.md` §8.1、`docs/G4-01_分支价值模板_2026-11-07.md`、`docs/G4-02_骨架随机_2026-11-07.md`
> 前置说明：G5 真人复测仍未取数；本切片只调整节点类型分配与生成校验，不改战斗数值、奖励、掉落、房间内容与 RNG 口径。

## 1. 做了什么

G4-01 要求首批 **4–6 套**模板，此前只有 3 套（standard / mirror / elite_first）。本轮补到 **5 套**：

| 模板 | 上路（n7–n9） | 下路（n10–n12） | 取舍 |
|---|---|---|---|
| `standard` | 普通 → 精英 → 商店 | 普通 → 精英 → 休整 | 先买 vs 先回血 |
| `mirror` | 普通 → 精英 → 休整 | 普通 → 精英 → 商店 | 上表左右互换；武器 n2 / 护符 n5 同步互换 |
| `elite_first` | 精英 → 普通 → 商店 | 精英 → 普通 → 休整 | 两侧都先打精英，奖励更早、风险更高 |
| `elite_upper`（新） | **精英 → 普通** → 商店 | 普通 → 精英 → 休整 | 只有上路前置精英：早奖励 + 早风险 |
| `elite_lower`（新） | 普通 → 精英 → 商店 | **精英 → 普通** → 休整 | 只有下路前置精英：与上表互为镜像 |

- 两条新模板仍满足：每套节点构成一致（1 起点 / 9 普通 / 3 精英 / 4 BOSS / 1 武器 / 1 护符 / 1 商店 / 5 休整）。
- 单局路径仍是 **8 场战斗**（4 共享段 + 2 中段 + 尾路首战 + BOSS）与 **13 格**；BOSS 前营地、四条尾路结构不变。
- 模板只在节点类型上换位，不改变骨架、深度、边、棋盘坐标与具体房间抽取。
- 新增 `BoardConfig.template_id`（空 = 随机）：测试、采集与排查可固定模板；正式开局不填。
- 局末路线总结新增模板名：上路精英前置 / 下路精英前置。

**没有改**：战斗数值、成长、奖励、掉落、商店货架、特殊格概率、RNG 序列口径、`balance_config.tres`。

---

## 2. 生成校验（防回归）

新增两条硬约束，避免以后加模板时无意识地改变单局结构：

1. `BATTLE_ORDER` 内的节点在任何模板下都必须仍是战斗节点；
2. 非战斗节点不得在模板里变成战斗节点。

否则单局战斗数会从 8 漂移，或出现「战斗节点不在 BATTLE_ORDER 里、拿不到 RoomData」的静默空置。
同时测试会校验每套模板的精英位置与定义一致，并验证 `template_id` 固定生效。
