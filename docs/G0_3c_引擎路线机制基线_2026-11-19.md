## 3. 结果：五套 Build 打法差异（每格 3 种子中位）

「W/L」= 3 局中胜/负；核爆 = 三局合计核爆伤害。

|---|---|---|---|---|

### 3.1 路线差异解读

1. **同系三连（mono_fire）**：唯一 12/12 全胜的 Build，核爆伤害显著领先（boss 房合计 90，其余路线多为 0–42）。峰值输出路线，符合「高浓度同族」定位。
2. **破甲穿透（armor_pierce）**：对有甲房（normal_armor 承伤 48）优于 elite，但 boss 房 1W/2L、承伤 170 —— 对高甲/爆发 BOSS 反而吃力（弹匣/重弩节奏慢），体现明确弱点。
3. **防御运筹（defense_recover）**：承伤最低（normal_frost 仅 8），但 boss 房承伤 113、核爆恒为 0，输出低。✅ `damage_blocked` 有值（22/18/12）证明护盾技能**确实注入生效**。
4. **异系组合 / DoT**：居中。异系核爆（0–42）低于纯火（6–90）——注意这是**配装差异**，异色协奏规则未实现，不能解释为「异色协奏弱」。
5. **DoT 路线**：普通/护甲房承伤最低（5/30），但 elite/boss 出现 1 负——底层 DoT 阈值爆发成立，状态反应规则未实装。

### 3.2 必须声明的口径

- **治疗量恒为 0**：`defense_recover` 的 `heal_total=0`，因探针 aim 固定 `fire_slash`、未主动停治疗符号；`mend` 需低血兑现但我们没刻意压血。**不能据此说「治疗路线无效」**，只能说「本探针口径下治疗未兑现」。
- **不证明 §12.4 六路线可玩**：对子稳定无 Build/无规则；异色、状态反应、末符回响、余量蓄电等专属规则未实装。本基线只回答「当前配装打法有无差异」——答案是有（峰值/防御/穿透节奏明显不同）。
- **样板房单场**：不是全流程；4 类房各 3 局，样本小，用于机制差异观察，不做绝对平衡结论。
