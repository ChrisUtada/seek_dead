# Seek Dead · 游戏整体可玩性与复玩评估优化方案

> 状态：整体评估与执行建议，未实施  
> 制定日期：2026-11-05  
> 代码参考：`99d5be0`；当前装备 177/200  
> 体验证据：ACT1 首局 F6 样本、P0-1 难度调优记录、P0-2 成长感知记录  
> 样本限制：当前只有 1 局首次游玩；P0-1/P0-2 已落地但仍待人工复测，本文不把单局结论当作确定平衡结论  
> 核心结论：**保留“实体转轮带 + 手动目押 + 双武器构筑”，优先让每次停轮、每次成长和每次解锁都产生清晰结果；不要靠收费旋转、永久属性或继续堆内容解决体验问题。**

---

## 1. 总体判断

游戏已经具备完整且有辨识度的基本盘：

- 转轮不是纯后台随机，而是由装备组成实体带子，玩家手动按停。
- 双武器、元素、三连、破甲、充能和 BOSS 干扰可以形成组合。
- 已有角色历练、技艺、武器熟练和铭印。
- 已有新档基础池、铁砧、图鉴、BOSS 信物和多种奖励来源。
- 已有 61 个房间、13 个 BOSS、90 把武器、45 个护符和 25 个消耗品。

当前真正的问题不是“系统数量不足”，而是以下四个体验承诺尚未完全兑现：

1. **操作承诺**：我能否通过目押主动打出好结果，而不是等待随机结果？
2. **构筑承诺**：两件装备组合后，是否比单独使用更有方向和能力？
3. **成长承诺**：我是否知道自己本局走了什么路线，并感到确实变强？
4. **复玩承诺**：下一局除了重新抽一遍，是否还有新目标、新打法和新收藏？

最佳解决方向是围绕这四条承诺做闭环，而不是再叠加一套平行系统。

## 2. 目标体验模型

### 2.1 四层循环

| 层级 | 目标体验 | 理想时长 |
|---|---|---|
| 单回合 | 读意图 → 选目标 → 目押 → 连线/克制/破甲 → 看懂结果 | 约 5–15 秒 |
| 单房间 | 战斗 → 奖励 → 成长/换装 → 明显感到构筑推进 | 约 45–90 秒 |
| ACT1 一局 | 学会基础 → 形成路线 → BOSS 验收 → 解锁收藏 | 约 12–20 分钟 |
| 完整一局 | 三幕构筑演进 → 多 BOSS 验收 → 最终收束 | 约 30–40 分钟 |
| 多局 | 新解锁 → 新构筑 → 新 BOSS/挑战 → 图鉴与成就 | 持续目标 |

这些时间是体验目标，不是立即修改数值的命令。实际调整必须以真人计时为准。

### 2.2 玩家应该能复述的四句话

一次成功试玩后，玩家应能回答：

- “我是靠看准带子、停中关键符号打出爆发的。”
- “我这两把武器一个负责 X，另一个负责 Y。”
- “这局我走了生存/运筹/目押，武器走了锋铸/调律。”
- “下一局我想解锁或尝试的是某个具体武器、组合或挑战。”

如果玩家只能回答“攻击越来越高、打完了”，说明构筑、成长和复玩目标仍然不够鲜明。

## 3. 当前体验证据与优先级

### 3.1 已确认的优势

ACT1 首局样本中：

- 能完整通关，无流程阻塞。
- 普通房 2–4 回合、BOSS 6–10 回合，回合数在目标窗口。
- 奖励卡能理解，商店和消耗品有实际使用价值。
- 换武器超过 2 次，换装后有提升感。
- 元素克制会影响选择。
- 三连/核爆是当前最明确的爽点。

这些部分应保留，不需要重做核心架构。

### 3.2 主要风险

| 优先级 | 问题 | 当前证据 | 处理原则 |
|---|---|---|---|
| P0 | 难度偏低、整体过快 | 首局默认配装 10 分钟内通关 | 先验收已落地的 P0-1，不继续盲目加血加攻 |
| P0 | 成长方向不可复述 | 玩家认为成长少、没变强、没改打法 | 先验收 P0-2；仍无效才改成长效果 |
| P1 | 目押可读性不足 | 停轮靠大概位置，三连较少 | 提升预览和停轮反馈，不直接推翻转轮 |
| P1 | 意图不驱动操作 | 玩家“只是知道”敌人要做什么 | 显示后果与可用对策，不新增按钮 |
| P1 | 双武器协同感弱 | 两把武器“各打各的” | 让共享符号、共鸣和元素路线显性化 |
| P2 | 长期目标不足 | 生涯、铸式、挑战尚未落地 | 用横向解锁与成就补目标，不堆永久属性 |
| P2 | 收集容易退化为抽取 | 铁砧仍有空白、重复和随机性 | 增加定向解锁渠道，保留已有保底 |

## 4. 玩法：让每回合都有操作与反馈

### 4.1 保留核心，不做全局旋转收费

不建议正常转轮消耗金币。正常攻击是必需行为，收费会形成死亡螺旋，并与商店、刷新争夺资源。

若未来需要限制无限等待，应优先考虑：

- 额外重转而非正常攻击收费。
- 特殊房型或 BOSS 的局部经济干扰。
- 更清晰的目标预览和节奏，而非先加惩罚。

### 4.2 目押：先提升“可读、可学、可复盘”

当前不建议立即做 ROWS=2、主动锁定、抢击或更多转轮按钮。先完成最小改进组合：

1. **目标可读**：当前列的克制、防御、治疗和净化符号应有清晰但不过度的强调。
2. **停轮反馈**：停下后提供“命中目标 / 差一格 / MISS”的短反馈，让玩家能逐渐建立手感。
3. **预览一致**：洞察等技艺提供的下一格预览必须与实际带子顺序一致。
4. **反馈不遮格**：匹配角标、元素条、滚动预览不能遮挡主符号。
5. **适度调速实验**：若复测仍无法学习，再做小幅转速 A/B，不先凭感觉永久减速。

目标不是让玩家每次都三连，而是让玩家能说出“我这次为什么停中/没停中”。

### 4.3 意图：从“预告”升级为“可执行信息”

每次意图至少回答：

- 敌人即将做什么？
- 会造成多少伤害或影响哪一列/哪类资源？
- 当前带子里有什么应对方法？
- 效果是马上发生还是下一回合发生？

推荐表达：

```text
重击 · 预计 -46 HP
可应对：护盾符号 / 治疗 / 净化
```

或：

```text
注废 · 第 2 列
可应对：净化药剂
```

只高亮当前真实可用的对策，不提供不存在的“假答案”。若本回合没有对策，也应明确告知，避免玩家误以为是自己没找到。

### 4.4 爽点：强化既有三连/核爆，不增加新乘区

当前爽点已经明确是三连和核爆，应集中表现：

- 停中最后一个关键符号时先有短暂确认。
- 三连、破甲、克制和总伤害按顺序呈现。
- 大数字与关键乘区可以回看，但不恢复大段常驻日志墙。
- 普通命中与三连在音效、位移和颜色上有明显等级差。
- 不让粒子和震屏遮住下一次目押。

三连的奖励应与构筑有关：同系集中更容易三连，异系覆盖更灵活，两者都可以强，但爽点节奏不同。

## 5. Build：让双武器与装备分类真正形成路线

### 5.1 双武器的核心取舍应保留

| 路线 | 优势 | 代价 |
|---|---|---|
| 同元素/共享符号 | 更容易三连、更容易触发集中爆发 | 面对不同敌人时覆盖较窄 |
| 异元素 | 克制覆盖与意图适应更灵活 | 三连浓度较低 |
| 高攻低命中 | 命中时收益高 | MISS 与操作波动更明显 |
| 高命中低攻 | 输出稳定、适合学习 | 峰值较低 |

关键不是哪种路线永远更强，而是玩家在选择前就能看懂差异。

### 5.2 共享符号与共鸣必须显性化

已有真实带子预览和共鸣查询基础，下一步只需把结果讲清：

- 同系双武器共享时显示“火斩 ×2 来源已合并”。
- 显示共鸣激活进度，如“烈焰共鸣 1/2”。
- 换装预览明确显示获得/丢失的共鸣与真实格数变化。
- 共鸣效果若只增加权重却不增加真实格数，必须判为无效或改用其他收益。
- 先验证现有 3 个共鸣的理解度，再扩充数量。

共鸣不应是玩家偶然读到代码才发现的隐藏公式。

### 5.3 装备职责保持稳定

| 分类 | 主要职责 | 不应退化成的内容 |
|---|---|---|
| 武器 | 攻击符号、元素、命中、基础攻击和武器机制 | 只有名称与攻击数字不同 |
| 技能 | 注入防御、恢复、状态或功能性符号 | 无限挤占主输出带子 |
| 护符 | 提供有限、可识别的构筑修正 | 无代价永久乘区叠加 |
| 消耗品 | 战斗中的主动战术与紧急对策 | 每房无脑使用的固定流程 |

新增装备应至少回答“它服务哪条路线、替换谁、在哪类敌人面前有价值”。不能为了 200 件目标复制同质物品。

### 5.4 建立少量可验收流派

优先验证而非继续扩张：

1. 同系三连爆发。
2. 异系克制与充能。
3. 破甲/穿透。
4. 灼烧/中毒/霜冻状态。
5. 护盾/治疗持久。
6. 资源与消耗品运筹。

每条流派至少需要：

- 一把核心武器或符号来源。
- 一个能强化它的技能、护符或共鸣。
- 一个适合它处理的敌人/BOSS。
- 一个明确弱点或代价。

## 6. 养成：成长必须改变打法，而非只改变面板

### 6.1 当前成长结构的评价

当前已有：

- 房间胜利提供历练，ACT1 升至 Lv.4。
- Lv.2/Lv.4 提供技艺三选一，分生存、运筹和目押。
- 武器按实际参与结算获得熟练。
- R2/R3 提供锋铸/调律铭印。
- P0-2 已增加方向提示、前后数值、常驻摘要和升级反馈。

这个结构是合理的，不应回到旧训练点或无限属性轨。

### 6.2 当前最重要的不是继续加成长，而是复测

P0-2 仍是“已落地、待人工复测”。复测时分别判断：

- 玩家是否理解方向？
- 玩家是否感到变强？
- 玩家是否因此改变操作或构筑？
- 玩家是否能复述本局路线？

如果“看不懂”已解决但“没改变打法”仍存在，下一步应修改技艺/铭印的实际效果，而不是继续增加文案。

### 6.3 成长改进的备选顺序

1. 让现有技艺更明确地影响当前可用对策。
2. 让锋铸/调律对应不同武器路线，而非所有武器都同样加攻。
3. 让武器铭印与共鸣、共享符号和意图对策产生联动。
4. 再评估是否增加 Lv.3 的小型成长或 R4 原型专精。

不建议为了“养成感”直接增加永久攻击、永久生命或永久护符乘区。

### 6.4 局外成长的正确定位

局外成长主要提供：

- 新武器、护符和技能的选择范围。
- 新技艺候选或开局身世。
- 横向武器铸式。
- 图鉴、成就与挑战入口。

永久数值只可作为极有限的体验辅助，不能成为通关前置义务。

## 7. 游戏平衡：用真实构筑与真人体验调，不只靠 bot

### 7.1 当前调优状态

P0-1 已实施：

- ACT1 BOSS HP +20%。
- ACT1 敌人攻击 +15%。

记录显示 ACT1 承伤和 BOSS 承伤出现明显非线性增长，已触发警觉线，因此不能继续机械加码。当前应进行人工复测。

### 7.2 调参顺序

1. 先复测当前 P0-1，不继续追加数值。
2. 若仍太简单，优先检查意图压力与对策可读性，不直接再加 HP。
3. 若过难，先区分是普通房、精英还是 BOSS 的问题，按局部旋钮修正。
4. 一次只改一个轴，并记录回合、承伤、死亡点和实际时长。
5. 不用最终幕 bot 路径变化直接推断 ACT1 真人平衡。

`player_dmg_mult=1.5`、现有充能和正式平衡常量不因本方案自动修改。

### 7.3 需要持续观察的指标

| 指标 | 用途 |
|---|---|
| 普通/精英/BOSS 回合数 | 判断战斗是否过短或拖延 |
| 每房承伤与死亡点 | 判断威胁来自哪里 |
| 旋转耗时与目标停中率 | 判断目押是学习还是等待 |
| 三连与充能频率 | 判断爆发是否过少或失控 |
| 武器替换率 | 判断奖励与成长是否阻止换装 |
| 奖励/技艺/铭印选择率 | 识别假选项和绝对最优解 |
| 玩家对成长路线的复述 | 验证成长是否真正被理解 |
| 再玩一局的意愿 | 验证复玩目标是否成立 |

低选择率物品应进入审查，而不是看到低选择率就自动加数值。

## 8. 游戏时长与节奏

### 8.1 ACT1 Demo

当前首局 10 分钟内通关且感觉太快。目标应是：

- 首次游玩约 12–20 分钟。
- 普通房 2–4 回合，精英约 4–7，BOSS 约 6–10。
- 至少有 1 次“差点翻车”但能理解原因的时刻。
- 试玩 3–5 局能覆盖不同武器路线与 4 个 ACT1 BOSS。

Demo 的内容不足感不能只靠增加白名单解决。应先让现有武器有区别，再决定是否从 14 把扩到 20–25 把。

### 8.2 完整三幕

完整局建议控制在约 30–40 分钟，避免通过 Act3 堆血拉长：

- 每幕引入新的构筑问题，而非只增加敌人 HP。
- 普通房承担教学和节奏缓冲，精英提供小型验收，BOSS 提供完整验收。
- 若普通房连续多轮无需调整操作，应减少重复房间压力，而不是增加动画时长。
- 后期新武器必须具备熟练追赶，否则玩家会拒绝换装。

### 8.3 弹窗与间歇

- 成长、奖励、商店、换装不应连续形成多层确认。
- 有选择时才弹成长界面，无选择的成长只做轻量反馈。
- 房间间歇是构筑决策窗口，不应只是额外等待。
- 不在正常攻击上加金币成本来“制造时长”。

## 9. 重复可玩性：目标来自新打法，而不只是新随机

### 9.1 复玩内容优先级

| 优先级 | 内容 | 原因 |
|---|---|---|
| 1 | 不同武器路线与 BOSS 对策 | 直接改变下一局操作和构筑 |
| 2 | 生涯成就与定向解锁 | 给玩家明确、可达成的下一局目标 |
| 3 | 武器铸式/身世等横向选择 | 让同一内容产生不同玩法 |
| 4 | 少量难度契约或种子挑战 | 服务熟练玩家，不替代基础内容 |
| 5 | BOSS RUSH、更多隐藏内容 | 后期扩展，不是当前阻塞项 |

### 9.2 生涯成就建议

首批控制在 8–12 个，全部有明确行为目标：

- 首次击败每幕 BOSS。
- 首次完成同系三连流与异系充能流。
- 使用某类武器完成特定机制挑战。
- 完成一次非暴力和解。
- 在特定条件下完成破甲、状态或护盾路线。
- 发现指定共鸣。

奖励优先给新选择、定向解锁和图鉴内容，不直接叠永久属性。

### 9.3 少量挑战即可

不要一次推出完整复杂 GAME+。可从 2–3 个可独立选择的挑战开始，例如：

- 敌人攻击提高，但定向解锁收益提高。
- 商店刷新成本提高，但初始收藏选择更丰富。
- 转轮节奏更快，但目押类技艺出现率提高。

挑战必须改变决策，而不是只把敌人血量和攻击乘大。

## 10. 收集：让“想要某件装备”比“再抽一次”更强

### 10.1 当前基础

已有新档基础池、铁砧抽取、重复返还、保底、图鉴里程碑、BOSS 信物和商店/奖励写入收藏。这些基础可保留。

### 10.2 主要风险

- 纯随机抽取使玩家难以追逐具体构筑。
- 空白和重复过多会削弱收集反馈。
- 新装备如果只代表数值变化，图鉴缺少吸引力。
- 如果全部内容都能在局内轻松获得，局外解锁又会失去意义。

### 10.3 推荐解决方案

1. **增加定向解锁渠道**：通过 BOSS、生涯成就或挑战获得“指定类别/元素”的解锁机会。
2. **图鉴显示来源**：每件装备标明可能的 BOSS、商店、铁砧或成就来源。
3. **保留已有保底**：不再新增另一套保底货币。
4. **新内容有明确玩法身份**：图鉴不只是名称和图标，还应显示路线、机制与使用记录。
5. **铸式作为后期横向目标**：先用 4 把代表武器验证，不做 90 套独立成长树。
6. **解锁反馈明确**：获得新装备时展示它带来的新符号、元素或组合，而不是只显示“收藏 +1”。

### 10.4 收集与复玩的闭环

```text
本局遇到新装备/新 BOSS
→ 图鉴显示它的路线与来源
→ 玩家形成下一局目标
→ 通过 BOSS/成就/定向解锁获得
→ 下一局用新装备组成不同 Build
→ 完成新的生涯成就
```

这条闭环比单纯提高装备掉率更能支撑长期复玩。

## 11. 推荐执行路线图

### P0 · 先验收已有调优，不继续加系统

- 复测 P0-1 难度与 P0-2 成长感知。
- 至少 3 名测试者 × 3 局，覆盖不同 ACT1 BOSS。
- 验证时长、难度、成长复述和再玩意愿。
- 若仍太简单或成长无感，先定位，不追加新系统。

**出口**：当前 ACT1 的体验基线可信，4 个 ACT1 BOSS 均完成覆盖。

### P1 · 修正核心操作与构筑可读性

按顺序单独验证：

1. 目押反馈与目标预览。
2. 意图后果与对策提示。
3. 共享符号、共鸣进度与换装得失。
4. 三连/核爆的表现层级。

每项都先小步修改、真人复测，不同时改转速、伤害和机制。

**出口**：玩家能说明停轮原因、意图应对和双武器分工。

### P2 · 收敛成长与 Build 路线

- 若 P0-2 仍不改变打法，调整技艺/铭印效果而非继续加文字。
- 验收同系、异系、破甲、状态、防御和运筹等路线。
- 检查无效共鸣、死升级、绝对最优与永不使用的内容。
- 完善后期换装追赶。

**出口**：至少 4 条路线有明确差异且能完成对应挑战。

### P3 · 建立最小生涯与定向收集

- 首批 8–12 个生涯成就。
- 图鉴显示装备路线与获取来源。
- BOSS/成就提供定向解锁机会。
- 选择 4 把武器验证横向铸式。
- 局末奖励与真实解锁内容关联，不再只有抽象点数。

**出口**：玩家结束后能明确说出下一局想解锁和尝试的内容。

### P4 · 再扩展完整三幕与挑战

- 用真实三幕数据验证 30–40 分钟目标。
- 再决定 GAME+、难度契约、BOSS RUSH 的优先级。
- 技能补齐 23 件与装备 200 收口必须服从路线需求，不为数量制造同质内容。

## 12. 验收与停止条件

### 12.1 玩家体验验收

- 玩家能主动描述目押、意图和构筑的关系。
- 玩家能说出本局成长路线与武器分工。
- 三连/核爆仍然是最明确的爽点，且不会过度频繁。
- ACT1 难度、时长和 BOSS 险情进入目标区间。
- 玩家愿意再玩，并能说出下一局的具体目标。
- 新解锁能实际改变下一局选择，而不是只增加图鉴数字。

### 12.2 停止扩内容的条件

以下信号若在多局中持续出现，应暂停铺量：

- 玩家仍无法理解停轮结果。
- 意图持续“只是知道”，从不改变操作。
- 双武器持续“各打各的”或不如单武器。
- 成长仍没有改变打法。
- 大部分装备只在数值上有微小差异。
- 新一局与上一局只有房间顺序不同。
- 收集变成反复抽重复物品，没有定向目标。

---

## 13. 明确不建议采用的做法

- 每次正常旋转消耗金币。
- 用永久无限属性成长制造养成感。
- 为增加时长而提高后期 HP 或拉长动画。
- 在证据不足时增加 ROWS=2、主动锁定、抢击或更多按钮。
- 为所有武器制作独立成长树或全量小人。
- 同时上线完整 GAME+、永久祝福、BOSS RUSH 和大量新意图。
- 只通过提高装备数量、稀有度或掉率解决复玩问题。
- 用更多文案掩盖成长效果本身不改变打法的问题。
- 在 P0-1/P0-2 尚未复测时继续叠加新平衡变量。

---

## 14. 最终建议

本项目最合适的方向是：

> **以目押提供操作爽点，以双武器和符号带提供构筑差异，以技艺和铭印提供本局成长，以定向解锁和生涯目标提供复玩动力。**

优先级应是：

```text
先验收当前难度与成长
→ 让停轮、意图和双武器分工变得清楚
→ 让成长真正改变打法
→ 用定向解锁与成就形成下一局目标
→ 最后扩展挑战与完整内容
```

玩家“玩得爽”的来源不是单次伤害越大越好，而是**我能理解、我能操作、我能组成路线、我能看到路线变强，并且下一局还有明确的新东西想试**。所有后续改动都应服务这条标准。
