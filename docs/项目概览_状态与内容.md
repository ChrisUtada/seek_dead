# Seek Dead（寻死者）— 项目概览

> 目的：让不了解本项目的人能在 15 分钟内看懂游戏现在**是什么**、**做到哪了**、**关键设计约束与待办**。
> 状态基准：截至 2026-08-07 的 `master`（提交 `68de1bb`）。文档描述以实际代码 / 资源为准，标注「提案」的为尚未落地的设计文档。

---

## 1. 一句话定位

**俯视角回合制「老虎机肉鸽」**：玩家靠转动一行三格的转轮产出攻击符号，靠「符号匹配 / 元素克制 / 破甲 / 状态」击败敌人；局间用金币在商店强化、用铁砧点数跨局抽装备，逐局逼近三幕 BOSS。本质是**「克制解谜」肉鸽**——敌人机制先于装备设计，装备围绕如何解机制展开。

- 技术栈：**Godot 4.7（纯 GDScript，无 C#）**
- 入口场景：`scenes/duel/duel.tscn`（F6 直接跑）
- 主控制器：`scripts/battle/duel_controller.gd`（状态机 + 全代码 UI 驱动）
- 美术：占位像素风 + Kenney UI 素材包（`assets/kenney_ui-pack-pixel-adventure/`，已入库 20/20，`68de1bb`）

---

## 2. 一局的结构（核心循环）

```
整备(Loadout) → 对决(Duel, 转轮) → 房奖励(三选一) → 间幕(可选商店)
      ↑                                                  │
      └──────── 死亡/通关后回整备 ──────────────────────┘
通关最终 BOSS 后 → 铁砧(Anvil) 抽装备 → 下一局更富
```

- 一局 = **12 房**（每幕：2 普通 + 1 精英 + 1 BOSS）× 3 幕。
- **仅通关最终 BOSS** 才弹元进度（三选一，候选已收敛为仅「铁砧点数」兜底）+ 铁砧抽装备。
- 死亡 → 回到整备页面（不重开本房，提交 `c7bd8d2`）。

## 3. 战斗系统

### 3.1 转轮
- 1 行 **3 格转轮**，玩家按 SPIN 转动，**何时停由玩家决定**（无自动停止上限）。
- 符号池 = 合并「武器 reel + 技能符号 + 金币符号」。
- 单符号必结算；**同符号匹配有连线倍率**（连线精通升级影响此轴）。

### 3.2 伤害结算（乘区）
```
total = (连线伤害 + special×连锁倍率) × 强袭 × 增益乘区 × 测试倍率
增益乘区 = 护符伤害乘区 × 状态/暴击等
逐符号再 × 元素克制系数
```
- 护甲是**扁平池**：先破甲再掉血；`pierce_armor` 绕过；special 三连清空护甲。
- 关键常量：`BASE_POWER_REF=32`（武器伤害归一支点）、`CHAIN_STEP=1.5`/`CHAIN_MAX=4`（special 三连连锁重转）、`TEST_PLAYER_DMG_MULT=1.5` / `TEST_STATUS_DMG_MULT=3.0`（手感验证保留值，正式平衡可改回 1.0）。

### 3.3 元素克制（五元环）
```
火 > 冰 > 毒 > 光 > 暗 > 火
克制 ×1.5 / 抵抗 ×0.85 / 无 ×1.0，单向 玩家→敌人
```
- ✅ **五元环已闭环**（`549e9b0`）：武器覆盖 fire / ice / poison / light / dark 全部五元素（§4.1），Act2（暗 BOSS 呓语教徒，弱光）与 Act3（光 BOSS 深渊监视者，弱暗）均有对应元素解。
- **元素充能（T21）**：每次克制命中 +1 充能，满 5 释放「元素爆发」（清甲 + 敌人 max HP 15% 穿透直击）——分散的克制收益变成节奏杠杆，覆盖流（异元素/技能补元素）与三连流并存。
- **平衡常量已资源化（T22）**：全部平衡数值收敛于 `resources/config/balance_config.tres`（ante/命中/连锁/暴击/铁砧/槽位/充能等），改数值 = 改 .tres。

### 3.4 状态（DoT）
`灼烧(burn) / 霜冻(frost) / 毒(poison)`，每回合结算，受 `TEST_STATUS_DMG_MULT` 放大。

### 3.5 敌人意图
敌人每回合声明意图（普攻 / jam 锁轮 / lock / chaos / heavy 等），玩家需针对性应对（抗干扰护符、`purify` 净化药剂、破甲）。

## 5. 敌人与 BOSS

共 **21 个房间资源**，分 3 幕，类型 `normal / elite / boss`。

### 5.1 三幕 BOSS（机制原型）
| 幕 | BOSS | 元素 | HP/ATK | 护甲 | 机制 gimmick |
|---|---|---|---|---|---|
| Act1 | 冰封铁瓮（原锈蚀傀儡） | ice | 175/15 | 20 | 熔铸护甲 rust_armor（每 3 回合 +1 层 8 甲）+ **寒霜侵蚀**（frost 冻结转轮 1 列失效格，上限 2，净化可解，T30） |
| Act2 | 呓语教徒 whispering_cultist | dark | 290/20 | 25 | 呓语锁轮 whisper_lock（锁轮 / 强化敌人伤害） |
| Act3 | 深渊监视者 abyss_watcher | light | 460/27 | 35 | 深渊侵蚀 abyss_erosion（注入废铁格干扰转轮） |

### 5.2 「衍生产品」课程化模型（设计原则）
一幕 = **先教分散子机制，最后 BOSS 合成**：
- **普通 A**：同源元素、无 gimmick（如 Act1 锈盲蝠 = 纯冰，同 BOSS 家族但没长全护甲）
- **普通 B**：异源 / 变奏，避免单调
- **精英**：同源元素 + BOSS gimmick 弱化版
- **BOSS**：元素 + 完整 gimmick + 全意图

> 该模型在数据结构上已半成立（锈盲蝠就是「没长全的锈蚀傀儡」），但普通 / 精英房尚未全部接入规范。

### 5.3 元素分布（实测）
- ice 敌：锈蚀傀儡、锈盲蝠、酸蚀傀儡、亵渎书吏、裂石像（light? 实际裂石像是 light，见下表）
- dark 敌：呓语教徒、暗影信徒、虚空回响、虚空低语者、深渊咏者
- fire 敌：湮灭使徒/领主、迷魂灯笼
- poison 敌：邪颂祭司、腐化史莱姆、腐殖巨蠕、毒孢菌、裂界游魂
- light 敌：深渊监视者、坍缩星核、裂石像、终焉守望

gimmick 脚本共 4 个：`rust_armor` / `whisper_lock` / `abyss_erosion` / `boss`（基类）。

## 6. 元进度与货币

三套货币，**生命周期与职能完全不同**：

| 货币 | 性质 | 来源 | 去处 |
|---|---|---|---|
| **金币 gold** | 每局清零 | 清房 / 精英 +18 / 卖出 / 连击结算 | 局内商店（买/卖装备与消耗品，**T27 后不再参与升级**） |
| **训练点 train_points** | 每局清零 | **仅 BOSS 击败**（一局 3 点，T27） | 商店升级轨道（每级 1 点） |
| **铁砧点数 anvil_points** | 跨局永久 | 通关（首通奖励 first_clears） | 铁砧老虎机抽装备 |

### 6.1 局内商店（S12，金币）✅ 两页签（T3 + T27 + T28）
商店 = **购入 / 卖出 两页签**（T28 升级页已迁出）；金币回归纯装备/消耗品职能。

### 6.2 训练房（T27/T28，训练点）✅ 已落地
- **BOSS 击败 → 战利品三选一 → 训练房**（`train_screen.tscn`）：当场分配训练点（每幕 BOSS +1，一局 3 点），每级消耗 1 点，4 条轨道上限 3、锋锐 +4/级；最终 BOSS 后训练房接元进度三选一。

### 6.3 铁砧老虎机（anvil，铁砧点数）✅ 已落地
- 界面 `anvil_screen.tscn/.gd`（提交 `c393976` 起的迭代）。
- **纯 gacha**：消耗 `ANVIL_ROLL_COST=10` 点摇一次，**单格转轮揭晓一件装备**（物品与稀有度随机；原「三格必出同一件」仪式已简化为单格，手动按停：点格子 / 停止按钮 / 空格）。
- 落点注入 `meta["owned_weapons / owned_charms / owned_consumables"]` 拥有池；新装备自动进整备备选。
- **重复处理**：摇到已拥有 → 按稀有度返还点数（`ANVIL_DUPE_REFUND`）+ 保底计数 +1，永不浪费；不再做 per-item 升阶（`weapon_base_bonus` / `charm_upgrades` 旋钮已随纯 gacha 定案退役，`5ed5d1f`）。
- **保底**：`ANVIL_PITY_MAX=10` 连续重复后，下次必出未拥有。
- **图鉴收集**：`collection_milestones` 记录收集度。
- 摇出的装备**不含消耗品**（修复于 `691dfd4`）。
- 元进度三选一（通关最终 BOSS 后）候选已收敛为**仅「铁砧点数」兜底**（`reward_system.gd` `roll_meta_choices()`）——双轨元进度旋钮退役后不再给出无生效通道的假选项。

## 7. 当前关键设计决策与待办

### 已定方向
1. **BOSS 先行 + 锁步**：先定敌人机制原型，再补能解它的装备（见 `docs/BOSS_设计_执行方案.md`）。
2. **元素词汇表须先于 BOSS 元素设计完备**（铁律）。
3. **铁砧 = 跨局抽装备的纯 gacha**；**商店 = 每局强化手上装备**。双系统边界清晰。
4. **净化完全走消耗品**（净化药剂），无独立净化按钮。

### 开放 / 阻塞项（按阻塞顺序）
1. **✅ 补 light / dark 武器**（`549e9b0` 已完成 4 把，五元环闭环）——此前 Act2、Act3 的 BOSS 无法被元素克制，现已有元素解。
2. **✅ 护符设计三项缺口**（T2 已完成）：破甲符 / 元素契印 / 疫病祭符（§11.2）——破甲、元素克制、状态三条轴全部有护符可投资。
3. **🟠 普通 / 精英房接入课程化规范**：让「衍生产品」模型覆盖全 21 房。
4. **✅ S12 商店升级 6 轨道重构**（T3 已完成）：joker 退役 → 体魄/精准/回复 + 动态锻造轨道（§6.1）。
5. **🟢 视觉细化**：消耗品格子虚线边框（StyleBoxFlat dash pattern）。（Kenney 素材已全部入库 20/20，`68de1bb`）

> 已退役（不再待办）：铁砧等级通道（`charm_upgrades` 扩展 5 类 effect）、元进度三选一双轨旋钮——`5ed5d1f` 已按铁砧纯 gacha 定案删除全链路死键（`weapon_upgrades` / `weapon_base_bonus` / `weapon_hit_bonus` / `charm_upgrades` / `interference_resist` / `first_clears`）。
