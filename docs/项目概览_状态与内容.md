# Seek Dead（寻死者）— 项目概览

> 目的：让不了解本项目的人能在 15 分钟内看懂游戏现在**是什么**、**做到哪了**、**关键设计约束与待办**。
> 状态基准：**2026-08-14**（master `0fe457d`）。文档描述以实际代码 / 资源为准，标注「提案」的为尚未落地的设计文档。
> 2026-08-14 刷新：机制四项变更同步（连锁重转已删 / 元素克制 v2 互克对 / 槽位硬顶 2·3 / 元进度单轨铁砧点）、内容量按实测更新（装备 92 / 房间 61 / BOSS 13）、武器「攻」列改 base_power、训练点 3~4 点/局。

---

## 1. 一句话定位

**俯视角回合制「老虎机肉鸽」**：玩家靠转动一行三格的转轮产出攻击符号，靠「符号匹配 / 元素克制 / 破甲 / 状态」击败敌人；局间用金币在商店强化、用铁砧点数跨局抽装备，逐局逼近三幕 BOSS。本质是**「克制解谜」肉鸽**——敌人机制先于装备设计，装备围绕如何解机制展开。

- 技术栈：**Godot 4.7（纯 GDScript，无 C#）**
- 入口场景：`scenes/duel/duel.tscn`（F6 直接跑）
- 主控制器：`scripts/battle/duel_controller.gd`（状态机 + 全代码 UI 驱动）
- 美术：占位像素风 + Kenney UI 素材包（`assets/kenney_ui-pack-pixel-adventure/`，已入库 20/20，`68de1bb`）

## 2. 一局的结构（核心循环）

```
整备(Loadout) → 对决(Duel, 转轮) → 房奖励(三选一) → 间幕(可选商店)
      ↑                                                  │
      └──────── 死亡/通关后回整备 ──────────────────────┘
通关最终 BOSS 后 → 铁砧(Anvil) 抽装备 → 下一局更富
```

- 一局 = **24 房**（每幕：5 普通 + 2 精英 + 1 常规 BOSS 战）× 3 幕 + 真·最终战（2026-08-09 定稿：BOSS 每幕 4 选 1）。
- **仅通关最终 BOSS** 才弹元进度（三选一，候选已收敛为仅「铁砧点数」兜底）+ 铁砧抽装备。
- 死亡 → 回到整备页面（不重开本房，提交 `c7bd8d2`）。

## 3. 战斗系统

### 3.1 转轮
- 1 行 **3 格转轮**，玩家按 SPIN 转动，**何时停由玩家决定**（无自动停止上限）。
- 符号池 = 合并「武器 reel + 技能符号 + 金币符号」。
- 单符号必结算；**同符号匹配有连线倍率**（连线精通升级影响此轴）。

### 3.2 伤害结算（乘区）
```
total = 连线伤害 × 强袭 × 增益乘区 × player_dmg_mult(1.5)
增益乘区 = 护符伤害乘区（封顶 charm_mult_cap=6.0）× 暴击/状态等
逐符号再 × 元素克制系数；三连必暴 ×crit_mult
```
- 护甲是**扁平池**：先破甲再掉血；`pierce_armor` 绕过；**triple_pierce 武器三连**清空护甲（2026-08-07 起不再绑定 special 符号）；special 现与 damage 同源结算。
- 符号级独立暴击 20%（`crit_chance`）；同元素三连 = 核爆（清甲 + 20% max HP 穿透）。
- 关键常量：全部收敛于 `resources/config/balance_config.tres`（T22）。**已退役**：`BASE_POWER_REF`（T12 后 flat = item_power + agg_flat）、`CHAIN_STEP/CHAIN_MAX`（连锁重转 2026-08-07 删除）、`TEST_*`（更名 `player_dmg_mult/status_dmg_mult`）。

### 3.3 元素克制（v2 互克对 + 毒链，2026-08-10 定稿）
```
互克对：火↔冰、光↔暗；毒链：火→毒、光→毒、毒→暗（单向）
克制 ×1.5 / 抵抗 ×0.85 / 同元素 ×0.85 / 无 ×1.0，单向 玩家→敌人
```
- ✅ **五元素全闭环**（`549e9b0`）：武器覆盖 fire / ice / poison / light / dark 全部五元素（§4.1），Act2（暗 BOSS 呓语教徒，弱光）与 Act3（光 BOSS 深渊监视者，弱暗）均有对应元素解。旧「五元环 火>冰>毒>光>暗>火」已废弃。
- **元素充能（T21）**：每次克制命中 +1 充能，满 5（`charge_max`）释放「元素爆发」（清甲 + 敌人 max HP 15% 穿透直击）——分散的克制收益变成节奏杠杆，覆盖流（异元素/技能补元素）与三连流并存。
- **平衡常量已资源化（T22）**：全部平衡数值收敛于 `resources/config/balance_config.tres`（ante/暴击/铁砧/槽位/充能/训练等），改数值 = 改 .tres。

### 3.4 状态（DoT）
`灼烧(burn) / 霜冻(frost) / 冻结(frozen) / 毒(poison)`（4 种，`resources/statuses/`），每回合结算，受 `status_dmg_mult(3.0)` 放大；状态定义资源化（StatusDef，T23）。

### 3.5 敌人意图
敌人每回合声明意图（普攻 / jam 注废 / lock 锁轮 / chaos 乱权 / auto_stop 夺轮 / heavy 重击等），玩家需针对性应对（抗干扰护符、`purify` 净化药剂、破甲）。**auto_stop 夺轮**（2026-08-14）：下一轮转轮每跳自动停一列（落点随机、无法目押），干扰类意图（purifiable）均可用净化药剂抵消。

## 5. 敌人与 BOSS

共 **61 个房间资源**（普通 36 / 精英 12 / BOSS 13），分 3 幕，类型 `normal / elite / boss`；每幕 12 普通 + 4 精英 + **BOSS 4 角色（1 固定首领默认出场 + 2 轮替 + 1 隐秘，BOSS设计草案口径；第 12 个 = 真·最终 BOSS「勇者的阴影」）**——**BOSS 池 12/12 齐 + 真·最终落地**（Act1：固定「冰封铁瓮」+ 轮替「碎裂石像鬼」「酸蚀恶鬼」+ 隐秘「茧居石雕」，2026-08-09；Act2：固定「呓语教徒」+ 轮替「迷宫低语者」「躁怒元素使」「天平审判官」+ 隐秘「无名虚空」，2026-08-10；Act3：固定「深渊监视者」三阶段 + 轮替「碎裂魔王」三阶段 + 隐秘「耻辱审判官」三阶段，2026-08-10；真·最终「勇者的阴影」——万象投影复刻验收 + 非暴力和解结局，2026-08-10）。普通/精英由 15 个行为族（EnemyArchetype，T5）实例化——族引用 + 元素 + 幕，数值走族基准。

### 5.2 「衍生产品」课程化模型（设计原则）
一幕 = **先教分散子机制，最后 BOSS 合成**：
- **普通 A**：同源元素、无 gimmick（如 Act1 锈盲蝠 = 纯冰，同 BOSS 家族但没长全护甲）
- **普通 B**：异源 / 变奏，避免单调
- **精英**：同源元素 + BOSS gimmick 弱化版
- **BOSS**：元素 + 完整 gimmick + 全意图

> **✅ 精英 mini 机制已全量落地（2026-08-24，P4 课程化复核）**：12/12 精英挂本幕 BOSS 家族弱化版（Act1 rust_armor×2 + acid_bomb×2；Act2 whisper_lock×2 + bipolar×1 + acid 复训×1；Act3 abyss_erosion×4——稀释主题跨元素适用）；`_start_room` 门控放宽为「凡配 gimmick_script 即实例化」。普通 A/B 维持无机制。回归 `tests/curriculum_test.tscn` 99 断言。

### 12.4 敌人（60）规划
单局固定 24 房（每幕 5 普通 + 2 精英 + 1 常规 BOSS 战）+ 真·最终；下列为**内容池**规模，随机抽取：

| 类型 | 每幕池规模 | 抽取/局 | 全游戏总计 |
|---|---:|---:|---:|
| 普通 | 12（12 选 4） | 4/幕 × 3 | **36** |
| 精英 | 4（4 选 2） | 2/幕 × 3 | **12** |
| BOSS | 4（1 固定 + 2 轮替 + 1 隐秘） | 1/幕 × 3 | **12** |

- **BOSS 池每幕 4 候选**（1 固定首领默认高权重 + 2 轮替 + 1 隐秘条件触发）：单局每幕 4 选 1 = 3 场常规 + 1 真·最终（通关后投影战）——组合 4×4×4=64 种，多周目见全。
