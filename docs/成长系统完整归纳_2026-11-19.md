# Seek Dead · 成长系统完整归纳（2026-11-19）

> 数据来源：全部 `scripts/systems/*.gd`、`scripts/battle/combat_system.gd`、`scripts/battle/pattern_*.gd`、
> `resources/config/balance_config.tres`、`scripts/battle/duel_controller.gd`。
> 本文是**全景归纳**，覆盖局内成长、局间成长、奖励机制、数值公式、重置规则与相互关系。
> 相关单点文档：`玩家等级成长现状整理`、`移除玩家等级_替代方案`、`牌谱系统汇总表`。

## 1. 总览：成长的五个来源

本作的"变强"由五类来源构成，只有一类跨局保留：

| # | 成长线 | 局内/跨局 | 影响维度 | 主要触发 |
|---:|---|---|---|---|
| 1 | **武器熟练与铭印** | 局内 | 攻击力 / 命中 / 暴击 / 符号权重 | 房间胜利结算 |
| 2 | **槽位成长（通用铭印）** | 局内 | 攻击力 / 命中 / 暴击 | 铭印选择写入槽位 |
| 3 | **局内加成层**（研磨/锻魂/护符/buff） | 局内 | 符号基础伤害 / 护盾 / 治疗 | 战利品、换幕、护符 |
| 4 | **技艺 + 牌谱 + 卡牌/装备** | 局内 | 打法 / 特殊机制 / 构筑 | 三选一、掉落 |
| 5 | **铁砧 meta / 图鉴 / 铸式 / 生涯** | **跨局** | 初始资源 / 新选项 | 房结算得点数、整备页 |

**2026-11-19 变更**：玩家等级（LV）已从成长体系中移除，原绑定的技艺改为概率注入三选一（见 §3）。

## 2. 玩家基础数值与伤害公式

### 2.1 基础值（`balance_config.tres`）

| 项 | 值 |
|---|---:|
| 初始最大 HP | 100 |
| 全局伤害倍率 `player_dmg_mult` | 1.0（测试期曾为 1.5） |
| 铁砧抽取花费 | 10 点 |
| 每局铁砧点数上限 | 40 点 |

### 2.2 伤害公式（`combat_system.gd:605-620`）

```
连线伤害 + 特殊伤害 = 符号基础伤害之和 × 专精 × 全局倍率 × buff × 虚弱 × 镜面
穿透伤害            = 穿透部分 × 同样的乘区
总伤害 = 整数(连线+特殊) + 整数(穿透)
```

符号基础伤害聚合（`agg_power_flat()`，`combat_system.gd:853`）：
```
符号基础伤害 = 武器攻击力 + run_power_bonus(研磨/锻魂) + 护符攻击加成 + 玩家buff
```

**等级 `level` 已删除，不出现在公式任何一环。**

## 3. 局内成长（一局内有效，重开清零）

### 3.1 武器熟练 R1–R4（`weapon_mastery.gd`）

| 项 | 值 / 规则 |
|---|---|
| 熟练获取 | 房间胜利时，按"本房有效符号结算"给已装备武器累计；每房每把上限 **3** |
| R 等级门槛 | R2=3、R3=7、R4=12 |
| 铭印欠选 | 升到 **R2 / R3 各欠 1 次铭印选择** |
| 追赶机制 | 局中新换上的武器每房额外 +1 基础熟练，追赶本局最高熟练 |
| 上限规则 | 同一铭印每把最多 2 次；命中率 >0.95 时不再提供"校准" |

**铭印四种**（写入武器运行时状态，不改共享 `.tres`）：

| 铭印 | 效果 | 适用武器原型 |
|---|---|---|
| 锋铸 forge | 基础攻击 +2 / 次 | MEDIUM / HEAVY / MAGIC |
| 调律 tune | 目标符号权重 +1 / 次 | LIGHT / MEDIUM / MAGIC |
| 校准 calibrate | 命中率 +5% / 次 | LIGHT |
| 暴虐 tyrant | 三连暴击倍率 +0.25 / 次 | HEAVY |

原型默认候选（`ARCHETYPE_CHOICES`）：LIGHT=调律/校准、MEDIUM=锋铸/调律、HEAVY=锋铸/暴虐、MAGIC=调律/锋铸。

### 3.2 槽位成长（`weapon_slot_growth.gd`）

通用数值铭印（锋铸/校准/暴虐）写入**武器槽位**而非武器本身：

| 项 | 值 |
|---|---:|
| 槽位数 | 2 |
| 单槽总预算 | 2 次铭印 |
| 单类型预算 | 2 次 |
| 锋铸 | +2 基础攻击 / 级 |
| 校准 | +5% 命中 / 级 |
| 暴虐 | +0.25 暴击倍率 / 级 |

优势：换装不复制、不刷新——槽位成长跟随位置而非武器（`replace_weapon_at_slot()` 原位替换）。

### 3.3 技艺（`growth_system.gd`，2026-11-19 改版）

| 项 | 规则 |
|---|---|
| 获取 | 战后三选一按 **15% 概率**注入技艺卡；前 **3 房保底 1 次**；池耗尽不再提供 |
| 选中 | `pick()` 直接授予，无待选计数门控 |
| RNG | 系统独立 RNG，不消耗全局随机序列 |
| 8 项技艺 | 分三家族：生存（坚韧+10HP / 守势+8护盾 / 回春+4HP每房）、运筹（备用药剂+1次数 / 积蓄+2金每房）、目押（落点吸附±1每回合2次 / 宽判窗口±1→±2 / 废铁豁免每回合1次改判） |

### 3.4 局内加成层

| 来源 | 效果 | 触发 |
|---|---|---|
| 攻击研磨 `run_power_bonus` | 符号基础伤害 +N | 战利品 / 房奖励 |
| 幕间锻魂 `grant_act_boon` | 符号伤害 **+8**、最大 HP **+20** | 进 ACT II / ACT III 各一次 |
| 护符（锋锐/守望） | 伤害 +N / 每房护盾 +N | 整备页勾选，整局生效 |
| 玩家 buff | 各类临时乘区 | 战斗内 |
| 连携卷轴 `assist_id` | 补牌凑成牌谱 | 战斗中 |

### 3.5 牌谱（`pattern_*.gd`，21 张）

| 类别 | 数量 | 机制 |
|---|---:|---|
| 基础牌谱 | 10 | 装备条件满足 + 转轮凑齐牌型 → 自动生效，效果改写伤害/状态 |
| 签名牌谱 | 11 | **携带专属武器 + 牌型满足 → 自动生效**（全解锁，无习得环节），强化对应基础牌谱；签名即武器的内置能力 |

牌谱是"构筑型成长"——不直接加数值，而是改写伤害规则（穿透、处刑、削敌攻、齐射等）。详见 `牌谱系统汇总表_2026-11-19.md`。

### 3.6 三选一奖励（`draft_composer.gd` / `reward_system.gd`）

- 战后三选一：卡牌 / 遗物 / 装备 / 技艺（概率注入）混池。
- 重抽：首次 5 金，之后每次 +5 金（`BASE_PAID_REROLL_COST + 5 × 次数`）。
- BOSS / 探索 / 商店走独立战利品路径，掉落品质分 common/uncommon/rare/epic 四档。

## 4. 跨局成长（持久化，meta）

### 4.1 铁砧 meta（`anvil_system.gd` / `meta_store.gd`）

| 项 | 规则 |
|---|---|
| 点数来源 | 房间胜利发放；每局上限 40 点 |
| 消耗 | 整备页抽取，每次 10 点 |
| 产出 | 武器 / 护符 / 消耗品 / 技能，含保底机制（`anvil_pity`） |
| 去重 | 已拥有的转为其他补偿（图鉴追踪 `owned_*`） |

### 4.2 铸式 forge style（`forge_style_system.gd`）

- 每把武器最多一个铸式，整备页选择，写入 `anvil_meta.forge_styles`，**跨局保留**。
- 解锁条件：该武器熟练达到 **R2**。
- 是"横向变体"——改变武器的符号/机制，不是数值叠加。

### 4.3 图鉴 / 生涯 / codex

| 系统 | 内容 |
|---|---|
| 图鉴 `owned_*` | 跨局记录已发现/拥有的武器、护符、消耗品、技能 |
| 生涯 `career_system.gd` | 跨局成就（每局临时标记清零，解锁保留在 meta） |
| 怪物图鉴 `codex` | 遭遇过的敌人记录 |

## 6. 成长的相互关系

```
房间胜利
  ├─ 熟练结算 → R2/R3 → 欠铭印 → 选择 → 锋铸/调律/校准/暴虐 → 攻击/命中/暴击/权重
  ├─ 战利品三选一 → 卡牌/遗物/装备/技艺(15%) → 构筑 + 特殊机制
  ├─ 攻击研磨 → run_power_bonus → 符号基础伤害
  ├─ 金币 → 商店 → 装备/消耗品
  └─ 铁砧点数 → 整备页抽取 → 跨局解锁新选项

换幕
  └─ 幕间锻魂 → 符号伤害 +8 / 最大 HP +20

整备页
  ├─ 勾选护符 → 整局被动
  ├─ 铸式选择 → 跨局武器变体（R2 解锁）
  └─ 铁砧抽取 → 跨局图鉴

战斗中
  ├─ 牌谱凑齐 → 改写伤害规则（穿透/处刑/削敌攻）
  └─ 连携卷轴 → 补牌凑成牌谱
```
