# 棋盘改版预览（2026-11-06）

> 对应：`docs/统一制作执行计划_2026-11-06.md` §5.2 G1-03
> 目的：记录「1D3 步数预算 + 逐格结算 + 两段岔路 + 四个 BOSS 结局」改版的实机状态，供 G1-03 人工验收对照。

## 1. 改了什么

| 项 | 改版前 | 改版后 |
|---|---|---|
| 骰子 | 1D3 决定落点，直接跳过中间节点 | 1D3 决定步数（1–3），逐格前进、逐格结算 |
| 节点 | 12 个，单链 + 一处商店/休整分支 | 21 个，共享骨架 + 两段岔路 + 4 个 BOSS 结局 |
| 单局 | 平均 3.9 场战斗 / 约 3 次成长 | 12 格 / 8 场战斗 / 7 次成长（与线性 ACT1 对齐） |
| BOSS | 1 个，随机抽 4 选 1 | 4 个全部在图上，路线决定打哪个；一局只打一个 |
| 战斗入口 | 落到战斗节点直接开打 | 先弹确认层（敌人 / HP / 攻 / 属性 / 剩余步数），点「进入战斗」才开打 |
| 路线信息 | 无 | 岔路节点展示下游 BOSS 名字 + 元素 |

单局路径：`起点 → 战 → 武 → 战 → 精 → 符 → 战 → 岔路 A → 战 → 精 → 店/休 → 岔路 B → 战 → BOSS`
（12 节点 / 8 战 / ria 0..6 + BOSS 7）
