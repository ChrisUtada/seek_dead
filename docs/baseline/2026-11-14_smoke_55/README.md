# 基线：全量 55 套回归（单路径收敛后，2026-11-14）

## 1. 用途

14×9 替换两套旧地图模型后的全量基线。上一版 57 套见 `docs/baseline/2026-11-14_smoke_57/`。

套数从 57 降到 55，是因为 27（4×4 扫雷内容）与 30（4×4 三模板）两套随旧模型退役。

## 4. 判读要点

- 若 16 套「巡逻占格不可进入」变红：检查 `BoardSystem.legal_targets()` 是否仍过滤 `runtime.patrol_at(cell)`。
- 若 44 套又出现 `checks=0` 却 PASS：说明 `_run` 在第一个 `_check` 前抛错退出，先看 `SCRIPT ERROR` 行。
- 若 21 套变红：检查整备页入口是否又变回两个按钮（`_toggle_grid_mode` 应不存在）。
- 若 22 套「ACT III 唯一 final」变红：检查适配层是否仍在多幕最后一幕绑定 `final_boss` 房。
- 退出期 `ObjectDB leaked` / `resources still in use` 属 Godot 告警，历史一致。
