## 5. 教训（写进基线以免重犯）

空实现不报错、不抛异常，只是什么也不做。它最容易在「收敛 / 重写门面」时产生，
并且只要测试不走真实入口，就会连 `node_mode` 一起错，把空实现伪装成别的模块行为差异。
**收敛时应对照旧实现逐个核对有副作用的方法是否都搬过来了**，不能只看签名还在。
