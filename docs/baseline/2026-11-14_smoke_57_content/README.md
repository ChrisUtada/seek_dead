## 5. 判读要点

- 第 50 套「三幕布局互不相同」变红：`LAYOUTS` 里两张表被写成一样了。
- 第 50 套某幕「数量不在预算」变红：改布局时没同步数量。
- 第 57 套某幕「诱导优先真的让怪踩到陷阱」变红：该幕的巡逻环不再经过陷阱——
  每幕至少要有一条环经过一个 `X`，否则这条玩法在那一幕不存在。
- 第 57 套某幕「精英优先真的打了精英」变红：精英全被挪到主干之外且策略绕不到。
- 第 55 套（巡逻）变红：`PATROLS_BY_ACT[act]` 的路径穿墙或与 `PATROL_SPAWNS_BY_ACT[act]` 不一致。
- 第 16 套变红：三幕里有某幕节点数超出 55–70，或三幕大小完全一致（说明布局没生效）。

## 6. 内容层改动最容易踩的坑

改「按幕取值」时，**替换可能静默失败**：`for cfg in PATROLS` 没改成 `for cfg in for_act(act)`，
测试照样全绿（旧路径在新布局上恰好也合法），只有打印实际路径才能发现。
本版就是靠诊断脚本打印 `path=[30,31,45,44]` 才抓到 ACT II 跑的是 ACT I 的巡逻。
