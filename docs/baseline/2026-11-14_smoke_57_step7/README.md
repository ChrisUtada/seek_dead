## 5. 判读要点

- 第 57 套「内容数量」变红：地图布局被改（`map_grid.gd` 的 `LAYOUT`）但没同步预算断言。
- 第 57 套「三条路线走到 BOSS」变红：先看是新加的墙/门切断了主干，还是巡逻把唯一通路长期占住
  （用「排除巡逻占格后的可达性」判定，不是靠运气）。
- 第 57 套「精英优先真的打了精英」变红：精英被挪到主干之外且策略没绕道，或精英被巡逻占格。
- 第 57 套「破甲后护甲上限归零」变红：`start_room_data()` 里 `pending_armor_break` 的消费
  位置被挪到 `enemy_armor_max` 赋值之前。
- 第 57 套「时间模型」变红：内容数量变了，全清预算超出 45–65 分钟区间。
- 第 56 套 G 组（进入战斗链路）与本次的破甲链路是两回事，互不替代。
