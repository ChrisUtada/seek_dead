## 1. 对外 API

```gdscript
func open(rows: Array[Dictionary]) -> void
func close() -> void
```

只读属性：`last_rendered_rows`（`open()` 时的深拷贝快照）、`rendered_texts`（按渲染顺序的文本数组，供结构断言，不依赖场景树遍历）。

## 2. 区段顺序（空分组不显示标题）

`基础组合(base) → 主组合(main) → 辅助组合(aux) → 签名(signature) → 通用(universal)`

6 行假数据实测渲染 11 条文本：5 个标题 + 6 行；标题顺序与上述一致。只给 main 行时仅显示「主组合」标题（2 条文本）。

## 3. 行文本三态

格式：`名称｜条件：condition_text｜状态[｜contribution_text]`

| 状态 | 判定 | 实测文本 |
|---|---|---|
| 已触发 | `matched_now == true` | `强化燃刃｜条件：条件-W07｜已触发｜🔥 强化燃刃：燃烧 +1 层` |
| 可用 | `matched_now == false && unlocked == true` | （构造用例中 W01/G01/X01 走此态） |
| 未解锁 | `unlocked == false` | `守护祷言｜条件：条件-T02｜未解锁` |

`contribution_text` 仅在 matched_now 且非空时追加。

## 4. 只读保证

- `open()` 对传入 `rows` 只做 `duplicate(true)` 深拷贝，不改原数组/字典；
- 不调用结算/面板以外的系统，不读写 `enemy_hp` / `enemy_status` / `charge` / RNG；
- 测试验证：`open()` 前后传入 rows 逐字段一致；`seed(1234)` 后 4 次 `randf()` 序列不变。

## 6. 间歇期接线（C 轮第 2 步）

**入口位置**：`battle_hud.gd` 在 `TopBar` 动态创建 `interroom_combo_btn`（文本「🗂 组合」），插在「✂ 精简」左侧、`ShopBtn` 之前；与精简同一套 `UI_BUTTON` 写法。`set_interroom_enabled(on)` 同步其 `visible` / `disabled`——**只在房间歇态（`in_interroom`）出现**，非间歇期不开放面板。

**信号流**：

```
interroom_combo_btn.pressed
  → BattleHud.combo_requested（信号）
  → DuelController._on_combo_requested()（in_interroom 守卫）
  → ComboCatalog.build_rows(_pattern_system, selected_loadout, _pattern_tag_of, last_settlement_acc)
  → BattleHud.show_combo_panel(rows) → ComboPanel.open(rows)
```

关闭路径：`ComboPanel` 内 ✕ → `close()` + `closed` 信号 → `BattleHud._on_combo_panel_closed()` 隐藏遮罩、鼠标交互回到 HUD。入口按钮保持可见。

**实例化位置**：`combo_panel` 挂在 duel 根节点（`get_parent()`），与 `_armory_dialog` 同级，`z_index = 96`，默认 `visible = false`；面板为全屏 `PRESET_FULL_RECT` 遮罩。

**`last_settlement_acc` 只读约定**：

- `DuelController.last_settlement_acc: Dictionary` 的唯一写入点是 `CombatSystem.evaluate()`：全部结算完成、`_present_turn` 回放之前，写入本轮 `acc.duplicate(true)`；
- `_reset_run_state()` 将其清空（新局不残留上一 SPIN）；
- 组合面板与 `ComboCatalog.build_rows` 只读该快照，**除 evaluate 外任何地方不得写入**；
- 打开/关闭面板不消耗 RNG、不改 `enemy_hp` / `charge_points` / `turn_count`（`t3c_combo_wiring_test` 断言）。

**验收**：`tests/t3c_combo_wiring_test.gd` → `T3CWIRE|RESULT PASS (checks=28 fails=0)`。改前红（先不接 `hud.show_combo_panel(rows)`）：`点击入口后 panel.visible == true` 等 4 条失败，`T3CWIRE|RESULT FAIL (checks=28 fails=4)`；接上后绿。
