### 2.2 探针复现（改前红）

把该行临时换回 `_unlock_charges`：

```
SCRIPT ERROR: Invalid assignment of property or key '_unlock_charges'
   at: _test_meta_single_result (tests/m1_reward_reach_test.gd:381)
PASSED 56 / FAILED 0
```

**结论：脚本错误会中断整个函数**，本该执行的 3 条断言从未运行。所谓 56/0 是「提前中断」造成的假绿。

### 2.3 连带暴露的陈旧断言（已修正）

修复脚本错误后，第 3 条断言真正执行：


（`reward_system.gd:271` 直接返回 `[]`；`m4_demo_test.gd` 已按空列表断言）。
按 m4_demo 同口径改为「局末无铁砧点数卡（S5-3 停用）」，只改测试断言，不改生产行为。
