# BOSS 与敌人设计执行方案

> 设计哲学：BOSS 先行 + 锁步工具检查 + 机制原型参数化。
> 武器 / 技能 / 护符 全部围绕"如何克制 BOSS 的谜题轴"展开。
> 本文档为设计源头，落地前须先补全元素词汇表缺口（见 §8）。

---

## 1. 一局结构与设计单元

一局 = 3 幕 × (5 普通 + 2 精英 + 1 常规 BOSS 战) = 24 房（2026-08-09 定稿：BOSS 每幕 4 选 1，真·最终通关后独立战）。
设计单元不是"12 个独立敌人"，而是 **3 个「幕包」**，每个幕包 = 1 个固定 BOSS 原型 + 它的衍生产品（5 普通 + 2 精英）。

## 2. 核心模型：小怪/精英 = 该幕 BOSS 的衍生产品（课程化）

**结论：是的，且数据结构已半实现。**

实测房间数据（resources/rooms/*.tres，全量池 51 房：3 boss / 12 elite / 36 normal，每幕 boss 1 / elite 4 / normal 12；
单局抽取：每幕 5 普通 + 2 精英 + 1 常规 BOSS 战（4 候选选 1：固定默认高权重/轮替随机/隐秘条件））：

- Act 1 BOSS 锈蚀傀儡 = `element=ice` + `gimmick=rust_armor`（熔铸护甲）
- Act 1 普通 锈盲蝠 = `element=ice`（**同源**）、无 gimmick、意图更弱（jam 0.12 vs BOSS 0.2）

即锈盲蝠已是"没长全的锈蚀傀儡"。建议正式定为**课程化（curriculum）模型**：

| 房间 | 角色 | 设计规则 |
|---|---|---|
| 普通 A | 教**元素** | 同源元素、无 gimmick（纯冰小怪） |
| 普通 B | 调色变奏 | **off-theme**（中性/异元素），避免一幕 7 房同味 |
| 精英 | 教**机制-lite** | 同源元素 + BOSS gimmick 的弱化版（如小护甲 + 1 个 jam 意图） |
| BOSS | **合成** | 元素 + 完整 gimmick + 全意图组合 |

> 反模式：所有房都克隆 BOSS 机制 → 单调。用"普通 B 异源"破局。

## 3. BOSS 机制原型 taxonomy（参数化）

Gimmick 脚本现状（scripts/battle/gimmicks/）：`rust_armor` / `whisper_lock` / `abyss_erosion` / `boss_gimmick`(基类)。
当前 3 个 BOSS 各占一个原型：

| 原型 | gimmick | 幕 | 元素 | 设计意图 |
|---|---|---|---|---|
| 熔铸护甲 | rust_armor | 1 | ice | 成长型护甲扁平池，逼玩家破甲 |
| 呓语封锁 | whisper_lock | 2 | dark | 高干扰意图（jam/lock/chaos） |
| 深渊侵蚀 | abyss_erosion | 3 | light | 高数值 + 侵蚀机制 |

**待补原型（让后续幕/变体有料）**，每个参数化 `element + gimmick + 数值缩放`：
- 玻璃大炮（高 atk / 低 hp，鼓励抢杀）
- 状态炸弹（叠加强状态，逼抗状/净化）
- 护盾回血（消耗战，逼穿透/破盾）
- 多阶段（血量阈值切换 gimmick）

> 每个原型须先过 §4 的"有无工具可解"检查再落地。

## 4. 克制动词矩阵 → 工具覆盖

BOSS 谜题轴 = 4 类动词（+ 元素）。设计 BOSS 时只能用这些动词，且每类须有对应工具：

| 克制动词 | 解法来源 | 当前覆盖 |
|---|---|---|
| 元素克制 ×1.5 | 武器元素（玩家符号→敌人元素，单向） | ✅ 五元环闭环（`549e9b0` 补 4 把 light/dark） |
| 破甲·穿透 | 破甲武器（triple_pierce）三连清甲 / shot 类穿透符号 | ✅ 机制在，但**无对应护符** |
| 抗干扰 | 抗扰护符 / 净化 | ✅ 护符 抗扰/呓语残页 |
| 状态叠加 | 灼烧/中毒符号、武器状态 | ✅ 机制在，但**无对应护符** |
| 数值碾压 | 护盾/回血/伤害护符 | ✅ 守备/铁壁/守望/回春/锋锐等 |

## 5. 武器设计（围绕克制）

当前 12 把武器（`resources/weapon_templates/`）：fire ×2 / ice ×1 / poison ×1 / light ×2 / dark ×2 / 无 ×4。
~~致命缺口：无 light / dark 武器。~~ **已补齐**（`549e9b0`：圣辉长剑/破晓之弓 = light，夜幕镰刀/暗影匕首 = dark）。

元素环 `火>冰>毒>光>暗>火` 下：
- ice BOSS（Act1）→ 弱火 ✅ 有
- dark BOSS（Act2）→ 弱光 ✅ 有（圣辉长剑/破晓之弓）
- light BOSS（Act3）→ 弱暗 ✅ 有（夜幕镰刀/暗影匕首）

> **设计铁律**：元素词汇表（武器侧）须先于 BOSS 元素设计完备。否则 2/3 BOSS 无元素解。

## 6. 护符设计（围绕克制，持久层 / 铁砧升阶）

护符是"武器/技能留白处的补位"。~~经铁砧 `charm_upgrades` 升阶（跨局永久）~~ **已退役**（`5ed5d1f`：铁砧纯 gacha，护符强度只由 `.tres` 决定）。
当前 13 护符（resources/charms/）按 effect 映射：

| 克制动词 | 对应护符 | 状态 |
|---|---|---|
| 数值·伤害 | 深渊之瞳/狂怒/锋锐（damage_mult）、锈蚀核心（damage_bonus） | ✅ 覆盖 |
| 数值·护盾 | 守备/铁壁（shield）、守望（room_shield） | ✅ 覆盖 |
| 数值·回血 | 回春（heal） | ✅ 覆盖 |
| 抗干扰 | 抗扰/呓语残页（interference_resist） | ✅ 覆盖 |
| **破甲·穿透** | 破甲符 pierce_charm（armor_pierce：每符号 25% 直击 HP） | ✅ **已落地（T2，2026-08-07）** |
| **元素优势增幅** | 元素契印 element_charm（element_boost：克制 ×1.5 → ×1.7） | ✅ **已落地（T2，2026-08-07）** |
| **状态叠加** | 疫病祭符 status_charm（status_boost：DoT ×1.5） | ✅ **已落地（T2，2026-08-07）** |

> 护符设计原则：每个 BOSS 原型威胁的轴，至少有一种护符能补位；三项缺口已随 T2 全部闭合（ItemData.effect 扩到 9 种 + `_apply_charms` 三分支 + 三结算点接线）。

## 7. 三幕阵容草图（参数化模板）

| 幕 | BOSS 原型 | 元素 | 普通 A（同源教元素） | 普通 B（异源调色） | 精英（mini 机制） |
