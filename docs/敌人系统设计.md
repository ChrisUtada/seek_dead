# 敌人系统设计 — 实施规划

## 架构总览

```
EnemyBase（HP/闪白/状态效果/击退/血条）
  ├── goblin.gd / skeleton.gd    ← 普通敌人（复用 AIComponent）
  ├── Elite*                      ← 精英敌人（独有脚本，独有行为队列）
  └── BossEnemy                    ← Boss（BossAIComponent 阶段系统）
```

**敌人 = 脚本（行为） + 场景（骨架/碰撞/节点） + 配置（EnemyConfig .tres）**

## AI 行为框架

**文件**：`scripts/components/ai_component.gd`

### AI 状态（AIState）

| 状态 | 触发条件 | 表现 |
|------|---------|------|
| IDLE | 出生/巡逻到头 | 原地停留 1~3 秒，然后切 WANDER 或 PATROL |
| WANDER | IDLE 超时 | 在 home 周围 wander_radius 内随机走，碰到 PLAYER 进 ALERT |
| PATROL | 有 patrol_points | 按路径点循环走，碰到 PLAYER 进 ALERT |
| ALERT | 检测到 PLAYER | 原地停顿，alert_cooldown 秒后进 COMBAT。同时通知周围友军 |
| COMBAT | ALERT 结束 / 战斗中 | 按 behavior 队列循环执行攻击行为。丢失目标 3 秒后切 ALERT |
| RETURN | 超出 home_radius | 返回 home_position，到家后切 IDLE/WANDER/PATROL |

### BehaviorType 枚举

| 行为 | 枚举值 | 表现 |
|------|--------|------|
| CHASE_MELEE | 0 | 冲向玩家 + instance_id 派生角度散开偏移 + 近战攻击 |
| STRAFE | 1 | 圆周走位，保持 attack_range×0.7 距离 + 周期射击 |
| RETREAT | 2 | 太近后退 / 太远前进 + 边退边射 |
| TURRET | 3 | 不移动 + 周期弹幕 |
| SUMMON | 4 | 拉远到 attack_range×1.5 距离后停下 + 召唤攻击 |
| FLEE | 5 | 反方向逃跑 + 不攻击 |

### 行为持续时间

- `> 0`：执行该秒数后自动切换到下一个行为
- `-1.0`：永久执行，直到外部条件触发切换（目标丢失、超出边界等）
- 队列自动循环：最后一个行为结束后回到第一个

### 配置方式（EnemyConfig .tres）

在 `EnemyConfig` 中直接配置三个字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `behavior_types` | Array[AIComponent.BehaviorType] | 行为队列（Inspector 下拉选名称） |
| `behavior_durations` | Array[float] | 每项持续时间 |
| `attack_range` | float | 攻击判定距离，影响 nav.target_desired_distance = ×0.8 |

示例 `goblin.tres`：
```
behavior_types = [0]          # CHASE_MELEE
behavior_durations = [-1.0]   # 持续到底
attack_range = 50.0
```

示例 `elite_mage.tres`：
```
behavior_types = [1, 2, 4]    # STRAFE → RETREAT → SUMMON
behavior_durations = [4.0, 3.0, -1.0]
attack_range = 200.0
```

## Phase 2 — 精英敌人系统（P0）

**目标**：实现 Elite* 专属脚本 + 投放 + 精英掉落。

### 2.1 现有精英脚本

`scripts/battle/elite_mage.gd` 已接入 AI 框架，配置在 `elite_mage.tres` 中。

**待新建**：
- `scripts/battle/elite_goblin.gd` — `extends EnemyBase`，CHASE_MELEE + 低血量切 FLEE，攻击力/血量高于普通
- `scripts/battle/elite_archer.gd` — STRAFE + RETREAT，远程射击

### 2.2 精英投放

RoomConfig 加字段：
```gdscript
@export var elite_count: int = 0
@export var elite_pool: Array[PackedScene]
@export var elite_spawn_mode: SpawnMode = SPAWN_RANDOM
```

RoomManager._spawn_enemies 逻辑：
1. `elite_count > 0` 且 `elite_pool` 非空时，从 `elite_pool` 随机选场景
2. 优先取 `groups=["spawn_elite"]` 的 SpawnMarker 位置
3. 不足时从普通 `groups=["spawn"]` 补位

### 2.3 精英掉落

RoomManager._on_enemy_died 中检测 `enemy.is_in_group("elite")`：
- 金币：50~100（普通 10~25）
- 装备掉落概率翻倍

## Phase 3 — 导航与环境碰撞（P0 积压）

**目标**：解决敌人穿墙、NavigationAgent2D 参数调优。

### 3.1 房间环境碰撞体

每个房间场景（room_1~5 + room_boss）加 StaticBody2D + CollisionPolygon2D 围住边界。

参考 `docs/房间环境碰撞体实施计划.md` 中每个房间的墙线坐标。

### 3.2 NavigationAgent2D 参数按敌种调整

| 敌种 | attack_range | target_desired_distance |
|------|-------------|------------------------|
| 近战（哥布林/骷髅） | 50 | 40 |
| 远程（精英法师） | 200 | 160 |

当前代码已在 `_ready` 设 `_nav.target_desired_distance = attack_range * 0.8`，若远战敌表现异常需单独覆写。

### 3.3 NavigationPolygon 障碍物烘焙

添加环境碰撞体后，在房间场景的 NavigationRegion2D 中重新烘焙 NavigationPolygon，使导航网格不覆盖墙壁。

**文件**：`scenes/rooms/room_*.tscn`
