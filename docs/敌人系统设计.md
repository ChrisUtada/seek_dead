# 敌人系统设计

## 架构总览

```
Damageable → EnemyBase（HP/闪白/状态效果/击退/血条）
  ├── BasicEnemy       ← 普通敌人（哥布林、骷髅等）
  ├── Elite*           ← 精英敌人（每类独有脚本）
  └── BossEnemy        ← Boss（BossAIComponent 阶段系统）
```

**敌人 = 脚本（行为） + 场景（骨架/碰撞/节点） + 配置（数据/掉落）**

## 三种层级

| 层级 | 脚本 | 行为来源 | 掉落 | 房间配置 |
|------|------|---------|------|---------|
| 普通 | `BasicEnemy`（通用） | AIComponent 巡逻/追击/攻击 | 基础掉落 | 任意数量 |
| 精英 | 各自独有脚本 | 独有 `_ready` + 独有技能 | 精英掉落 | 0-1/房间 |
| Boss | `BossEnemy` | BossAIComponent 阶段系统 | Boss 掉落 | 独立配置 |

## 配置层统一

```gdscript
# EnemyConfig（所有敌人共用）
enum EnemyTier { NORMAL, ELITE, BOSS }

class_name EnemyConfig
extends Resource

@export var display_name: String          # 显示名
@export var tier: EnemyTier               # 仅标记/视觉，不改变行为
@export var hp_min: float
@export var hp_max: float
@export var speed: float
@export var innate_type: int               # 伤害类型
@export var defenses: Dictionary           # { "slash_defense": 0.1 }
@export var stat_multiplier: float = 1.0   # 精英自动 ×2~3
@export var loot_table: Array[LootEntry]   # 掉落表
```

```gdscript
# LootEntry Resource
class_name LootEntry
extends Resource

@export var item_id: String                # 掉落物 ID
@export var weight: float = 1.0            # 权重
@export var min_count: int = 1
@export var max_count: int = 1
@export var drop_chance: float = 1.0       # 0.0~1.0
```

```gdscript
# BossConfig（extends EnemyConfig）
class_name BossConfig
extends EnemyConfig

@export var slam_damages: Array[float]         # 每阶段
@export var slam_ranges: Array[float]
@export var charge_speeds: Array[float]
@export var charge_durations: Array[float]
@export var burst_counts: Array[int]
@export var burst_damages: Array[float]
@export var attack_cooldowns: Array[float]
@export var bullet_speed: float = 400.0
```

## 敌人开发流程

1. **建场景** `scenes/enemies/<name>.tscn`
   - 骨架（Sprite2D/AnimatedSprite2D、碰撞形状）
   - Hurtbox / Hitbox
   - 组件：AIComponent / MovementComponent / StatusEffectComponent
2. **写脚本**（仅独有行为时需要）
   - 普通敌复用 `BasicEnemy`
   - 精英/Boss 新建脚本 `extends EnemyBase`
3. **配数据** `resources/enemies/<name>.tres`
   - 填 EnemyConfig 字段
   - 填 LootEntry 掉落表
4. **注册到房间** `resources/rooms/<room>.tres`
   - `enemy_pool` 加 PackedScene 引用

## 房间投放方式

精英怪支持两种投放方式，可混合使用：

### 方式一：SpawnMarker 显式放置（房间级配置）

在房间 `.tscn` 中直接放置精英专属 SpawnMarker：

```
SpawnMarker_Elite1  (Marker2D, groups=["spawn_elite"])
SpawnMarker_Elite2  (Marker2D, groups=["spawn_elite"])
```

`RoomManager` 运行时按 `groups=` 分组识别，指定 `enemy_scene` 生成。每个 Marker 精确控制位置和类型，适合固定精英站位。

### 方式二：RoomConfig 随机池（数据级配置）

对于纯随机的精英投放需求，也可保留 `RoomConfig` 配置：

```gdscript
@export var elite_count: int = 0                     # 本房间精英数量
@export var elite_pool: Array[PackedScene]            # 精英敌人池（随机选）
@export var elite_spawn_mode: SpawnMode = SPAWN_RANDOM  # 从普通 SpawnMarker 中选
```

`RoomManager._spawn_enemies` 逻辑：优先从 `spawn_elite` 组取位置，不足时从普通 `spawn` 组补位。

### 实际使用示例

```
房间 room_midboss.tscn:
  ├── TileMapLayer
  ├── DoorMarker (右)
  ├── PlayerSpawn
  ├── SpawnMarker (x5 普通哥布林位)
  └── SpawnMarker_Elite (x1 精英哥布林位)

RoomConfig:
  enemy_pool = [Goblin]
  elite_pool = [EliteGoblin]
  elite_count = 1              # 自动在 SpawnMarker_Elite 位置生成
```
