## 2. 新增的通用支撑（不绑定具体怪）

| 支撑 | 位置 | 用途 |
|---|---|---|
| `turn_resolved` | `duel_controller` + `turn_flow` + `combat.evaluate` | 区分「转轮前 / 结算中」施加的减益计时（修正多生效一回合） |
| `last_enemy_intent` | `enemy_system.take_turn` | 记录上一实际意图，供 `echo_half` / `echo_full` 复制 |
| 多段攻击 | `enemy_extra_attacks` + `enemy_system._resolve_extra_attacks` | 双段攻击（炎锋群蝠 / 毒针群蝠），每段走统一伤害闸口 |
| 攻击附毒 | `enemy_attack_poison` | 主段命中后附加毒层（毒针群蝠） |
| 护盾穿透 | `enemy_attack_pierce_pct` + `enemy_system._do_attack` | 按比例直接扣 HP（圣辉游侠 25%） |
| 行动后自损 | `enemy_self_damage_after` | 行动结束自扣 HP（湮灭使徒 3%） |
| 玩家灼烧 | `player_status["burn"]` + `_tick_player_burn` + HUD + 清净 | 每层 2 点、每回合 -1 层；清净可清 |
| 符号位序平移 | `normal_trait_gimmick._shift_symbols` | 同时平移已停当前行与后续转轮带，内容不变 |
| 缠绕空格路径 | `reel_system.stop_next_reel` | 缠绕时自动选方向要求列；修复全量自动跑在 rtl 缠绕下的软锁 |

纪律：全部确定性（`last_enemy_intent` 为复制、提示不掷随机）；多段/穿透/自损均在敌人行动唯一入口收口；行动失效（`enemy_stunned`）时清空全部一次性行动字段，不跨回合残留。

## 4. 难度设计

- 每只怪只问一个问题：留盾 / 破甲 / 换元素 / 读上一行动 / 改停列顺序 / 接受随机；
- 周期类不与数值膨胀绑定：重击倍率来自既有 `heavy` 定义，双段为 60%×2，穿透为 25%，自损为 3–4%；
- 不加多机制、不加长血条、不锁血；高爆发仍可直接击杀；
- 3 回合周期占多数（9 只），4 回合为“长呼吸”节奏，2 回合仅深渊蛮兵一只（高频重击，用破甲打断）。

## 7. 已知限制

- 「迷面诡匠」的位序平移同时改当前行与转轮带；视觉上当前行立即变化，转轮带顺序变化只有在后续目押中体现；
- 回声复制的是「上一实际意图」；若上一意图是随机目标（注废/锁轮/夺轮），复制时会重新随机目标列（与复制意图类型一致，不复制列号）；
- 灼烧目前只有熔壳壁垒使用；若后续更多怪需要，可将其上移到共用 debuff/DoT 模块；
- ACT2/ACT3 的数值仍走既有幕倍率与行为族，未单独调参；若真人试玩觉得某些怪过强/过弱，按用户反馈再调。
