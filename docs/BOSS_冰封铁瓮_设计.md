# BOSS · 冰封铁瓮（The Frozen Maiden）设计

> 状态：设计稿（待实现）。基于《BOSS设计草案》Act1 固定首领 + 当前架构收敛后的完整机制（护甲扁平池 / 三连破甲 / 克制核爆 / 元素充能 / 意图系统 / 训练点经济）。

## 1. 定位与教学主题

**教学主题：破甲三件套**——一个 BOSS 教完三条爆发路径：

```
① special 三连清甲（通用破绽）
② 克制元素 2 连 → 清甲 + 20% max HP 核爆（Plan C）
③ 元素充能满 5 → 清甲 + 15% max HP 穿透爆发（T21 新赛道）
```

叠甲压力让玩家必须主动掌握至少一条；火系克制 ×1.5 + 元素契印 ×1.7 提供保底削血。

## 3. 机制三件套

### 3.1 熔铸冰甲（rust_armor 现有，节奏调整）
- 每 **3** 回合叠 1 层冰甲（原 2 回合）——Act1 教学需要更宽的破甲窗口
- 每层 +8 甲，上限 3 层；叠加在基础甲 20 之上 → 峰值 44
- 玩家破甲手段：special 三连清空 / 穿透符号直击 / 破甲符概率穿透 / 充能爆发清甲
- 节奏/层数参数化（T24）：`RoomData.gimmick_params = {"interval": 3, "per_stack": 8, "max_stacks": 3}`

### 3.2 寒霜侵蚀（新，T23 frost StatusDef 落地为功能状态）
- **固定节奏**（用户拍板 2026-08-07：Act1 教学需要确定性窗口，随机化留给 Act2/3）：
  第 3/6/9 回合与熔铸冰甲同频挂 frost 1 层（可做节奏加速：第 3/6 回合各 1 层、之后每 2 回合——仍可预期）
- frost 改为**冻结转轮一列**（用户拍板 2026-08-07，替代"降命中"方案）：
  - **冻结格 = 失效格**：该列格子不参与连线匹配、符号效果不结算、不产生任何作用（3 列变 2 列有效 → 输出 -33%、三连/破甲/核爆/充能全部无法触发）
  - 每 1 层冻结 1 列，**上限 2 列**（`max_cols=2`）；`decay=1` 每回合 -1 层
  - 冻结列**每轮随机选择**（frost 持续期间不可瞄准，纯惩罚）；frost 解除前持续
  - 与 trash（池内废铁符号）区分：冻结 = 格子的临时状态；与 lock（锁列保持符号仍结算）区分：可叠加
- **交互**：净化药剂清除玩家 frost（解冻，与抵消意图合并进净化分支）——BOSS 战净化成为关键对策，腰带决策（净化/治疗/强袭）有压力；抗扰护符不影响 frost（那是意图减免）
- StatusDef.frost 更新：desc 改"冻结转轮一列（失效）"，新增 `max_cols: int = 2`（可配）
- 实现点：玩家侧 frost 层数字段 + 每轮随机冻结列（结算时跳过该列）+ HUD 冻结格冰色 ❄ 灰封标记 + 玩家状态行显示

### 3.3 意图剖面
- boss 默认表 attack/heavy（T20 已生效），不新增意图类型
- 叠甲/侵蚀回合有日志预告（gimmick 已有 `_log`），HUD 意图栏显示正常攻击/重击

## 4. 解法矩阵

| 解法轴 | 具体 | 联动 |
|---|---|---|
| **武器·主解** | fire_sword 45（克冰 ×1.5）/ flame_staff 40 | 同时喂元素充能（克制命中 +1）——充能教学场 |
| **武器·穿透** | pistol / ice_gun（pierce_armor 符号） | 无视冰甲直击 |
| **护符·克制流** | 元素契印（×1.5→×1.7） | T2 落地主用途 |
| **护符·穿透流** | 破甲符（25% 概率穿透） | 稳定削甲窗口 |
| **护符·数值/防御** | 锋锐/狂怒；守备/铁壁 | 保底与叠甲高攻窗口 |
| **消耗品** | 强袭×2（破甲窗口爆发）/ 重转（凑三连/克制 2 连）/ 净化（解 frost+意图）/ 治疗 | 腰带 4 格取舍 |
| **技能** | rage（泛用）/ recovery（容错） | magic_bolt（光）对 Act1 轮替 BOSS（酸蚀恶鬼弱光）有效 |
| **训练点** | 锋锐 / 卷轴掌握 | BOSS 战前训练房分配（T27/T28） |

**节奏参考**（教学叙事）：开局意图 attack/heavy 平压 → 第 3 回合首次叠甲+frost → 玩家首次体验"打不穿" → 引导凑 special 三连 / 换穿透 / 依赖克制削血 → 叠甲峰值后靠爆发窗口击杀。

## 5. Act1 配套敌人（课程化重组）

现状 6 非 BOSS 房：ice×2 / poison×3 / light×1，**无火系**，poison 偏多。

| 课程化位 | 现房 | 调整 |
|---|---|---|
| 普通 A（教火克冰） | 锈盲蝠（ice）✓ | 补 1 个冰系普通（frost 主题，如「寒鳞蝠」，纯 ice 无 gimmick） |
| 普通 B（异源） | poison ×3 | **换 1 个火系普通**（如「余烬傀儡」fire 85/10）——开局火武器直接有用，呼应 BOSS 弱火 |
| 精英·mini 机制 | 酸蚀傀儡（ice+甲22）✓ | 腐殖巨蠕加 mini 机制（毒 DoT 强化 → 教净化/疫病祭符） |
| 护甲渐进链 | 毒孢菌 10 → 史莱姆 12 → 裂石像 16 → 酸蚀傀儡 22 | 毒孢菌/腐化史莱姆对调（10→12 递增更顺） |

## 6. 配套缺口（随本 BOSS 落地）

**火系技能缺失**：技能是开局第二元素（T21 收敛），但 4 个技能无火——「火武器 + ?技能」开局对铁瓮只有武器一个火源。
- 新增技能「烈焰印记」（fire 符号，攻击型，仿 magic_bolt 结构：symbol = fire_slash 变体或新火符号，base 相近）
- 收益：开局「火武器 + 火技能」双火源 → Act1 全教学链成立；轮替 BOSS/火系小怪也受益
