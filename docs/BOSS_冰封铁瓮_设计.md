## 1. 定位与特色

**Act1 固定首领（教学位）**：Act1 BOSS 槽「4 候选选 1」的 fixed 候选（权重 6 ≈ 43%），**教学主题：破甲三件套**——一个 BOSS 教完三条爆发路径：

```
① 破甲武器三连清甲（triple_pierce：铁剑/战斧/夜幕镰刀，任意符号三连，通用破绽）
② 克制三连 → 清甲 + 20% max HP 核爆（Plan C）
③ 元素充能满 5 → 清甲 + 15% max HP 穿透爆发（T21 赛道）
```

叠甲压力让玩家必须主动掌握至少一条；火系克制 ×1.5 + 元素契印 ×1.7 提供保底削血。**关卡课程化链**（规范 §7）：普通 A 同源冰（火克冰教学）→ 精英机制-lite（mini 叠甲）→ 本 BOSS 合成验收。

## 3. 机制（rust_armor + frozen，全参数化 T24）

### 3.1 熔铸冰甲
- 每 **3** 回合叠 1 层冰甲（`interval`，原 2 回合拉宽教学窗口）；每层 +8 甲（`per_stack`），上限 3 层（`max_stacks`）——叠加在基础甲 20 之上 → 峰值 44
- 破甲手段：破甲武器三连清空（triple_pierce）/ 穿透符号直击 / 破甲符概率穿透 / 充能爆发清甲

### 3.2 寒霜侵蚀（玩家侧冻结格）
- **固定节奏**（用户拍板 2026-08-07：Act1 教学确定性窗口）：第 3/6/9 回合与叠甲同频挂冻结 1 层
- **spin 前冰封一列**：冻结列本轮无法 spin（锁定 spin 前符号、不参与转动、不可按停）——**不封 trash/MISS 格**（浪费）；全为废铁回落随机
- **冻结格 = 失效格**：结算不参与匹配/符号效果。输出损失（含 MISS）：冻结 1 列 → 实际输出 ≈ 2×(1-miss%)（命中 88% → 期望 -48%）；三连/破甲/核爆/充能触发率同比例下探
- 每 1 层冻结 1 列，**上限 2 列**（frozen StatusDef `max_cols=2`）；`decay=1` 每回合 -1 层；冻结列每轮 spin 前随机（不可瞄准）；与 lock（锁列仍结算）可叠加
- **交互**：**清净药剂**（cleanse，2026-08-09 新增）清除玩家冻结（解冻）——腰带决策（清净/治疗/强袭）有压力；抗扰护符不影响冻结（那是意图减免）
- **单侧性**（2026-08-09 纪律）：玩家侧冻结独立 `frozen` StatusDef；`frost` 回归纯敌人侧（冰武器减攻）——状态定义不跨侧共享

### 3.3 意图剖面
- boss 默认表 attack 60 / heavy 40（T20），不新增意图类型；叠甲/侵蚀回合有 gimmick 日志预告

### 3.4 参数化（gimmick_params）
```json
{"interval": 3, "per_stack": 8, "max_stacks": 3}
```
> 空 = 回落默认值（interval 2 / per_stack 8 / max_stacks 3），教学位零改动兼容。

## 4. 对策与联动（解法矩阵）

| 对策轴 | 具体 | 联动 |
|---|---|---|
| **克制·主解** | fire_sword 45/88% / flame_staff 40/86%（火武 ×1.5）；元素契印 → ×1.7 | 克制命中喂充能（充能教学场）；克制三连核爆 |
| **破甲·清甲** | 破甲武器三连（triple_pierce）/ 破甲符 25% | 清空冰甲开直击窗口（教学主解） |
| **穿透·直击** | pistol 20/82% / ice_gun 30/88%（pierce 符号） | 无视冰甲 |
| **爆发·窗口** | 强袭×2 / 元素充能核爆（清甲+15% max HP）/ 三连暴击 | 叠甲峰值后窗口兑击杀 |
| **消耗品** | 清净（解冻结）/ 治疗（容错）/ 重转（凑三连） | 腰带 4 格取舍；净化药剂本战无用（无干扰意图） |
| **技能** | 烈焰印记（火，组合型新解法 #1）/ rage / recovery | 开局第二火源 |
| **防御** | 守备/铁壁（叠甲高攻窗口）/ 回春 | 稳字流 |
| **基础功** | MISS 按停规避（带子传统频率 2-4 stops/符号，可目押） | 白回合 = 白吃叠甲 |

**节奏参考**（教学叙事）：意图 attack/heavy 平压 → 第 3 回合首次叠甲 + 冻结 → 玩家首次体验"打不穿" → 凑破甲三连 / 换穿透 / 依赖火武削血 → 叠甲峰值后爆发击杀。
