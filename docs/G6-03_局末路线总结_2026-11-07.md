## 1. 做了什么

- 新增 `RunSummary`（`scripts/systems/run_summary.gd`）：把本局状态压成固定 4 行摘要，追加到局末元进度屏副标题。
- 四行内容：
  1. `路线：棋盘 · 标准 · 精英前置 · 冰尾路 · 战斗5 精英1 商店1 休整1 特殊1`
     线性模式为 `路线：线性 · 战斗6 精英1 BOSS1 · 终局 <BOSS>`
  2. `成长：Lv.3 · 技艺1 · 熟练 毒匕首 R2、火焰剑 R1 · 铭印 锋铸×1`
  3. `新收藏：余烬长剑、耀火短匕`（与开局拥有池快照做差，最多列 3 件）
  4. `下一局建议：凑齐两把同元素武器；还有 1 次定向解锁`
- 拥有池基线在 `_reset_run_state()` 时快照，只存在内存；局末解锁/奖励获得的新装备会自动计入「本局新收藏」。
- 下一局建议复用生涯的 `next_goal_hint()`，并提示剩余定向解锁次数；全部成就完成时给通用的换路线建议。

**没有改**：战斗数值、成长曲线、奖励、掉落、商店、铁砧池/保底/重复返还、RNG、`balance_config.tres`、存档字段。

## 2. 数据来源

| 行 | 来源 | 说明 |
|---|---|---|
| 路线 | `board.shape_id / template_id / consumed / by_id`；线性为 `ROOMS[].kind` | 只统计已消耗节点；BOSS 终局取 `current_room` |
| 成长 | `growth.level / perk_ids`、`mastery.mastery / r_level / summary_line` | 熟练只列本局有结算的武器，最多 3 把 |
| 新收藏 | `meta.owned_weapons / owned_charms / owned_consumables` 与开局快照 | 不区分获取渠道；BOSS 信物同样计入图鉴 |
| 建议 | `CareerSystem.next_goal_hint() / unlock_charges()` | 无成就可提示时给通用建议 |

路线主题取本局终局 BOSS 的元素（与 G4 尾路主题一致）；`none/无` 不显示。
