## 1. 武器图标（12 把）· 最高优先

现状：白名单 14 把里只有 `fire_sword`、`flame_scimitar` 有图标，其余 12 把回落 emoji，是 demo 最直接的观感缺口。

**做法**：不按元素整批（那要做 75 把），只做 demo 需要的这 12 把；出图 → `tools/prep_weapon_icon.py --degreen` → 32px 格子图 `tools/make_weapon_cell_icons.py`。
**通用验收**：48×48 母版可读 / 主轴 -45°±15 / meanL 42-88 / 无手无布缠 / 元素色粒子目视可见 / 清单同步。

**图标跟随规则（2026-11-16 定）**

> `*_slash` 永远跟随武器；其余伤害符号（`pistol_shot` / `bolt_shot` / `dawn_light` 等）**只在该武器只有它一个 `kind==damage` 符号时**才跟随。状态、buff、技能、精华一律不跟随。

依据：90 把武器里有 **16 把带 2 个伤害符号**（`dawn_blade` 的 `holy_slash`+`dawn_light`、`rune_repeater` 的 `pistol_shot`+`arrow_shot`、`abyss_scythe` 的 `shadow_slash`+`abyss_bite` 等）。若一律跟随，这两格会显示同一张武器图，但两格伤害不同——等于抹掉符号区分度，比不显示武器图标更糟。
实测结果：`pistol` / `armor_pierce_crossbow`（唯一伤害）→ 跟随；`dawn_blade` → 斩击跟随、光弹不跟随；`rune_repeater` → 两格都不跟随。实现见 `DuelController._symbol_follows_weapon()` + `_weapon_damage_count`。
