# GAME+ 与通关奖励方案（元进度重做 + BOSS RUSH + 难度契约）

> 状态：**📋 方案定稿（2026-08-13，待落地）**——针对「通关后内容真空」与「元进度奖励无吸引力」两个问题。现状：通关真·最终后元进度三选一退化（只剩铁砧点 1 个候选，§10.5 双轨元进度 2026-08-07 退役后未补）；通关后无内容承接（打完即止）。
> 设计对标：Hades（热神等级 + keep-sake 祝福）/ Slay the Spire（进阶 1-20）/ Balatro（stake 难度契约 + 挑战模式）/ 挺进地牢（Past 结局 + 更高难度）/ 死亡细胞（BOSS 细胞难度）。
> 核心思路：**通关不是终点，是「下一阶段」的门票**——通关解锁 GAME+ 双模式（难度契约 + BOSS RUSH），通关奖励从「代币」升级为「盘外构筑」（永久祝福）。

---

| 问题 | 现状 | 根源 |
|---|---|---|

| 通关无承接 | 通关真·最终后即结算，无后续内容 | 无 GAME+ / 挑战模式 / 难度阶梯 |

## 2. 方案总览

```
通关真·最终（勇者的阴影）
  ├─ 元进度结算（重做三选一：铁砧点 / 永久祝福 / 收藏解锁券）
```

## 3. 通关奖励重做（元进度三选一恢复多候选）

`roll_meta_choices()` 候选池重建（当前池仅 anvil 1 项）：

| 候选 | 效果 | 定位 |
|---|---|---|
| 🔨 铁砧点 +15 | 跨局抽装备货币 | 保留（工具型保底） |
| **✨ 永久祝福**（新系统） | 从祝福池选 1 个**永久生效**（跨局，上限 5 个可切换） | **盘外构筑**——通关奖励 = 跨局 build 碎片 |
| 🗝️ 收藏解锁券 | 解锁 1 件未拥有装备（正式收藏制后价值凸显） | 收集驱动 |

### 3.1 永久祝福系统（核心新系统，Hades keep-sake × VS relic 温和版）

- **祝福池**（5 个起步，可扩充）：
  | 祝福 | 效果 |
  |---|---|
  | 磐石祝福 | 每局开局 +20 护盾 |
  | 富足祝福 | 每局开局 +30 金币 |
  | 锋芒祝福 | 本局全部伤害 +5% |
  | 洞察祝福 | 敌人意图提前 1 回合预告 |
  | 生机祝福 | 本局开局最大 HP +15 |
- **规则**：上限 5 个（防膨胀，克制解谜核心不破）；可自由切换（通关结算时选择/整备界面调整）；祝福在 `meta` 持久化（跨局）
- **吸引力逻辑**：不是给代币，而是给「我盘外的构筑选择」——每通一关攒一块

### 3.2 收藏解锁券

- 正式收藏制（owned 改初始子集）后：解锁券 = 指定解锁 1 件未拥有装备
- 测试期（owned 全量）降级为「铁砧点 +10」等效（或直接给随机装备入收藏）

## 4. GAME+ 难度契约（Balatro stake 式）

通关一次解锁一级，可叠加（5 级封顶）：

| 等级 | 契约名 | 效果 | 铁砧点结算倍率 |
|---|---|---|---|
| G+1 | 敌势 | 敌人 HP/ATK +15% | ×1.5 |
| G+2 | 通货膨胀 | 商店/刷新价格 +30% | ×2.0 |
| G+3 | 赤贫 | 开局金币 -30 | ×2.5 |
| G+4 | 无盾 | 开局护盾归零 | ×3.0 |
| G+5 | 孤军 | 技能符号 -1 格 | ×4.0 |

- 契约等级进 `meta`（跨局持久）；整备界面可查看/选择生效等级（0-5）
- 契约只影响数值（ante 缩放/商店系数/开局资源/转轮权重），**不动机制**——克制解谜不变
- 长期目标轴：同一套内容更高强度 + 更高回报

## 5. BOSS RUSH（12 常规 BOSS 连战）

- **入口**：通关真·最终后，整备界面新增「⚔ BOSS RUSH」按钮
- **流程**：12 个常规 BOSS（Act1-3 全部 12 个）连续挑战——固定开局装备（或结算时选择），房间间**无商店/无回血**，仅每击破结算胜利奖励
- **结算**：每击破 3 个 BOSS 结算一次盘外奖励（铁砧点 / 收藏解锁券）；全清解锁「混沌契约」（全 BOSS 机制数值翻倍，终极挑战位）
- **定位**：通关后的「技术验收」——24 房长局压缩为纯 BOSS 战，考验全对策熟练度（与勇者的阴影 P1 复刻验收互补：一个随机抽考、一个全量连战）
