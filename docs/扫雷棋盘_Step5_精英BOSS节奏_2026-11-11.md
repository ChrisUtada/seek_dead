## 1. 本切片范围

把 ACT1 的一场精英与一场 BOSS 整理成可复述的 **蓄势 → 爆发 → 恢复** 三段窗口，
让玩家在现有转轮 / 意图 / 护甲 / 冻结机制下，能用当前 Build 选择不同应对，而不是背唯一答案。

选定样板：

| 位置 | 房间 | 基础数值 | 机制 | 节奏参数 |
|---|---|---|---|---|
| ACT1 精英 | 寒铁精英 | 攻击 20，HP 200（行为族基准） | `rust_armor` 熔铸护甲 | `interval 3` / `first_pressure_turn 2` / 每层 +4 / 上限 2 层 / 冻结 1 列 |
| ACT1 BOSS | 冰封铁瓮 | HP 240，攻击 17，基础护甲 20 | `rust_armor` 熔铸护甲 | `interval 3` / `first_pressure_turn 2` / 每层 +8 / 上限 3 层 / 冻结 1~2 列 |

两者共用同一机制脚本，但参数不同；BOSS 的护甲层数与冻结列数更高，压力更持久。
`first_pressure_turn 2` 是 2026-11-11 Step 3 的静态阈值调整：高爆发 Build 常在 2 回合内击杀，
首轮爆发前移到第 2 回合，保证这类对局至少看到一次「蓄势→爆发」；之后仍按 `interval 3` 重复。

## 2. 窗口定义（实际回合）

熔铸机制每 `interval` 回合触发一次，触发后的下一回合不再加压：

| 窗口 | 回合 | 发生什么 | 玩家的可见信息 |
|---|---|---|---|
| **蓄势** | 首轮第 1 回合；之后每次爆发前 2 回合 | 尚不叠甲；护甲可能仍保留上一次层数 | HUD【蓄势】金色；提示「下回合爆发」 |
| **爆发** | 第 2 / 5 / 8 回合 | 叠 1 层护甲 + 冻结 1（寒铁）或 1~2（铁瓮）列 | HUD【爆发】红色；护甲条 / 冻结列当场可见 |
| **恢复** | 第 3 / 6 / 9 回合 | 不叠甲、不冻结；护甲保留 | HUD【恢复】绿色；标准提示进入「熔铸间隙」 |

首轮爆发前移到第 2 回合，是为了让 2 回合内结束的高爆发对局也能看到蓄势与爆发；
从第 2 回合起仍按 `interval 3` 推进（2 → 5 → 8），恢复始终是爆发的下一回合。

叠满 `max_stacks` 后机制停止加压（寒铁 2 层、铁瓮 3 层），HUD 不再声明窗口；
`special` 三连仍可清空护甲，神像 / 穿透路线继续有效。

不新增意图、充能或状态类型；爆发当回合若敌人抽到 `heavy`，按现有意图规则执行，
标准提示会先处理重击，再处理护甲。

## 3. 可读性实现

### 3.1 HUD

- `BossGimmick` 新增只读钩子 `rhythm_window(ctrl) -> String`（默认空串）；
- `rust_armor_gimmick` 返回 `蓄势 / 爆发 / 恢复 / ""`；
- `battle_hud` 把窗口标签拼在 `mechanic_summary` 前，例如 `【爆发】首轮蓄势1回合→爆发…`；
- 颜色：蓄势 = 交互金，爆发 = 危险红，恢复 = 治疗绿；
- 纯展示，不读写护甲、意图或 RNG。

### 3.2 标准提示（`ReadabilitySystem`）

三个窗口各自列出 **当前带内 / 腰带内真实存在的对策**，保留兜底，不指定唯一答案：

- **蓄势**：提前三连 / 穿透 / 破甲酸液（有护甲时）、保持输出、强化药剂、攻击药剂、
  「保留资源」兜底；
- **爆发**：三连破甲、穿透直击、破甲酸液、冻结时清净药剂、承压输出、强化药剂、
  「直接承伤」兜底；
- **恢复**：沿用「熔铸间隙」，列出破甲、穿透、输出、强化 / 攻击药剂。

目标行仍是「局势 + 可应对」，标准模式不显示 🎯 唯一目标；对策超过 2 条时主栏省略、
其余进 tooltip。

## 4. 数值纪律

- 没有修改任何房间的基础 HP / 攻击（寒铁 20 攻、行为族 200 HP；铁瓮 240 HP / 17 攻）；
- 机制只操作本房的 `enemy_armor` / `player_frost`，不读取 `selected_loadout`、玩家 HP、
  成长或玩家上限来动态调值；
- 没有锁血、复活、阶段强制或隐藏倍率；
- `gimmick_params` 仍只有 `interval / first_pressure_turn / per_stack / max_stacks / two_cols_chance` 五项；
  `first_pressure_turn` 只改首轮触发回合，不改变层数、护甲量或加压频率。

## 5. 棋盘样板保证

`board_grid` 为 ACT1 增加 `RHYTHM_SAMPLE`：精英位优先放入寒铁精英，BOSS 位优先放入冰封铁瓮；
资源缺失 / 幕不匹配时回落到原有随机池。默认 seed `20261110` 的 4×4 棋盘即可直接验收，
确认层读取 `mechanic_summary` 就能看到三段窗口。
