## 2. 统一词表

新增 `scripts/items/item_taxonomy.gd`，只提供词表与显示名，不承担掉落/结算逻辑。

### 2.1 家族（10）

`fire` / `ice` / `poison` / `light` / `dark` / `shield` / `charge` / `combo` / `reel` / `resource`

对应显示名：火焰/灼烧、冰霜/迟滞、毒素/酸蚀、光明/恢复、暗影/风险、护盾/反击、充能/爆发、连击/三连、转轮操作、消耗品/资源。

### 2.2 用途（7）

`damage` / `defense` / `recovery` / `control` / `resource` / `utility` / `conversion`

### 2.3 来源（8）

`normal` / `elite` / `boss` / `chest` / `event` / `shop` / `anvil` / `start`

当前实际使用的来源：普通战、精英战、BOSS、商店、铁砧、开局收藏；`chest` / `event` 预留给后续探索与事件接入，本轮不虚标。

### 2.4 资源字段

`LoadoutItem`（武器/技能）与 `ItemData`（护符/消耗品）各新增：

```text
family_tags: Array[String]
role: String
mechanism_summary: String
act_min: int
act_max: int
source_tags: Array[String]
unique_group: String
```

`unique_group` 用于同屏去重：同元素同机制、同 effect 的换皮件会落在同一组，Step 4 生成三选一时据此避免三项只是数值不同。

## 3. 明显错层修正

### 3.1 武器：纯数值高阶件降到进阶

以下武器没有状态符号、特殊符号或三连破甲，只有基础伤害/暴击/命中差异，不再占稀有/传说位：

`dueling_saber`、`holy_sword`、`judgment_greatsword`、`shadow_guillotine`、`sin_blade`、`dawn_blade`、`holy_lance`、`holy_mace`、`abyss_scythe`、`abyss_staff`、`seraph_codex`、`sunforged_blade` → `uncommon`

## 4. 标签口径

### 4.1 武器

- 所有武器至少带 `combo`（转轮连线是武器的共同职责）；带元素再叠加本系家族；带特殊符号叠加 `reel`。
- 来源：`normal` / `elite` / `shop` / `anvil`；12 把 BOSS 主题池武器再加 `boss`；4 把开局武器再加 `start`。
- 幕次：普通/进阶 1–3；稀有/传说 2–3；BOSS 主题池与开局件 1–3（ACT1 BOSS 可直接掉落）。
- 机制摘要由真实符号、权重、状态、三连、暴击、命中率生成，例如「冰系施法远程：霜（1权重，挂霜冻） + 冰霜晶弹（5权重，冰伤害）；三连×2.5，非三连暴击+12%；命中率88%，基础伤害17。符号需落线触发，未命中为废铁格。」

### 4.2 技能

- 按符号 `kind` 分配：`damage` → 元素 + `combo`；`heal` → `light`；`shield` → `shield`（光系再叠 `light`）；`status` → 本系家族；`buff` 按效果分为护盾向（`shield` + `charge`）、恢复向（`light`）、增伤向（`charge` + `combo`）。
- 来源：`shop` / `anvil`；4 个开局技能再加 `start`。本轮技能没有战斗掉落卡，不虚标 `normal` / `elite`。
- 幕次：普通/进阶 1–3；稀有/传说 2–3。

### 4.3 护符

- 按 `effect` 分配家族与用途；带 `downside_effect` 的混合护符额外叠 `dark`（暗影/风险）。
- 普通护符来源：`elite` / `shop` / `anvil`；4 个开局护符再加 `start`。
- 12 件 BOSS 信物只有 `boss` 来源，`act_min = act_max = 对应 BOSS 幕次`；不进商店、不进铁砧、不进精英掉落。
- 幕次：普通/进阶 1–3；稀有/传说 2–3；信物按 BOSS 所在幕。

### 4.4 消耗品

- 全部带 `resource`，再按效果叠加：治疗/清净 → `light`；重转 → `reel`；破甲 → `combo`；强袭 → `charge`；元素瓶/精华 → 本系 + `reel`；净化 → 仅 `resource`。
- 来源：`normal` / `elite` / `shop` / `start`。当前所有主动消耗品都在新档开局收藏中，故统一带 `start`；普通战 12% 掉落与精英补给位共用 `normal` / `elite`。
- 幕次：普通/进阶 1–3；稀有 2–3。

## 5. 家族基础入口

新增回归逐一验证 10 个家族都有 `common` 入口：

| 家族 | 基础入口示例 |
|---|---|
| 火焰/灼烧 | 烬木手斧 / 火舌短杖 / 点燃 |
| 冰霜/迟滞 | 霜匕 / 霜语短杖 / 寒触 |
| 毒素/酸蚀 | 酸液瓶 / 蛇毒镰 / 毒棱镖 |
| 光明/恢复 | 侍僧短剑 / 祈祷短杖 / 包扎 / 祈祷 |
| 暗影/风险 | 暮色手斧 / 暮影匕 / 暗影箭 |
| 护盾/反击 | 守备护符 / 守备 / 铁壁 |
| 充能/爆发 | 迅捷印记（本回合总伤害 ×1.5） |
| 连击/三连 | 铁剑（三连破甲）/ 战斧 |
| 转轮操作 | 重转卷轴 |
| 消耗品/资源 | 治疗药剂 / 重转卷轴 |

> `charge` 的基础入口是「本回合爆发」而非「充能点数」；真正的每回合充能仍是 BOSS 信物深渊凝视的高阶规则。若后续要补「基础充能件」，应在 Step 2/3 的内容批次里新增，而不是把现有纯数值件改标签凑数。

## 9. 已知限制

- 本轮只写数据与标签，不接掉落筛选；`act_min/act_max` 目前是设计口径，Step 3/5 才用于统一来源表与商店过滤。当前商店仍可能在 ACT1 展示稀有/传说件。
- `unique_group` 已写入，但同屏去重要等 Step 4 的三选一生成器读取后才生效。
- 12 件 BOSS 信物不参与「高阶必须有机制」的结构检查：它们的规则是「只从对应 BOSS 掉落、不进商店/铁砧」，且每只 BOSS 仅 1 件；若未来同屏出现多件信物，需要补充互斥或代价。
- 家族标签允许一件物品跨家族；`combo` 作为武器共同职责覆盖较多，不代表每把武器都是三连核心。
- 品质升降只改掉落权重/商店价格与标签；护符代价、消耗品次数是真实结算变化，需要试玩反馈再调数值。
