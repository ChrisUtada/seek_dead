## 4. 不同打法证据

### 4.1 同系三连：火系三连 → 核爆 + 收尾

`mono_fire` 在 8 场里触发 9 个核爆/破甲回合。BOSS 666：

```
T3 [熔铸间隙] 158 → 56：核爆-30 / -72 / 收尾窗口 / 炎爆×2 / 克制×1.5
T5 38 → -12：-40 / 收尾窗口 / 克制×1.5
```

它靠同元素火三连的核爆把 BOSS 从 158 直接压到 56，再在残血窗口收尾；期间只用 1 瓶治疗。

### 4.2 异系组合：不靠核爆也能更快

`cross_fire_ice` 平均 1.6 回合，是 6 套里最快的；核爆回合只有 3 个。BOSS 666 一回合击杀：

```
T1 240 → -11：破甲-8 / 核爆-30 / -221 / 火斩×2 / 克制×1.5
```

同元素三连不是唯一答案：火/冰双属性把伤害摊到两套符号上，靠连线与暴击同样能过。

### 4.3 防御恢复：用护盾/治疗换回合

`defense_recover` 的伤害最低、承伤最高（平均 64.8），但 8 场全胜；它会在低血时改瞄准包扎，用护盾与治疗把爆发窗口顶过去：

```
T1 护盾+6 / -54 / 圣辉斩×2
T2 重击 34：89 → 55（护盾先吸收，再吃剩余伤害）
T5 低血 34/100：瞄准包扎，34 → 17，随后 -27 收尾
```

同一套 BOSS，`mono_fire` 用 5 回合、`defense_recover` 用 5–6 回合；后者不靠核爆，靠「少掉血」把对局拖到收尾窗口。

### 4.4 破甲穿透：无视护甲的直接伤害路线

`armor_pierce` 全程 0 核爆、0 三连，靠弩矢的穿透与战锤的破甲三连过关。寒铁精英 666：

```
T1 200 → 116：-84 / 弩矢×2
T2 116 → 68：-48
T3 68 → 26：-42 / 收尾窗口 / 弩矢×2
T4 26 → -28：-54 / 铁斩×2
```

护甲从 0 涨到 4/16 的回合里，弩矢仍直接扣 HP；这是与火系核爆完全不同的处理方式。

### 4.5 状态持续：毒 DoT 的慢速路线

`status_dot` 同样 0 核爆、0 三连，平均 4.4 回合，是最慢的一套，但 8 场全胜。毒喉壁垒 999（7 回合）：

```
T1 高甲 20/20：170 → 153（酸液先清 8 甲）
T4 120 → 105：毒×2
T6 82 → 24：-35 / 抵抗×0.85
T7 24 → -7：毒×2
```

它对「高甲 + 高血」的样板最慢，但没有被护甲挡住；毒系不需要破甲符号也能完成。

### 4.6 无净化兜底：不带清净/净化也能过

`no_cleanse` 腰带只有治疗 ×2、破甲酸液、强袭；全程没有使用清净或净化。它在 6 个回合里遇到冻结（`frost_start>0`），仍然 8 场全胜，平均 2.0 回合：

```
BOSS 999 · T1：破甲-8 / 核爆-30 / -81 / 燃×2 / 同元素三连 / 克制×1.5
BOSS 999 · T2：57 → -15，2 回合结束
```

`normal_frost` 的「首回合冻结 1 列」只损失一列停轮，不会导致必败；清净或净化是提速选项，不是门票。

## 7. 边界与后续

1. 探针是 aim-only 固定策略（每回合只瞄准一个符号、消耗品按固定阈值触发），不是真人操作；它用于证明「机制上存在多条路线」，不用于判断真人难度。
2. 全部对局满血开局、不含局内成长、商店与护符；Build 只代表「带这套装备进入房间」的下限，不代表成长上限。
3. 种子只有 2 个，回合数波动主要来自落子/RNG；`cross_fire_ice` BOSS 1 回合击杀是暴击与连线同时命中的高roll，不应视为常态。
4. 普通房平均 1.4–2.8 回合，符合方案「普通怪 2–4 回合，爆发可以更快」的目标；精英 3.5、BOSS 4.2，处于「精英 4–7、BOSS 6–10」的下沿（AI 瞄准精度高、无成长差异）。
5. 后续（Step 6）进入真人体验验收：记录玩家为何选择某个符号、哪次 BOSS 变化迫使其改打法、是否感到被迫换装或被迫看提示。
