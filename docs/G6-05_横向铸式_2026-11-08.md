## 1. 做了什么

- 新增 `ForgeStyleSystem`（`scripts/systems/forge_style_system.gd`）：4 把代表武器的铸式定义、解锁、选择与运行时修正。
- 整备页底栏新增「🔨」入口：列出 4 把武器，每把在**标准形态**与**变体**之间二选一。
- 每个变体同时展示：
  - 优势与代价；
  - 最终属性差异（攻 / 命中 / 破甲连数 / 状态层数 / 符号权重）；
  - 基于 `ReelPreview` 的**真实带子格数差异**（含 MISS 格；其它武器保持标准形态以隔离本变体的影响）。
- 解锁条件：该武器在图鉴中的历史最高熟练达到 **R2**（跨局 `anvil_meta.codex.best_rank`）。
- 选择写入 `anvil_meta.forge_styles`，跨局保留；标准形态始终可选。
- 运行时只在内存中修正，不写回武器资源。

**没有改**：共享 `.tres`、战斗伤害公式本身、成长曲线、奖励、掉落、商店、铁砧池/保底/重复返还、RNG、`balance_config.tres`、武器数量。

## 2. 4 个铸式

| 武器 | 铸式 | 优势 | 代价 |
|---|---|---|---|
| 火焰剑 | 烈刃 | 基础攻击 18→20 | 命中率 88%→83%（MISS 权重上升） |
| 匕首 | 稳手 | 命中率 82%→90%（MISS 权重下降） | 基础攻击 10→8 |
| 战斧 | 破城 | 斧斩 2 连即可破甲（原 3 连） | 斧斩权重 5→3（普通攻击格 4→3） |
| 霜晶法杖 | 霜鸣 | 霜冻每次多 +1 层（每回合结算一次，不随连线数倍增） | 冰霜晶弹权重 4→3（直接攻击格 -1）、基础攻击 15→13 |

真实带子示例（本次采集，已计入当前武器组合）：

| 武器组合 | 变体 | 带子变化 |
|---|---|---|
| 火焰剑 + 霜晶法杖 | 烈刃 | MISS +1 格（1→2） |
| 匕首 + 战斧 | 稳手 | MISS -1 格（2→1） |
| 战斧 | 破城 | 🪓 -1 格（4→3）；匕首在场时另有 MISS -1 格 |
| 霜晶法杖 | 霜鸣 | ❄️💠 -1 格（4→3） |

### 平衡边界

- 每个变体都必须同时有优势与代价，标准形态始终保留：
  - 烈刃：期望伤害略升，但 MISS 更多、符号有效格被稀释；需要稳定命中/特定符号时标准更好。
  - 稳手：更稳但直接攻击更低；追求上限时标准更好。
  - 破城：破甲更频繁，但普通攻击格减少；无护甲目标时收益有限。
  - 霜鸣：状态更集中，但直接攻击与冰霜晶弹格数下降。
- 首批只验证 4 把；不扩到 90 把，不新增武器数量口径。
- 以上为首版观测值，不替代 G5 真人对难度/手感/复玩意愿的结论。

## 3. 解锁与存档

```json
"anvil_meta": {
  "forge_styles": {
    "res://resources/weapon_templates/fire_sword.tres": "lie_ren",
    "res://resources/weapon_templates/battle_axe.tres": "po_cheng"
  }
}
```

- 键为武器 `resource_path`，值为铸式 id（`lie_ren` / `wen_shou` / `po_cheng` / `shuang_ming`）。
- 老档缺 `forge_styles` 键：默认空字典，全部为标准形态。
- 载入时清理非法武器路径与非法 id；合法选择保留。
- 未解锁/未拥有/非法路径不会生效，按标准形态结算。
- 解锁读取 `anvil_meta.codex.best_rank`（G6-04）；该记录在 BOSS 结算或战败结算时写入，因此「本局刚达到 R2」要等本局结束后才能在整备页选择。
- 选择即写入 meta 并落盘；不改动 `codex`、`career`、拥有池与来源。

## 4. 运行时接入

| 修正 | 读取点 | 作用 |
|---|---|---|
| 基础攻击 | `ReelSystem.build_pool` | `base_power + 锋铸 + 铸式`，写入符号强度轴 |
| 命中率 | `ReelSystem.build_pool` / `ReelPreview.compose` | 影响 MISS 格与真实带子 |
| 符号权重 | `ReelSystem.build_pool` / `ReelPreview.compose` | 破城斧斩 -2、霜鸣冰霜晶弹 -1 |
| 破甲连数 | `CombatSystem.evaluate` | 破城把该武器符号的破甲阈值 3→2 |
| 状态层数 | `CombatSystem.contribute` | 霜鸣每次霜冻结算 +1 层 |
| 展示 | 武器卡片 / tooltip / 武器信息 / 替换预览 | 统一显示铸式后的真实攻/命中与铸式说明 |

预览与结算共用同一份 `ForgeStyleSystem` 修正；`ReelPreview.diff_lines` 新增 MISS 格差异行，避免「权重变了但预览只说无变化」。
`build_pool` 重建时同步清空旧的攻击/暴击/穿透/状态映射，避免换装或改铸式后残留上一套修正。

## 5. 界面

- 入口：整备底栏「🔨」（仅图标，避免 480 宽度挤压）。
- 面板：4 把武器各一段，依次为
  - 名称 · 当前形态（标准 / 变体）；
  - `标准形态` / `变体名（R2）` 两个按钮；
  - 解锁状态；
  - 优势 / 代价 / 属性差异 / 带子差异。
- 未拥有的武器显示「未拥有：装备后可选择」，按钮不可用。
- 未解锁的变体可查看优势、代价与属性，但点击只提示解锁条件，不写入选择。
- 未装备该武器时，带子行显示「装备该武器后显示真实格数差异」，不伪造格数。
- 标准形态按钮在当前已是标准时禁用；变体选择后可直接切回标准。
