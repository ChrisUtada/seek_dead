## 1. 缺陷与根因

`LootPool.roll()` 早就有「抽到的品质层在池里不存在时，改抽真实存在的层」的回退；
但 BOSS 走的 `roll_n()` 没有这段：

```gdscript
var tier := _tier(pool["items"], quality)
if tier.is_empty():
    result["reason"] = "empty_tier"     # ← 直接失败，整组主题武器一起消失
    return result
```

BOSS 品质权重是 `uncommon 10 / rare 60 / epic 30`（common 为 0）。
只要某个 BOSS 的主题池缺一档，抽到那一档就**整组没有武器**——不是「低概率变差」，是「这一局白给」。

## 3. 修复

复用现有两个辅助函数，不写第三套概率代码：

```gdscript
if tier.is_empty():
    if forced_quality != "":
        result["reason"] = "empty_tier"
        return result
    var avail := _available_weights(pool["items"], source, act)
    var alt := _roll_quality_from(avail, _rng)
    if alt == "":
        result["reason"] = "empty_tier"
        return result
    quality = alt
    result["quality"] = quality       # 结果里的品质必须同步成回退后的实际层
    tier = _tier(pool["items"], quality)
    if tier.is_empty():
        result["reason"] = "empty_tier"
        return result
```

回退只发生在「非 `forced_quality`」且「首次品质层为空」时；候选一律来自已完成
来源 / 幕次 / 类别 / 主题 / 排除 / demo 过滤的池，不跨来源或主题补物品。

修复后的过渡分布（方案 §4.2）：

| 池类型 | BOSS | 实际品质概率 |
|---|---|---|
| rare + epic 可出 | 冰封铁瓮 / 碎裂石像鬼 / 茧居石雕 | 稀有 66.67% · 传说 33.33% |
| uncommon + rare 可出 | 深渊监视者 / 耻辱审判官 / 天平审判官 | 进阶 14.29% · 稀有 85.71% |
| 只有 rare | 躁怒元素使 / 碎裂魔王 | 稀有 100% |
| 只有 uncommon | 酸蚀恶鬼 / 迷宫低语者 / 无名虚空 / 呓语教徒 | 进阶 100% |

## 4. 测试（第 59 套 `boss_loot_quality_test`，44 项）

| 组 | 断言 |
|---|---|
| A 不完整池不吞整组 | 80 次抽取全部返回武器；品质只能是进阶（池里唯一非零权重层） |
| B 同组同品质无放回 | 同组 `rarity` 都等于 `quality`；路径不重复；同层不足只标 `short_tier` 不跨层凑 |
| C 强制品质不回退 | `forced_quality="rare"` 但池里只有进阶 → `empty_tier`；指定有效层时正常返回 |
| D 排除后仍回退 | 唯一进阶件被 exclude 后，60 次都改抽稀有，不整组为空 |
| E 空池才允许无武器 | 空主题 / 全部候选被排除 → 明确失败原因 |
| F Step 0 审计 | 逐个 BOSS 输出覆盖 / 可用 / 缺失，断言每个至少有一个可用层 |
| G Step 3 真实入口 | `RewardSystem.roll_boss_rewards(room)` × 12 BOSS × 20 次：都有主题武器、同品质、不重复 |

### 修复前后对比（同一套测试）

| 组 | 修复前 | 修复后 |
|---|---|---|
| A（80 次） | **69 次失败**（`empty_tier`） | 0 次失败 |
| B 单件池 | 失败（抽到非进阶层就空） | 通过 |
| D（60 次） | **18 次失败** | 0 次失败 |

修复前的失败率 86% / 30% 正好对应 BOSS 权重里 `rare+epic = 90%` 与 `epic = 30%`，
证明测试确实打在缺陷上，不是「导入成功」类的假绿。

## 5. 边界

- 商店的 `roll_ladder()` 未改（固定品质阶梯）。
- `LootOffer.reroll()` 未改（重抽不重抽品质）。
- BOSS 权重、武器数值、主题池内容均未改 —— 本轮只做程序兜底。
- `forced_quality` 语义保持：指定层为空时仍返回 `empty_tier`，不静默改层。
