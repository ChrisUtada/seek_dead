# 战斗驱动成长｜精英元素武器 + 难度曲线｜设计评估

> 日期：2026-11-18
> 性质：设计评审 + 决策记录（**本文未改代码**）
> 触发：用户实测反馈两点——① 15 层打完整体强度不够对抗 BOSS；② 精英掉落和普通没区别，玩家会躲精英。
> 用户设计取向：**玩家应通过战斗获得成长，而非更多靠事件/商店/休整。**
> 依据：源码核实 + 实测探针（ante 曲线）

---

## 1. 结论先行

1. **核爆不下调**（用户实测体感 OK；L1 已把 player_dmg_mult 从 1.5 降到 1.0，核爆绝对伤害已随之下降）。
2. **两个问题同源**：敌人强度按战斗房序号**指数复利**，玩家成长**线性**且主来源偏向商店/armory（非战斗），精英又缺乏"必须打"的理由 → 玩家躲精英 → 成长更慢 → BOSS 成数值墙。
3. **解法（用户拍板方向）**：
   - **精英给武器，且武器元素与精英元素绑定**——BOSS 给遗物、精英给武器、普通给消耗/金币，三者身份分层，不撞车。
   - **正面压平难度曲线**：`ante_room_step_hp` 从 1.15 下调（约 1.07），不靠增加事件/休整来稀释战斗（违背"战斗即成长"取向）。
   - 游离的 3 个遗物**先不动**。

## 2. 现状核实（代码事实 + 实测）

### 2.1 难度曲线：指数 vs 线性（问题 1 根因）

实测探针（ACT1 分岔图，2026-11-18）：

| 项 | 数值 |
|---|---|
| ACT1 战斗房数量 | **19 场**（41 节点中 19 个战斗） |
| 第 1 场敌人 HP | ×1.00 |
| 第 10 场敌人 HP / ATK | ×3.52 / ×1.69 |
| 第 19 场（BOSS）敌人 HP / ATK | **×12.38 / ×2.85** |

来源：`run_setup.gd:97-98` 的 `ante_scale`：
```
hp_scale  = pow(ante_act_step_hp, a-1) * pow(ante_room_step_hp, ria)
atk_scale = pow(ante_act_step_atk, a-1) * pow(ante_room_step_atk, ria)
```
`ria` = 同幕内战斗房序号。配置（`balance_config.tres`）：
- `ante_room_step_hp = 1.15`（复利 18 次 → ×12.4）
- `ante_room_step_atk = 1.06`（复利 18 次 → ×2.85）

玩家侧成长（`_settle_victory` + `_award_victory`）：
- 历练经验：普通 +1 / 精英 +2 / BOSS +3；升级只给 **+5 HP**，Lv.2/4/6 给技艺（多为被动小数值）
- 武器熟练：每房 +1~3，R2/R3 给铭印（小乘区），R4 仅外观
- 铁砧点 / 金币 / 掉落
- **无乘法型成长**；而真正的 Build 组件（新武器/护符）主来源偏向**商店 / armory / 事件**（非战斗）

**结论**：敌人 HP 一幕涨 12 倍，玩家靠线性积累追赶 → 强度墙。

### 2.2 精英激励缺位（问题 2 根因）

- 精英三选一（`roll_elite_rewards`）：金币 / 铁砧 + 从 weapon/consumable/maxhp_heal 里抽 1 个 bonus——与普通房三选一差别有限
- 精英额外掉落：保底 1 护符（`_drop_elite_charm`），但护符普通途径也能拿，稀缺性不足
- 精英房**有明确元素字段**（`RoomData.element`）：寒铁精英=ice、毒疫术士=poison、炎爆群王=fire、深渊咒师=dark、圣盾守关=light…
- 每个元素有 **15 把武器**，池子充足

**结论**：精英风险高但回报≈普通，理性玩家躲精英。且地图节点自带元素信息，可做"元素绑定武器"的路线决策。

## 3. 经典最佳实践对照

| 原则 | 经典做法（杀戮尖塔 / 哈迪斯 / Balatro） | 本项目落地 |
|---|---|---|
| 节点类型 → 奖励身份分层 | 普通=卡、精英=遗物、BOSS=大遗物 | **BOSS=遗物、精英=武器、普通=消耗/金币** |
| 精英提供独占稀缺资源 | 精英固定给普通拿不到的遗物 | 精英给**绑定元素的武器**（品质应高于普通途径） |
| 敌人曲线温和可预期 | 一幕约 6-8 场战斗，复利可控 | 保留 19 场（用户取向），但**压低复利系数** |
| 玩家靠 Build 滚雪球 | 卡牌/遗物组合产生乘区 | 元素武器 → 元素符号/护符 → 构筑联动 |

## 4. 推荐方案

### 4.1 精英给元素绑定武器（用户拍板）

- 精英房胜利 → 三选一里**固定包含 1 把与其 `element` 相同的武器**（可再加金币/铁砧等辅助项）
- 武器池按 `element` 过滤未持有者（每个元素 15 把，充足）
- 品质建议保底 uncommon+（避免"和普通没区别"）
- 实现落点：`reward_system.roll_elite_rewards()` 读取当前房间的 `element`，从对应元素武器池抽 1 把注入候选

**收益**：
- 精英身份独立（不撞 BOSS 遗物）
- 地图选路变成"选哪个元素的精英" → 玩家为凑 Build 主动打精英（解决问题 2）
- 武器是 Build 核心组件 → 战斗直接产出成长（符合用户取向）

### 4.2 压平难度曲线（问题 1）

- `ante_room_step_hp: 1.15 → ~1.07`（19 场复利 ×12.4 → ×3.6）
- `ante_room_step_atk: 1.06 → ~1.03`（×2.85 → ×1.7）
- 配合每场战斗的元素武器 + 熟练成长，玩家线性+小乘区即可跟上
- **不动战斗房数量**（19 场保留，符合"战斗即成长"）
- 数值调整后必须重跑 6 种子标定（`strategy_probe`），验证通关率与回合数分布不破坏 player_dmg_mult=1.0 平衡

### 4.3 不做的事

- 不下调核爆
- 不把成长主路径转向事件/商店/休整
- 不处理 3 个游离遗物（本次）

---

## 5. 实施顺序（待用户批准后执行）

1. **Step 1**：`roll_elite_rewards()` 注入元素绑定武器（精英）。验证精英三选一必含对应元素武器。
2. **Step 2**：`balance_config.tres` 压低 ante 复利系数；跑 6 种子标定。
3. **Step 3**：真机 F6 验证——精英武器是否让"打精英"变有吸引力、BOSS 前强度是否够。

---

## 6. 一句话总结

**BOSS 给遗物、精英给绑定元素的武器、普通给消耗/金币——让战斗本身成为 Build 成长的主来源；同时压平敌人复利曲线，让"打战斗变强"跑得赢"敌人变强"。核爆不动，游离遗物不动。**
