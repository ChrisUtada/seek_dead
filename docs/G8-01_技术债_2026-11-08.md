## 2. 具体改动

### 2.1 `combat_system.evaluate()` 四阶段

原单函数按阶段拆分，`evaluate()` 只做编排：

- `_phase_symbols(acc)`：符号计数、元素三连判定、增益/金币、逐符号贡献、匹配角标；
- `_phase_defense(acc)`：护盾/治疗/状态落地与 0.25s 间隔；
- `_phase_counter(counts, acc)`：三连钩子、破甲/核爆；
- `_phase_attack(counts, acc)`：伤害汇总、分解日志、扣血、充能爆发、回合收口与 0.35s 间隔。

执行顺序、RNG 调用（`randf`/`randi`）与 `await` 时序与拆分前逐行一致；
`_new_acc()` / `_reset_turn_state()` 仅做原初始化搬移。

### 2.2 `_build_pool` 物品段与纯函数

`reel_system.build_pool()` 拆为：

- `_reset_pool_state()`、`_apply_weapon_strength()`、`_apply_skill_strength()`；
- `_collect_weapon_items()`、`_collect_skill_items()`、`_collect_essence_items()`；
- 纯函数：`make_pool_item()`、`weapon_syms()`、`skill_pool_item()`、`essence_pool_item()`、`flatten_pool()`。

装配顺序、条目格式（name/hit/syms/rarity）与扁平池顺序保持不变；真实带子差异测试（G6-05）未改。

### 2.3 tooltip 与飘字池

- 新增 `scripts/ui/symbol_tooltip.gd`：面板外观、两行文本、按格子定位并夹紧 HUD 边界；
  HUD 只传文本与两个矩形。
- 新增 `scripts/ui/popup_pool.gd`：满屏忽略鼠标的浮层 + 16 个 Label 池、上浮淡出与归还。
- `battle_hud.gd` 保留 `_popup()` 与 `symbol_tooltip` 字段作为兼容入口，外部调用点不变。

### 2.4 退役 `screen.gd`

`battle_hud._build_overlay()` 的「背景 + CenterContainer + 居中 VBox」就地内联，
删除 `scripts/ui/screen.gd` 与 `.uid`；布局与原先一致。
