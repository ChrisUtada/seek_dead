# 武器-装备统一方案

## 一、当前问题

武器系统与装备系统处于割裂状态：

- `WeaponBase` / `MeleeWeapon` / `RangedWeapon` 是独立于 `EquipmentBase` 的 Resource 体系
- `WeaponComponent` 扫描子节点发现武器，与 `EquipmentManager` 零交互
- `EquipmentDrop` 生成武器槽装备时只给名字字符串，无战斗数据
- 武器没有独立身份，只是"一个叫武器的装备槽贴了几个通用词缀"

## 二、统一思路

将所有"物品"统一到 `EquipmentBase` 这一个 Resource。武器的战斗数据作为 `EquipmentBase` 的**内嵌子资源**（`WeaponData`）存在，仅 WEAPON 槽有值，非武器槽保持 null。

```
EquipmentBase (Resource)
├── equipment_name
├── slot (WEAPON / HELMET / BODY / ...)
├── rarity
├── affixes[]
├── set_id, icon, level
└── weapon_data: WeaponData    ← 仅 WEAPON 槽有值
      ├── archetype (LIGHT / MEDIUM / HEAVY / MAGIC)
      ├── 隐式修正（由 archetype 决定，复用 StatModifier）
      ├── 通用战斗属性（damage / attack_speed / attack_range）
      ├── 近战专属（cleave_angle / knockback_force）
      └── 远程专属（bullet_speed / max_ammo / bullet_scene）
```

## 四、Archetype 与隐式修正

每种 archetype 自带隐式修正，不占词缀槽，不计入词缀容量。

| Archetype | 隐式修正 | 设计意图 |
|-----------|---------|---------|
| LIGHT | +10% 攻速，-20% 基础伤害 | 高频触发流 |
| MEDIUM | 无修正 | 平衡型 |
| HEAVY | +20% 基础伤害，-10% 攻速，+100 击退力 | 一击流 |
| MAGIC | +15% 攻击伤害，-10% 攻速 | 法术协同流 |

### 关键设计：复用 StatModifier 走现有管线

隐式修正**不用字典**，直接返回 `StatModifier` 数组，复用 `EquipmentManager._apply_modifier()` 现有管线，避免维护第二套属性映射：

```gdscript
# WeaponData 内的静态方法
static func get_implicit_modifiers(archetype: Archetype) -> Array[StatModifier]:
    var result: Array[StatModifier] = []
    match archetype:
        Archetype.LIGHT:
            result.append(_mod(StatTarget.ATTACK_SPEED, ModifierType.MUL, 0.10))
            result.append(_mod(StatTarget.ATTACK_DAMAGE, ModifierType.MUL, -0.20))
        Archetype.HEAVY:
            result.append(_mod(StatTarget.ATTACK_DAMAGE, ModifierType.MUL, 0.20))
            result.append(_mod(StatTarget.ATTACK_SPEED, ModifierType.MUL, -0.10))
        Archetype.MAGIC:
            result.append(_mod(StatTarget.ATTACK_DAMAGE, ModifierType.MUL, 0.15))
            result.append(_mod(StatTarget.ATTACK_SPEED, ModifierType.MUL, -0.10))
    return result

static func _mod(target: int, type: int, value: float) -> StatModifier:
    var m = StatModifier.new()
    m.target_stat = target
    m.modifier_type = type
    m.value = value
    return m
```

### 隐式修正的生效方式

隐式修正**不经过 EquipmentManager 的词缀管线**（不写入 affixes），而是在 `WeaponNode._equip()` 时直接作用于 WeaponNode 自身的运行时属性：

```gdscript
# WeaponNode._equip() 中
func _equip(equip: EquipmentBase):
    equipment = equip
    weapon_data = equip.weapon_data.duplicate()  # 副本，避免修改原始资源
    _apply_archetype_modifiers()

func _apply_archetype_modifiers():
    var mods = WeaponData.get_implicit_modifiers(weapon_data.archetype)
    for m in mods:
        match m.target_stat:
            StatTarget.ATTACK_SPEED:
                weapon_data.attack_speed *= (1.0 + m.value)
            StatTarget.ATTACK_DAMAGE:
                weapon_data.damage *= (1.0 + m.value)
            # 其他武器属性...
```

这样做的好处：隐式修正只影响武器自身数值，不会泄漏到 StateComponent 的角色属性上。装备卸下时副本自动丢弃，无需清理。

### 关于 MAGIC 原型的说明

原设计中 MAGIC 有"+15% 技能范围"，但现有 `StatTarget` 枚举没有 SKILL_RANGE。两个选择：

- **方案 A**：在 `StatTarget` 新增 `SKILL_RANGE`，`EquipmentManager._target_to_string()` 新增对应分支。如果后续技能系统有 range 属性，自然对接。
- **方案 B**：MAGIC 改为"+15% 攻击伤害，-10% 攻速"（上表已采用），不涉及新枚举。

建议先用方案 B 快速推进，等技能系统成型后再按需新增 SKILL_RANGE。

## 五、武器模板：保留 .tres 格式

武器模板**保留 .tres 文件**，放在 `resources/weapon_templates/` 目录下。每个模板是一个 `WeaponData` Resource 实例。

理由：策划文档列了 8+ 种武器类型（单手剑、双手斧、双手锤、长枪、匕首、枪械、弓箭、法杖），后续还会增加。用 .tres 可以在 Godot 编辑器里直接调参数、实时预览，不需要改代码重启。

## 六、WeaponNode 统一

砍掉 `MeleeWeaponNode` / `RangedWeaponNode` 子类，合并为通用 `WeaponNode`。内部通过 `_attack_melee()` / `_attack_ranged()` 两个私有方法分离攻击逻辑，`attack()` 只做分发：

```gdscript
class_name WeaponNode
extends Node2D

signal hit_landed(hit_pos: Vector2, hit_dir: Vector2, damage_type: int, body: Node2D)
signal attack_finished(weapon_node: WeaponNode, hit_count: int)

enum WeaponState { IDLE, ACTIVE, COOLDOWN }

var equipment: EquipmentBase
var weapon_data: WeaponData

var shooter: Node2D = null
var aim_direction: Vector2 = Vector2.RIGHT
var weapon_color: Color = Color.WHITE
var attack_speed_modifier: float = 1.0

var _ws: WeaponState = WeaponState.IDLE
var _active_timer: float = 0.0
var _cooldown_timer: float = 0.0

# ── 近战运行时 ──
var _hitbox: Hitbox
var _hit_count: int = 0

# ── 远程运行时 ──
var _bullet_pool: Array = []


func _ready():
    # 不扫描不绑定，等待 WeaponComponent 通过 _equip() 注入
    pass


# ════════════════════════════════════════
#  装备注入
# ════════════════════════════════════════

func _equip(equip: EquipmentBase):
    equipment = equip
    weapon_data = equip.weapon_data.duplicate() as WeaponData
    _apply_archetype_modifiers()
    weapon_color = DamageSystem.get_color(weapon_data.damage_type)
    _init_for_weapon_type()
    visible = true

func _unequip():
    visible = false
    equipment = null
    weapon_data = null


func _init_for_weapon_type():
    if weapon_data.weapon_type == WeaponData.WeaponType.MELEE:
        _init_melee()
    else:
        _init_ranged()


func _init_melee():
    # 复用现有 Hitbox 节点（WeaponNode 场景内预置）
    _hitbox = $Hitbox
    _hitbox.set_deferred("monitoring", false)
    _hitbox.set_deferred("monitorable", false)
    _hitbox.lifespan = 0
    if not _hitbox.hit_landed.is_connected(_on_melee_hit):
        _hitbox.hit_landed.connect(_on_melee_hit)


func _init_ranged():
    # 远程不需要 hitbox，子弹通过对象池生成
    pass


# ════════════════════════════════════════
#  攻击分发
# ════════════════════════════════════════

func attack():
    if not can_attack():
        return
    _start_attack()
    if weapon_data.weapon_type == WeaponData.WeaponType.MELEE:
        _attack_melee()
    else:
        _attack_ranged()
    _end_active()


# ════════════════════════════════════════
#  近战攻击
# ════════════════════════════════════════

func _attack_melee():
    flash_range()
    swing()
    AudioManager.play_sfx(AudioManager.SfxType.PLAYER_MELEE)

    var cs = _hitbox.get_child(0) as CollisionShape2D
    if cs and cs.shape:
        var circle = cs.shape as CircleShape2D
        circle.radius = weapon_data.attack_range
    _hitbox.damage = weapon_data.damage
    _hitbox.damage_type = weapon_data.damage_type
    _hitbox.shooter = shooter
    _hitbox.knockback_force = weapon_data.knockback_force
    _hitbox.status_effect_type = weapon_data.status_effect_type
    _hitbox.status_effect_damage = weapon_data.status_effect_damage
    _hitbox.status_effect_duration = weapon_data.status_effect_duration
    _hitbox.reset()
    _hitbox.global_position = shooter.global_position
    _hitbox.monitoring = true
    _hitbox.monitorable = true
    # _end_active 后关闭 hitbox（在 _on_attack_timeout 或延迟帧中）


func _on_melee_hit(target: Node2D):
    _hit_count += 1
    hit_landed.emit(target.global_position, aim_direction, weapon_data.damage_type, target)


# ════════════════════════════════════════
#  远程攻击
# ════════════════════════════════════════

func _attack_ranged():
    AudioManager.play_sfx(AudioManager.SfxType.PLAYER_SHOT)

    var ammo_node = shooter.get_node_or_null("AmmoSystem")
    if weapon_data.max_ammo > 0 and ammo_node and not ammo_node.consume_ammo():
        return

    flash_range()

    var parent = shooter.get_parent()
    var pool = GameManager.get_bullet_pool()
    var scene = weapon_data.bullet_scene if weapon_data.bullet_scene else preload("res://scenes/battle/projectile.tscn")
    var bullet
    if pool:
        bullet = pool.acquire(parent)
        bullet.set_pool(pool)
    else:
        bullet = scene.instantiate()
        parent.add_child(bullet)

    bullet.global_position = shooter.global_position
    bullet.direction = aim_direction
    bullet.data = weapon_data.bullet_data
    bullet.damage = weapon_data.damage
    bullet.damage_type = weapon_data.damage_type
    bullet.shooter = shooter
    bullet.status_effect_type = weapon_data.status_effect_type
    bullet.status_effect_damage = weapon_data.status_effect_damage
    bullet.status_effect_duration = weapon_data.status_effect_duration

    var sprite = bullet.get_node_or_null("Sprite2D")
    if sprite:
        var color = DamageSystem.get_color(weapon_data.damage_type)
        sprite.texture = DamageSystem.get_circle_texture(10, color)
        sprite.centered = true

    if not bullet.hit.is_connected(_on_ranged_hit):
        bullet.hit.connect(_on_ranged_hit)
    attack_finished.emit(self, 1)


func _on_ranged_hit(hit_pos: Vector2, hit_dir: Vector2, hit_damage_type: int, body: Node2D):
    hit_landed.emit(hit_pos, hit_dir, hit_damage_type, body)


# ════════════════════════════════════════
#  共用逻辑（状态机、视觉、冷却）
# ════════════════════════════════════════

func can_attack() -> bool:
    return _ws == WeaponState.IDLE and weapon_data != null

func get_cooldown_time() -> float:
    return 1.0 / (weapon_data.attack_speed * attack_speed_modifier) if weapon_data else 1.0

func _start_attack():
    _ws = WeaponState.ACTIVE
    _active_timer = 0.15
    _cooldown_timer = get_cooldown_time()
    _hit_count = 0

func _end_active():
    _ws = WeaponState.COOLDOWN
    if _hitbox:
        _hitbox.monitoring = false
        _hitbox.monitorable = false
    attack_finished.emit(self, _hit_count)

# _process / _draw / swing / flash_range 等视觉逻辑保持现有实现，
# 仅将 stats.xxx 替换为 weapon_data.xxx
```

### 方法拆分原则

| 方法 | 职责 | 行数控制 |
|------|------|---------|
| `attack()` | 纯分发：检查 → 开始 → 按类型调用 → 结束 | < 10 行 |
| `_attack_melee()` | Hitbox 配置 + 碰撞开启 | ~20 行 |
| `_attack_ranged()` | 子弹生成 + 属性设置 | ~30 行 |
| `_init_melee()` / `_init_ranged()` | 运行时组件初始化 | 各 ~10 行 |
| `_process()` / `_draw()` | 视觉更新，共用逻辑 | 保持现有 |

近战和远程的攻击逻辑完全隔离，互不干扰。后续加新武器类型（比如"投掷类"）只需加一个 `_attack_thrown()` 方法，不影响现有代码。

## 七、WeaponComponent 改动

```gdscript
class_name WeaponComponent
extends Node2D

signal weapon_changed(weapon: WeaponNode)
signal attack_performed(weapon: WeaponNode, hit_count: int)

var weapons: Array[WeaponNode] = []
var weapon_index: int = 0
var current_weapon: WeaponNode:
    get: return weapons[weapon_index] if weapons.size() > 0 else null

var aim_direction: Vector2 = Vector2.RIGHT

# 保留粒子池、相机震动等辅助逻辑（不变）
var _particles_pool: Array[ColorRect] = []


func _ready():
    # 扫描子节点，收集所有 WeaponNode（不再检查 stats 属性）
    for child in get_children():
        if child is WeaponNode:
            child.shooter = get_parent() as CharacterBody2D
            child.aim_direction = aim_direction
            child.visible = false
            child.hit_landed.connect(_on_weapon_hit)
            child.attack_finished.connect(_on_attack_finished)
            weapons.append(child)


# ── 新增：由 EquipmentManager 调用 ──

func equip_weapon(equip: EquipmentBase):
    if equip.slot != EquipmentEnums.EquipmentSlot.WEAPON or equip.weapon_data == null:
        return
    # 找到第一个可用的 WeaponNode（统一后只有一个通用节点）
    var node = weapons[0] if weapons.size() > 0 else null
    if node == null:
        return
    node._equip(equip)
    weapon_index = 0
    weapon_changed.emit(node)


func unequip_weapon():
    var node = current_weapon
    if node:
        node._unequip()


# attack / switch_weapon / _on_weapon_hit / _on_attack_finished 等
# 逻辑保持不变，仅将 node.stats.xxx 替换为 node.weapon_data.xxx
```

## 八、EquipmentManager 改动

```gdscript
func equip(item: EquipmentBase):
    var slot = item.slot
    unequip(slot)
    _equipped[slot] = item
    _apply_item(item)

    # ── 新增：武器槽特殊处理 ──
    if slot == EquipmentEnums.EquipmentSlot.WEAPON and item.weapon_data:
        var player = get_parent()
        var wc = player.get_node_or_null("WeaponComponent") as WeaponComponent
        if wc:
            wc.equip_weapon(item)

    EventManager.equipment_changed.emit(slot, item)
    equipment_equipped.emit(slot, item)
    if _set_manager:
        _set_manager.check_all()


func unequip(slot: int):
    var old = _equipped.get(slot) as EquipmentBase
    if not old:
        return

    # ── 新增：武器卸下 ──
    if slot == EquipmentEnums.EquipmentSlot.WEAPON:
        var player = get_parent()
        var wc = player.get_node_or_null("WeaponComponent") as WeaponComponent
        if wc:
            wc.unequip_weapon()

    _remove_item(old)
    _equipped.erase(slot)
    EventManager.equipment_changed.emit(slot, null)
    equipment_unequipped.emit(slot)
    if _set_manager:
        _set_manager.check_all()
```

## 十一、数据流全景

```
房间清空
  │
  ▼
EquipmentDrop.generate_drop()
  │  随机槽位 + 品质 + 词缀
  │  WEAPON 槽 → 从模板池 .tres 选一个 → duplicate() → 品质倍率 → 内嵌进 EquipmentBase
  │
  ▼
EquipmentPickup（地面拾取）→ EquipmentInventory（背包）
  │
  ▼
玩家装备 → EquipmentManager.equip(item)
  │
  ├─ 非武器槽 → _apply_item() → StatModifier → StateComponent
  │
  └─ WEAPON 槽 → _apply_item()（词缀部分）
                  + wc.equip_weapon(item)（武器部分）
                    │
                    ▼
              WeaponNode._equip(equip)
              → duplicate weapon_data（副本，不污染原始资源）
              → _apply_archetype_modifiers()（隐式修正作用于副本）
              → _init_for_weapon_type()（初始化近战/远程运行时）
                    │
                    ▼
              攻击 → attack() → _attack_melee() 或 _attack_ranged()
                    │
                    ▼
              命中 → hit_landed 信号 → WeaponComponent 粒子/震屏
                                       → EquipmentManager 词缀触发判定
```

所有物品从掉落到装备到战斗走同一条管线。

## 十三、兼容性注意事项

**存档兼容：** 如果 SaveSystem 已保存了 EquipmentBase 数据，旧存档中 `weapon_data` 为 null。加载时检查：如果 `slot == WEAPON && weapon_data == null`，从模板池匹配 `equipment_name` 补一个默认 WeaponData。

**visual_scene 处理：** `visual_scene` 保留在 WeaponData 中。当前 WeaponNode 的 `_draw()` 是纯代码绘制（弧线、拖尾），不依赖 visual_scene。如果后续需要加载武器精灵图，在 `_init_for_weapon_type()` 中根据 `weapon_data.visual_scene` 动态实例化 Sprite2D 子节点即可。

**SetDatabase 不覆盖 WEAPON 槽：** 现有 6 个套装的 slots 数组只包含 HELMET/BODY/HAND/LEG/ACCESSORY，不会分配到武器槽。无需额外处理。
