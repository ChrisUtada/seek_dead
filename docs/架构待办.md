# 架构待办

## 1. 武器硬耦合到 Player 场景

**问题：** `WeaponComponent._ready()` 遍历子节点收集武器，换武器必须手动改 Player `.tscn`。无全局武器库/掉落系统。

**目标：** 引入武器数据库 + 掉落/拾取机制，武器不再硬编码为场景子节点。

---

## 2. 子弹对象池未接通

**问题：** `projectile.gd` 有 `_pool` 字段和 `_return_to_pool()`，但从未被赋值。每次射击 `instantiate` + `queue_free`，高频射击时 GC 压力大。

**目标：** `RangedWeaponNode` 发射时从 `ObjectPool` 借弹，命中/超时归还。

---

## 3. Boss 配置数据流混乱

**问题：** `boss_enemy.gd` 同时存在 `_apply_boss_config()`（硬编码数值）和 `apply_config(config: EnemyConfig)`（数据驱动），两套入口互打架。

**目标：** 统一走 `BossConfig` Resource，删除 `_apply_boss_config()` 硬编码分支。

---

## 4. 技能硬编码

**问题：** `player_controller.gd:63-64` 写死注册 `HealSkill` + `ShockwaveSkill`，换角色不能换技能列表。

**目标：** 技能列表由 `PlayerConfig` 定义，`@export var skills: Array[SkillBase]`，角色 `.tres` 配置自带技能组。

---

## 5. `visual_scene` 字段冗余

**问题：** `WeaponBase` 有 `@export var visual_scene: PackedScene`，但所有武器 `.tres` 里都指向自身 `.tscn`，字段已失效。

**目标：** 从 `WeaponBase` 中删除 `visual_scene`。

---

## 6. RoomManager 硬编码 fallback

**问题：** `room_manager.gd:44-47` 硬编码 `room_1.tres` / `room_2.tres` 路径作为 `DirAccess` 失败的兜底。新增房间时需同步更新此列表。

**目标：** 删除 fallback，确保 `DirAccess` 路径在生产构建中也能正常工作，或替换为可维护的注册机制。
