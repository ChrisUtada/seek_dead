# 成长 Build 可选内容清单

> 数据来源：项目代码实查（非估算）。核心文件：
> `scripts/systems/growth_system.gd`、`weapon_mastery.gd`、`weapon_slot_growth.gd`、
> `growth_loot_offer.gd`、`career_system.gd`、`anvil_system.gd`、`reward_system.gd`。
> 整理日期：2026-11-17。

---

## 0. 总览：成长分散在几套系统里

本项目的"成长"不是单一系统，而是按**局内 / 局外**分成多套。真正构成 build（主动选择、影响本局强度）的是前三套：

| 层级 | 系统 | 性质 | 选择时机 |
|---|---|---|---|
| 局内构筑 | A. 历练技艺 | 三选一 | Lv.2 / Lv.4 / Lv.6 |
| 局内构筑 | B. 武器熟练 / 铭印 | 二选一 | 熟练 R2 / R3 |
| 局内构筑 | C. 武器槽成长 | 通用数值 | 每件装备槽最多 2 次 |
| 其他渠道 | D. 战后战利品成长项 | 战利品三选一里的成长卡 | 房间胜利 |
| 其他渠道 | E. 幕间锻魂 | 自动发放 | 进入 ACT2 / ACT3 |
| 局外成长 | F. 铁砧 | 抽装备 / 永久收集 | 盘外 |
| 局外成长 | G. 生涯 | 成就解锁装备 | 盘外 |

## 一、局内构筑（真正的 build 选择）

### A. 历练技艺（GrowthSystem）

- **升级途径**：房间胜利发经验 = 普通 1 / 精英 2 / BOSS 3。
- **等级门槛**（累计经验）：Lv.2=3、Lv.3=7、Lv.4=12、Lv.5=20、Lv.6=30，满级 Lv.6。
- **每级收益**：最大 HP +5，并立即恢复 5 HP。
- **技艺选择**：升到 Lv.2 / Lv.4 / Lv.6 时各获得一次三选一。
- **候选规则**：按家族打乱后各取一项未拥有技艺，保证三选一覆盖不同家族；池不足时从剩余技艺补齐。展示即定完整效果，选择后不再随机。

技艺池共 **8 项，分 3 个家族**（每次三选一从不同家族各抽一个）：

| 家族（打法方向）  | 技艺   | 效果                               |
| --------- | ---- | -------------------------------- |
| 生存 · 更耐打  | 坚韧   | 最大 HP +10，立即恢复 10 HP             |
| 生存        | 守势   | 每房开局获得 8 护盾                      |
| 生存        | 回春   | 每次房间胜利恢复 4 HP（BOSS 房 8 HP）       |
| 运筹 · 更多资源 | 备用药剂 | 获得时，腰带上所有消耗品各 +1 次使用次数           |
| 运筹        | 积蓄   | 每次房间胜利获得 2 金（BOSS 房 5 金）         |
| 目押 · 更易停中 | 稳定节奏 | 每房前 2 回合转轮基础间隔 0.15→0.17s，加速曲线不变 |
| 目押        | 洞察   | 旋转时，每列显示下一格符号                    |
| 目押        | 稳手   | 每回合首次按停可多缓冲一拍，等视觉中心到下一格          |

**兼容项（不在随机池）**：精打细算（frugal）= 每个房间间歇首次商店刷新免费。仅为旧存档兼容保留，不再进入随机候选。

**技艺落点说明**：多数技艺（守势 / 稳定节奏 / 洞察 / 稳手）是在各自落点读取查询接口生效；只有坚韧、备用药剂、回春、积蓄在选择或结算时即时生效。

---

### B. 武器熟练 / 铭印（WeaponMastery）

- **熟练来源**：武器出战累计，每把每房熟练上限 +3；换装后有追赶补偿（每房 +1 基础熟练）。
- **R 等级门槛**（累计熟练）：R2=3、R3=7、R4=12（满级）。
- **铭印选择**：升到 R2、R3 时各欠一次铭印选择；同一铭印每把武器最多 2 次。
- **候选规则**：给哪两种铭印**由武器原型决定**（见下表），且只保留当前仍有效的项——校准在命中 >95% 时不出现，调律只在真实改变格数时出现，避免死升级。

铭印共 **4 种**：

| 铭印 | 效果 | 每次增量 |
|---|---|---|
| 锋铸 forge | 基础攻击提升 | +2 攻 / 次 |
| 调律 tune | 主符号权重 +1（转轮多一格） | 权重 +1 / 次 |
| 校准 calibrate | 命中率提升（上限 100%，>95% 不提供） | +5% / 次 |
| 暴虐 tyrant | 三连暴击倍率提升 | +0.25 / 次 |

**原型 → 可用铭印组合**（键为 `WeaponData.Archetype` 整数值）：

| 原型 | 可用铭印 |
|---|---|
| 0 = LIGHT 轻武器 | 调律 / 校准 |
| 1 = MEDIUM 中武器 | 锋铸 / 调律 |
| 2 = HEAVY 重武器 | 锋铸 / 暴虐 |
| 3 = MAGIC 法器 | 调律 / 锋铸 |

> 注：状态型武器可把主符号调律替换为主符号调律（按状态符号实现）。

---

### C. 武器槽成长（WeaponSlotGrowth）

- **槽位数**：2 个装备槽。
- **预算**：每槽最多 2 次通用数值铭印，同一种最多 2 次。
- **只有 3 种纯数值**（无调律，调律归 WeaponMastery 管）：

| 铭印 | 效果 | 每次增量 |
|---|---|---|
| 锋铸 forge | 基础攻击提升 | +2 / 次 |
| 校准 calibrate | 命中率提升 | +0.05（5%）/ 次 |
| 暴虐 tyrant | 三连暴击倍率提升 | +0.25 / 次 |

> ⚠️ B 与 C 是两套并存的铭印系统：名称相同（锋铸 / 校准 / 暴虐），但 **B 按武器原型给、带调律、靠熟练 R 等级触发**；**C 是槽位通用数值、无调律、按槽预算分配**。梳理或合并 build 时需注意区分。

## 二、其他成长渠道（非主动 build 选择）

### D. 战后战利品成长项（growth_loot_offer）

房间胜利后的战利品三选一里，成长类选项的候选池（品质决定数值）：

| 类别 | 内容 | 数值 |
|---|---|---|
| 武器训练 | 提升当前已装备武器熟练（R4 满级后不再出现） | 按品质（`loot_duplicate_mastery`），默认 1 |
| 符号灌注 | 提升现有符号权重，转轮格数变化（本局生效） | 按 `symbol` 奖励的 value |
| 技艺 | 授予一项未拥有技艺 | 同 A 的 8 项池 |
| 坚韧 | 最大 HP 增加并恢复等量生命 | 按品质：普通 5 / 精良 8 / 稀有 12 / 史诗 16 |
| 守望 | 进入下一场战斗时获得护盾 | 按品质：普通 8 / 精良 12 / 稀有 18 / 史诗 25 |
| 休整 | 恢复当前最大 HP 的 35%（不超过上限） | 仅当前未满血时出现 |

### E. 幕间锻魂（GrowthSystem.grant_act_boon）

- **触发**：换幕成功、进入 ACT2 / ACT3 时自动发放各一次（ACT I 不发放，单幕局不触发）。
- **收益**：本局符号伤害 +8、最大 HP +20 并回血。
- **性质**：复用"攻击研磨"同一本局加成层，不新增状态字段，不改敌人 / ante / 存档。

### F. 铁砧（AnvilSystem，局外）

- 花铁砧点数摇动铁砧抽取装备（武器 / 技能 / 护符 / 消耗品），永久收集。
- 重复获取返还点数；收集进度有里程碑。
- 铁砧点数来源：战后 drip、BOSS 奖励、生涯解锁等。

### G. 生涯（CareerSystem，局外）

10 个成就，解锁新装备进入抽取池：

| 成就 | 达成条件 |
|---|---|
| 初次深入 | 首次击败任意 ACT1 BOSS |
| 四席猎手 | 累计击败 4 个不同 ACT1 BOSS |
| 同系共振 | 用两把同元素武器击败 BOSS |
| 异系调度 | 用两把不同元素武器击败 BOSS |
| 破甲专家 | 在 BOSS 战触发破甲并获胜 |
| 状态使徒 | BOSS 战状态伤害 ≥ 25 并获胜 |
| 坚守 | 击败 BOSS 时本局累计格挡 ≥ 40 |
| 棋盘寻宝 | 在棋盘武器格获得一把武器 |
| 高危路线 | 经过精英分支并击败 BOSS |
| 特殊结局 | 以非暴力和解击败 BOSS |
